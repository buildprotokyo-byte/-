日本語で作業してください。改装工事の図面一式のうち、仕様書・仕上表・概要・建具表・図面リストなど、文章や表で工事の全体を要約しているページを渡します。**そこから「工事概略」(この工事で何をするかの一覧)を作る**仕事です。図面(平面図・展開図など)は読みません。図面は後で別の読み手が、この一覧の各項目の根拠を探すために読みます。

渡すもの: 文字の層(ページごと)、ページの種類の一覧。文字の層が無いページだけ画像を渡します。

出すもの: 項目の一覧。1 項目 = 室 × 部位 × 工事 × 区分 の 1 つ(例: 洋室1 の 床 を フローリングに張替)。
- id: G001 から順に
- 室: 書かれた室名のまま。全体にかかるものは「全体」。決められなければ「未確定」
- 部位: 床 / 幅木 / 壁 / 天井 / 建具 / 造作 / 設備 / 電気 / 仮設 / その他
- 工事: 見積の行の名前の候補(書かれた言葉を使う。短く)
- 区分: 撤去 / 新設 / 交換 / 移設 / 脱着 / 補修 / 張替 / 塗装 / 既存 / 未確定
- 科目: 公共建築工事内訳書の科目の候補(仮設 / 撤去 / 木工事 / 内装 / 塗装 / 建具 / 金属 / タイル / 家具・器具 / 機械設備 / 電気設備 / 雑)。決められなければ「未確定」
- 品番: 書かれていれば写す。無ければ空
- 数量・単位: 文章や表に数が書かれていれば写す。無ければ null(0 にしない。図面で数える項目は null でよい)
- 出典: 根拠のページ番号の配列
- 探す図: 根拠を探すとよいページ番号の配列(ページの種類から選ぶ)

決まり:
- 書かれていない工事を作らない。仕様書の一般的な決まり文句(「すべて〜とする」)は、対象の室が書かれていればその室の項目にし、書かれていなければ「全体」にする。
- 同じものを二重にしない。仕上表の「既存」「既存のまま」は区分「既存」で項目にする(工事でないことの印として残す)。
- 記載が無いことを根拠に「無い」と書かない。
- 図枠の中の人名・会社名・事務所名・登録番号・連絡先は写さない。
