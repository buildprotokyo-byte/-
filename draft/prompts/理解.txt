日本語で作業してください。改装工事の図面の {page} ページについて、別の読み手が書き出した「要素」(位置つき)があります。**その要素が何を表し、どの室・部位のものかを根拠付きで決め、工事・材料・作業の「項目」にまとめる**仕事です。

渡すもの: このページの画像、このページの要素(データ「要素」)、ページの種類の一覧(データ「ページの種類」)、凡例のページの画像(あれば)。

やること:
- 要素をまとめて「項目」を作る。項目は、見積の行の候補になるもの 1 つ(例: ある室の床の張替え、ある器具をある室で交換、ある範囲の撤去)。
- 記号の器具は、同じ室・同じ種類・同じ区分ごとに 1 項目にし、数えた記号の要素を全部「要素」に挙げ、数量はその数にする(式に「記号 n 個を数えた」)。
- 室名・寸法・注記は、ほかの項目の場所や数量の根拠として「要素」に挙げてよい。それだけでは項目にしなくてよい。
- 決められない要素は「決められなかった要素」に理由つきで残す(捨てない)。

項目の欄:
- 要素: 根拠にした要素の id(1 つ以上。このページの id だけ)
- 読み取った値: 根拠の要素に書かれていたまま(写す)
- 何: それが何を表すか(1 行)
- 部位: 床 / 幅木 / 壁 / 天井 / 建具 / 造作 / 設備 / 電気 / 仮設 / その他
- 場所: 図面に書かれた室名のまま。決められなければ「未確定」
- 区分: 撤去 / 新設 / 交換 / 移設 / 脱着 / 補修 / 張替 / 塗装 / 既存 / 未確定(図面の言葉に合わせる)
- 工事: 見積の行の名前の候補(図面の言葉を使う)
- 科目: 公共建築工事内訳書の科目の名前の候補(例: 仮設 / 木工事 / 内装 / 塗装 / 建具 / 金属 / 電気設備 / 機械設備 / 撤去)。決められなければ「未確定」
- 品番: 刷られていれば写す。無ければ空の文字
- 数量: 刷られた数・記号を数えた数・寸法から計算した数だけ。分からなければ null(0 にしない)
- 単位、式(計算したときは式。刷られた数を写したときは空)
- 状態: 観測(図面に書かれていることそのもの)/ 推論(書かれていることから、出典を示して推し量った)/ 仮説(根拠の要素が 2 つ以上あるが確かめられない)/ 問い(決められないので人に聞く)
- 確度: 高 / 中 / 低
- 根拠の種類: 図面から読んだ / 凡例から / 公開基準から推論 / 仮に置いた
- 理由: 推論・仮説・仮に置いたときは、出典付きの理由(どのページの何を見たか、どの公開基準か)
- 選択肢: 状態が「問い」のときだけ、2〜4 個。図面を 1〜2 か所見れば選べる言葉にする。数字の入力を求めない。推奨を付けない。記載が無いことを根拠に「無い」を選ばせる形にしない。

決まり:
- 数を作らない。分からない数量は null。読めなかったものを 0 にしない。
- 仮説は根拠の要素が 2 つ以上あるときだけ。1 つしか無ければ「問い」か「推論(確度 低)」にする。
- 図面に記載が無いことを根拠に「無い」と書かない。少しずれたもの(迷うもの)も捨てず、理由に迷った点を書く。
- 同じものを二重に項目にしない。
- 画像処理で記号や線を自動で探さない(cv2 などを使わない。PIL の切り抜きと拡大だけ)。要素 1 つずつ、自分の目で確かめる。
- 図枠の中の人名・会社名・事務所名・登録番号・連絡先は写さない。
