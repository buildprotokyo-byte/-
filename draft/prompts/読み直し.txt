日本語で作業してください。改装工事の図面の {page} ページ(1 ページだけ)に、何が書いてあるかを全部認識して書き出す仕事です。意味づけ(工事かどうか、数量の組み立て)はしません。**書いてあるものを、書いてあるとおりに、位置と一緒に挙げる**ことだけをします。

読み方: 縮小画像でざっと通し、要素の多いところは切り抜いて拡大して読む。

出すもの:
- 描かれているもの: そのページが何の図・表か(1行)
- 要素: 読み取った文字・数字・記号・線・表・図・写真を1つずつ。
  - 種類: 文字 / 数字 / 記号 / 線 / 表 / 図 / 写真
  - 内容: 文字と数字は刷られたとおりに写す(全角半角・記号もそのまま)。記号は形を言葉で書き(例「円の中に×」「黒い三角」)、同じページの凡例に名前が刷られていればそれも書く。線は色・線種・太さ・何を囲む/結ぶか。表は見出しの行と行数・列数、升目の中身は分かる範囲で。
  - 位置: [x0, y0, x1, y1](幅 2000 画素の画像の座標)。**位置は、その要素だけをぴったり囲む四角にする。線は 1 本ずつ(壁なら 1 辺ずつ)別の要素にし、部屋や図の全体を囲む位置を書かない。**
  - 確かさ: 読めた / 一部読めた / 推し量り
- 分からなかったもの: 位置と理由(小さすぎる・かすれ・重なり・文字の層と画像が食い違う など)

決まり:
- 記号は1つずつ別の要素にする。「約40」「多数」のようにまとめない。同じ形の記号が並んでいても、1つずつ位置を書く。
- 記号の要素には、凡例のどの記号に当たるか(凡例に刷られた名前をそのまま)と色(赤・黒・灰など)を「内容」に書く。凡例に無い形なら「凡例に無い」と書く。
- 線の要素(実線・破線・点線・一点鎖線・斜線や網の塗り)には、色と線種を書き、凡例または近くの注記でそれが何を示すか(範囲・撤去・新設など、図面に書かれた言葉のまま)を「内容」に書く。示すものが図面に書かれていなければ「示すもの不明」と書く。
- **自分で書いた四角を、画像処理で墨に合わせて縮めない。**四角は自分の目で見て書く。
- **線を画像処理で拾わせて、1 本ずつ見ないまま要素にしない。**cv2 などの画像処理は使わない(PIL の切り抜きと拡大だけ)。
- 書かれていないものを作らない。読めない字は「?」にして、分からなかったものに書く。
- 同じ文字が画像と文字の層の両方にあれば1つの要素にする。文字の層にあって画像で見当たらない、または画像にあって文字の層に無いものは、その旨を書く。
- 図面に記載が無いことを根拠に「無い」と書かない。
- 少し形や色がずれていても捨てず、似たものとして拾い、どこが似ているかを書く。
- 図枠の中の人名・会社名・事務所名・登録番号・連絡先は、見えても写さない(「図枠の名前の欄」とだけ書く)。
- {page} ページの項目だけを入れる。量が多いので Python で JSON を組み立てて書いてよい。ただし要素の中身は自分で見て読んだものにする(文字の層を丸ごと機械的に写すだけにしない。文字の層は画像で読んだ字の確かめに使う)。
