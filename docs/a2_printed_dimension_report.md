## 仮説

> 図面に印字された寸法を拾って突き合わせれば、人が入れた寸法の誤りを見つけられる。

**ここを校正済みにすると「人が 1 回入れた値と印字が合った」だけで

### U3 の内訳(**ここがこの周のいちばんの中身**)

| 誤らせ方 | 見つけた |
|---|---|
| **桁違い(10 倍)** | **46 / 46 = 1.000** |
| **1 桁落ち(10 分の 1)** | **46 / 46 = 1.000** |
| **縦横の入れ替え** | **0 / 46 = 0.000** |

**桁の取り違えは全部見つかる。縦横の入れ替えは 1 つも見つからない。**

入れ替えが見つからないのは、実装の粗さではない。
**縦も横も図面に印字されているので、入れ替えても両方とも印字に当たってしまう。**
見つけるには「どの向きの寸法線か」という位置の情報が要るが、この層は位置を見ていない。

## 足し合わせを許さなかった理由(**測って決めた**)

壁の寸法は区間ごとに分けて印字されるので、「印字された値の和」と突き合わせたくなる。
**測ったら駄目だった。**

| 突き合わせ方 | でたらめな寸法が一致してしまう割合 |
|---|---|
| そのまま印字にあるか | **0.000** |
| **2〜3 区間の和も許す** | **0.151** |

**和を許すと、でたらめな数の 15% が「印字にある」になってしまう。** 検算にならない。

## 判定と理由

**保留。**

採否の基準(9 節)は「採用 = U1 ≤ 0.10 かつ U2 = 1.000 かつ **U3 ≥ 0.80**
かつ U4 = 0 かつ U5 全検出 かつ 対照が全部通る」だった。

- U1 ✓ / U2 ✓ / **U3 = 0.667 ✗** / U4 ✓ / U5 ✓ / 対照 ✓
- 不採用の条件(U1 ≥ 0.30 または U4 > 0)にも当たらない。**だから保留である。**

## 基準の外で測ったこと(**判定には使わない。ただし重い**)

**正しく入れた値でも「印字に無い」と言われる割合を測った。**

壁が区間に分かれて印字されている室では、室の寸法は「区間の和」になる。
その和が、そのまま印字にもある割合を数えた。

| 値の作り方 | そのまま印字にもある | **「印字に無い」と言われる** |
|---|---|---|
| 2 区間の和(871 通り) | 0.014 | **0.986** |
| 3 区間の和(6,528 通り) | 0.003 | **0.997** |

**正しい入力でも、区間に分かれていれば 98.6% が「食い違い」として出てしまう。**

**いまの出し方には欠陥がある。** `印字に無い` を「食い違い」として数えているが、
実際には **「確かめられない」**である。20 周目に見つけたのと同じ形の間違い
(**「間違っている」と「判定できない」を同じに数えている**)。

**この周では直さない。** 直すと、いま測った U1・U2・U3 が
別のものを測ったことになってしまう。**23 周目に、基準を先に書いてから直す。**

## 言えること

- **桁の取り違え専用の検算としては、いまのままで使える。**
  でたらめな数はまったく通さず(U1 = 0.000)、桁違いは 100% 捕まえる。
- **一般の検算としては使えない。** 正しい入力の 98.6% を食い違いとして出してしまう。
- **縦横の入れ替えは原理的に見つからない。** 位置の情報が要る。

## 次の周(23 周目)

**指摘の出し方を直す。** 基準を先に書いてから測る。

1. `印字に無い` を **「確かめられない」**に分ける(食い違いとして数えない)。
2. 指摘として出すのは **桁違いだけ**にする。
3. **「確かめられない率」を別に出す**(20 周目に決めた測り方と同じ形)。

そのうえで 24 周目以降に、**寸法の位置(どの向きの寸法線か)**を見て
縦横の入れ替えを捕まえられるかを測る。
