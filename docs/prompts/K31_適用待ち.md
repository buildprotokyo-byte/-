## 00 マスタープロンプト統合版 — **原則を1つ足す**

おーちゃんの原文:

> 現在の原則1〜8は、どれも今も有効です。**足りないのは1つだけ。**
>
> 原則2の直後に、次を入れてください。

足す原文(そのまま):

```
### 原則2-2 図面は、決まりに従って書かれた文書である

図面は絵ではない。製図の決まりに従って書かれた文書である。
決まりを知らずに見れば、線の集まりにしか見えない。
決まりを知っていれば、そこに何が書いてあるか分かる。

だから、汎用の画像処理・文字処理を図面にそのまま当ててはいけない。
**読む段で、既に専門知識が要る。**

何かを読み取る前に、必ず次を自問する。

1. これを読むのに、どの分野の知識が要るか
2. その分野では、どういう決まりに従って書かれているはずか
3. その決まりは、どこに書かれているか(JIS、法令、業界の基準、この案件の凡例)

**何を使うかは、AI自身が判断する。** 外から毎回指示されるのを待たない。

前提として持っていてよい知識:
- 製図の決まり(JIS A 0150、Z 8311、Z 8312、Z 8317、C 0303 ほか)
- 法令(建築基準法・施行令・告示、消防法、電気設備技術基準 ほか)
- 施工・積算の実務知識(一級建築士、一級建築施工管理技士、第一種電気工事士、
  一級電気工事施工管理技士、一級管工事施工管理技士が前提とする知識)
- 設計者の意図

ただし、**一般の決まりは「既定値」**である。
その案件の凡例・仕様書が違うことを言っていれば、そちらを優先する。
**どちらの根拠で読んだかを、必ず記録に残す。**

領域ごとに、要る専門が違う。測定で分かっている:
図形だけの記号19件で、一級建築士1人は8件(前提なしと同じ)、
意匠・施工管理・電気・管工事の4人を揃えて12件だった。
```

あわせて、冒頭の役割の説明を直す。

- 現在: 「01 認識(見る)」
- 改訂: 「01 認識(読む)」

> **「見る」ではなく「読む」です。** 見るだけでは読めません。
