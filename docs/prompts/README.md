## 原文から外したところ(1 か所だけ)

**実案件の件数と行名を共有フォルダへ移した。2026-09-24**(K-33 おーちゃんの判断)。
`06_ループ作業マスタープロンプト.md` の 0 節と 2 節にあった、実案件の見積と突き合わせて
出た**件数**(当たらなかった行の数、対応づいた行のうち判定できた行の数)と
**見積の行の名前**が対象。

移した先は**共有フォルダの `reports/06_ループ作業マスタープロンプト_外した件数と行名.md`**。
節の見出しは 06 と同じにしてある。リポジトリ側は〔…は共有フォルダ〕と書いて場所を指すだけ。

**それ以外は原文のまま。**ほかの 7 つは、外したところが無い。

> 行名は、見積の構成そのものを表しています。件数も、どの区分が何行かという情報です。
