## 原文から伏せたところ(1 か所だけ)

`06_ループ作業マスタープロンプト.md` の **0 節と 2 節の件数と行名は、見積明細由来なので伏せた**
(2026-09-24 おーちゃんの判断)。伏せたのは、当たらなかった行の数、対応づいた行のうち
判定できた行の数、見積の行の名前。**それ以外は原文のまま**で、伏せた所は〔…は伏せた〕と
書いてある。原文の控えはおーちゃんの手元にある。

ほかの 7 つは、伏せたところが無い。
