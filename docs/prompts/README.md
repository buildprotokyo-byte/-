## 確認中のこと

`06_ループ作業マスタープロンプト.md` の 0 節と 2 節に、実際の見積との突き合わせから出た
**件数**(当たらなかった行の数、対応づいた行のうち判定できた行の数)と、**見積の行の名前**が
入っている。データの取り決めは「実図面・見積明細・そこから作ったデータは匿名化済みでも
コミットしない」なので、**原文のまま置いてよいかをおーちゃんに確認中**(金額と数量の値は
含まれていない)。外すことになれば、その節だけ伏せて差し替える。
