# プロンプト一式の使い方(00〜06)

図面解析・積算・見積作成AIのための一式です。Claude Code の docs/prompts/ に、言い換えずにそのまま保存してください。

| 番号 | 名前 | 何のためのものか | 誰が使うか |
|---|---|---|---|
| 00 | マスタープロンプト(統合版) | 全体の決まり。絶対原則、役割の構造、スタートキット、全体の流れ、成果物 | 全員の土台 |
| 01 | 認識AI(見る) | 図面に何が書いてあるかを、位置を付けて取り出す | 実行時 |
| 02 | 理解AI(考える) | それが施工上どんな意味か。区分・目的との照合・波及・差分・施工の構成 | 実行時 |
| 03 | 最適解AI(まとめる) | 数量・人工・原価・見積・質疑・質問の選定 | 実行時 |
| 04 | 異常検知AI(疑う) | 間違いの兆候を見つけ、本当に誤りかを判定し、正しい相手に差し戻す | 実行時。全階層 |
| 05 | 技術選択のルール | 精度が上がらない所に、どの技術を当てるかを決める手順 | 開発側 |
| 06 | ループ作業マスタープロンプト | 検証を回し続けるための指示。試験の型、3つのトライアル、汚染を防ぐ決まり | 開発側(Claude Code の自走) |

## 関係
- 00 がすべての土台。01〜04 は 00 の原則を、役割ごとの手順に落としたもの
- 05 と 06 は、01〜04 の精度を上げるための開発側の手順
- 既存の docs/principles/start_kit.md と docs/design/overall.md が、この一式と食い違う場合は、食い違いを一覧にして報告する(勝手に直さない)

## 元になったもの
- おーちゃんが用意した積算のマスタープロンプト(仕事の網羅)
- 今日までの検証で決めた原則(精度の仕組み)
- P011 の比較実験の採点結果(2026-09-22)

## 使うときの注意
- 実験の読む側には、この一式を渡さない(条件が変わるため)
- 実図面・見積は、匿名化済みでもコミットしない
- 判定のしかたを変える修正は、プルリクエストで待機する
