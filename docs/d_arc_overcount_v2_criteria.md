# 53周目 基準: **紙を中身で特定してから、円弧の数を正解と比べる**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。52 周目のやり直し。

## なぜやり直すのか

52 周目は**対照1 が通らなかったので結論を出さなかった。**
**参照データが紙を「8 ページ目」としか書いておらず、そのページ番号が
匿名化 v2 では通用しなかった**からである。

**今度はページ番号を使わない。中身で紙を決める。**

## 紙の決め方(**測る前に決める**)

参照データには**人が目視で拾った室名が 14 件**入っている
(`benchmarks/real_drawing_fixtures.P011_ROOMS`)。
**34 ページ全部について、その 14 件がいくつ現れるかを数え、いちばん多いページを紙とする。**

**数え方は 2 通りで、多いほうを採る。**

1. **そのまま**の文字列で探す
2. **括弧の中を落として**探す(`物入(ホール)` → `物入`)。
   **図面では括弧の書き方が違うことがある**ため。

**紙と認めるのは、次の 2 つが両方そろったときだけ。**

- **1 位のページの一致数が、2 位のページの 2 倍以上**であること
- **そのページに図面名の文字がある**こと

**そろわなければ「特定できない」とし、結論を出さない。**
**そのときはおーちゃんに「どのページか」を聞く。こちらで決めない。**

## 測るもの

| 記号 | 何を測るか |
|---|---|
| **V0** | 紙と決まったページ(1 始まり)と、その一致数・2 位の一致数 |
| **V1** | **そのページ**でベクターの経路が拾った円弧の件数 |
| **V2** | 参照データの円弧の件数(`HINGED_DOOR_ARCS` の数 = 5) |
| **V3** | **V1 ÷ V2**(人が正解 1 件につき見ることになる数) |
| **V4** | 34 ページ全体で拾った件数 |

**出すのはページ番号・件数・比・真偽だけ。室の名前も図面の文字も座標も出さない。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **紙が特定できない** → **結論を出さない。**おーちゃんに聞く。
- **V1 = 0** → **正解のある紙で 1 件も拾えていない。**縮尺が読めたかどうかを名指しする。
- **V3 ≦ 2** → **人がさばける量である。**
  51 周目の「人が見る材料として成立している」は**そのまま保たれる。**
- **V3 > 2** → **人は正解 1 件につき V3 件を見ることになる。**
  **51 周目の結論に但し書きが要る**ので、報告書とまとめの文書に足す
  (**設計の記録。判定のしかたは変えない**)。

**V3 を「精度」とは呼ばない。** 1 件ずつ突き合わせたわけではなく**数を比べただけ**である。
**言えるのは「人が見る量」だけ。**
