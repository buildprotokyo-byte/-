## 上限について(大事)

K-23 の上限(線 1,800・閉領域 300・小輪郭 600)では、**匿名化v2 の電気・設備のページで小輪郭の 9 割以上が台帳に入らない**(24 ページは 9,126 個中 600 個)。残すのは大きいものからなので、小さい記号ほど落ちる。

**台帳は「そのページに何があるか」の全部ではない。** 記号を数える段が台帳を使うなら、上限に当たったページでは数えないか、上限を上げて取り直す必要がある。上限に当たったことはページごとに残しているので、黙って欠けることは無い。

## 実装の中身(SUGORAKU の手順から、こちらで決めたこと)

K-23 の本文にない細かい値は、こちらで決めた。**実図面で校正した値ではない。**

- ページの処理のしかた: 画像がページの半分以上を覆っていればラスター、それ以外で線があればベクター。
- ラスターは長いほうの辺を 3,000 画素にそろえてから CLAHE(2.0、8×8)→ Canny(50/150)→ HoughLinesP(しきい 80、切れ目 3 画素)→ 輪郭(穴を閉領域、小さい外側の輪郭を小輪郭)。
- ベクターは PDF の線を直接取る。長方形として入っている図形(壁や枠に多い)の 4 辺も線に数える(ラスターの HoughLinesP も長方形の辺を線として拾うので、意味を揃えるため)。
- 大きさの区切り(0〜1,000 の単位で): 長さ 10 未満の線は残さない、外接矩形の長いほうが 20 以下なら小輪郭、1 未満は点の汚れとして落とす(落とした数は残す)、閉領域は面積 100 以上。
- 座標まで同じ線は 1 本にまとめる(閉じた線の戻りや重ね描き。まとめた数は残す)。
- **ベクターのページの小輪郭には文字が入らない**(PDF の文字は線ではないため)。**ラスターのページの小輪郭には文字が入る。** 同じ「小輪郭」でも中身の性質が違う。

## 品質ゲートの決め方

- **blocked**: 処理が止まった / 描画も画像も無い / 文字の層が無い(OCR を掛けていない)
- **needs_review**: 縮尺が取れていない / 表題欄から名称も図番も取れていない / 上限に当たった / 候補が 0 件 / 台帳に入っていない画像がある
- **passed**: 上のどれにも当たらない。**正しいという意味ではない。**

縮尺の欄に「NON SCALE」「-」と書いてあるページは「縮尺が無いと書いてある」として別に記録し、縮尺が取れていない扱いにしない。P011 にはそういうページは無かった。

## 次の周(「認識から 4 段を順に通す」)が使うとき

```python
from axes.image_axis.candidate_ledger import build_ledger, LedgerCache, LedgerSettings

ledger = build_ledger(pdf_path)                       # 全ページ
ledger = build_ledger(pdf_path, pages=[21])           # 0 始まり。22 ページ目だけ
ledger = build_ledger(pdf_path, cache=LedgerCache(dir))                # 使い回す
ledger = build_ledger(pdf_path, settings=LedgerSettings(max_small=20000))  # 上限を上げる

for page in ledger.pages:
    page.page_index        # 0 始まり
    page.source            # "vector" / "raster" / "none"
    page.rotation, page.width_pt, page.height_pt   # 表示の向きの紙の大きさ
    page.title             # TitleBlock(read, drawing_name, drawing_number, scale_text,
                           #   scale_denominator, scale_stated_none, revision_date, labels_seen)
    page.lines             # LineCandidate(x0, y0, x1, y1, length) の並び
    page.regions           # BoxCandidate(x0, y0, x1, y1, area)
    page.small             # BoxCandidate(x0, y0, x1, y1, area)
    page.counts["small"]   # KindCount(found, kept, limit, cap_hit)
    page.gate              # PageGate(status, reasons)
    page.to_dict()         # JSON にできる形
```

- 座標は表示の向きで、ページ全体が 0〜1,000。ポイントに戻すには `x / 1000 * width_pt`、`y / 1000 * height_pt`(横と縦で 1 単位の長さが違う)。
- 候補に「何か」を表す欄は無い。意味を当てるのは使う側。
- **1 室ぶんを通すなら、上限を上げて取るか、上限に当たったページかを先に見ること。**
