## 3. 理由で合格(K-71 作業1 c)

出力の行に付いた理由を、行とその行がまとめた項目(`理解.項目`)と、機械の検算の `行ごとの要確認` から読む。**4 種類**:

| 理由 | 決め方(どれか 1 つ) |
|---|---|
| 未確定 | 項目の状態が 仮説・問い / 項目の確度が 低 |
| 要確認 | 項目の 検算 が空でない / 機械の検算の `行ごとの要確認` が空でない / 行のメモが「ページで数量が違う」で始まる |
| 根拠が図面に無い | 項目の根拠の種類が 仮に置いた・公開基準から推論 / **行の数量が未取得で、項目の理由の文が空でない** |
| 会社ルールが要る | 項目の理由の文か行のメモに 会社・ルール・原価表・職人・諸経費 のどれか |

- 理由が 1 つでもあれば「理由つき」。
- **根拠なしの数量** = 数量を出しているのに理由が 1 つも無い行。**合否には使わない**(別に数える)。
- 正解の行(性質 4・5)ごとの判定: 当たった出力の行が理由つき → **理由で合格** / 当たったが理由なし → **理由なし** /
  当たる出力の行が無い → **出していない**(合格にも理由なしにも入れない。件数を別に出す)。
- 性質 1〜3 でも、数量が未取得で理由つきの行は「理由つきの分からない」として別の列に出す(合否の分子には入れない。仮の判断 2)。

## 5. 金額(仮)

- 数量に**正解の参考単価**(正解の金額 ÷ 正解の数量)を借りる。単価の当たり外れは測らない。利益の幅はこの測定に入らない。
- 対象は性質 1〜3 の行で、当たった出力の行が数量を持ち、正解の数量が 0 でないもの(=「拾えた行」)。
- 科目(正解の科目)ごとに:
  - **被覆** = 拾えた行の正解の金額の合計 ÷ その科目の正解の金額の合計(93 行のうちその科目の全部)。
  - **近さ** = 拾えた行の (出力の数量 × 参考単価) の合計 が、同じ行の正解の金額の合計の ±15% / ±30% に入るか。
  - **被覆が 0.50 未満の科目は近さを出さない**(`被覆が低いので出さない` と出す。仮の判断 3)。
- 全体の合計の近さは**参考**(拾えた行の合計で)。
- 自前の単価で金額を出す段階になったら、±30% を「方向が合っている」、±15% を「良い」に使う(この周は使わない)。
