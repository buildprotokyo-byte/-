# 37周目 基準: 建具表の見出しは、そもそも 1 つも当たっていないのか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。36 周目の「次の周」に書いたとおり。

## なぜこの題なのか

36 周目で 2 つ確定し、1 つ分かれなかった。

- **確定**: 罫線の表は 107 個あり(L1 でない)、**107 個すべての升目に文字がある**(L2 でもない)。
- **確定**: 建具番号らしい列を持つ表は 5 つで、**その 5 つとも付き添いの列が 0**。
  しきいを 2 から 1 に下げても **0 は 1 にならないので何も通らない。**
- **分かれなかった**: その 5 つが「凡例表の記号列に当たっただけ」なのか、
  「本物の建具表で付き添いの見出しが当たっていない」のか。

36 周目の E5(一番多く落ちた場所)は **L3a 101 / 107 と出たが、その数字は捨てた。**
107 のほとんどはそもそも建具表ではないので、当たり前を数えているだけだった。
**同じ設計ミスを繰り返さないために、この周は「建具番号」を数から外す。**

## 測るもの

**建具番号を無視して、付き添いの役割だけを 107 個すべてで数える。**

| 記号 | 何を測るか |
|---|---|
| **F1** | 付き添いの役割(種別・幅・高さ・数量)が**1 つでも**当たった表の数 |
| **F2** | その分布(付き添い 1 個 / 2 個 / 3 個 / 4 個の表がそれぞれ何個か) |
| **F3** | **役割ごとの内訳**。種別・幅・高さ・数量が**それぞれ何個の表で**当たったか |
| **F4** | 付き添いが 2 個以上当たっているのに**建具番号の列が無い**表の数 |
| **F5** | 36 周目の 5 つの表(建具番号あり・付き添い 0)が、**F1 に 1 つも入らないか** |
| **F6** | 同じ数え方を**内装仕上表の役割**でやった数(対照) |

**中身は出さない。** 当たった / 当たらないの数だけ。見出しの文字も出さない。

## 何を確かめたいのか(**先に書く**)

**見込み**(測る前に書く。外れたらそのまま外れたと書く):

1. **F1 は 0 にはならない。** 幅・高さ・数量は面積表・仕様書・凡例でも使う語なので、
   建具表でない表でいくつか当たるはず。
2. **F4 が 1 以上なら、列の切り出しか表のまたぎを疑う番になる。**
   付き添いだけ揃っていて建具番号が無い表は、**建具表の続きのページ**の形である。
3. **F3 で、どの役割が当たっていないかが分かる。** 4 つとも 0 に近いなら
   「見出しの言い方が合っていない」で、1 つだけ 0 なら「その列の切り出し」である。

## 分かれ道(**先に書く。測ったあとで変えない**)

| 見えた形 | 結論 | 次にやること |
|---|---|---|
| **F1 = 0** | **見出しの言い方が図面とまったく合っていない** | 言い換えの表を増やす案を書く(判定に触るので PR のまま待つ) |
| **F4 ≧ 1** | **列の切り出しか表のまたぎ**が落ちどころ | その表の形を測る周を作る |
| **F1 ≧ 1 かつ F4 = 0 かつ F5 が「1 つも入らない」** | **(あ)の側。建具番号らしい 5 つは凡例で、建具表はこの図面の罫線の表として存在しない** | 建具表がどのページにどの形であるかを、表以外の手がかりで探す周を作る |
| 上のどれにも当てはまらない | **名指ししない。** 分かったことだけ書く | 測り方を作り直す |

**F1 ≧ 1 かつ F4 = 0 の形が出たときだけ、「建具表が罫線の表として無い」と言ってよい。**
それ以外でこの言い方はしない。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 合成の建具表で同じ数え方 | 付き添い 4 個で当たる |
| **2** | 内装仕上表の役割で同じ数え方(F6) | 通っている 2 つが当たる |
| **3** | 反復 3 回 | 3 回とも同じ |
