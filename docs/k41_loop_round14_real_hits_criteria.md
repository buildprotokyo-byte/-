# K-41 10時間ループ 周14: 当たり 64 件のうち何件が本物かを数える — **測る前の基準**

この文書は**数える前に**コミットする。周 1〜13 を足した当たり 64/93 は、囮を足しても 31/93 になる。件数ではなく、本物の数を数える。

## 数えるもの

当たり 64 件(正解の番号)を 1 件ずつ、次の 3 つに分ける。

- **本物だけ**: その正解を当てた周のうち少なくとも 1 つで、**同じ周の囮が当てていない**。
- **名前だけで当たる**: その正解を当てたどの周でも、同じ周の囮も当てている。
- **数量まで合った**: 上の 2 つとは別に数える。採点する役か私が、±5%(㎡など)・±1(個数)に入ったと判定したもの。数量を持たない行(注記など)の当たりは「数量なし」とする。

## 同じ周の囮の決め方(先に決める)

| 当てた側 | 比べる囮 |
|---|---|
| 周 1 の読む役 2 本 | 周 1 の囮 2 本(資料なし)の和 |
| 周 4 の深く見る段 | 周 1 の囮 2 本の和(周 4 に混ぜた囮は正解に無い作り物なので) |
| 周 6 の色つきの注記 | 周 6 の囮(黒い文字) |
| 周 7 の電気の読み | 周 7 の囮(既存電気図) |
| 周 8 の展開図の注記 | 周 8 の囮(厳しい読みでは 0 件。**寛い読みで囮が当たるとした約 13 件も「囮も当てた」として別に数える**) |
| 周 11 の網 | 周 11 の囮(黒い網、名前では 4 件当たった) |
| 機械の 67 行 | 囮が無いので、**全部の周の囮の和**と比べる(厳しめ) |

- 採点者の線引きは決めない。周 8 は厳しい読み・寛い読みの両方で数える。
- あわせて、**全部の周の囮の和**と比べた数も出す(いちばん厳しい見方)。

## 何を出すか

本物だけ・名前だけで当たる・数量まで合った、の件数(科目ごとも)。本物の数が 64 からどれだけ減るか。

## 守ること

自動確定は 0 件のまま。判定のしかたは変えない。数え直すだけで、新しい行は作らない。
