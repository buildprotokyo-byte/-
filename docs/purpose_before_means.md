# 解体は手段であって目的ではない(2026-09-23、おーちゃんの訂正)

**この文書は、私が出した問いそのものが原則に違反していたことの記録である。**
設計を1行も変えていない段階の記録なので、実装には何も入っていない。

## 1. 何が起きたか

判断待ちの札として、こう聞いた。

> 「解体図しか無いとき、そこから読んだ数量を撤去として出してよいですか」
> 選択肢: **出す(推論の印つき)** / 出さない / まだ決めない
> 推しは「出す」。理由は「落ちた工事より、印の付いた行のほうが人は気づけるため」。

おーちゃんはいったん「出す(推論の印つき)」を選んだあと、**問いのほうを取り下げた。**

## 2. おーちゃんの言葉(要旨)

> まず目的から推論する、というルールに違反している。
> **解体をした後に何かを作る、というのが目的**になった場合に、
> **その手段として「解体する」が出てくる。**
> その解体する範囲や、どう解体するかを示しているのが図面である。
> 何も無いときに、**解体が見積の目的を飛び越えて、「解体すること」が目的になり、
> それが見積書を支配する** ——それが基本の考え方になるのはおかしい推論だと気づいた。

## 3. 何が間違っていたか

**選択肢の中身ではなく、問いの立て方が間違っていた。**
「出すか、出さないか」という二択は、**解体の数量が見積の骨格になりうる**ことを
前提にしている。その前提自体が原則違反である。

| | 間違った順番 | 正しい順番 |
|---|---|---|
| 出発点 | 解体図にある数量 | **この工事の目的** |
| 図面の役割 | 数量の出どころ | **目的を果たす手段の、範囲とやり方を示すもの** |
| 解体の位置 | それ自体が見積の項目の根 | **目的(何かを作る)に従属する手段** |

`docs/principles/start_kit.md` の第1層「読むことと目的は、常に対で働く」、
および要素ごとの推論3段階(区分・目的との照合・波及)に照らすと、
**目的との照合を飛ばして区分だけで行を立てようとしていた。**

## 4. 立て直した問い(まだ答えを決めていない)

解体図しか無いとき、問うべきはこちらである。

> **その解体は、何を作るための手段か。** それが分からないとき、
> 目的をどう推定し、その推定をどう示し、人にどう確かめるか。

原則には既に「目的が与えられていなくても処理は止めない。AI が図面から推定した
目的には、推定であることを示す」とある(3-2節)。**足りないのは、
推定した目的を人に確かめる経路と、その推定が外れたときに手段側の数量が
どう扱われるかの取り決めである。**

**取り下げた札の答え(出す・推論の印つき)は、この文書では採用しない。**
前提が違う問いへの答えなので、そのまま持ち越さない。

## 5. 自分への申し送り

**札に出す前に、問いそのものが原則に違反していないかを確かめる。**
58〜60 周で「問いの質」を測っていた最中に、**自分の出した問いの質が低かった。**
測っていたのは仕組みの問いだけで、**自分が人に出す問いは測っていなかった。**
