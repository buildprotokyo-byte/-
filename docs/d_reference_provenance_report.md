## 基準に先に書いた枝のとおりの判定

> **片方のファイルだけ Y1 ≧ 1、もう片方が Y1 = 0** → **参照データはそのファイルのものである。**
> さらに**複数**なら → **ファイルは決まったがページは決まらない。**

**ファイルは決まった。ページは決まらなかった**(古いほうの 32 ページが形の上では収まる)。

**ただし、ページはもう争点ではない。**
参照データの説明書きは「**8 ページ目**」と書いている。
**52・53 周目でそれが通らなかったのは、v2 の 8 ページ目を見ていたからである。**
**ファイルが決まった今、その記録に矛盾は無い。**
**「古いほうのファイルの 8 ページ目」で筋が通る。**

**とはいえ、それは記録がそう言っているだけで、測って裏を取ったわけではない。**
**測定が言えるのは「ファイルは古いほう」までである。**(取り決め①)

## **ここから出てくる、もっと大きい問題(次の周で測る)**

**古いほうのファイルは 34 ページ全部がスキャンで、文字データが 1 文字も無い。**

**スキャンの紙にベクターの図形は無い。**

つまり、**こうなっている疑いがある。**

- **正解データがある紙** = 古いほう。**ベクターの経路が動かない。**
- **ベクターの経路が 90 件拾っている紙** = v2。**正解データが無い。**

**もしそうなら、「ベクターの円弧が正解を何件当てているか」は、今のところ測れない。**

**これは 51 周目の結論を変えない**(51 周目は箱の座標を使っていない)。
**変わるのは「ベクターの経路の当たり外れを測った」と言えるかどうかである。**
