# 段階0.5(方式A2)採否判定 — 反復10回での再測定結果

実施日: 2026-09-22。判定基準は測定前に `docs/stage05_a_vs_a2_remeasurement_criteria_2026-09-22.md`
としてコミット済み(commit 816e95b)。このスレッドの担当は測定と判定のみで、
本番の既定変更(方式Aへ戻す作業)は別スレッドが同時並行で実施し、

## 1. 測定設計(実施どおり)

- 難易度1・3・4それぞれで、方式A・A2を**反復10回**、6セット×3問=**180問/条件**で測定した
  (トライアル15と同一の資料・設問。正解値は `benchmarks/two_stage_reading_key.json` のまま変更していない)。
- 読み手は Claude Sonnet のサブエージェント。**1反復=1回の独立した呼び出し**
  (同一文脈内で同じ設問を繰り返させていない)。ただし実行の都合上、
  1回の呼び出しの中で6セット分の資料を順番に読ませ、まとめて回答させた
  (トライアル15はおそらくセットごとに別呼び出しだったと見られるが、
  6件は互いに無関係な架空案件であり、情報の混入は起きない設計にした。
  プロンプトにも「他の案件の数字を流用しない」と明記した)。
- 読み手には「指定した1ファイルだけを読み、他のツール(検索・Bash等)は使わない」と指示した。
- 生の回答: `docs/stage05_a_vs_a2_10reps_runs.json`(360件。2方式×3難易度×10反復×6セット)。
  採点結果: `docs/stage05_a_vs_a2_10reps_result.json`。
- 60回の読み取りのうち2回(L4-A2 rep02, L4-A2 rep08)は初回呼び出しでJSON本体を
  出力せず「上に出力済みです」という参照だけを返したため、同一条件で1回だけ
  再実行した(内容の改変なし、フォーマット不備のみの再試行)。

## 2. 結果

| 条件 | 正答 | 正答率 |
|---|---|---|
| 難易度1 方式A | 180/180 | **100.0%** |
| 難易度1 方式A2 | 180/180 | **100.0%** |
| 難易度3 方式A | 179/180 | **99.4%** |
| 難易度3 方式A2 | 180/180 | **100.0%** |
| 難易度4 方式A | 180/180 | **100.0%** |
| 難易度4 方式A2 | 180/180 | **100.0%** |

トライアル15(反復3回)との比較:

| 条件 | 反復3回(54問) | 反復10回(180問) |
|---|---|---|
| 難易度4 方式A | 54/54 (100%) | 180/180 (100%) |
| 難易度4 方式A2 | **50/54 (92.6%)** | **180/180 (100%)** |

**難易度4で方式A2がAを下回った現象は、反復10回では再現しなかった。**
反復3回のときに外した4問(S2 rep1, S5 rep2 に集中していた)は、
今回の10反復(セット×反復=60通りの独立試行)ではすべて正解した。

設問の狙い別(scope / condition / extra_rule)で見ても、両難易度4方式とも
scope 60/60・condition 60/60・extra_rule 60/60で完全一致している。
唯一の誤りは**難易度3・方式A・rep8のS2Q1**(scope、272.16が正解のところ
279.36と回答、集計表のおとりの版に寄ったとみられる)で、方式A2側には
1件も誤りが無い。

## 3. 判定基準に照らした結果

`docs/stage05_a_vs_a2_remeasurement_criteria_2026-09-22.md` の基準どおりに判定する。

### 不採用基準(難易度4でA2がAを5ポイント以上・有意に下回る)
**該当しない。** 難易度4はA・A2とも180/180で差は0ポイント。

### 採用基準
1. **難易度1・3・4のいずれでも、A2の正答率がAの正答率を有意に下回らない**
   → 満たしている。難易度1・4は同点(100%)。難易度3はA2(100%)がA(99.4%)を
   わずかに上回っている(Fisherの正確検定で両側p=1.0、有意差なし。
   そもそも方向がA2優位なので「下回る」の検定自体が不要)。
2. **extra_rule設問(数え方の決まり)の正答率が、各難易度でA2がA以上**
   → 満たしている。全難易度・両方式ともextra_rule 60/60(100%)で同点。

**結論: 採用基準を満たし、不採用基準には該当しない。**
反復3回で観測された「難易度4でA2がAを下回る」現象は、10反復では再現せず、
反復3回の標本が小さかったことによる偶然のばらつきだった可能性が高い
(トライアル15報告書5節8項で「反復3回では偶然を排除しにくい」とすでに
指摘されていた懸念が、今回そのとおりの形で表面化した)。

## 4. この結果で言えないこと(先に明記しておく)

- 方式Aが今回も全難易度で天井(99.4〜100%)に近いため、**「A2がAより
  精度を上げるか」は依然として測れていない。** 測れたのは「A2がAを
  下回るかどうか」だけである。今回の10反復では下回らなかった、という
  範囲の結論にとどまる。
- 難易度4は「食い違う旧版」という一種類の罠しか含んでいない。この罠に
  対する結果を他の罠一般に外挿しない。
- 難易度3・方式A・rep8の1件の誤りは、方式Aの側にも稀に誤りが起きうることを
  示しているが、n=1では方式Aの真の正答率を云々するには足りない。
- 反復10回・6セットでも、難易度4は依然として1種類の罠×6セットという
  小さい母集団である。今回の結果は「トライアル15で見えた劣化が10反復では
  消えた」という事実であって、他の罠や条件でA2が劣化しないことの証明ではない。
