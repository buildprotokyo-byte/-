## 参考(**あとから足した診断。線1〜4 の判定には使っていない**)

**足した理由**: 種類が 6 つだと分かったあと、**「だから規則も 6 本で足りる」と
読まれかねないから**である。`MappingRule` は種類のほかに
**単位の次元・属性・現況か計画か**も条件にできる。

| 数えたもの | 件数 |
|---|---:|
| 現況か計画かが**決まっている** | **0** |
| `不明`(**規則の条件には書けない**) | 164 |
| **意味そのものが付いていない** | **2,723** |
| 単位の種類 | 3 |

**2,887 件のうち、現況か計画かが決まっているものは 1 件も無い。**

**これを「規則が書けない」とは書かない。**`MappingRule` の `phase` は
**空なら問わない**ので、現況/計画を条件にしない規則は書けるし、当たる。
**正しい言い方はこうである**——**いま規則を書くと、
「撤去する物」と「新しく付ける物」を区別しない規則しか書けない。**
区別する規則は**書いても 1 件も当たらない**(決まっている数量が 0 件だから)。

**`MappingRule` の説明文は、その理由まで書いている**——
「`不明` は書けない。決まっていないことを根拠に行を立てることになる(原則2)」。
**原則のほうは守られている。足りないのは、決める段のほうである。**
