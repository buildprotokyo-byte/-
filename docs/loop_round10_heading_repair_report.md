**直したことで前は合っていたものが外れた件数も 0 件。**

**線4**: 置き換わった前後の組は共有フォルダの `reports/周◯_直した組.json` に全部ある。

## なぜ 1 件も掛からなかったか

**正解の 8 か所の崩れ方が、この直しの対象ではなかった。**

- **記号と室名**(3 か所): 崩れたのは「入」が「人」、括弧の全角半角、繋ぎの記号。
  **どれも見出しではない**ので、作りの上で触らない。
- **外枠の寸法**(3 か所): 文字列が英字で始まる。**値に触らないために英数字で始まる
  文字列は直さない**と決めてあるので、触らない。
- **枠の見込み**(2 か所): ここだけは見出しが縮んでいて対象になるが、
  **2-gram の Dice が 0.5 に届かなかった。**見出しが縮むほど 2-gram は減るので、
  **短くなった見出しほど、元の語から遠く出る。**

**つまり、先に決めた線(Dice 0.5)が、直したい相手に届かない値だった。**

## 結果を見てから計算したこと(**この周の判定には使わない**)

しきいを下げるとどうなるかを、あとから計算した。**K-33 の追記と同じ扱いで、
この周の採否には使わない。**

| しきい | 周6 本物直した / 囮直した / そのまま一致 | 周9 本物直した / 囮直した / そのまま一致 |
|---|---|---|
| **0.5(先に決めた値)** | 26 / **0** / **4 / 8** | 17 / **0** / **1 / 8** |
| 0.4 | 30 / 0 / 4 / 8 | 25 / 0 / 1 / 8 |
| 0.3 | 38 / 0 / 4 / 8 | 33 / 0 / 1 / 8 |
| 0.2 | 41 / 0 / **6 / 8** | 39 / 0 / **3 / 8** |

**0.2 なら線1 を超える。だが、これは同じ 8 か所を見ながら値を選んだ数字である。**
**採るなら、先に 0.2 と決めてから、別の紙(別のページ・別の案件)で測る。**
**この 8 か所で 0.2 に決め直すのは、答えを見て線を引くことになる。**

## 囮についての断り書き(**この周でいちばん大事な線が、実は効いていない**)

基準では**囮にも同じ直しを掛けることを、この周でいちばん大事な線**と書いた。
**囮では 1 件も直しが起きなかった。**

**だがこれは「直しが当てずっぽうを作らない」ことの証明にならない。**
**囮から返る文字列はほとんど 1 文字で、この直しは 2 文字以上の先頭しか触らないからである。**
**囮は、この直しにとっては最初から当たらない相手だった。**

**次にこの直しを測るなら、囮を作り直す必要がある**(たとえば
**語彙表に無い、もっともらしい見出しを混ぜた紙**)。

## 頭打ちの判定(おーちゃんの設計④)

> **同じ対象に、技術を 3 つ・出典を 3 つ当てて増えなければ頭打ち。**

このメーカー図 3 枚の 8 か所に、これまで当てたもの:

| 何を変えたか | 周 | そのまま一致 |
|---|---|---|
| 紙を端から全部読む | 周6 | 4 / 8 |
| 罫線の升目だけ | 周7 | 0 / 8 |
| 製図の決まり 4 本 | 周8 | 1 / 8 |
| 切り出しを広げる | 周9 | 1 / 8 |
| 読んだあとに直しを足す | 周10 | 4 / 8(周6 に掛けて変わらず) |

**5 通り当てて、最初の 4 / 8 を超えられなかった。頭打ちと判定する。**

**この 8 か所は、ここで止める。**「何通り試したか」を付けて残し、
**設計の周2(意味が決まらなかったまとまりに、10〜20 の知識を当てる)へ進む。**

**止める時点で残っている事実**(次に戻ってくる人のため):

- **どの読み方でも「近い」は 8 / 8。値そのものは当てている。**
- **残っているのは字の細かい崩れだけで、崩れ方は 5 周を通して同じ種類だった。**
- **しきい 0.2 が効きそうに見えるが、同じ 8 か所で決めてはいけない。**
  **別の紙で先に線を決めて測ること。**
