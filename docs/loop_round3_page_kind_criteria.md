# 周3の基準: ページの種類を見分ける

作成: 2026年9月25日。**測る前にコミットする。**

## 前の周と何が違うか

周6〜周10 は**メーカー図 3 枚の中の 8 か所**を相手にしていた(頭打ちで止めた)。
**この周は相手が変わる。冊子 34 ページ全部を、1 ページ 1 件として見る。**
設計の周3「**ページの種類を見分けて専門を選ぶ**」の 1 段目である。

## 正解は、図面が自分で書いている

**この冊子の 1 ページ目に、図面自身が書いた図面リストがある**(ページ番号・図面番号・
図面名称の表)。**これを正解にする。**

- **正解は共有フォルダに置く**(`reports/周3_ページの種類_正解.json`)。
  **リポジトリには置かない。**実案件の図面名だからである。
- **正解を作るのに、見分ける側が使う手がかりを一切使わない。**
  正解はリストの文字から、見分ける側は**墨・図形・画像・罫線の数だけ**から作る。

## 見分ける側が使ってよいもの(**測る前に決める**)

**文字を読まない。**製図の決まりと、紙の上の墨の性質だけを使う。

1. 図形(線・曲線)の数
2. 画像の数と、画像が紙に占める面積の割合
3. **4 辺に墨が続く升目の数**(周7 で作ったもの)
4. 取り出せる文字の数(**中身は読まない。数だけ。**)
5. 紙の向きと大きさ

## 分ける種類(**測る前に決める。あとで増やさない**)

正解のリストに出てくる言葉から、**6 種類**にまとめる。

| 種類 | 正解のリストでの見分け方 |
|---|---|
| 表 | 図面名に「表」「リスト」が付く(仕上表・建具表・照明器具リストなど) |
| 図面(線が主) | 平面図・展開図・詳細図・位置図など、線で描いた図 |
| 文章 | 仕様書・計画概要 |
| 凡例 | 図面名に「凡例」が付く |
| 画像が主 | 写真・ボード・シートなど、画像で埋まっているもの |
| 索引 | 図面リストそのもの |

## 測ること

### 線1(この周の採否)

**34 ページのうち、正しく見分けられた数。**

- **23 ページ(3 分の 2)以上で通過。**
- **22 ページ以下なら「墨の性質だけではページの種類は決まらない」と書いて閉じる。**

**いちばん多い種類を全部に答えるだけで何ページ当たるかを先に出し、
それを超えなければ「見分けている」と書かない。**

### 線2: 囮

**ページの手がかりを、ページのあいだでシャッフルする**(種 20260925)。
**シャッフルした手がかりで見分けた正解率が、本物の半分以上なら、
この見分けは手がかりを見ていない。**

### 線3: 種類ごとに出す

**まとめて「何ページ当たった」と書かない。**種類ごとに、
**その種類の枚数・当たった数・他の種類と取り違えた先**を出す。

### 線4: 文字が 0 件のページ

**この冊子には、取り出せる文字が 0 件のページが 4 枚ある**(周6 で 3 枚と書いたが、
**もう 1 枚あった**。そちらは画像 1 枚のページで、線で描かれた 3 枚とは別)。
**その 4 枚を正しく見分けられたかを、別に出す。**文字に頼らない見分けの値打ちは、
そこにいちばん出る。

## 書かないこと

- **図面名・室名などの中身はリポジトリに書かない。**共有フォルダとスレッドだけ。
- **本番の経路には繋がない**(K-29)。
- **当たった数が多くても、いちばん多い種類を答えるだけの数を超えていなければ
  効いたと書かない。**
