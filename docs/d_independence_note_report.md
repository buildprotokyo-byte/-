> 座標の取り違えは両方に同じように効き、**この突き合わせでは捕まらない**。

**コードは「この一致は独立ではない」と言っている。では判定はそれを読んでいるのか。**

## 判定(基準に先に書いた線のとおり)

> **X1 = 0 かつ X4 = 変わらない** → **但し書きは判定に効いていない。**
> **記録もされ、固定もされているのに、読む側がいない。「書いてあるだけの安全」である。**

**そのとおりだった。**

**45 周目とは形が違う。** あちらは「正しいのに、固定するテストが無かった」だった。
**こちらは記録もされ、固定するテストもある**
(`tests/test_intake_start_kit.py::test_the_shared_coordinates_caveat_is_carried_in_the_evidence`。
消したら現に落ちた)。**足りないのは読む側である。**

**そして 45 周目より重い。** あちらは**順番が偶然正しかった**だけで、実害はまだ出ていなかった。
**こちらは、危険が現に通る経路の上にある。**

- 2 つの読みは**紙の上の同じ 2 点**から出ている(`paper_distance_pt` が共有)。
- それでも `independence_key` が違うので、**ファイアウォールは 2 つの独立したデータ源として数える。**

**いま実害が出ていない理由は 1 つだけである。`calibrated=False` だから。**
**校正した瞬間にこの経路は開く。** 47 周目に実測したとおりである。
