# 実際の平面図で数えた: **凡例が宣言した建具の寸法の書き方は、図面で 1 件も使われていない**

測定日: 2026年9月24日。数え方は `docs/k22_door_width_count_criteria.md`
(**数える前にコミット済み**)。対象: P011 匿名化v2(34 ページ)。
**図面の数値そのものは書かない。件数だけを書く。**

## 結果

`H` + 3〜4 桁の数(建具の高さの書き方)を目印に数えた。

| | 件数 |
|---|---:|
| 図面全体で `H` + 数 の形の語 | **4**(**4 件とも 6 ページ、つまり凡例そのもの**) |
| 図面全体で `W` + 数 の形の語 | **3**(**3 件とも 6 ページ**) |
| **凡例以外のページでの `H` + 数 / `W` + 数** | **0 / 0** |

**先に決めた読み方の「0 件」にあたる。**PR #131 の「内部の新設建具だけ幅に `W` が
付かない」は、**図面では確かめられない。**凡例の絵にしかない書き方だった。

## もっと大きいことが出た

**凡例が宣言した建具の寸法の書き方は、既存の建具の分も含めて、図面に 1 件も無い。**

凡例(6 ページ g・h)は、既存建具を `W` + 数 と `H` + 数 で書くと決めている。
**その形の語は、凡例のページ以外に 1 つも無い。**

ゆるく数え直しても同じである。`W` か `H` で始まり数で終わる形は、
凡例以外では **1 件**(`W=` の形が 1 ページに 1 件)と、
**建具番号らしい語が 1 ページに 6 件**だけだった。

一方、**建具番号らしい語**(記号 + 番号)は **7 ページに 17 件**ある。
**番号は使われていて、寸法は使われていない。**

## これは天井高と同じことである

| | 凡例が宣言した書き方 | 図面が実際にしていること |
|---|---|---|
| 天井高(項目 c) | 3 段の枠を室の中に置く | **枠は使わず、別の形の注記を 71 か所** |
| **建具の寸法(項目 g・h)** | **幅は `W` + 数、高さは `H` + 数** | **その形は 1 件も無い。番号だけが 17 件** |

**2 件続けて、凡例の宣言と図面の実際が食い違った。**
**凡例が宣言していることを、そのまま実装の根拠にしてはいけない。**
**宣言を読んだら、図面で数えるまでが 1 組である。**

## 言えないこと(**言い過ぎないために書く**)

- **裸の 3〜4 桁の数は、凡例以外のページに 155 件ある。**そのうちのいくつかが
  建具の幅である**可能性は消えていない。**この数え方では、裸の数が建具の幅なのか、
  壁の寸法なのか、室の寸法なのかを**区別できない。**
- だから「**建具の寸法は図面に書かれていない**」とは書かない。書けるのは
  「**建具の寸法だと分かる形で書かれているものは 1 件も無い**」までである。
- 区別するには、その数が**建具の絵のそばにあるか**を見る必要がある。**まだしていない。**

## 建具表の話にどう効くか

**建具番号は図面にあり(17 件)、寸法は分かる形では無い。**
番号から寸法を得るには**建具表を引くしかない**という筋は、**この数え方の範囲では残る。**
ただし上のとおり、**裸の数の中に幅が混じっている可能性は消えていないので、
「建具表以外に道が無い」とはまだ書かない。**

建具表の読み取りが実図面で 0 件である話は `docs/b_door_schedule_zero_report.md` の
とおりで、**ここでは動かしていない。**
