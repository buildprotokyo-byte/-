# 56周目 報告: **本番の取り込み経路は「探せなかった」と「探したが 0 件」を区別している**

- **基準**: `docs/d_silent_zero_criteria.md`(測る前にコミット `d116b4f`)
- **ベンチマーク**: `benchmarks/measure_silent_zero.py`
- **実装は 1 行も変えていない。**

## 結論

**区別している。** 55 周目に心配した「黙って 0 件」は、**取り込み経路では起きていない。**

| | v1(スキャン) | v2 |
|---|---|---|
| ページの扱い | **`unsupported_raster` 34 ページ**(全部) | `processed` 34 ページ(全部) |
| 「スキャンなので読めない」記録 | **34 件** | 0 |
| 「縮尺が読めないので開き戸を探さない」記録 | 0 | **14 件** |
| 「開き戸の円弧が 0 件」記録 | 0 | **15 件** |
| 出力された数量 | **0 件** | 7 件(うち建具 5 件) |

**v1 の 0 件は、0 という数字ではなく「このページはこの経路では読めない」という
記録として出ている。**「開き戸が無い」とは言っていない。

**v2 の中でも 3 つに割れている。**

- **縮尺が読めないので探さなかったページ**(14)
- **探したが円弧が 0 件だったページ**(15)
- **拾えたページ**(5。35 周目の「90 件が 5 ページ」と合う)

**「探せなかった」と「探したが無かった」が別の文字列で残っている。**

## **この測り方の限界(正直に書く)**

**v2 の記録 124 件のうち 95 件が、こちらで先に決めた 5 つの分類のどれにも当たらなかった。**
**分類の網が粗い。**「その他」の中身は数えていない(図面から読んだ文字が混ざる
可能性があるので、文字そのものは出さない決まりにしてある)。

**言えるのは「区別を表す記録が現に別々に残っている」までで、
「記録の全種類を把握した」ではない。**

## 次の周(57)でやること

**基準に先に書いたとおり。**

> **B1 = 区別している** → どこにどう出ているかを名指しする。
> そのうえで、**その区別が人の目に届く場所まで来ているか**を次の周で測る。

**取り込み経路の中で区別が残っていることと、
人が最後に見る一覧にその区別が載っていることは別である。**
**記憶にある落とし穴そのもの**(「実装済みの記録を信じない。
本番経路から呼ばれているかまで確認する」)。

**測る先は、人が読む形に畳んでいるところ**
(`TargetDecision` と `arbitration/provisional_audit.py`)。
**基準を先に書いてコミットしてから測る。**
