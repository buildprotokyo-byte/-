## 判定と理由

### 基準が自分自身と食い違った

**この周の本当の結果はこれである。** 基準に 2 つの決まりを書いていて、**この数字の上で 2 つが逆を指す。**

- **分かれ道の表**: `F1 ≧ 1 かつ F4 = 0 かつ F5 が「1 つも入らない」` → **(あ)。建具表は罫線の表として存在しない。**
  観測は F1 = 1、F4 = 0、F5 = 5(5 つとも付き添い 0)。**この行に当てはまる。**
- **見込み3 に書いた読み方**: 「4 つとも 0 に近いなら**見出しの言い方が合っていない**」。
  観測は 4 つ中 3 つが 0 で 1 つが 1。**こちらにも当てはまる。**

前者は「建具表が無い」、後者は「建具表はあるが言い方が合っていない」で、**直し方が正反対である。**

### 名指ししない

分かれ道の表は「言ってよい」と書いてあって、「言わねばならない」とは書いていない。

> F1 ≧ 1 かつ F4 = 0 の形が出たときだけ、「建具表が罫線の表として無い」と言ってよい。

**許しであって義務ではないので、使わない。** 基準が自分と食い違っているときに、
**どちらを採るかをこちらが選んでよいことにすると、基準を先に書く意味が無くなる。**
28・32・36 周目に続いて 4 回目の、自分の基準の設計ミスである。

さらに、**(あ)を採ると記録と正面からぶつかる。** 匿名化 v2 の評価では「建具表・仕上表・仕様書・
凡例が読める」と記録されている。取り決め①は記録を信じるなと言っているので、
記録を根拠に(あ)を捨てもしないが、**記録とぶつかる結論を、それを確かめる測定なしに置かない。**

### この周で確実になったこと

1. **`幅`・`高さ`・`数量` の言い換えは、107 個の表のどこにも 1 個も当たっていない。**
   これは言い換えの表(`DOOR_COLUMN_SYNONYMS`)の**当て方そのもの**を疑う理由になる。
   照合は**升目の文字と言い換えの完全一致**で、`巾 W` や `寸法` のような書き方は当たらない。
2. **照合の仕組みは、この図面で死んではいない。** 同じ 107 個の表で仕上表の語は当たった。
   「実図面では完全一致が効かない」は否定された。
3. **しきいを下げても通らない**(36 周目)ことと合わせて、**数の調整では直らない。**

## 次の周

**(あ)と(い)を直接分ける。** 図面の中身を印字せずに分けられる数え方がある。

> **こちらの言葉である「建具」が、どのページの文字に現れるかをページ数だけで数える。**

- **建具の語が現れるページがあり、そこに罫線の表がある** → **(い)。建具表はある。**
  落ちどころは見出しの当て方で、言い換えを増やすか照合を完全一致から変えるかになる
  (**どちらも判定に触るので PR のまま待つ**)。
- **建具の語がどのページにも無い** → **(あ)に寄る。** 表以外の手がかりで探す周を作る。

あわせて、**見出し行の升目のうち、どれにも当たらなかったものが何個あるか**も数える。
当たらない升目が多いなら言い換え不足、そもそも升目が少ないなら見出し行の取り方の問題である。

**この測定も測るだけで、実装には手を入れない。**
