# A-2 の残り: 造作で割れた室を寄せ直す案 — **不採用**

2026-09-23。**不採用も必ず記録する**(同じことを繰り返さないため)。

## 何をやろうとしたか

壁から壁まで届く造作(浴槽・カウンター・便器)は、室を 2 つ以上の面に割る。
測定で、この条件だけ再現が 6/7 に落ち、面積の相対誤差が最大 93.7% になっていた。
トイレは便器で割れて出なくなった。

案は「**隣り合う面のうち、室名を 1 つしか含まないまとまりを作る**」。
割れた面のうち室名が入るのは 1 つだけなので、名前を持つ面から出発して
名前の無い隣を吸い寄せれば元の室に戻るはず、という考えだった。
**`area_sqm` は書き換えず、寄せ直した面積を別の欄で出して人に確かめてもらう**
形にした(どちらが正しいかは図形からは決まらないため)。

## なぜ効かなかったか

**壁の線と造作の線を、図形だけでは区別できない。**

面どうしは**壁をまたいでも「隣り合って」いる**(隣の室と壁の線を共有している)。
だから素朴に吸い寄せると、**浴室がトイレの断片を吸った**。
別の室を 1 つにしてしまうのは、割れたままより悪い。

そこで「**吸い寄せてよいのは、ほかの名前付きの面に接していない面だけ**」
という条件を足した。これで誤った併合は止まったが、
**造作で割れた断片は必ず隣の室にも接している**ので、
**寄せ直しは 1 件も起きなくなった**(造作の条件で「確かめが要る」0 件)。

つまりこの案は、**安全にすると何もしなくなり、働かせると別の室を壊す。**
中間が無い。

|---|---|---|---|
| きれいな図面 | 0.000 / 0.000 | 0.000 / 0.000 | 0 |
| **壁に接する造作(この案の対象)** | 0.152 / 0.937 | **0.152 / 0.937(変わらない)** | **0** |
| 壁を 2 本線で描いた図面 | 0.147 / 0.319 | 0.004 / 0.013 | 7 |

## 気づいたこと(**未検証。次の周で確かめる**)

壁を 2 本線で描いた条件では、寄せ直すと誤差が 0.147 → **0.004** に落ちた。
室の内法に壁の中身を足すと、**ほぼ芯々の面積になる**からである。

**これはこの案の目的ではなく、たまたま出た結果である。**
合成図面の描き方に依存している可能性が高いので、
**この 1 回の結果を根拠に何かを作らない。**

ただし筋は通っている。もし確かめられれば、
**同じ図面から内法と芯々の両方を出せる**ことになり、
A-2 の判断待ち(内法か芯々か)に対して「どちらでも出せます」と答えられる。
次の周で、**壁の中身だけを足す**(名前の無い面を無差別に足すのではなく)
形で作り直して確かめる。

## 次に試すこと(この案の代わり)

**仕上表の部屋一覧と図面の部屋を突き合わせる**(05 の対応表の候補 4)。

図形だけで壁と造作を区別しようとする今回の行き詰まりを回らずに済む。
