## 対照

| 対照 | 結果 |
|---|---|
| 1 読みが正しいときの突き返し | **0 件**(4 シナリオとも) |
| 2 ずらしが効いた組があるか | **はい**(7 組) |
| 3 反復 3 回 | **6・6・6** |
| 4(記録だけ)数えた組 ÷ 試した組 | **7 / 15 = 0.47** |

**対照4 の意味**: **試した 15 組のうち 8 組は「ずらせていない」ので捨てた。**
等式で縛られている変数は、自分の読みをずらしても候補が動かないためである
(59 周目に見つけた形)。**だから「6 / 7」は、ずらしが効く場所に限った話である。**
**「15 組中 6 組」ではない。どちらの分母で読むかで印象が変わるので、両方書く。**
