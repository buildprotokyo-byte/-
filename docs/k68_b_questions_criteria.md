## 周 2 状態・有無・まとめ方・科目を、固定の選択肢+「どれでもない」にする

**変えること。** 型が `工事の有無`・`状態`・`まとめ方`、と新しい型 `どの科目か` のカードは、
**AI が書いた選択肢を使わず、型ごとに決めた固定の選択肢+「どれでもない」だけにする。**
(固定の選択肢は測る前にここで決める)

| 型 | 固定の選択肢(この順。最後に「どれでもない」) |
|---|---|
| `工事の有無` | ある / ない / 別の行に含む / 別途 |
| `状態` | 撤去 / 新設 / 改修(既存を活かす) / 既存のまま(工事しない) |
| `まとめ方` | 1 行にまとめる / 分けて数える |
| `どの科目か` | 仮設 / 撤去 / 木工事 / 内装 / 塗装 / 建具 / 金属 / タイル / 家具・器具 / 機械設備 / 電気設備 / 雑(`draft/prompts/工事概略.txt` の 12 科目) |

- `どの科目か` は、決められなかった所の項目で **科目が未確定** のときに付ける(室が未確定なら
  室を先に聞く)。この型は連鎖を辿らない(`科目` の辺を辿ると「1 問で全部決まる」嘘が出る。K-65 追記 1)。
- 「読めなかった所」の問いは、`draft/stages.py` が決めた閉じた選択肢(`UNREADABLE_OPTIONS`)を
  そのまま使う(これも固定の選択肢)。抜き取り・枠の問いは `工事の有無` の固定の選択肢にそろえる。
- 答えは機械が下書きに戻す(`draft/answers_io.apply`)。「ない」「別の行に含む」「別途」
  「既存のまま」は項目を内訳から外す印を付ける(消さない。外した理由を残す)。
  「どれでもない」は何も決めない(K-64 の「分からない」と同じ扱い)。

**線(測る前)。**

1. **固定の線**: 4 つの型のカードのうち、選択肢が固定の表と 1 字でも違うものが **0 枚**。
2. **入力の線**: 数字の入力欄・自由記述欄・推奨の表示があるカードが **0 枚**(全部の型)。
3. **戻す線**(合成): 固定の選択肢の 1 つ 1 つを答えたとき、下書きに戻る(または「何も決めない」と
   記録される)。**黙って捨てられる答えが 0 件。**
4. **自動確定 0**: 答えを戻しても、`機械の検算` の自動確定は 0 のまま(K-61 が保存した 5 版で数える)。
5. 型ごとのカードの数を K-65 と並べる(線は置かない。**数を増やす話ではない**ので、
   カードの数は大きく動かないはず。動いたら理由を書く)。

## 周 3 数量の型: 3 回の値・機械の値・縮尺で換算した値を候補にする

**変えること。** 型が `数量` のカードの選択肢を、次の出どころの値から作る(**数字は打たせない**。
値は小さい順に並べ、どれが機械の推しかは書かない。出どころはカードの別の欄 `数量の出どころ` に書く)。

| 出どころ | 中身 | K-65 |
|---|---|---|
| 同じものの値 | 同じ回で `同じもの` と結ばれた項目の数量 | あった |
| 3 回の値 | ほかの回で旧の鍵 `(工事, 室, 部位, 品番)` が同じ項目の数量 | あった |
| 3 回の値(K-66 の鍵) | ほかの回で K-66 の鍵(`agreement_key`)が同じ項目の数量。**その鍵の行が、この回にも、ほかの回にも 1 行だけのときに限る**(粗い鍵で別の行の値を拾わないため) | 無い |
| 機械の値 | K-61 が保存した機械の検算の「機械は ◯(埋めていない)」(その項目を含む内訳の行)。**機械を動かし直さない**(保存した出力だけ) | 無い |
| 縮尺で換算した値 | `draft.flags.scale_length`(PDF の線と縮尺だけ。床・天井の面積、幅木の周長)。**縮尺が読めない・食い違うページ、値が 1 つに決まらない室は使わない**(flags の決まりのまま) | 無い |

- 数量が無い値(未取得)からは選択肢を作らない(**0 を作らない**)。単位が項目と違う値は使わない。
- 答えは機械が下書きに戻す(`draft/answers_io.apply`): 値を選ぶと、その項目の数量と単位をその値にし、
  根拠「人の回答」(K-64 周 4 の決め方)。「どれでもない」は何も決めない。
  **周 2 までは、K-64 の口に渡した答えが選択肢に無い文字だと黙って捨てられていた**(`stages.apply_answers` は
  AI の選択肢に無い文字を受け取らない)ので、渡して戻らなかった答えも `戻せなかった答え` に数える。

**線(測る前)。**

1. **作れる割合の線**: 型が `数量` に決まった問い(捨てる前)のうち、選択肢の値が 1 つ以上ある問いの割合
   (`値のある問い ÷ 数量の型の問い` を和と並べる)。**新が全部あり版 3 版それぞれで 20% 以上、かつ 5 版
   すべてで旧(K-65 の作り方、同じ問いの集まりで測り直す)を下回らない。**どれか 1 つでも割れば不合格。
2. 出どころごとの値の数、数量が無い項目全部のうち候補の値が 1 つ以上ある項目の数(和と並べる)を書く
   (線は置かない)。縮尺が決まったページの数も書く。
3. **捏造の線**: 選択肢の値のうち、出どころ(回・行・ページ)を辿れないものが **0**。数量が無いところから
   作った値(0 を含む)が **0**。
4. **入力の線**: 数字の入力欄・自由記述・推奨のある `数量` のカードが **0 枚**。
5. **戻す線**: 聞く `数量` のカードと、聞くカード全部の 1 つ目の答えを戻したとき、**黙って捨てた答えが 0 件**
   (K-64 の口に渡して戻らなかった答えも数える)。合成のテストで、値を答えると数量と単位がその値になること、
   「どれでもない」は何も決めないことを確かめる。
6. **自動確定 0**: 答えを戻しても `機械の検算` の自動確定は 0 のまま。
