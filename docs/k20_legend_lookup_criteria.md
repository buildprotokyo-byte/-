# 【測る前に決めた基準】凡例を対照表にして、記号と線種を照合する(K-20)

作成日: 2026年9月24日
依頼: おーちゃん [K-20]
**この文書は実装より先にコミットする。測ったあとで基準を書き換えない。**

---

## 0. 何をするのか

**凡例を「読ませる」のをやめて、「照合させる」。**

11 周目・12 周目は、凡例のページを見て「名前 ↔ 図形」を**作らせた**。
その結果、1 つの名前に最大 474 通りの形が付いた(`docs/a1_legend_region_report.md`、
`docs/a1_legend_one_per_row_report.md`)。**原因は K-12 で分かっている。**
名前を付ける相手が「記号 1 個」ではなく「線や円弧の 1 本 1 本」だった。

この周は向きを変える。

1. 凡例の中身を**対照表**(引き当て表)にする。**表そのものは共有フォルダに置き、
   リポジトリには入れない**(実図面から取った文字のため)。
2. 図面の中のものを、その対照表に**引き当てる**。
3. **引き当たらなかったものは「不明」として出す。名前を推測しない。**

**捏造は「作らせない」ことで止める。** 引き当ては、対照表にある値を返すだけなので、
表に無い名前は原理的に出てこない。**それを測って示す**のがこの周である。

## 1. 照合の経路は 2 本

| 経路 | 図面の側の手がかり | 対照表の側の鍵 |
|---|---|---|
| **文字の記号** | 図面に印字された短い語(`WPE` `2E` `専` など) | 凡例の記号の欄 |
| **線の種類** | 線・塗りの**色**(と線幅) | 凡例が自分で名乗っている色 |

**どちらも完全一致の引き当てにする。** 部分一致・あいまい一致は入れない。
入れた瞬間に「それらしい名前」が出て、11 周目と同じ壊れ方をする。

**線の色を鍵にするのは、凡例のページが色の意味を自分で書いているからである。**
色の値は凡例から読む。**こちらで「赤はふつう撤去だろう」と決めない。**

## 2. 測る指標

対象は P011 匿名化v2。**パスは引数で渡す。図面はリポジトリに入れない。
対照表の中身も書かない。**

| 記号 | 指標 |
|---|---|
| M1 | 対照表に入った件数(記号 / 線種、それぞれ) |
| M2 | 照合できた件数 / 図面の中の図形(と語)の総数 |
| M3 | 名前が付いた件数 |
| M4 | **捏造(対照表に無い名前を出した)件数** |
| M5 | 「不明」として出た件数 |
| M6 | 線種から撤去・新設・既存が取れた件数 |

## 3. 先に決めておく採否の基準

**採用**: 次を全部満たす。

- **A1 M4(捏造)が 0 件。1 件でもあれば不採用。**
- **A2 M5(不明)が 0 件でない。** 全部に名前が付くのは、引き当てが緩すぎる印である。
- **A3 M3(名前が付いた件数)が 12 周目の 6 件を上回る。**
- **A4 M6(線種から取れた工事の区分)が 0 件でない。**
- **A5 自動確定が 1 件も増えない。** この部品は本番の入口に繋がない。繋いでいないことを
  呼び出しの数で確かめる。
- A6 全件テストが通る。

**保留**: A1・A5 は満たすが A3 か A4 が外れた。**数字をそのまま報告する。**

**不採用**: A1 か A5 が外れた。**その場で止めて報告する。**

**外れたときに表のほうを合わせに行かない。** 外れたことと外れ方をそのまま書く。

## 4. 対照(先に走らせる)

| 記号 | 対照 | 通る条件 |
|---|---|---|
| C1 | 同じページを 3 回 | 件数が同じ |
| C2 | **入れ替え**: 電気の対照表で意匠の図面を照合 | 電気の記号はほとんど当たらない |
| C3 | **対照表を空にする** | 名前 0 件・全部が不明。照合が表に依存していることの確認 |
| C4 | **壊し試験**: 引き当てを部分一致に緩める | **捏造が出て、テストが落ちる** |
| C5 | 対照表に無い記号を入れた合成の図面 | その記号が「不明」に出る |

C3 と C4 がこの周の要である。**C4 が落ちないなら、捏造を止めているのは
引き当ての厳しさではない**ということなので、そのときは採用しない。

## 5. やらないこと(K-20 の指示)

数量を出さない。見積の行を立てない。部屋の範囲を取らない。
波及・施工順序・図面を読む順番の知識に触らない。数え方の知識 26 件の採否をしない。
**判定のしかたを変えない。変える必要が出たら飛ばして次へ行き、報告に書く。**

## 6. 置き場所

| もの | 置き場所 |
|---|---|
| 対照表の中身(記号の名前・意味・色の値) | **共有フォルダのみ。** リポジトリにも記憶にも入れない |
| 対照表を作る道具・引き当てる仕組み | リポジトリ |
| テスト | リポジトリ。**合成データのみ** |
| 報告書 | リポジトリ。**件数だけ。** 中身は書かない |

## 追記 3(2026年9月24日 02:05、測る前に書く)

### 何を測るのか: **対照表の取りこぼし(M8)**

報告書 1 節に「写していない行もある」と書いたが、**何行あるのかを数えていない。**
分母が無いまま「66 件写した」とだけ書くのは、**取りこぼしを見えなくする書き方**である。
そこで、凡例のページ(6・22)にある罫線の表の行を数え、写した行と突き合わせる。

**分母**: `axes/image_axis/pdf_tables.find_tables()` が凡例の 2 ページから取り出した
罫線の表の**行**。罫線が無い並びは分母に入れない(拾えないので)。

**行を 5 つに分ける**:

| 区分 | 意味 |
|---|---|
| **写した** | その行の文字が対照表に入っている |
| **図形だけ** | 記号の升目に文字が無い(丸・四角・線だけで描かれている) |
| **見出しの行** | `名称` `記号` `内容` のような列の名前 |
| **注記の行** | 「※」「〜の場合」など、記号と内容の対ではない文 |
| **写し漏れ** | **上のどれでもないのに写っていない** |

### 先に決める採否

- **「写し漏れ」が 1 行でもあれば、写す道具を直す。**これは取りこぼしなので直す対象。
- **「図形だけ」は直さない。**文字で引き当てる道では原理的に取れない。
  **数だけ出して、報告書の「効かなかったこと」に書く。**
- **数が思ったより悪くても、分母の取り方を後から変えない。**
  罫線の表が凡例の並びを取り切れていないなら、**それ自体を結果として書く**
  (「凡例の 3 つの表のうち 1 つしか罫線で組まれていなかった」なども結果である)。

### 対照

| 記号 | 対照 | 通る条件 |
|---|---|---|
| **C8** | 罫線の表の**行の数**を、凡例のページを画に起こして目で数えた数と比べる | **ずれが無い。**ずれるなら、分母が信用できないので**割合を書かない**(件数だけ書く) |
| C9 | 凡例ではない普通のページ(平面図)に同じ数え方を掛ける | 凡例の表が出てこない(このページには無いので) |

**この測定で判定のしかたは変えない。**対照表に行が増えれば照合の件数は動くが、
**階層の条件・許容差・群合計・質問の選び方には触らない。**

## 追記 4(2026年9月24日 02:30、測る前に書く)

### **対照表の行のうち、図面で 1 回でも当たった行はいくつか(M9)**

いままで数えていたのは「図面の語のうち名前が付いた数」(M3)だけで、
**対照表の側から見た数を数えていない。**66 件写しても、当たっているのが数件なら、
**対照表の大きさは成果ではない。**

数えるのは 2 つだけ。

| | |
|---|---|
| **当たった行** | その行の記号が、図面のどこかに 1 回以上出た |
| **0 件の行** | 1 回も出なかった |

**0 件の行は、当たらない理由で分ける**(推し量りではなく、記号の書き方だけで決まる):

| 理由 | 見分け方 |
|---|---|
| **完全一致しようがない形** | 記号の中に空白がある、または括弧の中が空欄(図面では数や機種名が入る) |
| **仮の判断で落ちた形** | 1 文字、または数字だけ(`docs/provisional_decisions.md` 3 番) |
| **1 つに決まらない** | 同じ記号が対照表の中で 2 つ以上の名前に繋がる |
| **図面に出なかった** | 上のどれでもないのに 0 件 |

### **これは数えるだけで、採否は無い**

**この数字で何かを採る・落とすという判断は先に持っていない。**
悪い数が出ても対照表を削らないし、数え方も変えない。**そのまま報告書に載せる。**
「対照表に 70 件入った」という数を、**当たった数と並べて書くため**に数える。

## 追記 5(2026年9月24日 02:40、測る前に書く)

### **1 文字の記号を「記号の塊の上にあるか」で分けられるか(M10)**

いまいちばん効いているのは**仮の判断**で、記号の文字が図面に出ている 32 行のうち
**26 行がそれで黙っている**(2-1 節)。仮の判断の中身は「1 文字と数字だけの記号は、
寸法や室番号と見分けが付かないので落とす」である。**これは文字だけを見た線引きで、
当たっているかどうかは確かめていない。**

**確かめる道がある。**記号は線で描かれた絵の上に刷られ、寸法や室番号は絵の上に無い。
**その 1 文字が、記号くらいの大きさの線の塊の上にあるかどうか**を見れば、
文字の形を見ずに分けられる。下調べでは、電気位置図の 2 ページに
**記号くらいの大きさの塊が 248 個**ある(いま名前が付いている設備の記号は 40 件)。

### 数えること

| | |
|---|---|
| M10-1 | いま名前が付いている設備の記号のうち、**塊の上にあった件数** |
| M10-2 | 仮の判断で落ちている 1 文字・数字だけの語のうち、**塊の上にあった件数** |
| M10-3 | 同じ語のうち、**塊の上に無かった件数**(寸法や室番号のはず) |

### 先に決める採否

| 記号 | 通る条件 |
|---|---|
| **A10** | **いま名前が付いている 40 件が、この条件で落ちない**(9 割以上残る)。落ちるなら条件が厳しすぎて使えない |
| **C10** | **1 文字の語が、塊の上にあるものと無いものに分かれる。**全部が塊の上なら、条件は何も見ていない |
| **C11** | **塊の位置をわざと 50pt ずらして**同じ判定をすると、採られる件数がはっきり減る。減らないなら位置を見ていない(10 周目・12 周目・形の重なりと同じ失敗) |

**A10 と C11 の両方が通ったときだけ、9 節 1 番の「選べる案」として報告に足す。**
**既定にはしない。**仮の判断を採るか外すかはおーちゃんの判断待ちであって、
こちらで差し替えない。**通らなかったら、通らなかったことを数字で書いて終わりにする。**

### 追記 5 の続き(1 回目は落ちた。作り直しを 1 回だけ許す)

**1 回目の測定は A10 に落ちた。**いま名前が付いている 40 件のうち、
記号くらいの大きさ(3〜25pt)の塊に触れていたのは **5 件**だけだった
(**9 割どころか 1 割強**)。C11(塊を 50pt ずらす)は通っている
(20 件 → 2 件)ので、**位置は見ている。落ちたのは塊の作り方である。**

**切り分けた**: いま名前が付く語 36 件が触れている塊は、**36 件とも幅 200pt 以上**だった。
**記号は配線の線に繋がっているので、繋がりで塊を作ると配線の網ごと 1 つになる。**
大きさで絞る条件が、記号ではなく配線の網を見て落としている。

**これは測定の作りの欠陥であって、図面について分かったことではない。**
そこで、**作り直しを 1 回だけ許す**。直すのは 1 か所だけ:
**長い線(配線)を塊に入れない**(それ自体が細長い図形を先に除く)。

**A10・C10・C11 の通る条件は 1 文字も変えない。**
**作り直して 1 回測り、それでも A10 に落ちたら、落ちたことを数字で書いて終わりにする。**
**2 回目の作り直しはしない。**(ここで作り直しを重ねると、通るまで作り直したのと
同じことになる。10 周目・12 周目が踏んだ形である。)

## 追記 6(2026年9月24日 03:00、測る前に書く)

### **記号 1 個について、色と改装種別の印は同じことを言うか(M11)**

凡例は工事の区分を **2 通り**で書いている。**色**(赤=交換・新設 / 青=既存移設・脱着 /
黒=既存のまま)と、**改装種別の印**(`交` `脱` `移` の文字)である。
いまは別々に数えている(色から 33/2/5、印から 45 件)。**同じ記号 1 個について
2 つが何を言っているのかは、突き合わせていない。**

### 数えること

記号 1 個(名前が付いた設備の記号の 1 つ 1 つ)について、次の 2 つを並べる。

| | |
|---|---|
| **その記号が刷られている色の意味** | 赤・青・黒のどれか(凡例が自分で書いた意味) |
| **いちばん近い改装種別の印** | `交` `脱` `移` のどれか。近くに 1 つも無ければ「印が無い」 |

出すのは**その組み合わせの表だけ**である。

### **こちらで意味を繋がない**

**`交` が赤に当たるはず、といった対応表をこちらで作らない。**
凡例は**その対応を書いていない**(しかも改装種別の表は `撤去` を赤で刷っているのに、
色の表の赤には撤去が無い。凡例自身が食い違っている)。
**こちらで辻褄を合わせると、図面が言っていないことを言わせることになる。**
**組み合わせの表をそのまま出して、読むのはおーちゃんに任せる。**

### 対照

| 記号 | 対照 | 通る条件 |
|---|---|---|
| **C12** | 改装種別の印の**位置だけを入れ替えて**(同じページの印どうしで)同じ表を作る | **表の形がはっきり崩れる。**崩れないなら、近さを見ていない |

**この数字での採否は無い。**悪い表が出ても何も落とさないし、近さの決め方も変えない。
**そのまま報告書に載せる。**
