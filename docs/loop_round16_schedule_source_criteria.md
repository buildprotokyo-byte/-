# 周16(出典を変える。仕上表から室を取る)の基準

**測る前に決めてコミットする。結果を見てから、ここは書き換えない。**

## 前の周と何が違うか(**これが書けないなら別の周ではない**)

**周11〜周15 は、技術を 5 通り変えた。出典は 5 通りとも同じ**——
この PDF の**線の図形データ 1 つ**だった。**今回は出典を変える。**
線ではなく**内装仕上表の文字**から「どの室があるか」を取る。

**変えるのは出典ひとつだけ。**紙(P011 匿名化 v2)も種(20260925)も
区分の語の表も、周14・周15 と同じものを使う。

## なぜこれを測るのか

おーちゃんの決まり④「**同じ対象に技術 3 つ・出典 3 つ当てて増えなければ
頭打ち**」。**技術の側は 5 通りで頭打ちになった。出典の側は 0 通りだった。**

`axes/image_axis/schedule_tables.py` に `read_finish_schedules()` があり、
`FinishSchedule.rooms()` は**出てきた室名を出た順に返す**。
**これはコードを読んで確かめた**(記録を信じない、取り決め①)。
**ただし本番の経路から室名の一覧として呼ばれているかは、この周で数える。**

## 何に触らないか

**判定には触らない。数えるだけ。**`read_finish_schedules` にも
`find_room_outlines` にも手を入れない。本番の経路には繋がない(K-29)。
自動確定は 0 件のまま。

## 測るもの

P011 匿名化 v2 の **34 ページ全部**に `read_finish_schedules()` を当て、
取れた室名を数える。**室名そのものはリポジトリに書かない**
(共有フォルダの `reports/周16_仕上表から室を取る.json` にだけ置く)。

## 囮

**この周の囮は、周14・周15 とは別の作りになる。**位置をばらすのではなく、
**列を取り違えたときに同じだけ取れるか**を見る。

- **囮A(列の取り違え)** … 同じ表の、**室名の列ではない列**から同じ行数だけ
  文字を取り、そのうち区分の語に当たるものを数える。
  **表から室名が取れているのか、どの列でも同じだけ取れるのかを分ける。**
- **囮B(突き合わせ)** … 平面図の文字から**でたらめに同じ数だけ**選び、
  仕上表の室名と一致するものを数える。

**どちらも値そのもので比べる。増え方では比べない。**

## 線(3 本)

### 線1 — 仕上表から室名が取れるか

**取れた室名の数**(重複を除く)を数える。囮A と比べる。

- **通過**: 本物が囮A を **5 個以上**上回る
- **不通過**: 差が 5 個未満

**なぜ 5 個か**: 周14 の線2 が差 1 個で形の上は通過し、それを根拠に
できなかった。**周15 と同じ幅を使う。**

### 線2 — 仕上表の室名は、平面図にも印字されているか

仕上表から取れた室名のうち、**平面図のページ(天井高の注記がある 5 ページ)の
文字と一致するもの**を数える。囮B と比べる。

- **通過**: 本物が囮B を **5 個以上**上回る
- **不通過**: 差が 5 個未満

**通っても「独立した 2 つ目の根拠」にはならない。**同じ 1 つの PDF から
来ているので、K-08 の決まり(同じ出典は 1 つに畳む)にそのまま当たる。
**この線が見ているのは「同じ室を 2 通りの読み方で指せるか」だけ。**

### 線3 — 落とした行に室名が隠れていないか(**守りの線**)

`skipped_rows` に入った行の文字のうち、**区分の語に当たるもの**を数える。

- **但し書きが要る**: 落とした行の室名が、読めた行の室名の **2 割以上**
- **但し書きは要らない**: 2 割未満

**2 割以上だったときは、線1 の結論に「読めた件数だけでは語れない」と
書く。**「読めた行」だけを見て件数を語らない(この案件の落とし穴)。

## 先に書いておく落とし穴

1. **`read_finish_schedules` が 0 件を返すことは十分ありうる。**
   見出しの語が揃わない表は仕上表と名乗らない作りになっている。
   **0 件は「仕上表が無い」ではなく「この見出しの表では当たらなかった」。**
   建具表が実図面で 0 件だったのと同じ落ち方をしうる
   (`jidou-sekisan-door-schedule-zero`: しきいを下げても 0 は 1 にならない)。
2. **0 件だったときに、しきいや見出しの語をその場で足さない。**
   足すなら**次の周の基準として先に書いてから**当てる。
3. **`schedule_tables.py` の冒頭に「室の輪郭を取る実装がこのリポジトリに
   無い」と書いてあるが、これは古い**(`pdf_room_outlines.py` がある)。
   **記録ではなくコードを読んで確かめた。**この周では直さない
   (文言の直しは別の変更として出す)。
4. **34 ページに表の読み取りを掛けるので時間がかかる。**
   **30 分を超えたらこちらでは測らず、Codex 側へ回す**(恒常ルール)。
