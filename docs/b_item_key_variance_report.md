## 判定

**4 つとも保留(N0 は不採用)。** 採用の条件は「A1 が N0 より大きい かつ A2 = 0 かつ A3 = 0」で、
**A3 がどれも 1 件ある。**

## A3 の 1 件は、揃え方の欠陥ではなかった(**指標の設計を間違えた**)

**A3 は N0(何も揃えない)でも 1 件出る。** つまりこの 1 件は、
揃え方が作った偽の一致ではない。

中身はこれである。

> **「ビニル幅木撤去」から「撤去」を落とすと「ビニル幅木」になり、
> 「ビニル幅木」は内訳書標準書式に**別の行として実在する**(J 節 3 の改修(新設)側)。

**基準の品目名そのものが、接尾語を落とすと衝突する。**

したがって **A3 は「揃え方の良し悪し」を見分けられない指標だった。**
4 つの候補すべてで同じ 1 件が出るので、候補の順位を何も変えない。
**設計を間違えたのはこちらである。**

**基準の文字どおりに判定し、保留のままにした。** 気づいたあとで A3 を外したり、
条件を「A3 ≦ 1」に書き換えたりしていない。
33 周目に、**揃え方を見分けられる罠に作り直す。**

## いちばん大きい数字: 語順を無視すると 0.395 → 0.952

**ゆれの大半は「括弧の位置と語順」だった。** T2・T3(先頭の語を括弧に入れて末尾へ回す)
が 124 通り中 69 通りを占め、**N1・N2 はここを 1 つも拾えず、N3 は全部拾う。**

これは PR #72 が挙げた例(「埋込コンセント」と「コンセント(埋込)」)そのものの形である。

## **A2 = 0 は、安全の証明ではない**(ここは正直に書く)

測る前に「N3 がいちばん危ない」と書いた。**結果は A2 = 0 で、危なくなかった。**
しかし**この 0 を「N3 は安全だ」と読んではいけない。**

- **35 品目は、長くて特徴的すぎる。** 文字の多重集合がほぼ一意になる。
  実案件の見積は行がもっと多く、もっと似た名前が並ぶ。
- **対照 2 も役に立たなかった。** でたらめな 35 個でも偽の一致は 10 回とも 0 だった。
  **つまりこの対照は「衝突の起きやすさ」を測れていない。**
  0 と 0 を比べても、何も言えない。

**A2 = 0 が意味するのは「35 品目では衝突しなかった」だけである。**

## T4(送り仮名)は、どの揃え方でも 0 / 6

「床タイル張り」と「床タイル張」は、**4 つの揃え方すべてで別の鍵になる。**
送り仮名の扱いは誰も手当てしていない。**数は小さいが、穴は穴である。**

## 次の周(33 周目)

この周で分かった、**測り方の穴 3 つを先に直す。**

1. **A3 を作り直す。** 揃え方を見分けられる罠にする
   (N0 では衝突せず、強く揃えると衝突する対を作る)。
2. **A2 を意味のある大きさで測る。** 35 品目では足りない。
   内訳書標準書式の品目をもっと集めるか、**短くて似た鍵**を機械的に作って、
   **N3 がどこで壊れるかを数で出す。**
3. **対照 2 を作り直す。** でたらめな文字列では衝突の起きやすさを測れない。
   **本物の品目名と同じ文字を使い、並べ替えたものを使う。**

そのうえで、A1 は N3、A2 は別の候補、という**分かれた結果になった場合にどうするか**も
基準に先に書く(**向きで分ける**: 人へ回す向きでは広く揃え、黙って確定させる向きでは狭く揃える)。
