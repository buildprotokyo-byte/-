## 測るもの

実図面(匿名化 v2)に、`main` にある経路を全部当てて、**何が出て、何が重なるか**を数える。

| 経路 | どこから読むか | 実装 |
|---|---|---|
| **P1 建具表** | 罫線の表 | `schedule_tables.read_door_schedules` |
| **P2 内装仕上表** | 罫線の表 | `schedule_tables.read_finish_schedules` |
| **P3 開き戸の円弧** | ベクトルの曲線 | `pdf_vector_symbols.find_door_arcs` |
| **P4 面積の記載** | 文字 | `pdf_vector_symbols.find_area_labels` |
| **P5 縮尺の印字** | 文字 | `pdf_vector_symbols.extract_scale` |

| 記号 | 何を測るか |
|---|---|
| **D1** | 経路ごとの出力件数と、取れたページ数 |
| **D2** | **折れている経路の数**(0 件しか出ない経路) |
| **D3** | 経路が作る鍵の重なり。**34 周目の `item_keys` を使い、狭い向きと広い向きの両方で数える** |
| **D4** | **独立したデータ源の数。** すべて同じ PDF から来ているなら、一致は独立した証言にならない |
| **D5** | 1 本の経路にしか出てこないもの(片方にしか無いもの)の件数 |

## 何を確かめたいのか(**先に書く**)

**合成した案件では 5 経路が重ならず、合わせて 18 / 18 だった。**
実図面でも同じ形になるのか、それとも**そもそも経路が動かないのか**を分ける。

**見込み**(測る前に書く。外れたらそのまま外れたと書く):

1. **D2 は 1 以上になる。** 29 周目に建具表が 0 件だと分かっているため。
2. **D4 はすべて 1 になる。** 5 経路とも同じ PDF から読むので、
   **一致しても独立した証言にはならない。**
3. **D3 の重なりはほとんど無い。** 建具・仕上・面積・縮尺は別の種類のものを出すので、
   そもそも同じ鍵にならない。

**3 が当たるなら、実図面では「突き合わせ」より前に「経路を増やすこと」が要る**
という話になる。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 同じ PDF を 2 回読んで突き合わせる | 全件が一致し、**独立したデータ源は 1** |
| **2** | わざと違う値にした写しと突き合わせる | 食い違いとして出る |
| **3** | 反復 3 回 | 3 回とも同じ |

## 採否(**この周は「測るだけ」なので、採否ではなく結論の形で書く**)

- **D2 = 0 かつ D3 の重なりがある** → 実図面でも突き合わせが効く。次は値の食い違いを見る。
- **D2 ≧ 1 または D3 の重なりが無い** → **実図面では突き合わせの前に経路が足りない。**
  どの経路が折れているかを名指しで書き、**次の周はそこを直す。**

## この周で変えないもの

- **実装には手を入れない。** 測るだけ。
- 判定のしかた・基準値・階層の条件にも触れない。
- 実図面のパスは引数で渡す。**出すのは件数と割合とページ番号だけ。**
  室名・寸法・数量・事務所名は 1 文字も出さない。
