# 測定の手順書(Codex-A 向け)

2026-09-23 の役割の整理で、**実図面・実見積を使った測定は Codex-A が行う**ことになった。
**この文書は、こちら(クラウド側)が用意した測り方を、そのまま回せるようにするためのもの。**

---

## 1. 先に守ること(これを外すと、出た数字が使えない)

1. **採否の基準を、測る前に書いてコミットする。**
   `docs/d_<名前>_criteria.md` に、**何を数えるか・線をどこに引くか・
   結果ごとに何をするか**を書く。**結果を見てから基準を変えない。**
2. **対照(コントロール)を必ず置く。**
   「測り方が壊れていたら 0 が出る」測定は、0 が出ても何も言えない。
   **既知の数字が再現することを、同じ経路で確かめる。**
3. **別の経路の数字どうしを比べない。**
   62 周目に、読み取りの関数を直接当てた数字(90 件)と、本番の入口が出した数字(5 件)を
   比べて止まった。**同じ入口・同じ前提・同じファイルで比べる。**
4. **実図面・実見積・そこから作ったデータはコミットしない。**
   パスは引数で渡す。**図面の中身(室名・寸法・数量・事務所名)は報告にも書かない。**
   件数・割合・手法の名前だけを出す。
5. **うまくいかなかった結果もそのまま報告する。** 効かなかった記録も残す。

## 2. いま用意してある測り方

すべて `.venv/bin/python benchmarks/<名前>.py` で動く。**出力は JSON。**

| 測り方 | 何が分かるか | 引数 |
|---|---|---|
| `measure_second_case_intake.py` | 本番の入口に図面を通すと、手法ごと・階層ごとに何件出るか | `--second <図面>` `--control <P011v2>` |
| `measure_declaration_effect.py` | **人が「平面図」と宣言するかどうかで、出てくる数がどれだけ変わるか** | `--control <P011v2>` `--second <図面>` |
| `measure_question_path_in_production.py` | 問いの経路が本番から呼ばれているか | `[実図面]` |
| `measure_line_attribution.py` | 見積の行から「何が効いたか」を辿れるか | なし(合成) |
| `measure_knowledge_format_coverage.py` | 知識の表の形式が候補を受け取れるか | なし |

**`measure_declaration_effect.py` は、こちらでは時間切れで最後まで回せていない。**
A3 の図面 2 冊に対して入口を 4 回通すので重い。**Codex-A の環境で回してほしい。**
基準は `docs/d_declaration_effect_criteria.md` に**すでにコミットしてある。**
対照(P011v2 に前提なしで当てたとき 62 周目と同じ数になること)が通らなければ、
**数字を出さずに止めること。**

## 3. 手順(1 回分)

```
# 1. 基準を書いてコミットする(測る前)
#    docs/d_<名前>_criteria.md

# 2. 測る
.venv/bin/python benchmarks/<測り方>.py --second <図面のパス> --control <P011v2のパス>

# 3. 対照を見る
#    "C1_通過": false なら、そこで止める。数字は出さない。

# 4. 報告を書く
#    docs/d_<名前>_report.md と docs/d_<名前>_result.json
```

## 4. 報告に書くこと

- **測った数字を 1 つ。**(1 周で変えるのは 1 つ、出す数字も 1 つ)
- **対照が通ったかどうか。**
- **測れていないこと。**(何が言えて、何が言えないか)
- **使ったコミット。**

## 5. いま止まっている測定(引き継ぎ)

**2 件目の案件を本番の入口に通す測定**は、62 周目で対照が通らず止まっている。
止めたときに見えたのはこれである。

> **読み取りの関数が 90 件見つけられるところで、本番の入口は 5 件しか試していない。**

**不具合ではない。**入口は、縮尺が読めたページと人が「平面図」と宣言したページでしか
円弧を試さないからである。**だが「宣言しないとどれだけ減るか」は誰も測っていない。**
それを測るのが `measure_declaration_effect.py` である。
