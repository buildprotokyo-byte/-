## 1. 測る対象

どれも本番と同じ組み方(`AxisQualityFirewall.assess()` →
`killer_question/firewall_bridge.py` → `ConsistencySolver`)で作り、
`GroupTotalConstraint` で群合計を立てる。

### 1-1. 名前つきの場面(設計書 2節・4-1節の表と、テストの場面)

同じ単位の10要素、正解はどれも3、群合計30。`door_0` が停止した要素。

| 名前 | door_0 の読み | 仕込んだ誤り |
|---|---|---|
| N1 誤りなし・停止なし | 強い2軸が 3 で一致 | なし |
| N2 誤りなし・停止(幅広) | (0, 6) | なし |
| N3 誤りなし・停止(幅狭) | (2, 4) | なし |
| N4 誤りなし・強い軸0 | (2, 4) 未校正 + 弱 (1, 9) | なし |
| E1 階層1が −2 | (0, 6) | door_1 = 1 |
| E2 階層1が −2 ×2 | (0, 6) | door_1 = door_2 = 1(設計書では unsat) |
| E3 階層1が +1(死角) | (0, 6) | door_1 = 4 |
| E4 階層1が −2・強い軸0 | (0, 6) 未校正 + 弱 (0, 6) | door_1 = 1 |
| E5 停止した要素の読みがずれ | (2, 10)(中心 6) | door_0 の読みそのもの |
| E6 停止2つ・階層1が −2 ×3 | door_0, door_5 とも (0, 6) | door_1〜3 = 1 |

### 1-2. 格子(117 群)

- 10要素、正解 `[3, 4, 2, 5, 3, 4, 2, 3, 4, 3]`(合計33)
- 停止する要素の数 k ∈ {1, 2, 3}(`door_0`, `door_5`, `door_9` の先頭から k 個)
- 停止した要素の読みの半幅 w ∈ {1, 2, 3}。読みは (正解 − w, 正解 + w)、
  強い軸1つ(校正済み)+ 弱い軸1つ。**階層3 になることを前提として確かめ、
  ならなかった群は数から外して件数を報告する**
- 仕込む誤り(13通り)
  - なし(陰性対照)
  - 階層1の `door_1` の強い2軸が、正解 + d で一致(d ∈ {−3, −2, −1, +1, +2, +3})
  - 停止した `door_0` の読みの中心が、正解 + d にずれる(同じ d。半幅はそのまま、
    下限は0で切る)

3 × 3 × 13 = 117 群。

## 2. 前と後

- **前**: (c) の入口は無い。群合計から立つ問いは 0。あわせて、既存の
  `KillerQuestionEngine.next_question()`(標準モード)がその群に何を聞くかも記録する
  (こちらはこの変更で触っていない)
- **後**: `group_total_question()` が返す問い

## 3. 合否の基準(どれか1つでも外れたら「不合格」と書く)

| # | 基準 | 合格の条件 |
|---|---|---|
| A1 | **陰性対照**: 誤りを仕込んでいない群(N1〜N4 と格子の「なし」27群) | (c) の問い **0件** |
| A2 | 吸収が無い群(`check_group_total` が unsat、または sat で吸収なし) | (c) の問い **0件** |
| A3 | 吸収と判定された群 | 1群につき **ちょうど1問** |
| A4 | 階層・監査の割り当て | `group_total_question()` を呼ぶ前と後で、呼び出し側の solver とエンジン内の solver の中身(範囲・検出用の範囲・`requires_confirmation`・制約名)と、`check_group_total` の結果(`targets_requiring_audit` を含む)が**全群で一致** |
| A5 | UNSAT の安全装置 | unsat の群は、前と後で同じく群全体が `targets_requiring_audit` に入る |

## 4. 合否ではなく、数字で報告するもの(予想を先に書く)

| # | 何を | 予想 |
|---|---|---|
| R1 | 選ばれた要素が、仕込んだ誤りの要素か | 停止した要素の読みがずれた場合(E5 など)は**当たる**。階層1に誤りを仕込んだ場合は**当たらない**(群合計は階層1のどれが誤りかを言えない。選ばれるのは停止した要素) |
| R2 | 正しい値で答えた後の群の状態(unsat で群が止まる / sat で吸収が消える / まだ吸収 / 候補の外で食い違い) | 停止1つなら「まだ吸収」は0。停止が2つ以上なら残ることがある(1問で解けない群) |
| R3 | 階層1に誤りを仕込んだ群で、答えの後も誤りが隠れたままの件数 | 停止が2つ以上の群で出うる |
| R4 | 既存の `next_question()` が同じ群に何を聞くか | 標準モードでは吸収された群に何も聞かない(`None`) |
| R5 | 吸収と判定された群の数(誤りの種類・大きさ別) | 階層1の誤りが ±1 のときは死角(許容差の中)で吸収にならない |
