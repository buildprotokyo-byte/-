# 50周目 基準: **「人の入力は図面と独立している」は、何を根拠に言えているのか**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。49 周目の「次の周」を、より重いほうへ置き換える。

## なぜこの題なのか(**先の周で予告したものより、こちらが重い**)

49 周目の予告は「同じ形が `基準寸法` 以外に無いか」だった。**コードを読んだら、その答えは
すぐ出た**: 人の入力が証拠を作る場所は 1 か所だけ(48 周目に確認済み)なので、
**2 つの鍵を持ちうる対象は `基準寸法` だけである。数えるまでもない。**

**そこで、もっと効く問いに差し替える。** 48 周目の札でおーちゃんに
「**人が数える**」入口を足すか聞いている。**その札の前提そのものを確かめる。**

> **人の入力は、本当に図面と独立したデータ源なのか。**
> **仕組みは、それを確かめているのか。**

**人が図面を見て書き写した値は、図面と独立ではない。** だが仕組みが見ているのは
**入れた値の sha256** である(`start_kit_fingerprint`)。
**値が違えば別の指紋になる。書き写したかどうかは指紋に出ない。**

**もし「書き写しほど通り、独自に測った値ほど落ちる」なら、いまの一致の見方は
独立性を確かめるどころか、逆を選んでいることになる。** それを測る。

## 測るもの

実図面(匿名化 v2)に対して**本番の入口**を回す。**人が入れる値だけを変える。**

| 記号 | 人の入力(基準点 1 つ、同じ 2 点。**長さの申告だけ変える**) |
|---|---|
| **S0** | **書き写し**: 印字された縮尺から逆算した値(= 図面をそのまま写した人) |
| **S1** | **独自 +3%**: 自分で測って少しずれた人(**中心値の許容差の内側**) |
| **S2** | **独自 +10%**: 自分で測ってもっとずれた人(**許容差の外側**) |

| 記号 | 何を測るか |
|---|---|
| **Q1** | 鍵(`independence_key`)を決める入力は何か(**コードから**) |
| **Q2** | **同じ PDF を別の `source_id` で渡すと鍵は分かれるか** |
| **Q3** | **人の入力の値を変えると鍵は変わるか** |
| **Q4** | **S0 と S1・S2 で、鍵に違いが出るか**(= 書き写しを見分けられるか) |
| **Q5** | **反実仮想(全手法 `calibrated=True`)で、S0・S1・S2 の階層1 の件数** |

**出すのは件数と真偽だけ。図面に印字された文字は出さない。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **Q2 = 分かれない** → **資料の出どころは正しく見分けている。** 鍵の作りは悪くない。
- **Q4 = 違いが出ない** → **仕組みは書き写しを見分けられない。**
- **Q5 で S0 が通り、S1 か S2 が落ちる** → **いまの一致の見方は、独立性を確かめるどころか、
  書き写しを選んで通している。**
  そのとき言えるのは**「人の入力を 2 つ目のデータ源として数えてよいかは、仕組みでは決められない」**
  であり、**48 周目の札の読み方が変わる**(技術の選択ではなく、運用の決めになる)。
  **札は取り下げず、この事実を添えて出し直す。**
- **Q5 で S0・S1・S2 が同じ** → **一致の見方は書き写しを優遇していない。** 札はそのままでよい。
- **Q5 で S0 が落ちる** → 見込みが外れているので、**何が落としたのかを名指しする。**

**Q5 の差を「改善」とは絶対に書かない。** これは**危険の測定**である。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | S0 の階層1 | **49 周目と同じ `基準寸法` 1 件** |

**対照1・2 が通らなければ結論を出さない。**
