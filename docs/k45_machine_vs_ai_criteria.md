# K-45: 同じ仕事を機械・AI・両方にやらせて比べる — **測る前の基準**

この文書は**測る前に**コミットする。

## なぜ

K-41 で「AI の通読 50〜53 対 機械 8」と出たのに、その後の実装は機械で進んだ。**どちらがどの場面で強いかを一度も比べていない。**分担(数える・測る/検算/線引き・判定を機械)は想定で、根拠が無い(おーちゃん K-45)。

## 比べる仕事(5 つ)

| | 仕事 | 見るページ | 機械(いまの実装) |
|---|---|---|---|
| T1 | 色つきの注記を読む | 改装平面 | `intake/plan_colour_notes.py`(色の幅で判定) |
| T2 | 撤去の網を面積にする | 既存撤去図 | `intake/demolition_hatch.py`(色・角度・閉じる) |
| T3 | 工事の行かどうかの線引き | (行の文字だけ) | 工事の語の一覧(案 B、「改修」入り) |
| T4 | 電気の器具を数える | 電気位置図+凡例 | 文字の層の改装種別の記号(新・交・移・脱)を種類ごとに数える |
| T5 | 木工の個数を数える(床見切・フック・棚など) | 改装平面+展開図 | 注記の数が印字されていればそれ、無ければ同じ注記の数 |

## 条件(3 つ)

| 条件 | 中身 |
|---|---|
| 機械 | いまの実装をそのまま |
| AI | 同じページを画像(と文字の層)で渡し、同じことを答えさせる。機械の出力は見せない |
| 両方 | 機械の出力を AI に見せ、画像を見て直させる(足す・消す・数を直す) |

- **AI と両方は 3 回ずつ**動かす(揺れを見るため)。機械は 1 回(同じ入力なら同じ出力。念のため 2 回動かして一致を確かめる)。
- AI には見積・正解・採点の資料を見せない。
- かかった時間: 機械はスクリプトの実行時間、AI と両方は 1 回の作業の経過時間。

## 囮

| | 囮 |
|---|---|
| T1 | 同じページの**黒い**文字(各条件で同じやり方で読ませる) |
| T2 | 同じページの**黒い**斜線の網(各条件で同じやり方で測らせる) |
| T3 | 黒い文字の行(K-42(a) の囮の 67 行)。工事の行として通したら囮の通過 |
| T4 | 既存電気位置図(K-41 周 7 と同じ。**この図にも改装の記号があるので弱い囮**と先に書いておく) |
| T5 | この改装に無い造作の品目 3 つを混ぜる(読む役には知らせない)。個数を出したら囮の通過 |

## 物差し(3 条件とも同じ)

1. 正解に当たった件数(伏せた名前で採点する役が結ぶ。`採点の基準.md` §3。T1・T2・T4・T5 はそれぞれ 1 人の採点者が、その仕事の全条件・全回の行をまとめて伏せた名前で結ぶ)
2. 数量が合った件数(個数 ±1、面積 ±5%)
3. 囮との差(当たりの件数 − 同じ条件の囮の当たり)
4. かかった時間
5. 揺れ: AI と両方の 3 回の、当たりと数量一致の最小〜最大

T3 の正解: K-42(a) の 201 行のうち、線引きをせずに採点したとき正解に結ばれる行(当たり・細かく割れた行・まとめ行)を「工事の行であるべき行」とする。線引きで落ちていた 91 行は、線引きなしでもう一度採点する(採点する役 1 人、伏せた名前)。T3 の物差しは、工事の行として通した行のうち「あるべき行」の数・落とした「あるべき行」の数・通した囮の数。

## 「明確に強い」の線

ある仕事で、ある条件が別の条件より**明確に強い**と書くのは、次を全部満たすときだけ:

- 当たりか数量一致の差が 3 件以上
- 囮との差でも同じ向き
- 3 回の範囲が重ならない(弱いほうの最大 < 強いほうの最小)

満たさなければ「差は見えない」と書く。**件数が増えたことを成果にしない。囮と比べる。**

**不通過(明確に強いと言えない)数字の例**: AI 3 回の当たりが 12・15・9、機械が 11 → 範囲が重なるので「差は見えない」。

## 特に答えること(おーちゃんの 3 つ)

- 機械が捨てたものを AI は拾えるか(棚の枚数の注記など): T3 で、機械が落として AI が通した「あるべき行」を数える。
- AI が揺れるものを機械は安定して出せるか: 5 の揺れの幅を並べる。
- どちらか一方が明確に強い場面はあるか: 上の線で判定する。

## 守ること

自動確定は 0 件のまま。人の入力・合成の寸法は使わない。捏造は 0 件のまま(AI の出力の引用・数は機械で確かめる)。数字が動かなくても構わない。
