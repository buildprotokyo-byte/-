# 6 ページの凡例、残りの 13 項目を読んだ(K-22 (d) の続き)

K-22 (d) でおーちゃんが指示したのは「**6 ページの凡例の 14 項目のうち、c から
読んでください**」だった。c(天井高・室名・床高)は `docs/k22_ceiling_height_printed.md`
に書いた。**この文書は残りの 13 項目(d〜p)である。**

**実図面の数値・室名・表題欄の文字はこの文書に書かない。**読み取った中身そのものは
共有フォルダの `reports/K-22_6ページ凡例_dからp.md` に置く。

対象: P011 匿名化v2 の 6 ページ「凡-1 意匠図凡例」(**回転 270 度**)。
この凡例は a〜p の **16 項目**で、そのうち記号の表は 1 つだけである
(残りは**読み方の決まり**)。

## 0. 結論を先に

**13 項目のうち、いまの機械がこの決まりを読んでいるものは 1 つも無い。**

`axes/image_axis/legend_lookup.py` は凡例から写した対照表を引き当てる部品だが、
**`grep` で確かめたところ、試験と測定の道具以外のどこからも呼ばれていない。**
本番の入口はこの凡例を 1 文字も見ていない。

そのうえで、**数量に直に効く決まりが 4 つある。**

| | 何を決めているか | いま効いているか |
|---|---|---|
| **g・h** | 建具の寸法を、**内部は枠外・外部は枠内**で書く。**新設建具は寸法を書かず番号だけ** | **効いていない** |
| **l・p** | **下地の中身**(天井・躯体壁・間仕切壁・床それぞれの組み方)を凡例が定義している | **効いていない** |
| **o** | 意匠・電気・設備に共通する部分は**まとめて 1 か所に表記する** | **効いていない** |
| **d・e・f** | 各室の仕上げ・撤去種別・改装種別を、**層の決まった並び**で書く | **効いていない** |

## 1. g・h — **新設建具は、図面に寸法が書かれていない**

- **g.内部建具ｻｲｽﾞ表記**: 内部建具は**枠外寸法**。既存建具は幅と高さを書く。
  **新設建具は寸法を書かず、建具番号だけを記入する。**
- **h.外部建具ｻｲｽﾞ表記**: 外部建具は**枠内寸法**。幅・高さのほかに、床からの高さと
  枠見附の寸法も書く。インナーサッシの交換・新設は、別の記号と番号で書く。

**これは建具表の話に直に効く。**建具表の読み取りが実図面で 0 件だったことは
`docs/door_schedule_*` に書いたが、**仮に建具表を読めなくても平面図から寸法を拾えば
よい、という逃げ道は無い。新設建具には寸法が書かれていないからである。**
新設建具の寸法は、**建具表を読む以外に取りようがない。**

**内部と外部で枠の内外が逆**なのも効く。取り違えると、建具 1 本あたり枠の見込み分
だけ寸法がずれる。**いまの機械はこの区別を一度もしていない**(`枠外`・`枠内` という語は
コードのどこにも無い)。

## 2. l・p — **下地の中身は、知識ではなく図面が書いている**

- **l.備品、住設の工事範囲**: 備品は枠内に**名称と改装種別**を書き、住設は枠内に
  **改装種別だけ**を書く。そして「**共通撤去範囲**」として、天井・躯体壁・間仕切壁・床
  それぞれの**下地の組み方**を表にしている。
- **p.各表記の範囲の区別**: 床・壁・天井それぞれについて、**どこまでを「下地材」と呼び、
  どこからを別の層と呼ぶか**を図で分けている。

**これは重い。**K-17 で「図面に現れない行」と呼んだもの(下地・野縁・吊木など)の
**中身が、この図面自身に印字されている。**会社のルールや一般的な知識を持ち込まなくても、
**この案件についてだけは、下地が何で組まれるかを図面が宣言している。**

`axes/image_axis/pdf_room_outlines.py` の冒頭には「石膏ボード・天井野縁組はこれまで
1 行も数量の判定に乗っていなかった」と書いてあるが、**その組み方が凡例に書いてある
ことは、そこに書かれていない。**

## 3. o — **まとめて表記されたものを、そのまま 1 件と数えると誤る**

**o.共通事項の表記の仕方**: 意匠・電気・設備に関係なく、**共通している部分は
なるべくまとめて表記する**と宣言している。

**つまり、図面の 1 つの注記が、複数の工種・複数の部屋にかかっていることがある。**
注記を 1 つ拾って 1 件と数えると**足りなくなる**し、かかる先を推し量って割ると
**推し量りが入る。**

**これは「候補の数を数量にしない」(K-23 でおーちゃんが書いた注意)と同じ話である。**
凡例がここで、**数え方の危険を図面自身が予告している。**

## 4. d・e・f — 層の並びが決まっている

- **d.仕上げ**: 既存の仕上材を、**上から天井・壁・床・巾木・廻縁の順**に書く。
- **e.各室撤去種別**: 既存の仕上材に**矢印**を付けて、その層の工事範囲を書き分ける
  (仕上材だけ撤去 / 下地材から撤去 / 既存のまま)。
- **f.各室改装種別**: **仕上材は書かず、改装種別と改装範囲だけ**を書く。

**e と f は、仕上表でやっている区分(撤去して新設 / 下地からやり替え / 既存のまま)を、
平面図の側でも同じ語で書いているということである。**
`estimating/finish_schedule_scope.py` は仕上表の 69 行からこの区分を出しているが、
**平面図側にも同じ区分が書かれていることは使っていない。**

**これは独立した 2 つ目のデータ源になりうる形をしている。**ただし
**同じ PDF の同じ案件なので、いまの独立性の数え方(PDF 1 ファイルごとの指紋)では
1 つに畳まれる。**足す前に、この 2 つを独立と数えてよいかの判断が要る。

## 5. 残り(a・b・i・j・k・m・n)

- **a.ピット範囲** / **b.工事対象外とする部屋** — **この 2 つだけ、解説の欄に文字が
  1 つも無い。**見出しと使用図面の名前のほかは絵だけなので、**文字からは読めない。**
  見出しから言えるのは「**b は数えてはいけない部屋の指定である**」ということまでで、
  **どう表すかは絵を見ないと分からない。**いまの機械は工事対象外の部屋を除く経路を
  持っていない。
- **i.内部の工事範囲** — 矢印線で範囲を指定し、注記に工事内容を書く。
  **建具は「撤去」とだけ注記したら建具と枠の両方、建具だけなら特記する**と決めている。
  **「撤去」の 2 文字が枠を含むかどうかが、ここで決まっている。**
- **j.軸組の撤去範囲** / **k.軸組の新設範囲** — 記号と**色**で表す。
  色の意味は n が定義している。
- **m.撤去範囲** — 床組・天井組の撤去範囲。**部分的に撤去する場合は範囲を表記する。**
  直床・乾式二重床・下地材・軸組・天井組それぞれに撤去と新設がある。
- **n.改装種別凡例** — 新設・交換・脱着・移設・撤去・既存のままの**意味の定義**と、
  **色の定義**(既存の移設と脱着を表す色 / 交換と新設を表す色)。
  **これが K-20 で対照表に写した「工事の区分」95 件の出どころである。**

## 6. 数えたこと

| | 件数 |
|---|---:|
| 6 ページの項目 | **16**(a〜p) |
| この文書で読んだ項目 | **13**(d〜p) |
| 既に読んだ項目 | **1**(c) |
| 解説が絵だけで文字から読めない項目 | **2**(a・b) |
| 13 項目のうち、いまの機械が読んでいるもの | **0** |
| 数量に直に効くと判断したもの | **4 組**(g・h / l・p / o / d・e・f) |

**「読んでいるものが 0」は、凡例が役に立たないという意味ではない。**
`legend_lookup.py` が本番の入口から呼ばれていないので、**繋げば効く可能性があるものが
そのまま残っている**という意味である。
