# A-1 繰り返す記号の読み取り — 測る前に決めた採否の基準

作成: 2026-09-22。**測定を始める前にこの文書をコミットする。**
結果を見てから基準を変えない(変える必要が出たら、変更と理由とコミットを残す)。

## 何を測るのか

`axes/image_axis/pdf_repeated_symbols.py` は、CAD 由来の PDF で
**同じ図形が繰り返し現れること**だけを手がかりに、記号の候補を群にまとめて数える。
テンプレートを持たない。名前は凡例と形が一致したときだけ付く。

測るのは次の 3 つ。**合成図面の上での測定であって、実図面での誤り率ではない。**

| 指標 | 定義 | 分母 |
|---|---|---|
| 記号の群の再現 | 正解の記号の種類のうち、群として出たもの | 置いた記号の種類の数 |
| 個数の的中 | 群の個数が正解と一致した種類の数 | 群として出た種類の数 |
| 誤検出 | 記号でないのに群として出たもの(寸法線の矢印・ハッチング・外枠) | 出た群の総数 |

## 先に決めておく採否の基準

- **採用**: 記号の群の再現が 1.00、個数の的中が 1.00、**かつ誤検出が 0 件**。
- **保留**: 再現・的中が 1.00 でも誤検出が 1 件以上出る場合。
  誤検出が出るなら、この手法は「候補を出す」までで、数量には使えない。
  どういう形が誤検出になるかを報告書に書き、大きさの窓の校正を次の周に回す。
- **不採用**: 再現が 1.00 未満。繰り返しという手がかり自体が効いていないことになる。

## 必ず回す負の対照(これを回さずに数字を報告しない)

[[jidou-sekisan-golden-coverage-not-recall]] の失敗を繰り返さないため、
**「でたらめでも同じ数字が出ないか」を先に確かめる。**

1. **記号を 1 つも置かない図面**。壁・寸法線・ハッチング・外枠だけ。
   期待: 記号の群は 0。**ここで群が出るなら、出ている群は記号ではない。**
2. **同じ形を 1 個だけ置いた図面**。期待: 既定(`min_count=2`)では 0 群。
3. **記号を一切置かず、寸法線の矢印だけを 20 個置いた図面**。
   期待: 大きさの窓で落ちる。落ちなければ、窓の既定値が実図面で
   誤検出を生むという結果になる。

## この測定で分からないこと(報告に必ず書く)

- **実図面での誤り率は測れない。** 実図面 PDF はこの作業環境に無い。
  合成図面は「記号は同じ図形の複製である」という前提どおりに作られているので、
  実図面でその前提が崩れる場合(記号が毎回描き直されている、線幅だけ違う複製が
  ある、記号が他の線と 1 つのパスにまとめられている)は測れていない。
- **スキャンされたページでは常に 0 件**になる。0 件は「記号が無い」ではない。
- 見積の行が埋まるかどうかは測っていない。記号の個数から見積の行までには
  「数量化と見積の行への対応付け」(`estimating/mapping.py`)がもう 1 段ある。
