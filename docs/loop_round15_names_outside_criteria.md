# 周15(室名は囲いの外にあるのか)の基準

**測る前に決めてコミットする。結果を見てから、ここは書き換えない。**

## 前の周と何が違うか(**これが書けないなら別の周ではない**)

**周14 は「室名が面の**内側**にあるか」を数えた。周15 は「室名が面の**外周の
近く**にあるか」を数える。変えるのは**探す場所ひとつだけ。**
面の取り方(`find_room_outlines` の既定値)も、囮の作り方も、
使う紙(P011 匿名化 v2 の同じ 5 ページ)も、種(20260925)も変えない。

## なぜこれを測るのか

周14 で、幅 600mm 以上の面 43 個のうち**室名が 1 つ入っているのは 4 個**
(囮 3 個)だった。**そこから「43 個は室ではない」とは書かなかった。**
室名は輪郭の**外**に置かれることがあるからである。

**そこが分かれ目になっている。**

- **室名が外にあるだけなら** … 面は室かもしれない。壊れているのは
  「室名は輪郭の中にある」という**実装の前提**のほうで、
  `RoomOutline.name` の取り方(「輪郭の中にあった文字」)が
  この図面に合っていないことになる。
- **外にも無いなら** … 面のある場所と室名のある場所が本当に別である。
  面が室だという見込みは薄くなる。

**どちらに転んでも、次にどこを直すかが変わる。**だから測る値打ちがある。

## 測り方

面の輪郭を**外へ広げた帯**を作り、その帯の中に室名の語があるかを数える。
帯の幅は **500mm・1,000mm・2,000mm** の 3 段(実寸)。

- 帯は輪郭の外側だけ。**内側は入れない**(周14 で数えた分と二重に数えない)。
- 広げた帯が**別の面の内側**に入ってしまう分は**落とす**。
  落とさないと、隣の室の名前を自分の名前として数えてしまう。
- 区分の語は**周14 と同じ表を使う**(`measure_where_faces_are.py` の
  `LIVING_WORDS` / `SERVICE_WORDS`)。**測ってから足さない。**

## 囮

**周14 と同じ作り。**室名らしい文字の位置を紙の中にばらばらに置き直す。
**数は変えない。**種は 20260925。

**囮とは値そのもので比べる。増え方では比べない。**

## 線(3 本)

### 線1 — 外の帯に室名はあるか

**幅 600mm 以上の面のうち、帯の中に室名の語がある面の数**。
帯の幅ごとに 3 回数える。

- **通過**: 3 段のどこかで、本物が囮を **5 個以上**上回る
- **不通過**: どの段でも差が 5 個未満

**なぜ「5 個以上」か。**周14 の線2 は本物 4・囮 3 の**差 1 個**で
形の上は通過したが、それを根拠にできなかった。**同じことを繰り返さない
ために、差の大きさを先に決める。**43 個のうち 5 個は約 12% に当たる。

### 線2 — 帯を広げると、室名は「増えて」から「混ざる」か

帯を広げれば当たる室名は必ず増える。**増えること自体は何も言っていない。**
見るのは**混ざり方**で、**1 つの面の帯に 2 つ以上の室名が入った面の数**を
帯の幅ごとに数える。

- **室名が外にあるだけ**なら … 狭い帯で**1 つだけ**当たる面が多く、
  広げると混ざり始める
- **面と室名の場所が別**なら … 狭い帯では**ほとんど当たらず**、
  広げるといきなり混ざる

**通過**: いちばん狭い帯(500mm)で、**ちょうど 1 つ当たった面が
2 つ以上当たった面より多い**
**不通過**: そうでない

### 線3 — 天井高の注記も外にあるのか

同じ帯で、**天井高の注記が帯の中にある面の数**を数える。
囮は周14 と同じ(でたらめな点)。

- **通過**: 3 段のどこかで、本物が囮を **5 個以上**上回る
- **不通過**: どの段でも差が 5 個未満

## 先に書いておく落とし穴

1. **帯を広げれば必ず当たる。**だから「当たった」ことではなく
   **囮との差**と**混ざり方**を見る。線1・線3 は差で、線2 は混ざり方で書いた。
2. **外へ広げる向きを間違えると内側へ広がる。**輪郭の向き(符号つき面積)で
   確かめる。**合成の紙で先に確かめてから実図面に当てる**(周12 の教訓)。
3. **「条件の言い換え」を線にしない**(周13・周14 の教訓)。
   **3 本とも「どういう数字が出たら不通過になるか」を書いてある。**
   線1・線3 は差が 5 個未満、線2 は 1 つ当たりが 2 つ以上当たりを超えないとき。
4. **室名の語の表がこの図面に合っているかは、周14 では測れなかった。**
   この周でも測れない。**だから線1 が不通過でも「室名が無い」とは書かない。**
   書けるのは「**この語の表では当たらなかった**」まで。
