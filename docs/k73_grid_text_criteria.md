## 直し(1 つだけ)

`draft/table_grid.py` の「AI が表の中身を読んだ証拠」を、**位置**から**位置と中身**に厳しくする。

### 前(K-71 周 1)

表の中の文字の層の語のうち、AI の「文字」「数字」の要素の箱(面積の上限 1% 以内、余白 3 画素、見本の点の半分)で
印が付く語の割合が 0.5 以上なら、AI が表の中身を読んだとみなして罫線を足す。**箱の中身(AI が読んだ文字)は見ていない。**
だから、でたらめに置いた箱(囮 5)でも半分以上の語に印が付く表があり、罫線が足された(325 / 279 / 527 本)。

### 後: 「AI の文字の中身が一致する」の定義

表の中の文字の層の語 1 つずつについて、次の 2 つを両方満たすとき「中身が一致した語」と数える。

1. **位置**: 前と同じ。その語に印を付ける AI の「文字」「数字」の要素(面積の上限 1% 以内・余白 3 画素・見本の点の半分が箱に入る)がある。
2. **中身**: 1 の要素のうち少なくとも 1 つで、**正規化した語が、正規化した AI の「内容」に部分文字列として含まれる。**
   - 正規化: Unicode NFKC(全角・半角をそろえる)→ 空白をすべて除く → 大文字小文字をそろえる(casefold)。
   - 正規化した語が空なら一致にしない。AI の「内容」が無い・空の要素は一致にしない。
   - 部分文字列にするのは、AI が 1 つの要素に複数の語(1 行・1 升目)をまとめて読むことがあるため。
     逆向き(AI の内容が語に含まれる)は一致にしない(短い内容で長い語を稼がないため)。

**証拠の割合 = 中身が一致した語 ÷ 表の中の語(全部)。0.5 以上なら罫線を足す**(0.5 は前と同じ値。分母は前と同じ「表の中の語全部」)。
足す罫線そのもの(升目の縁に乗る直線・矩形、位置は図形の外接矩形そのまま)は変えない。表の選び方(`_ruled_tables` の守り)も変えない。

前後を比べるため、`grid_elements` / `ledger` / `page_readthrough` / `readthrough` に `text_match`(既定 True = 後、False = 前)を足す。

### この直しで分母は動かない(測る前に書く)

この直しは、台帳に足す機械の罫線(要素)を減らすだけで、図形の層(数える図形)にも表の切り口(`_ruled_tables`)にも触らない。
**だから、4 種類とも分母は前後で同じになるはず**で、動くのは分子(拾えた)だけ、向きは「同じか減る」だけのはず。
K-72 の囮 5 の R1 の +0.0345 は、分母(ページ 15 の 847 図形)を外したことで割合だけ上がったもの。今回は分母を外さない。
これを確かめるため、**4 種類それぞれ、分子(拾えた)と分母(数える・全部)を前後で別々に出す。**
