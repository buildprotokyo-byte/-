# 56周目 基準: **「0 件」が「無かった」なのか「探せなかった」なのかを、本番経路は区別しているか**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。55 周目から出てきた問いである。

## なぜこの題なのか

55 周目で、**スキャンの紙に円弧を探す経路を当てると 0 件**になると分かった。
**探す相手が無いので 0 件**である。**「開き戸が無い」のではない。**

**この 2 つが出力の上で同じ顔をしているなら、人は読み違える。**

- **本当に開き戸が 1 つも無い紙** → 0 件
- **スキャンなので探せなかった紙** → 0 件

**人が見るのは後者を「開き戸なし」と書いた表である。**
参照データの説明書き自身が、この区別を
「**検出できなかった、ではなく、探し方が形と合っていない**」と呼んでいる。
**その区別が本番の取り込み経路に残っているかを測る。**

**取り決め①のとおり、記録ではなくコードを読み、本番経路から呼ばれているかまで見る。**

## 測るもの

**`intake/drawing_intake.read_drawing()`(本番の取り込み経路)に、
2 つのファイルをそのまま通す。**

| 記号 | 何を測るか |
|---|---|
| **B0** | 通ったか(例外で落ちないか)、ページ数 |
| **B1** | 出力に「**この紙ではこの手法を試せなかった**」という記録が残るか(真偽) |
| **B2** | v1(スキャン)で、**読めなかった旨の記録が何件**残るか |
| **B3** | v1 で出力された**建具の数量の件数**と、v2 での同じ件数 |
| **B4** | v1 の出力に、**0 件であることと、探せなかったことを区別できる手がかり**が
いくつあるか(ページごとの手法の可否・理由の別) |

**出すのは件数と真偽だけ。図面の文字は 1 文字も出さない。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **B1 = 区別していない**
  → **欠陥である。**人に「開き戸なし」と読ませる形で 0 が出ている。
  **取り決め②のとおり、再現する失敗テストを先に書いてから**、
  **記録を足す変更**を出す。
  **足すのは記録だけで、判定のしかたも基準値も変えない**
  (数量が確定するかどうかは 1 件も動かさない)。
  **全件テストと CI が通れば、判定を変えない追加としてマージ可。**
  **動かしてしまう形になったら、その時点で PR のまま止めておーちゃんに聞く。**
- **B1 = 区別している**
  → **どこにどう出ているかを名指しする。**
  そのうえで、**その区別が人の目に届く場所まで来ているか**を次の周で測る。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1(経路が生きているか)** | v2 を通したときの建具の数量の件数 | **1 件以上**。0 なら経路自体が動いていないので結論を出さない |
| **2** | v1 のページ数 | **34** |
| **3** | 反復 3 回(B2) | 3 回とも同じ |

**対照1 が通らなければ結論を出さない。**
