# 裸の数が建具の絵のそばにあるかを数えるときの数え方

作成日: 2026年9月24日。**数える前にコミットする。**

`docs/k22_door_width_count_report.md` で「**裸の 3〜4 桁の数は凡例以外に 155 件ある。
その中に建具の幅が混じっている可能性は消えていない**」と書いて止めた。ここを 1 歩進める。

## 何を目印にするか

**開き戸の振りの円弧**(`axes/image_axis/pdf_vector_symbols.find_door_arcs`)を
「建具の絵」の目印にする。

**この目印は建具の一部でしかない。引戸・折戸は円弧を描かないので拾えない。**
だから**どの結果が出ても「建具の絵が無い」とは書かない。**

縮尺はページごとに `extract_scale` で読む。**読めないページは数えない**
(実寸の窓を使う判定なので、縮尺を推し量ると窓ごとずれる)。

## 何を「そばにある」とするか

円弧の外接矩形を、**当てた円の半径ぶん**だけ四方に広げた範囲。
その中に裸の 3〜4 桁の数の**中心**が入っていれば「そばにある」。

## 数えるもの

1. 縮尺が読めたページの数
2. 拾えた円弧の本数
3. **そばに裸の数がある円弧の本数**
4. その範囲に入った裸の数の個数(重複を含む)

**図面の数値そのものは書かない。件数だけを書く。**

## 結果の読み方(**先に決める**)

| そばに裸の数がある円弧の本数 | 書くこと |
|---|---|
| **0 本** | 裸の数は建具の絵から離れている。**「建具の幅は印字されていない」に一歩近づく。**ただし引戸・折戸を拾えていないので**断定しない** |
| **1 本以上、円弧の半分未満** | 件数をそのまま書く。**どちらとも言えない** |
| **半分以上** | 建具のそばに数がある。**「建具の幅が印字されている見込みが高い」**と書き、**次に何を確かめるか**を書く |

## 先に書いておく注意

**そばにあることは、その数が建具の幅であることではない。**壁の寸法も室の寸法も
建具のそばに来る。**この数え方で分かるのは「建具の絵のそばに数があるかどうか」までで、
その数が何の寸法かは分からない。**
