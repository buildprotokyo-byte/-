## 2. **なぜこの問いにするか(目的から)**

**入口が出す 2,887 件のうち 2,488 件(86%)が記号である**(周31 の線1、周38 で裏取り)。

**その 2,488 件は、いま名前が付いていない。**
`intake/drawing_intake.py:2053` の `_repeated_symbol_findings()` は、
凡例と形が一致しなければ対象名を **`記号::名前不明◯◯mm::ページN`** にする。

**「何かが 12 個ある」までで、「何が 12 個あるか」は言えていない。**
**見積の行にするには名前が要る。だから数量の 86% はここで止まっている。**

## 3. 測る前に読んだこと(取り決め①)

- **名前を付ける部品はある**——`legend_symbols` は `drawing_intake.py:1222` で
  `name_clusters()` に渡る(周38 の訂正で分かった)。
- **`legend_symbols` は、ページを `凡例` と宣言したときだけ作られる**
  (`:2019` の `LEGEND_PAGE_KINDS`)。**宣言が無ければ空である。**
- **だから、いままでの周は全部「名前を付ける材料が 0 件」の条件で測っていた。**
- 名前が付いたかは `provenance["symbol_name"]`(付かなければ `None`)と
  `naming_basis` に残る。**数え直さずこれを読む。**

## 4. 測るもの

図面は **P011 の匿名化v2**(34 ページ、A3)。**v1 ではない。**

### 凡例のページ

**6 ページ目と 22 ページ目。**
**これは記憶からではなく、人が作った対照表(共有フォルダの `knowledge/p011_legend_lookup.json`)の
`source_page` から取る。**(9 件の工事の印は 6 と 22、61 件の記号は 22。)

**これは原則4 の条件1「人がすぐに、確実に分かる」に当たる入力である**
——どのページが凡例かは、人がめくれば分かる。

### 条件

| | 宣言 |
| --- | --- |
| **前** | 宣言しない(いままでの周と同じ) |
| **本物** | **6 と 22 だけを `凡例` と宣言。他のページは宣言しない** |
| **囮** | **凡例ではない 2 ページを `凡例` と宣言**(種 20260925 で引く) |

**囮は当たりうる**——凡例でないページにも図形はあるので、
`read_legend_symbols` は何かを読んで返しうる。**読んだものが記号の名前になれば、
「凡例を読んでいるから名前が付く」という話は崩れる。**

## 5. 線(合格・不通過の数字を先に書く)

### 線1 — **名前は付くか**

`provenance["symbol_name"]` が `None` でない数量の件数。

- 前(対照): **0 件**であること。3 節のとおり材料が無いので 0 のはず。
  **0 でなければ、この周の読みが間違っている。**
- 本物: **合格 = 1 件以上、かつ囮の 2 倍以上。**

### 線2 — **囮**

- **囮で 1 件も付かなければ、線1 の差は「凡例を読んでいる」ことの証拠になる。**
- **囮のほうが多ければ、`read_legend_symbols` は凡例でなくても何か返している。**

### 線3 — **対照(2 ページぶんの関門の代金)**

`凡例` と宣言した 2 ページでは、繰り返す記号と室の輪郭の関門が閉じる(周38)。

- **合格 = 数量の総件数の減りが 289 件未満(2,887 の 10%)。**
- **予想**: 合格する(34 ページ中 2 ページぶんなので)。**予想であって事実ではない。**
- **落ちたら、凡例のページにこそ記号が集まっていることになる**(そのときは
  名前を付ける相手を自分で消していることになる)。

### 線4 — **裏返しの危険**

- **合格 = どの条件でも自動確定した数量が 0 件。**
- **0 でなければ、その場で止めて報告する。**

## 6. 測らないこと(先に宣言する)

- **付いた名前が正しいかは測らない。** 正解の対応表はあるが(K-20)、
  **付いた名前を正解と突き合わせるのは別の周にする。**
  ここで測るのは**付くか付かないか**だけである。
- **`app.py` と `intake/` は 1 行も変えない**(K-29)。渡すのは実行時の引数だけ。
- 実案件の金額・数量の値・記号の名前。**出すのは件数だけ。**

## 7. この測り方で分からないこと(先に書く)

- **名前が付いても、その名前が合っているかは分からない**(6 節)。
- **名前が付いた数量が見積の行になるかは分からない**(規則が要る。周37)。
- **凡例が 2 ページで足りているかは分からない。** 対照表は 61 件の記号を
  1 ページから取っているが、**図面にある記号の種類がそれで尽きているかは数えていない。**
