## 2. **なぜこの問いにするか(手段からではなく目的から)**

周32〜周36 は「位相をどうやって付けるか」を 5 周やった。**それは手段である。**

**位相を付ける目的は、撤去の行と新設の行を分けることである。**
そこで、**手段を全部成功させたことにして、目的の側が動くかを先に見る。**

**動かないなら、周32〜周36 の続きは全部むだである。**
**動くなら、どれだけ動くかが、位相の仕事の上限になる。**

周47 で「校正を全部済ませても自動確定は 1 件も増えない」を出したのと**同じやり方**
(`jidou-sekisan-tier1-unreachable`)。

## 3. 測る前に読んだこと(取り決め①)

- **`Meaning.is_complete` は本番で 1 か所も読まれていない。**
  `axes/reading/meaning.py` の外では、テストと `benchmarks/` にしか出てこない
  (`arbitration/` の `is_complete` は制約探索の別物)。
  原則の「**意味が付けられない値は、数量に使わない**」を**守らせている場所は無い。**
- **`intake/start_kit.py` の `PagePairing` は自分でこう書いている**——
  「**この対応から差分(撤去・新設)を計算する実装はまだ無い。**」
- `estimating/rules.py` は `PHASE_UNKNOWN` と `PHASES` を読んでいる。
  **規則の側には位相を見る口がある**(周36 の線4 で 3 件当たった)。

**だから読んだだけで分かっていることは、この周では線にしない**(周33 の失敗の型)。

## 4. 測るもの

図面は **P011 の匿名化v2**(34 ページ、A3)。**v1 ではない。**

### 反実仮想の作り方

入口が出した数量 **2,887 件すべて**に、**器ごと位相を入れる**。
器(`Meaning`)が無い行には器を作って入れる。**`intake/` は 1 行も変えない**
(測定の道具の中で、出てきた数量を組み直す)。

**入れる値は 3 通り作る。**

1. **全部 `現況`**
2. **全部 `計画`**
3. **ページ番号で機械的に振る**(奇数=現況、偶数=計画)

**どれも「正しい位相」ではない。** 正しい位相はこの図面からは分からない(周32・周35)。
**ここで見たいのは「位相が何であれ、行の側が動くか」である。**

## 5. 線(合格・不通過の数字を先に書く)

### 線1 — **行に数量が入る数は増えるか**

`app.py` の一本通しで、**数量が入った行の数**。

- 入れる前(対照): 周27 で **5 行**。**まずこれを測り直して同じ数が出ることを確かめる。**
- 入れた後: **合格 = 1 行でも増える。**

### 線2 — **撤去の行は 1 行でも作られるか**

- **合格 = 1 行以上。**
- **予想は 0 行**(3 節の `PagePairing` の断り書き)。**予想であって、確かめた事実ではない。**

### 線3 — **裏返しの危険**(いちばん大事)

- **合格 = 自動確定した数量が、入れる前も後も 0 件。**
- **0 でなければ、その場で止めて報告する。**
  **この周は 2,887 件全部に位相を作って入れる**ので、周36 より危ない。

### 線4 — **囮 = 位相の中身を入れ替える**

4 節の 3 通りで、**行の側の出力が 1 つでも違うか**を突き合わせる。

- **3 通りとも同じなら、位相の中身は行に何も効いていない。**
- **合格(=位相が効いている)= 3 通りのうち少なくとも 2 つで、行の側の出力が違う。**
- **この囮は当たりうる**(`estimating/rules.py` は `phase` を条件に読むので、
  中身が変われば当たる規則が変わりうる)。**当たりようのない囮ではない**(周22 の型)。

## 6. 測らないこと(先に宣言する)

- **位相の値が正しいかは測らない。**(4 節のとおり。正しい位相は分からない。)
- 実案件の金額・数量の値・対象名・室名。**出すのは件数だけ。**
- **`app.py` と `intake/` と `estimating/` は 1 行も変えない**(K-29)。
- コードは直さない(取り決め②)。

## 7. この測り方で分からないこと(先に書く)

- **行が動かなかったとしても、「位相は要らない」という意味ではない。**
  言えるのは「**いまの実装では、位相を全部入れても行は動かない**」まで。
- **行が動いたとしても、その行が正しいという意味ではない。**
  入れた位相はこちらが作ったものである。
