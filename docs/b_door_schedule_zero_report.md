# 36周目 結果: 建具表が 0 件になるのは、どこで落ちているからか

基準は `docs/b_door_schedule_zero_criteria.md`(コミット `4ada878`、**測る前**にコミット済み)。
測定は `benchmarks/measure_door_schedule_zero.py`。対象は匿名化 v2(34 ページ)。

## 判定と理由

### 基準の字面どおりの答えと、それが役に立たない理由

基準に書いた E5 の定義は「L1〜L4 のどれで**一番多く**落ちているか」だった。
**その字面どおりなら答えは L3a(101 / 107 = 0.944)である。** そう出たとおりに書く。

**だがこの数字は、この問いには役に立たない。** 107 の表のほとんどは**そもそも建具表ではない**
(凡例表・面積表・記事欄・仕上表)。建具表でない表で「建具表の役割が当たらない」のは当たり前で、
L3a の 101 はその当たり前を数えているだけである。**32 周目と同じ種類の設計ミスを、また基準に入れた。**

**なので L3a を直す場所として名指ししない。** ここで「見出しの言い方を増やして L3a を減らす」
と言えば、凡例表まで建具表として飲み込む方向に働く。基準に「決まらないときは名指ししない」
と書いたのは、まさにこの倒れ方を防ぐためだった。

### それでも確実に狭まったこと

役に立たない数字を捨てても、**3 つは確実に言える。**

1. **L1 ではない。** 34 ページ中 28 ページに、罫線の表が合わせて 107 個ある。
2. **L2 でもない。** **107 個すべて**の升目に文字がある。読めていないのではない。
3. **建具番号らしい列を持つ表は 5 つあり、その 5 つとも付き添いの列が 0 だった。**
   しきいの 2 に「1 つ足りない」のではなく、**1 つも当たっていない。**

**3 が今回いちばん重い。** しきいが厳しすぎるという話ではない。
`DOOR_MIN_SUPPORTING_COLUMNS` を 2 から 1 に下げても、**0 は 1 にならないので何も通らない。**
**数の問題ではなく、種別・幅・高さ・数量の見出しが 1 つも当たっていない問題である。**

### まだ分かれていないこと

**その 5 つが何なのかは、この測定では分からない。** 2 通りあって、直し方が正反対になる。

- **(あ) 5 つとも建具表ではない。** 建具番号の言い換えには `記号`・`符号`・`番号` が入っていて、
  **凡例表の「記号」列にそのまま当たる。** だとすれば付き添いが 0 なのは正しい振る舞いで、
  **建具表はそもそも 1 つも見つかっていない**ことになる。
- **(い) 5 つの中に本物の建具表がある。** だとすれば落ちているのは付き添いの見出しの当て方で、
  言い換えの表を増やすのが直し方になる。

**どちらかを決めずに実装を触らない。**

## 次の周

**(あ) と (い) を分ける測定を作る。** 中身を印字せずに分けられる数え方が 1 つある。

> **建具番号を無視して、種別・幅・高さ・数量の役割だけを 107 個すべてで数える。**

- どの表でも 1 つも当たらない → **見出しの言い方が図面と合っていない**((い)側の証拠)。
- 当たる表はあるのに建具番号の列が無い → **列の切り出しか、表のまたぎ**の問題。
- どこにも当たらず、かつ当たる表も無い → **(あ)。建具表のページ自体が別の形**である可能性が上がる。

この測定も**測るだけ**で、実装には手を入れない。
