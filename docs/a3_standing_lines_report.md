## 1. 診断

6 本とも当たらなかった 39 行のうち **6 行が「会社のルールの行」**
(仮設水道料・仮設電気料・小運搬費・荷上費・墨出し・竣工時清掃)。
駐車場代を入れると 7 行。**6 本の答案すべてで 0 件。**

これらは図面のどこにも書かれていない。**読み取りをどれだけ良くしても 1 行も
埋まらない。** A-1(記号)・A-2(面積)とは種類の違う欠落である。

## 2. 仮説: 知識の欠け。ただし本当の問題はそこではなかった

図面から決まらないのだから、会社のルールが無ければ出ないのは当たり前である。
**問題は「出ない」ことではなく、「出ないことが見積から分からない」ことだった。**

いま見積にその行が無いとき、理由は 3 つありうる。

1. 工事にその行が無い
2. 図面から読めなかった
3. **会社のルールを持っていない**

**この 3 つが見分けられない。** 見積を受け取った人には、
3 の見積が「その工事には仮設水道が要らない見積」に見える。
これは数量の誤りより危ない(誤りではなく、見えない欠落だから)。

## 3. 着手して分かったこと: **見積の行までつなぐ経路がそもそも無かった**

作業の決まりの 1 番(「記録を信じず、コードを読んでから着手する。
本番の経路から呼ばれているか確認する」)に従って確かめた結果:

- `estimating/mapping.py` の `map_quantities()` を呼ぶ**本番の経路は 0 件**
  (呼んでいるのはテストだけ)
- `app.py` は**空**(1 行)
- `intake/drawing_intake.read_drawing()` を呼ぶ本番の経路も 0 件

つまり「数量を見積の行に当てはめる仕組み」は部品としては在るが、
**図面から見積の行までを 1 本につなぐ呼び出しがどこにも無かった。**

**A-1 と A-2 の報告がどちらも「見積の行が埋まるかどうかは測っていない」で
終わっていたのは、測れなかったからではなく、測る先が無かったからである。**

## 4. 作ったもの

### 4-1. 図面からは決まらない行(`estimating/standing_lines.py`)

会社のルールだけで立つ行を作る。守っていること:

- **ルールが無いときに、黙って 0 行にしない。**
  「その行が無い」ではなく「**ルールを持っていない**」と書いて返す
- **行を捨てない。** もとになる数量が無くても、率が決まっていなくても、
  行だけは出して「何が足りないか」を添える
- **数量を勝手に埋めない。** 率が空なら数量は入らない(1 で埋めない)
- **自動で確定させない。** 会社のルールに基づく行なので常に人の確認が要る

### 4-2. 規則ファイルの版 2(`estimating/rules.py`)

`standing_lines` を足した。**版 1 のファイルはそのまま読める**(立て行が
無いだけ)。逆に、版を上げずに `standing_lines` を書いたファイルは断る
(半分だけ効いた規則がいちばん危ない、という既存の約束を変えていない)。

「式」「一式」は**行の単位としてだけ**受け、数量として正規化しない。
仲裁層が扱うのは測れる量(個数・長さ・面積・金額)だけで、
**「式」は量ではなく数え方の宣言**だからである。単位が「式」なのに
ほかの数量から計算する規則は断る。

### 4-3. 図面から見積の行までの経路(`estimating/pipeline.py`)

`read_drawing` → 数量 → 当てはめ → 立て行 → **行の一覧と足りないものの一覧**。
**金額は出さない**(単価をコードに持たない約束を変えない)。

## 5. 測ったこと(A-3 の指標そのまま)

| 測るもの | 結果 |
|---|---|
| **ルールを与えたときに、これらの行が出るか** | **7/7 出る**(架空の見本の規則で) |
| ルールが無いときに「ルールが欠けている」と正しく示せるか | **示せる**。行 0 件・欠け 1 件として返り、文面に「工事にその行が無いからではなく」と書かれる |
| 率が決まっていない行 | 行は出て数量は入らない。欠けとして 2 件(墨出し・竣工時清掃) |
| もとになる数量が複数あるとき | **選ばない**。欠けとして残す |
| 自動で確定した行 | **0 件** |

見本の規則は**すべて架空**で、率も式も入れていない(`per_unit` は `null`)。
**`null` は「まだ決まっていない」という意味で、1 ではない。**

## 6. 判定: **採用(形と動作まで)**

自走の範囲は「形と動作の確認まで」と決まっていた。その範囲では動いている。
**ルールの中身(率・式・どの工種に何を掛けるか)は 1 つも入れていない。**

## 7. 判断待ち(おーちゃんの確認が要る)

**会社のルールの中身。** 少なくとも次の 3 つが決まらないと数量が入らない。

1. **墨出し・竣工時清掃の 1㎡ あたりの値**(いまは `null`)
2. **荷上費の決め方**(階数とエレベーターの有無で変わるはずだが、規則が無い)
3. **駐車場代の決め方**(工期と台数で変わるはずだが、規則が無い)

知識収集のスレッドが `docs/knowledge/` に積算基準を集めているが、
**これらは公共の基準ではなく会社ごとの決めごとなので、そこからは出てこない。**
おーちゃんの会社の実際の決め方を聞く以外に埋める方法が無い。

## 8. キラークエスチョンを当てたらどうなるか(**推論であって測定ではない**)

A-1・A-2 と違い、この領域の問いは**図面についての問いではない**。

- **問い**: 「仮設・運搬・墨出し・清掃・駐車場の 5 つは、御社では何を基準に
  決めていますか(一式か、面積あたりか、工期あたりか)」
- **性質**: **案件ごとではなく会社ごとに 1 回**で、以後ずっと使い回せる。
  使い回してよい問いの中でもいちばん寿命が長い
- **推論する変化**: 落ちている 6〜7 行は、**全部この 1 問の下流にある。**
  いま行は出るが数量が入らない状態なので、基準が決まれば数量まで入る。
  読み取りの精度は 1 ミリも関係しない
- **推論する大きさ**: 金額としては小さくないが、**件数は 7 行で頭打ち**である。
  A-1(記号 10 行)・A-2(面積 14 行)と違い、この領域は
  **伸びしろが最初から決まっている**
- **当てる時機**: いまが時機である。理由は 2 つ。①行を受け取る器ができた
  (作る前に聞いても、答えを入れる場所が無かった)②この問いは
  **読み取りの進み具合と無関係**なので、他の周を待つ理由が無い。
  むしろ**いちばん早く当てられる問いだった**と言える。
  A-1・A-2 の問いは「その機能が動いてから」でないと意味が無かったが、
  **これは最初から当てられた。** 当てる時機を測るなら、ここが基準点になる。
