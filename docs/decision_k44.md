# K-44 の決定(2026-09-26 おーちゃん):「ぴったり一致しなければ進めない」縛りを直す

## 原文(要所をそのまま)

> ぴったり一致するものという世界で、我々は図面を見ていません。
> **積算というのは一つの物語になっていて**、認識する・読む・理解する、と進んでいかないと、二次的・三次的・四次的にどんどん影響していって、**不明確なところだらけになります。**
>
> 人間は、**70〜80%だとしても、一旦いちばん確率が高いものを仮説・仮定で決めて進んでみて、辻褄が合わなかったら、やはり間違っていたかと戻る**という作業を繰り返します。

> 一流の人間は、100%ではないにしろ**裏取りをして、これと近しいものを探して、また一致したものを複数合わせて、やはりこれは正しいのであろうと総合的に判断**できます。

### 捏造と仮説を分ける

| | 中身 | 扱い |
|---|---|---|
| **捏造** | **根拠なしに作ったもの。** 対照表に無い名前、図面に無い数字 | **禁止のまま。1件も出さない** |
| **仮説** | **根拠は複数あるが、確証が無いもの。** 近いものが3つ見つかり、互いに矛盾しない | **通す。ただし印を付ける** |

### 1. 裏取りのやり方

1. **近いものを複数探す**(完全一致でなくてよい)
2. **見つかったものが互いに矛盾しないかを見る**
3. **矛盾せず、3つ以上揃えば「確からしい」とする**
4. 揃わなければ「根拠が足りない」として、件数と中身を残す

**「近い」の判定は、場面ごとに決めて記録する。決めたら、その定義を仮の判断として残す。**

### 2. 仮説を下流に流す

- **いちばんありそうなものを仮に置いて、先へ進む**
- **必ず「仮説」の印を付ける**
- **なぜそれを選んだか、ほかの候補は何だったかを残す**
- **確からしさを記録する**(高い / 中 / 低い)
- **仮説から出た数量は、自動確定しない。**

### 3. 辻褄が合わなければ、遡って捨てる

場面: 数が合わない / 順序が成り立たない / 別の資料と食い違う / 物理的にありえない / 同じものを2回数えている / 工事の連鎖が切れている / 単位が合わない / 金額の桁が違う / 範囲が重なる / 仕様書にあるのに図面に無い。**それぞれを検算にする。**
**辻褄が合わなかったら、その仮説まで遡って捨てる。捨てた記録を残す。**

### 4. 物語として進める

**「分からないから出さない」をやめる。「こう仮定した。根拠はこれ。確からしさはこの程度」と書いて出す。**

### 守ること

捏造は0件のまま / 仮説には必ず印を付ける / 自動確定は0件のまま / 捨てた記録を残す / 数字が動かなくても構わない。
**仮説を通したことで捏造が増えたなら失敗。捏造0件を保ったまま当たりが増えたなら成功。**

## K-42 との関係(私の読み)

- K-42 の「記載が無いことを根拠に『無い』と推奨しない」は変わらない。K-44 の仮説は**根拠があるもの**だけで、記載が見当たらないことは根拠にならない。記載が見当たらないものは、仮説にせず「根拠が足りない」に残し、質疑にする。
- 「少しずれたものを捨てない」「類似を集めて確かさを上げる」(K-42 の追記 1・2)を、この決まりで数え方まで決めた。

測り方と定義は `docs/k44_hypothesis_story_criteria.md`。
