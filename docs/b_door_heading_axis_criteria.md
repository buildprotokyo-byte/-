同じ表なら K2a は通っていた。**役割が別々の表に散っているなら、言い換えを何語足しても
1 つの表の中で揃うことは無い。**

## 問い

`_find_header()` は表の**上から 3 行**だけを見て、**行に並んだ見出し**を探す
(`HEADER_SEARCH_ROWS = 3`、`table.rows[row_index]`)。
**列に並んだ見出しは、仕掛けのうえで見えない。**

> **建具表の見出しは、本当に「行」にあるのか。**

日本の建具表には、**建具 1 本を 1 列に立てて、左端の列に
「記号・種別・幅・高さ・数量」を縦に並べる**書き方がある(姿図つきの建具表はたいていこの形)。
**その形なら、いまの読み方は原理的に 0 件になる。** 語彙をどれだけ直しても 0 のままである。

## 測るもの

**表を転置して、同じ 4 通りの当て方をもう一度当てる。実装は 1 行も変えない。**

| 記号 | 何を測るか |
|---|---|
| **N1** | **転置した**表で、内側の建具表として通った表の数(**当たり**) |
| **N2** | 転置した外側の表で通った数(**誤爆**) |
| **N3** | **誤爆 ÷ 当たり** |
| **N4** | 取り違え(升目が 2 役割以上) |
| **N5** | 役割ごとの当たり(転置・内側)。種別・幅・高さ・数量 |
| **N6** | **転置しても向きが分からない表の数**: 転置前と転置後の**両方**で通った表 |
| **N7** | 内装仕上表を転置して測った、通った表の数 |

**転置は「行と列を入れ替える」だけ。** 升目の文字はそのまま。**文字は 1 つも出さない。**

## 採否の線(**39・40 周目と同じ 3 つ。結果を見てから変えない**)

| 条件 | 線 |
|---|---|
| **当たり** | **N1 が、転置しないときの最大(K1 の 1)より多い。つまり N1 ≧ 2** |
| **誤爆** | **N3 < 0.5** |
| **取り違え** | **N4 = 0** |

**当たりの線を「1 個以上増える」ではなく「N1 ≧ 2」にした理由**: 39・40 周目に
転置なしで最大 1 まで届いている。**1 では「転置が効いた」と言えない。**

- **3 つとも満たす** → **答え: 見出しは列にあった。** 直す場所は語彙ではなく**表の向き**。
  **実装案を書く。判定に触るので PR のまま待つ。**
- **N1 ≧ 2 だが誤爆か取り違えで落ちる** → **向きは効いているが、それだけでは足りない。**
  向きと当て方を組み合わせる周を作る。
- **N1 ≦ 1** → **答え: 見出しは行にも列にも無い。** 語彙でも向きでもないので、
  **表の升目の取り方そのもの**(結合された升目・続き表・分割された表)を疑う周に変える。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 合成の建具表(見出しが行にある)を**転置して**当てる | **通らない**(転置が効くなら、行の表は転置すると壊れるはず) |
| **2** | 合成の建具表を**転置せず**に当てる | 4 通りとも通る(40 周目の再現) |
| **3** | 転置なしの内側の当たりが 40 周目を再現するか | K0 0 / K1 1 / K2a 0 / K2b 0 |
| **4** | 反復 3 回 | 3 回とも同じ |

**対照1 が「通ってしまう」なら、転置が何も変えていないか、測り方が壊れている。**
そのときは結論を出さない。
