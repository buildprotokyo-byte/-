## 3. 線ごとの結果

### 線1 — 近いか → **不通過**

合格は「本物 0.10 以上、かつ囮との差 0.20 以上」。
**絶対値(0.1438)は 0.10 を超えたが、囮との差が −0.0233 なので不通過。**
**線は下げていない。**

### 線2 — 囮 → **囮が 3 段とも勝った**

**周32 の反省が効いた。** 周32 の囮(材料と性能の語)はこの図面にほとんど無く、
勝ち目が薄かった。今回は**紙に実際に印字されている位相以外の語 4,052 個**から引いたので、
囮に十分な勝ち目があり、**実際に勝った。**

**ただし囮に有利な偏りがある(先に書いておく)。** 入口が出した数量の一部は
印字された文字そのものから作られている(寸法の数字、記号の名前)。
**その語は定義上その物の上に載っているので、囮の値は本来より高く出る。**
だから言えるのは**「囮に勝てなかった」**までで、
**「位相の語のほうが決定的に遠い」とは書かない。**

### 線3 — つまみを振ると中身が入れ替わるか

| | 件数 |
| --- | --- |
| 10mm で当たった | 392 |
| 50mm で当たった | 1,327 |
| 10mm の集合が 50mm に含まれる | **392(全部)** |
| 50mm で新しく入った | 935 |

**この欄はこちらの設計ミスだった(自己批判)。**

周18 の教訓「つまみを振る測定には、数だけでなく中身の入れ替わりも数える線を入れる」を
持ち越したつもりだったが、**同じ距離の目盛りを広げるだけなら、狭い集合が広い集合に
含まれるのは当たり前である。**入れ替わりは原理的に起きない。

**しかも、その性質は自分で書いたテストで固定してあった**
(`test_狭い集合は広い集合に含まれる`)。**テストは分かっていて、基準は分かっていなかった。**
**周31 でも同じ形を踏んでいる**(線3 の母数の誤りを、自分のテストは既に固定していた)。

**持ち越す形**: **テストを書いたら、基準と突き合わせる。**
テストで「必ずこうなる」と固定した性質は、**測定の線にしてはいけない。**
周18 の教訓が効くのは「対象の中身が変わりうるつまみ」であって、
**同じ量のしきい値ではない。教訓を形だけ当てはめた。**

## 5. この測定で言えないこと(先に宣言したとおり)

- **近いことは「指している」ことではない。** 注記は引出線で離れた所を指す。
  **逆に、遠いことも「指していない」ことではない。**
  だから線1 が落ちたことは「位置に手がかりが無い」の証拠であって、
  **「引出線をたどっても駄目」の証拠ではない。引出線はたどっていない。**
- **どの数量が現況でどの数量が計画か、という判定はしていない。**
- 座標を持たない 161 件については何も測っていない。
