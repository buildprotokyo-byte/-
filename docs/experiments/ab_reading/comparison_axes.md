# 読み方の比較 — 比較の軸（実行の前に固定する）

> **この文書は実行の前に固定する。結果を見てから軸を選び直さない。**
> 差が出た所だけを軸にすると、どんな結果からでも物語が作れてしまう。

おーちゃんが求めている最終成果は、数字の勝ち負けではない。
**「目的を理解してから推論する」読み方と、「全部読んでから組み立てる」読み方で、
動き・推論の進み方・出てくる答えが何がどう違うのかを、理論立てて並べた表**である。

記録の取り方は [output_format.md](./output_format.md)、点の付け方は
[scoring_rules.md](./scoring_rules.md)。この文書は**何と何を並べるか**を決める。

## 0. 中心は精度（2026-09-22 におーちゃんが言い直したこと）

**この実験が測りたいのは、最初に工事内容の理解（目的の理解）があると
推論の精度が上がるか、である。**

そのため、軸には**主**と**補助**がある。

| | 軸 | 何のためか |
|---|---|---|
| **主** | 2-12（余計な項目の抑え方）、3 節の 3 指標、[scoring_rules.md](./scoring_rules.md) 7-0 の精度 3 面 | **精度そのもの** |
| **主に近い** | 2-4（見つからないものの扱い）、2-5（区分の決まり方）、2-6（波及）、2-7（空にした数量とその理由）、2-8（要確認の質） | **精度がどう作られたか・壊れたか**の説明になる |
| **補助** | 2-1・2-2（読む範囲）、2-3（問いの出どころ）、2-9（速さ）、2-10（推論の回数）、2-11（手間） | 振る舞いの違い。**これ単独で「精度が上がった」とは言わない** |

**補助の軸で差が出ても、それは精度の話ではない。**
速く読めた・少なく読めた・推論が少なかったことは、それ自体では良し悪しにならない。
表を書くときは、**主の軸を先に置き、補助を後に置く。**

## 1. 最終的な表の形

軸ごとに、次の 4 列を並べる。

| 列 | 中身 | これは何か |
|---|---|---|
| A の振る舞い | 実測 | **観測** |
| B の振る舞い | 実測 | **観測** |
| なぜそうなるか | 読み方の違いから説明した理由 | **解釈（観測ではない）** |
| 6 回の実測で見えたか | 見えた / 見えなかった / どちらとも言えない | **観測** |

**「なぜそうなるか」の列は解釈であって観測ではない。**表の中でもそう明記し、
観測の列と混ぜない。**解釈が先にあって観測を選ぶことがないよう、観測の 3 列を
先に埋め切ってから理由の列を書く。**

「6 回の実測で見えたか」は、**3 回とも同じ向きに出たかどうか**で書く。
**6 回では偶然かどうかを断定できない**ので、「有意」「効果があった」とは書かない。

## 2. 軸の一覧（12 軸）

### 2-1. 読む順番と読んだ範囲
何を見るか: どのページをどの順で開いたか、どこを開かなかったか、
**同じページを何度開き直したか**。
記録: `ページを開いた順`（重複を含む）、`読んだページ`、`開かなかったページ`。

### 2-2. 読みに行った範囲
何を見るか: 開いたページ数が全体の何割か。**開き直しの回数**（同じページが
`ページを開いた順` に何回出るか）。
記録: 上と同じ欄から数える。

### 2-3. 問いの出どころ
何を見るか: その項目を調べようと思ったきっかけが**図面の観測**か、
**目的・要約資料**か、**一般の知識**か。
記録: 各項目の `問いの出どころ`。

### 2-4. 見つからないものの扱い
何を見るか: **要約資料にあるのに図面に無いもの**を「探したが見つからない」として
挙げられたか。**図面にあるのに要約資料に無いもの**を落とさずに出せたか。
記録: `要確認` の `種類` が `探したが見つからない` の件数と中身。
工事項目のうち `問いの出どころ` が `図面の観測から` でありながら要約資料に無いもの。

### 2-5. 区分の決まり方
何を見るか: 既存のまま／撤去／新設／改修／不明をどう決めたか。**根拠の種類の内訳。**
記録: 各項目の `区分` と `区分の根拠`。

### 2-6. 波及
何を見るか: ある工事に巻き込まれて必要になるものを出せたか
（壁を撤去したらそこに付いていたものはどうなるか、など）。
記録: `出どころ` が `波及から出た` の件数と、`波及の道筋` の中身。

### 2-7. 空にした数量とその理由
何を見るか: 数量を `null` にした件数と、その理由の内訳。
**埋めなかったこと自体は減点ではない。**読み方によって「埋めない」の出方が
違うかを見る軸である。
記録: `数量` が `null` の項目と、対応する `要確認` の `種類`。

### 2-8. 要確認の質
何を見るか: **辻褄が合わない**（図面の側に問題がある）のか、
**単に分からない**（こちらが決められない）のか。
記録: `要確認` の `種類` の内訳。

### 2-9. 推論できた速さ
何を見るか: 最初の工事項目が出るまでの時間、全部出そろうまでの時間、
**読んだページ 1 ページあたりの時間**。
記録: `開始時刻`・`最初の工事項目が出た時刻`・`全部出そろった時刻`・`読んだページ`。

### 2-10. 推論をした回数
何を見るか: **往復の回数**（読む→考える→また読みに行く）と、
**1 つの数量に至るまでの段の数**の分布。
記録: `往復の回数`、各項目の `段の数`、`推論の数`、`計算の数`。

### 2-11. 手間
何を見るか: 読んだページ数、読んだ文字量、所要時間。
記録: `作業記録` のそのままの欄。

### 2-12. 余計な項目の抑え方（目的の理解が効くとすれば、ここに出るはず）

**この実験の言い直した目的に、いちばん近い軸。**

- 正解に無い項目を、いくつ出したか。**図面に根拠があるもの／根拠が無いもの**に分ける
  （[scoring_rules.md](./scoring_rules.md) 7-2）。
- 出した行数そのものと並べて見る（同 7-2-2）。**行数が多ければ、両方が一緒に増える。**
- 根拠が無い項目については、**なぜそれを出したのか**を、その項目の
  `問いの出どころ` と `区分の根拠` から辿る。

**仮説（解釈であって観測ではない）**: 先に工事の目的をつかんでいれば、
目的に関係しない項目を出さずに済むので、余計な項目が減る。
**逆に出るかもしれない**: 目的をつかんだことで「あるはずだ」と思い込み、
図面に根拠の無い項目を作るかもしれない。**どちらに出るかを見る軸である。**

## 3. 「正解に近づく確率」をどう測るか（置き換えの説明）

おーちゃんから「正解に近づく確率」を比べたいという要望が出ている。
**この言葉のままでは測れない。**理由は 2 つある。

1. **6 回では確率にならない。**片方 3 回ずつで出た差は、偶然でも普通に起きる。
   確率だと書いた時点で、無い保証を作ってしまう。
2. **「近づく」には途中経過が要る。**最終の答えだけでは、近づいたのか
   最初から当たっていたのかが分からない。

そこで、**件数と割合で出せる 3 つの形に置き換える。**
**これは同じものの言い換えではなく、測れる範囲に縮めた代わりの指標である。**

| 置き換えた指標 | 定義 | 何が言えないか |
|---|---|---|
| **正解と一致した行の割合** | [scoring_rules.md](./scoring_rules.md) 7-1 の「言い当てた行数」と同じ | 1 回ごとの当たりやすさであって、確率ではない |
| **段の数ごとの当たり方** | 各項目の `段の数` 別に、数量が許容差内だった件数と割合 | 段を重ねたから当たったのか、当たりやすい項目が短い段で済んだのかは分けられない |
| **見直しで近づいた件数** | `途中で変えた` がある項目について、**最初の数量**と**最後の数量**のどちらが正解に近いかを数える（近づいた / 遠ざかった / 変わらない の 3 つに分ける） | 変えなかった項目は数に入らない。**変えたことを申告しなかった場合は見えない** |

**3 つとも、分母と件数を必ず書く。割合だけを書かない。**

## 4. 速さと回数を比べるときの条件

`所要時間`・`往復の回数`・`推論の数`・`段の数` は、**読み方だけでなく、
モデルと実行環境の揺れも一緒に測ってしまう。**

- 比べる実行は**同じモデル・同じ環境**で揃える。
- 揃っていない実行は、**速さと回数の軸からは外す**（言い当てた行数などには使ってよい）。
- 各実行の `使ったモデル` は、そのスレッド自身が `get_session` で確かめた値をそのまま書く。

## 5. この表で言えないこと（先に書いておく）

- **どちらの読み方が優れているかは、この 6 回では決まらない。**
  出せるのは、差の大きさと、3 回とも同じ向きだったかどうかだけである。
- **軸のうちいくつかは自己申告に頼っている**（`往復の回数`、`段の数`、
  `問いの出どころ`、`途中で変えた`）。読む側が正直に書かなければ測れない。
  **自己申告であることを表に明記する。**
- `ページを開いた順` と `読んだページ` は、**実行したスレッドの記録から
  後で突き合わせられる**（自己申告だけに頼らない）。
  突き合わせの手順は [access_audit.md](./access_audit.md)。
