# 読み方の比較実験 — 条件ごとに渡った記憶が違っていた(2026-09-23 の記録)

> おーちゃんの K-04(2026-09-23)1 番による記録。**測り直しは今はしない。**
> 比較実験の凍結は同じ K-04 で解かれ、「当面は B を既定にする」はそのまま続く。

## 1. 事実

採点した 6 本(A = P-S1・P-S2・P-S3、B = Q-S1・Q-S2・Q-S3)には、実行の初めに
記憶が 1 回ずつ自動で渡っている(`memory_recall`、各回 5 件)。渡った記憶の名前を
6 本並べると、**4 件は 6 本とも同じで、1 件だけ A と B で違っていた。**

| 記憶(先頭の `jidou-sekisan-` を省く) | A(P-S1〜P-S3) | B(Q-S1〜Q-S3) |
|---|---|---|
| trial15-two-stage-reading | 3 本とも | 3 本とも |
| measurement-priors-in-memory | 3 本とも | 3 本とも |
| reading-protocol | 3 本とも | 3 本とも |
| memory-reaches-threads | 3 本とも | 3 本とも |
| **measurement-script-rot** | **3 本とも** | **0 本** |
| **design-summary-menu**(要約資料のメニューの設計) | **0 本** | **3 本とも** |

根拠: 各回のセッションの `memory_recall` の記録(時刻と記録の番号は
`/mnt/project-files/reports/K-03_回答.md` の付録 2 節)。

**B の 3 本だけが受け取った `design-summary-menu` は、B のやり方そのものについての
知識である。** 記憶は各回の指示文に合わせて自動で選ばれるので、指示文が違えば
選ばれる記憶も変わる。**条件を変えると、渡る記憶も一緒に変わりうる。**

## 2. この事実から言えること・言えないこと

- **精度の差の結論は変わらない。** 精度の差はもともと「偶然と区別できない」大きさだった。
- **速さの差は、やり方だけの差とは言い切れない。** かかった秒数は A が 929・1037・980、
  B が 738・814・807 で、B のほうが速かった。**その理由の一部が、やり方ではなく
  B だけが受け取った余分な知識だった可能性がある。**
- **その知識が速さや精度にどれだけ効いたかは測っていない。**
  「効いた」とも「効かなかった」とも言えない。

## 3. 決まりが既にあったのに、見落とした

`isolation_checklist.md` の手順 8 には、もともと
「`memory_recall` で何が選ばれたかを毎回記録し、A と B で選ばれ方が偏っていないかを
最後にまとめて見る」と書いてあった。**記録は各回のセッションに残っていたが、
最後にまとめて見る段が行われず、採点の報告にも載っていなかった。**
気づいたのは 2026-09-23、別の汚染の疑いを調べるために 13 本の記録を並べたときである。

## 4. 今後の比較試験の決まり

1. **条件ごとに、各回に渡った記憶の名前を必ず記録する**(`memory_recall` の記録から。
   読む側の自己申告ではなく)。
2. **採点の報告に、条件ごとの記憶の名前の表を必ず載せる**(上の 1 節の表の形)。
3. **条件の間で 1 件でも食い違いがあれば、結果と一緒に報告する。**
   食い違いを見つけても、その回を黙って捨てたり差し替えたりしない。
4. 食い違いがあった指標(とくに速さ)については、**「やり方だけの差とは言い切れない」と
   結果の文に書く。**
