# 読む側が開いたファイルを、後から確かめる

> 目的は、**実行したスレッドが「渡したもの以外を開いていない」と言えるようにする**
> こと。読む側に自己申告させる方法は、それだけでは根拠にならない
> （開いたことを書かなければ済んでしまう）。

## 1. 使えなかった方法（先に書く）

**ファイルの最終アクセス時刻（atime）は使えない。**
共有フォルダ `/mnt/project-files` は `rclone` の FUSE で `relatime` として
マウントされている。実測すると、ファイルを読んでも atime は変わらなかった。

```
$ mount | grep project-files
... on /mnt/attach/project-files type fuse.rclone (rw,...,relatime,...)
$ T1=$(stat -c %X index.md); cat index.md > /dev/null; T2=$(stat -c %X index.md)
before=1790070360 after=1790070360 changed=NO
```

**「変わらなかった」ので、atime を根拠に「開いていない」とは言えない。**

## 2. 使える方法: 実行したスレッドの記録を読む

`mcp__claude-code-remote__list_events` は、そのセッションの `assistant` イベントを
**道具の呼び出しの入力ごと**返す。`Bash` ならコマンドの文字列そのもの、
`Read` なら `file_path` が入っている。**読む側の自己申告ではなく、
実際に呼ばれた道具の記録である。**

返ってくる形（実測）:

```json
{"assistant": {"internal_anthropic_catchall": {"message": {"content": [
  {"type":"tool_use","name":"mcp__claude-code-remote__list_events",
   "input":{"limit":4,"session_id":"session_…"}}]}}}}
```

### 手順

1. 実行を頼んだときに、そのスレッドの **セッション ID** を控えておく。
2. 実行が終わったら `list_events` を**新しい順**に呼び、`before_id` に
   前回の `first_id` を渡して**セッションの最初まで遡る**。
3. すべての `tool_use` の `input` から、**パスらしき文字列を全部拾う**
   （`file_path`、`Bash` の `command` の中の `/mnt/...` や `docs/...`）。
4. 渡した入力パッケージのフォルダの中に無いパスが 1 つでもあれば、**その実行は
   条件が崩れている**。どのファイルをいつ開いたかを添えて報告する。

### 実務上の注意

- **1 回の応答がトークンの上限を超えることがある。**超えた場合、中身は
  `/root/.claude/projects/.../tool-results/*.txt` に保存され、その旨が返る。
  **そのファイルを `grep` すればよい**（全部読む必要はない）。
- 本体の文脈を汚したくない場合は、この作業を下請けのエージェントにやらせ、
  **パスの一覧と判定だけを返させる。**
- **この方法で見えないもの**: そのスレッドが起動する前に渡された文章の中身は
  イベントに残るので見えるが、**モデルが「思い出して」書いたことは見えない。**
  開いていないのに知っていた、という形の漏れはこの方法では検出できない。

## 3. そもそも置かない（こちらが本体）

記録の突き合わせは**後から気づくための手立て**であって、防ぐ手立てではない。
防ぐほうは、**読む側から届く場所に答えを置かない**ことで行う。

| 置き場所 | 他のスレッドから見えるか |
|---|---|
| `/mnt/project-files/` | **見える**（プロジェクトの全スレッドで共有） |
| 各スレッドの `/home/user`・`/tmp` | **見えない**（セッションごとに別の入れ物） |
| リポジトリ | 取ってくれば**見える** |

したがって、**正解・作り方・済んだ実行結果は `/mnt/project-files` に置かない。**
共有フォルダに残すのは、**いま読ませている材料 1 件だけ**にする。
耐久のための控えは、鍵をかけた 1 つの塊として共有フォルダに置く
（鍵が無ければ中身は読めず、`grep` にも掛からない）。

**正直に書いておく。** プロジェクトの中のスレッドは、他のスレッドの記録も
読める。**本気で探しに行くスレッドから隠し切ることはできない。**
上の置き方が止められるのは「たまたま目に入る」「一覧して開いてみる」までで、
それより先は 2 節の突き合わせで**後から気づく**しかない。
