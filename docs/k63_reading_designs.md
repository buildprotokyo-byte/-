## 2. 物差し(どの案も同じ数え方)

1. **費用(相対)**: 固定の式 `入力トークンの目安 + 5 × 出力トークンの目安` で数える。入力は文字 1 字 = 1、画像は画素数 / 750(長い辺 1,568 画素に縮めた後)。
   重い出力の単価は入力の 5 倍(重いモデルの単価 4 : 20)。考える分は入らない。**V1(b1 の 3 回の平均)を 1.0 とした比**で出す。画像の枚数と呼び出しの回数も並べる。
   本当の費用はパソコン側の手順書(使用量の記録)で測る。
2. **時間**: 機械の段の秒。AI の段は作業役の時間なので API の時間として使わない。代わりに「直列に待つ AI の段の数」と「1 回の通しの呼び出しの数」を並べる。
3. **落ち**(消して確かめる、K-51 と同じ、面積の上限 1%): 最後の読みの四角で数える図形のうち拾えなかった割合。
   **線: 3 回とも 21.23% 以下(K-61 の最悪回)。**
4. **3 回のばらつき**(線: **V1 以上**):
   - 行の名前の一致 = 3 回とも出た行の鍵 / 3 回の和。鍵は (科目, 工事項目, 揃えた室名)。V1 は 163 / 1,556。
   - 数量の一致 = 3 回とも同じ数量・単位の鍵の数。V1 は 50。
   - 質問の一致 = 3 回とも出た質問の中身の鍵の数(通常の段階、上限 5)。中身の鍵は (種類, 見るページ, 揃えた室名, 部位または工事)。項目の番号は回ごとに違うので使わない。
   - 線は、名前の一致の割合 ≥ V1、数量の一致の数 ≥ V1、質問の一致の数 ≥ V1。
5. **仕様書で宣言された項目を図面で見つけた割合**(正解を使わない自己整合): 仕上表の原本の行(室 × 部位)のうち、仕上表以外のページに同じ室(揃えた室名)・同じ部位の項目があった割合。原本はどの案も同じ段で書き写す。線は置かない(報告だけ)。
6. **囮との差**(落ちと同じ数え方で「拾えた − 囮」): 囮は 4 つ。(a) 四角の位置をでたらめに置き直す(K-51)、(b) 四角をページの中心から 0.95 倍、(c) 1.05 倍、
   (d) 別のページ(同じ案件の別の平面図・設備図)の四角を当てる。左右反転は使わない。線: **4 つの囮すべてより本物の読みの「拾えた」が多い。**
   (e) 数字だけ変えた偽の注記: 1 ページの注記の数字を書き換えた PDF を作り、その 1 ページだけ各案の読みに通す。線: 出力の数字が書き換えた数字に従う(図面から読んでいる)。

## 7. 頑健性(K-63 5 節)

壊した版: (a) 全ページを画像にしたスキャン版(文字の層なし)、(b) 凡例を隠した版、(c) 仕上表と概要を全部隠した版、(e) ページの順序を入れ替えた版、
(f) 回転・向きが混ざった版、(g) ページの半分が抜けた版。(d) 原価表なしは済。
どの案で通すか: 勝った案があればその案、無ければ V1(仮の判断)。各版 1 回。
- 止まらないか、止まった場所。
- 確度の表示が読みの悪化に合わせて下がるか: 「高」の割合が壊していない版より下がること。
- 質問が増える向きか。
- **確度の較正**: 「確度が高いのに外れた」件数。外れの基準は正解ではなく、壊していない版の 3 回の合意(同じ鍵で 3 回とも同じ数量)と数量が違う「高」の項目。
