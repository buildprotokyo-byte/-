## どうやって出しているか

**仮定は 1 つも置いていない。**

1. 壁を 2 本線で描いた図面では、線の交差から「室の内法」のほかに
   **壁の中身**が細長い面として生まれる(これまでは幅の条件で捨てていた)。
2. 室の**辺ごとに**、その向こうにある壁の中身の厚みを測る。
   厚みは「壁の中身の頂点から、その辺の直線までのいちばん遠い距離」で測る。
   面積÷長さ で測ると、隅を斜めに落としてある壁で厚みが太く出る。
3. 各辺を、**その辺の壁の厚みの半分だけ**外へ押し出し、
   押し出した直線どうしを交わらせて新しい輪郭を作る。
   辺ごとに厚みが違ってよい(外周 400・間仕切り 200 のような図面でも合う)。
4. **1 辺でも厚みが読めなければ、壁芯を出さずに「不明」のまま返す。**

## 負の対照

| 対照 | 期待 | 結果 |

| 壁の厚みを 2 倍にする | 通り芯は動かないので壁芯も動かない | **7 室とも動いた割合 0.000** |

## 壊し試験(8 通り。すべて試験が落ちることを確認した)

厚みが分からない辺を 0 として壁芯を出す / 厚みを平均距離で測る /
厚みの半分でなく全部を押し出す / 壁の中身にも面積の下限を掛ける /
数え方の検査をやめる / 内向きに押し出す / 既定でも壁芯にする /
内法の判定を厚み無しでも通す。

入口(`intake/drawing_intake.py`)についても 3 通り試した。
入口が数え方を渡さない / 既定を「不明」に戻す / 理由を根拠に残さない。
**3 通りとも `tests/test_drawing_intake_area_basis.py` が落ちる。**

## 途中で消したもの(記録)

最初、「建具の開口の辺には壁の中身が無いはずだから、**同じ直線に乗っている
別の辺から厚みを借りる**」処理を書いた。ところが、
**試験でも合成の間取りでも一度も通らなかった**(その行に例外を置いて確かめた)。
開口は壁の**両方の面**に開くので、こちらが仮に閉じた辺の向こう側も
やはり壁の中身の面になるからである。
**通らない処理は消した。** 借り先を間違えると黙って違う面積を出すので、
使われないまま残しておくほうが危ない。

## 入口につないだときに分かったこと

室の輪郭は前の周で入口から呼んではいたが、**入口からの通しの試験が無かった。**
「実装済み」の記録を信じない決まりに従って入口から呼んで確かめ、
通しの試験を `tests/test_drawing_intake_area_basis.py` に 6 本足した。
入口の既定は「壁芯」で、`IntakeConfig.area_basis` で変えられる。
**求めても、図面から厚みが読めなければ「不明」のまま出る。**

## この測定で分からないこと

- **実図面での成績は測れない。** 実図面 PDF はこの作業環境に無い。
- **合成図面は壁を必ず 2 本の平行線で描いている。** 実図面では壁の中身に
  ハッチングが入ったり、断熱材・下地の線が入ったりして、
  壁の中身が 1 つの面にならない。**そこは測れていない。**
- **1 本線の図面が実案件で何割あるかは分からない。**
  割合が高ければ、この実装で埋まる面積の行はごく一部にとどまる。
  P011(匿名化v2)で壁がどう描かれているかは、まだ数えていない。**次の周の対象。**
- **壁の厚みが読めない図面をどうするかは決まっていない。**
  厚みを会社のルールとして決めてもらうか、内法のまま出すか。**判断待ち。**
- 見積の行が埋まるかは測っていない。面積から見積の行までにはもう 1 段ある。
- **自動確定は 0 件のまま。** 手法は未校正(`calibrated=False`)である。
