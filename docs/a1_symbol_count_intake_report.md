# 14周目 報告: 人が数えた記号の個数を受け取る口(**保留**)

2026-09-23。基準は `docs/a1_symbol_count_intake_criteria.md`(測る前にコミット済み、`435989d`)。

## 今回の対象

ゴールデンの `symbol_count` **26 行**(全 99 行のうち)。

## 仮説と候補

> 人が「記号の種類と個数」を入れる口を、9 周目(室の寸法)と同じ形で作れば、
> `symbol_count` の行は数量まで届く。

候補は 3 つ挙げ、**2 つは実装前に消した。**

- 候補2(電気の機器表の文字から拾う)… 34 ページ全部の文字を走査したところ、
  **「機器表」「器具表」「姿図」「個数」はどのページにも出てこなかった。**
  この図面に電気の機器表は無い。13 周目と同じく、作る前に消えた。
- 候補3(図面の群を人に見せて確認させる)… 10 周目の 674 群で既に消えている。

## 試したこと

| 作ったもの | 中身 |
|---|---|
| `intake/symbol_counts.py` | 記号名・個数・単位・ページ・数え方を受け取る。**画面は作らない** |
| `estimating/from_symbol_counts.py` | それを `QuantityItem`(`記号数量::<記号名>`)に直す |
| `estimating/examples/synthetic_symbol_rules.json` | 合成の規則 4 件。**実案件の品目名は使っていない** |
| `arbitration/method_policies.py` | `human_symbol_count` を **未校正・上限 weak** で登録 |
| `tests/test_symbol_counts.py` | 合成データのテスト 40 件 |
| `benchmarks/measure_symbol_counts.py` | 測定。抽出と採点を分けてある |

**入口で止めることを 3 つ決めた。**

1. `式` は受け取らない。**数えて出す単位ではない**ので、個数では原理的に答えられない。
2. `台` `組` も受け取らない。数えられるが `arbitration/units.py` がまだ知らない。
   **勝手に `箇所` に読み替えない**(2 個で 1 組のものが 2 箇所として流れるため)。
   この 2 つは理由が別なので、**別の文言で止める。**
3. 個数 `0` は「入れていない」と区別して受け取る。
   0 は「数えたが 1 つも無かった」という**主張**であって、未入力ではない。

同じ記号名が 2 回入っても**自動で足さない。** 同じページを 2 回数えたのか、
別のページを数えたのかが、この層では区別できないためである。両方を出して
理由に並べ、足してよいかは人が決める。

## 対照

| 対照 | 結果 | 判定 |
|---|---|---|
| 1 空の入力 | 数量 0 / 見積の行 0 | ◯ 既定値で埋めていない |
| 2 でたらめな記号名 4 語 × 10 回 | 届いた行 すべて 0 | ◯ |
| 3 入れ替え(床・天井・建具・仮設) | **届いた行 3** | **×(0 のはずだった)** |
| 4 反復 3 回 | (4, 4) × 3 で一致 | ◯ |

### 対照3 の設計が間違っていた(**基準は変えない**)

「床・天井・建具・仮設」を**記号とは無関係な語**のつもりで並べたが、
**`建具` は無関係ではなかった。** 26 行のうち 3 行は建具の記号を数える行で、
電気の記号だけではなかった。つまり対照3 は「無関係な語を入れた」対照になっていない。

- その 3 行は、本測定で届いた 13 行と**1 行も重なっていない。**
- 見積の行(合成の規則)には **0 件**当たった。経路の側は正しく弾いている。

**参考**(基準の外。判定には使わない): 本当に無関係な語(保険・運搬・養生・値引)
に入れ替えると、届いた行は **0** だった。

これは 10 周目と同じ種類の失敗である(**宣言した対照が、測りたいことを測れない
形になっていた**)。**結果を見てから基準を変えない**ので、対照3 は「満たしていない」
として扱う。

## 判定と理由

**保留。**

採否の基準(9 節)は「採用 = M1 4/4 かつ M3 0 かつ **対照1・2・3 が 0** かつ
対照4 一致かつ M5 全検出」だった。**対照3 が 0 でない。**
不採用の条件(M1 < 4/4 または M3 > 0)にも当たらない。

- 経路そのものは動いている(M1 4/4、M3 0、M5 20/20)。
- **対照を作り直して測り直すまで、採用とは言わない。**
- 作ったコードは残す。**登録簿は未校正・上限 weak のままなので、
  この経路だけで自動確定することはない**(壊し試験 17・18 で固定してある)。

## 次の周(15 周目)の対象

**語彙と表記のゆれ。** 届かなかった 13 行を数えたところ:

- 13 行は**単位では説明できない**(個数で答えられない単位はそのうち 4 行だけ)。
- 13 行の品目名に出てくる語のうち、**5 行以上に出る語は 1 つしかない。**
  語彙を 1 つ足しても最大 5 行しか増えない。**残りは 8 語以上いる。**
- つまり「4 語では足りない」は語彙の数の問題であって、経路の問題ではない。

15 周目は「記号名をどう突き合わせるか(表記のゆれ)」を対象にする。
**その前に採否の基準を書いてコミットする。**
