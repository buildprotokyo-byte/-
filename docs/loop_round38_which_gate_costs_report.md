## 3. **足し算が合うことを、別の周が裏から確かめた**

基準の 6 節にこう書いた——「**繰り返す記号の関門の値段は引き算でしか出ない。
足し合わせの確認ができない。3 つ目の関門を見落としている可能性は、この測り方では消えない。**」

**消えた。周31 が独立に数えていた。**

`docs/loop_round31_what_rules_would_cover_report.md` の線1 は、
入口の 2,887 件が**何種類の対象に集まるか**を数えている。

| 順位 | 件数 |
| ---: | ---: |
| 1 | **2,488** |
| 2 | **233** |

**引き算で出した 2,488 と、測った 233 が、そのまま並んでいる。**
**2,488 + 233 = 2,721 で、`その他` で失われた件数とちょうど合う。**

**だから 3 つ目の関門は無い。2 つで全部である。**

**これは別の周・別の技術(種類ごとの件数を数える)で出した数なので、裏取りになる。**
**周38 だけでは言えなかったことが、周31 の記録と突き合わせて言えるようになった。**

## 4. **線2 は不通過 — 凡例の道は数量を 1 件も足していない**

`凡例` は `LEGEND_PAGE_KINDS` に入っているので、**止まるのではなく別の道へ入る**
(`read_legend_symbols`)。**だから件数は `その他` と違うはずだと先に書いた。**

**同じだった。どちらも 166 件。**

**凡例として読んだ記号は、数量になっていない。**
**「別の道がある」ことと「その道が何かを出している」ことは別である。**

**これは `NOT_CONNECTED`(繋げなかった部品の記録)とは違う形の途切れ方**——
**道は通っていて、出口が無い。**

**この 1 件は、基準に「合格 = 違う件数」と先に書いていなければ気づかなかった。**
**同じ数字が出たことが答えになる線は、書いておく値打ちがある。**
