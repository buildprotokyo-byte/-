# 裸の数は、開き戸の絵のそばに無い

測定日: 2026年9月24日。数え方は `docs/k22_bare_number_near_door_criteria.md`
(**数える前にコミット済み**)。対象: P011 匿名化v2。
**図面の数値そのものは書かない。件数だけを書く。**

## 先に決めた数え方での結果

| | 件数 |
|---|---:|
| 縮尺が読めたページ | **20** |
| 開き戸の振りの円弧が取れたページ | **5** |
| 円弧の本数 | **90** |
| **そばに裸の 3〜4 桁の数がある円弧** | **0** |
| その範囲に入った裸の数 | **0** |

**先に決めた「0 本」の枝にあたる。**

> 裸の数は建具の絵から離れている。**「建具の幅は印字されていない」に一歩近づく。**
> ただし引戸・折戸を拾えていないので**断定しない**。

## 距離の散らばり(**先に決めた数え方の外。判定には使わない**)

「そばにある」の範囲を後から広げると、**結果を見てから線を引き直すこと**になるので
しない。そのかわり、**判定に使わない説明として**、円弧 1 本ずつについて
「いちばん近い裸の数までの距離」を扉の幅を 1 とした倍数で出した。

| | 扉の幅の何倍か |
|---|---:|
| 最小 | **0.9** |
| **中央** | **10.3** |
| 最大 | 30.8 |

| 距離 | その中に入る円弧 |
|---|---:|
| 1 倍以内 | **1 本** |
| 2 倍以内 | 4 本 |
| 3 倍以内 | 4 本 |
| 5 倍以内 | 19 本 |
| 10 倍以内 | 40 本 |

**いちばん近い数でも、半分の円弧は扉 10 枚ぶん以上離れている。**
**裸の数は建具に付いていない。**

## ここまでで言えること

3 つ並べる。

1. **凡例が宣言した建具の寸法の書き方(`W` + 数 / `H` + 数)は、図面に 1 件も無い**
   (`docs/k22_door_width_count_report.md`)。
2. **建具番号らしい語は 7 ページに 17 件ある。**番号は使われている。
3. **裸の数は、開き戸の絵のそばに無い**(この文書)。

**開き戸については、幅が図面に印字されている見込みは薄い。**

## まだ言えないこと(**断定しないために書く**)

- **引戸・折戸は円弧を描かないので、この目印では 1 枚も拾えていない。**
  引戸・折戸の幅が図面に書かれているかは、**この数え方では 1 件も確かめていない。**
- **円弧が取れたのは 5 ページだけ**である。ほかのページに開き戸が無いのか、
  取れなかっただけなのかは、ここでは分けていない。
- **そばに数が無いことは、幅がどこにも無いことではない。**寸法線が離れた位置に
  まとめて置かれている描き方もある。**この数え方では、離れた寸法線を建具に
  結び付けられない。**
- **だから「建具表以外に道が無い」とは、まだ書かない。**書けるのは
  「**開き戸については、幅が建具の絵のそばには印字されていない**」までである。

## 次に確かめるなら

**寸法線そのものを拾って、その両端が何に当たっているかを見る**のが筋である。
いまの機械に寸法線を拾う経路はない(`axes/image_axis/printed_dimensions.py` は
文字としての数を拾うだけで、線と結び付けていない)。
