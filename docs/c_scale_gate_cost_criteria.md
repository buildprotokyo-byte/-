# 44周目 基準(トライアルC): 「縮尺が読めなければ開き戸を探さない」は、何を取りこぼしているか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。トライアルC(段階の順番)に移る周。

## **まず、マスタープロンプトの前提とコードが食い違っていることを書く**

マスタープロンプト4章のトライアルCは「**段階0〜10の順番を入れ替える。原則は変えず、順番だけ**」。

**その「段階0〜10」が、設計書にもコードにも無い。** 取り決め①(記録を信じずコードを読む)
に従って確かめた。

- `docs/design_v8.md` にあるのは **章 1〜17**、**段階A / 段階B**(過去の検証フェーズの呼び名)、
  **段階0.5**(読み取り時の指示。方式A2)、**3段階確信度階層**(確信度の分類)。
  **0〜10 の連番の工程は無い。**
- 一番近いのは `docs/handoff_2026-09-20.md` の **Layer 0〜9**(10 層)。**0〜9 であって 0〜10 ではない。**
  そして **`Layer` という語はコードに 1 か所も無い**(`STAGES`・`PIPELINE`・`STAGE_ORDER` も無い)。
  README がディレクトリを層に対応づけて説明しているだけで、コードにその対応は無い。

**つまり「並べ替えられる段階のリスト」は存在しない。** 順番は **Python の文の並び**として
`intake/drawing_intake.py` に直接書かれている。**入れ替えるとは、文の並びを書き換えることである。**

**トライアルCを字面どおりには実行できない。** おーちゃんに報告したうえで、
**問いの中身(順番は結果を変えるのか)を、実在する順番に当てて測る。**

## 実在する順番と、そのうち入れ替えられないもの

本番のページ内の並びは `intake/drawing_intake.py:909-967`。

| 並び | 入れ替えられるか |
|---|---|
| 縮尺を読む → 開き戸を拾う | **入れ替えられない。** `955` が `if scale is not None:` で塞いでいる |
| 縮尺を読む → 表を読む | **入れ替えられる。** コード自身が `931-932` で「表の読み取りは縮尺に依存しない」と書いている |
| ページごとの処理 → ページ横断の集約 | 入れ替えられない(集約はループで貯めた値を使う) |
| 判定 → 抜き取り監査 | 入れ替えられない(監査は判定結果を母集団にする) |

**この周で測るのは 1 行目。** 35 周目に「測れていないこと」として自分で書いた穴そのものである。

> 開き戸の円弧は **P5(縮尺)が読めたページでしか走っていない。** 34 ページ中 20 ページでしか
> 縮尺が読めないので、**残り 14 ページでは開き戸を探してすらいない。**

**順番の決まりが、何も探さないページを 14 枚作っている。** その値段を測る。

## 測るもの

**縮尺が読めなかったページに、同じ図面の別のページで実際に読めた縮尺を仮に当てて、
開き戸の円弧が出るかどうかだけを数える。**

**これは「その縮尺が正しい」という主張ではない。** 正しい縮尺は分からない。
**「どの縮尺を当てても 0 件なら、この 14 ページには開き戸が無い」**と言えるだけである。
**片側しか言えない測り方であることを、結論に必ず書く。**

| 記号 | 何を測るか |
|---|---|
| **R1** | 縮尺が読めたページ数 / 読めなかったページ数 |
| **R2** | 読めたページに実際に出てきた**縮尺の種類**の数 |
| **R3** | 縮尺が読めなかった各ページで、**R2 の各縮尺を当てたときの円弧の数** |
| **R4** | **どの縮尺を当てても 0 件だったページの数**(=取りこぼしが無いと言えるページ) |
| **R5** | **1 つでも円弧が出たページの数**(=取りこぼしているかもしれないページ) |
| **R6** | R5 のページでの円弧の数が、**当てる縮尺でどれだけ振れるか**(最小・最大) |
| **R7** | 対照として、**縮尺が読めたページ**に別の縮尺を当てたときの振れ |

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **R4 = 14(全部)** → **順番の決まりは何も取りこぼしていない。** トライアルCのこの 1 行目は
  「入れ替える価値なし」で終わり。次の並びへ移る。
- **R5 ≧ 1** → **取りこぼしているかもしれないページがある。** ただし
  **R6 の振れが大きければ、縮尺を仮に当てて拾うのは危ない**(35 周目の「縮尺が 2 倍ずれると
  通る面の数が 4 倍前後ずれる」と同じ形)。**その場合は「拾える」と書かない。**
  書くのは**「探してすらいないページに、拾える候補が何個あるか」の上限**だけ。
- **どちらとも言えない**(R7 の対照で、読めたページでも振れが大きい)
  → **測り方が縮尺に敏感すぎる。** 結論を出さず、測り方を作り直す。

**この周では実装を変えない。** 入れ替える価値があると出ても、**順番の変更は判定のしかたに
触るので PR のまま待つ。**

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 縮尺が読めたページで、本来の縮尺での円弧の数を出す | 35 周目の 90 件を再現する |
| **2** | 縮尺が読めたページに**別の**縮尺を当てる(R7) | 数が変わる(縮尺が効いていることの確認) |
| **3** | 反復 3 回 | 3 回とも同じ |

**対照2 で数が変わらなければ、縮尺は円弧の判定に効いていない。** そのときは結論を出さない。

## この周で変えないもの

- **実装には手を入れない。** 仮の縮尺を当てるのはベンチマークの中だけ。
- 判定のしかた・基準値・階層の条件にも触れない。
- 実図面のパスは引数で渡す。**出すのはページ数と件数だけ。図面の文字は 1 文字も出さない。**
