## 壊れた 4 件の中身

4 件はすべて同じ形である。

> **「壁軽量鉄骨天井下地撤去」** と **「天井軽量鉄骨壁下地撤去」** が同じ鍵になる。

**壁に付いている天井下地**と、**天井に付いている壁下地**は、**別の行である。**
文字は同じで、並びだけが違う。動作(撤去・張り・塗り・敷き)の 4 通りで同じことが起き、
合わせて 4 件になった。

**これは作り話ではない。** 材料の語は標準書式の品目名から機械的に切り出したもので、
「軽量鉄骨壁下地」と「軽量鉄骨天井下地」は**どちらも内訳書標準書式に実在する品目**である。

## 判定(**基準の文字どおり**)

基準に書いた決め方はこうだった。

| 結果 | 決め方 |
|---|---|
| B1 = 0 | どちらの向きにも使える |
| B1 > 0 だが B2 = 0 | **向きで分ける** |
| B2 > 0 | 確定させる向きには絶対に使わない |

**N3・N4 は B1 = 4、B2 = 0。したがって「向きで分ける」である。**

- **人へ回す向き**(質問を作る・漏れを見つける)では **N4** を使う。真の一致 0.992。
  間違って同じ鍵にまとめても、**人が見るので取り返せる。**
- **黙って確定させる向き**では **N1** を使う。真の一致 0.395 と低いが、**偽の一致 0。**
  一致が根拠を強める向きに働く以上、**ここで別物を混ぜてはいけない。**

これは PR #6 で出した「誤りが人へ回る向きでは広く、黙って確定させる向きでは狭く」という
考え方と、**同じ形の答えになった。**

## 送り仮名を落とすと、偽の一致は増えなかった

N4(N3 + 送り仮名を落とす)は、**真の一致を 0.952 → 0.992 に上げて、
偽の一致は 4 件のまま**だった。

測る前に「送り仮名を落とすと動作の語が短くなるので、偽の一致が増える向きにも働く」と
書いたが、**この規模では増えなかった。** ただし対照 1(並べ替えた鍵)では
N3 が 10 回とも 4 なのに **N4 は 2〜4 とばらついた。** 送り仮名を落とすと
**鍵の文字が減り、並べ替えで壊しにくくなる**ためで、**N4 のほうが壊れ方が読みにくい。**
人へ回す向きに限るなら差し支えないが、**確定させる向きに上げるときはここを測り直す。**
