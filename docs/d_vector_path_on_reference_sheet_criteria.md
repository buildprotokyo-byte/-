# 55周目 基準: **正解データのある紙で、ベクターの経路は動くのか**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。54 周目の「次の周」に書いたとおり。

## なぜこの題なのか

54 周目で、**正解データ(開き戸の円弧 5 件)は古いほうのファイルで作られていた**と分かった。
**v2 では 34 ページのどこにも収まらない。**

一方、**35 周目からずっと「90 件拾った」と言っている円弧は v2 のものである。**

**この 2 つが別の紙なら、「ベクターの円弧が正解を何件当てたか」は測れていない。**
**当たっているとも外れているとも言えない。**

**それを確かめる。**

## 測るもの

**古いほうのファイル(正解データのある紙を含むほう)に、同じ経路をそのまま当てる。**

| 記号 | 何を測るか |
|---|---|
| **Z0** | 古いほうのページ数と、**文字数の合計** |
| **Z1** | 古いほうで**ベクターの図形があるページ数**(`page.get_drawings()` の件数 > 0) |
| **Z2** | 古いほうで**縮尺が読めたページ数** |
| **Z3** | 古いほうで**ベクターの経路が拾った円弧の合計** |
| **Z4** | **v2 で拾った円弧の合計**(対照。35 周目と同じ数になるはず) |

**出すのはページ数・件数・真偽だけ。図面の文字は 1 文字も出さない**
(**文字数**は出すが、**中身は出さない**)。

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **Z3 = 0** → **ベクターの経路は、正解データのある紙で 1 件も動かない。**
  **「ベクターの円弧の当たり外れは、実図面で測れていない」ことが確定する。**
  **なぜ動かないのかを、Z1 と Z2 で名指しする。**
  - **Z1 = 0** なら「ベクターの図形が無い(スキャンだから)」
  - **Z1 > 0 かつ Z2 = 0** なら「図形はあるが縮尺が読めない(文字が無いから)」
  - **Z1 > 0 かつ Z2 > 0** なら「図形も縮尺もあるのに円弧として通らない」
  **そのうえで、実図面の報告書に但し書きを足す**
  (**設計の記録。判定のしかたも基準値も変えない**)。
- **Z3 ≧ 1** → **動く。**
  **次の周で、その紙の円弧を正解 5 件と IoU 0.10 で突き合わせる。**

**どちらの枝でも、51 周目の結論は変えない**(51 周目は箱の座標を使っていない)。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1(経路が生きていることの確認)** | 同じ関数を v2 に当てた合計 | **90 件**(35 周目と同じ) |
| **2** | 古いほうのページ数 | **34** |
| **3** | 反復 3 回(Z3) | 3 回とも同じ |

**対照1 が通らなければ結論を出さない**(経路そのものが壊れているのか、
紙のせいなのかを切り分けられないため)。
