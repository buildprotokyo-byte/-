## 今回の対象

38 周目で落ちどころが「列の見出しの当て方」に確定した。**素直な直し方は含み一致だが、
`幅` は `幅木` に、`数` は `係数` に含まれる。入れる前に上限を測る周。**

内側 = `建具` の語があるページの表 **47 個**(当たりを数える側)。
外側 = それ以外の表 **60 個**(誤爆を数える側)。
**これは当たり・誤爆の代わりの目印であって正解ではない**(基準にもそう書いた)。

## 判定と理由

基準に先に書いた 3 つの線で見る。

| 条件 | 線 | 観測 | |
|---|---|---|---|
| 当たり | 内側で H0 から 1 個以上増える | 0 → 1(増分 **1**) | **◯** |
| 誤爆 | H2 < 0.5 | **1.000** | **×** |
| 取り違え | H4 = 0 | **7** | **×** |

> **当たりはあるが誤爆か取り違えで落ちる** → **保留。** 役割ごとに緩め方を変える案を次に測る。

**判定: 保留。案1(丸ごと含み一致)はこのまま入れない。**

### 何が起きているか

**`幅` の当たりが 0 → 12 に跳ねたのが、そのまま危険の中身である。**
内側の 47 個のうち 12 個で `幅` が当たったのに、**建具表として通ったのは 1 個だけ。**
つまり**当たった 12 個のほとんどは建具表ではない。** 基準に先に書いた
「`幅` は `全幅`・`幅木` に含まれる」が、そのとおりの形で出た。

**H4 の 7 も同じ話。** 1 つの升目が 2 つの役割に当たるということは、
**その升目が役割の名前を含んだ別の言葉**だということである。

**誤爆 ÷ 当たり = 1.000 は、27〜31 周目の面積の語で「図面から作った語彙はどれも
0.56〜1.00 に着地した」のと同じ帯に入る。** 緩め方が粗いときに毎回ここに落ちる。

### 対照2 に小さな警告がある

**内装仕上表が 2 → 3 に増えた。** 基準の「通り続けたか」は満たしているが、
**現に動いている経路まで 1 個動かしている。** 増えた 1 個が本物の仕上表かは測っていない。
**緩め方を変える案は、建具表だけでなく仕上表にも同じ測り方を当てる。**
