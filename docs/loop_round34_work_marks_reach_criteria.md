## 2. 測る前に読んだこと(取り決め①)

**この周に入る前に、コードと過去の報告を読んで 2 つ分かった。**

1. **色の道はもう死んでいる。**
   `benchmarks/measure_legend_code_colors.py` の説明文が自分でこう書いている。

   > **この道具の数字から「赤なら交換・新設」とは読めない。** 実物を見たところ、
   > **この図面は撤去の記号も赤で描いていた。**
   > **色で分かるのは「記号かどうか」までで、「撤去か新設か」は分からない。**

   **色を出典にする周は立てない。**(記憶には無く、残っていたのはコードの説明文だった。
   周11〜20 で踏んだ形と同じなので、ここに書き残す。)

2. **線種の見本は凡例に無い**(`legend_lookup.py`、`line_styles` は 0 件)。**刻みの比率の道も立てない。**

3. **工事の区分の印は 95 件読めている**(`docs/k20_legend_lookup_report.md`)。
   内訳は電気位置図 45 件・仕上表 34 件・平面図と撤去図 16 件。
   **だが K-20 が数えたのは「読めたか」までで、「数量に届くか」は数えていない。**
   **そこがこの周である。**

## 3. なぜこの問いか(手段ではなく目的から)

見積は撤去する物と新しく付ける物を分けないと書けない。

周32・周33 で分かったのは、**こちらが選んだ位相の語は、ページ単位でも位置でも数量に付かない**
ということだった。周33 では**囮(そのへんの普通の印字語)に 3 段とも負けた。**

**だが周32・周33 で当てたのは「私が選んだ 12 語」である。**
**図面自身が凡例で名乗っている印は、別のものかもしれない。**

周5 の形をもう一度置く。**天井高は紙に 71 か所あったのに、室に結び付いたのは 1 個だった。**
**読めた件数と、届いた件数は別である。**

## 4. 測るもの

図面は **P011 の匿名化 v2**(34 ページ、A3)。**v1 ではない。**
パスと対照表のパスは引数で渡す。リポジトリには入れない。

距離は**紙の上のミリ**で測る(縮尺がページごとに違うので実寸には直さない)。
**10mm / 25mm / 50mm** の 3 段。**周33 とまったく同じ測り方**にして、比べられるようにする。

**囮も周33 と同じ**——紙に実際に印字されている、工事の区分の印でない語から同数を引く
(10 回、中央値、seed 20260925)。**同じ囮を使わないと周33 と比べられない。**

## 5. 線(合格・不通過の数字を先に書く)

### 線1 — **届くか**

いちばん狭い **10mm** で、工事の区分の印がそばにある数量の割合。

- **合格 = 0.10 以上、かつ囮との差 0.20 以上。**
- **周33 とまったく同じ合格の条件にする。** そうしないと「出典を変えて良くなったか」が読めない。

### 線2 — **囮**

3 段とも本物と囮の両方を報告に載せる。**周33 の数字も並べて載せる。**

### 線3 — **ページが重なるか**

工事の区分の印が出るページと、数量が出るページの重なりを数える。

K-20 は「**工事の区分はまったく別のページ**(2 ページで 47 件)に出る」と書いている。
**これは 95 件のうちいちばん強い 45 件の話で、残り 50 件がどこに出るかは
数量のページと突き合わせていない。** ここで突き合わせる。

- **これは合格・不通過の線ではない。** どこで途切れているかを見る欄である。
  **どういう数字なら不通過かを先に書けないので、線にしない**(周13・周14 の失敗、
  および周33 で線3 を形だけ立てた失敗)。

### 線4 — **安全確認**

- `app.py` と `intake/` は変更しない(K-29)。
- 自動確定は 0 件のまま。
- **合格 = 本番の判定を 1 か所も変えていないこと。**

## 6. 測らないこと(先に宣言する)

- **凡例の印そのもの(記号と意味の対)は、リポジトリにも報告にも書かない**(K-20・K-22・K-33)。
  出すのは件数・割合・ページ番号・距離だけ。内訳は共有フォルダだけ。
- **どの数量が撤去でどの数量が新設か、という判定はしない。**
- コードは直さない(取り決め②)。

## 7. この測り方で分からないこと(先に書く)

- **近いことは「指している」ことではない。遠いことも「指していない」ことではない。**
  引出線はたどらない。
- **座標を持たない数量(周33 で 161 件)は測れない。**
- **95 件のうち仕上表の 34 件は、別の経路がすでに読んでいるところ**
  (`estimating/finish_schedule_scope.py`)。**二重に数えていることになるので、
  内訳を分けて報告する。**
