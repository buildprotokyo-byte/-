## 測っていて分かった、測り方のほうの問題

### 1. 同じ前提でも、回ごとに振れ幅が大きい

**前(v1)の 3 回は、名前を出した件数が 0 / 52 / 38 だった。**
1 回目は 96 件すべてに名前を出さず、理由として
「凡例と突き合わせるのは意味の解釈だから、認識の仕事ではない」と書いた。
2 回目は同じ前提で 52 件に名前を出した。
**同じ前提・同じ紙で、やるかやらないかが割れている。**
中央値で判定する決め方にしておいたのは正しかった。

### 2. 採点の当て方が負けている(**追記2 の補助の数字**)

両方の条件とも「正しい」が 96 件中 3〜5 件しか出なかったので、外れの中身を見た。
**送り仮名が 1 文字違うだけ、語順が入れ替わっているだけ、の組が外れになっていた。**
追記1 の当て方(完全一致か、短いほうが 60% 以上を占める含み)は、
**文字が挿入されたり語順が入れ替わると当たらない。**

そこで**基準に追記2 を足し(測り直す前にコミットした)**、
2 文字ずつの重なり(Dice 係数)0.5 以上を「近い」として、前後の両方に同じ当て方で掛けた。

| | 前(v1) | 後(v2) |
|---|---|---|
| 群A の「近い」(中央値) | **15**(0 / 18 / 15) | **15**(18 / 12 / 15) |
| 群B の「近い」(中央値) | **6**(0 / 9 / 6) | **4**(6 / 2 / 4) |

**当て方を直しても、前後の差は出ない。**むしろ群B は後のほうが少ない。
**結論は変わらなかった。**

**それでもこの数字は下振れしている。**言い換え(別の言葉で同じものを指す)は
文字が重ならないので、この当て方でも当たらない。
実際に外れの中で目立つのは、**同じ器具を、読み手は規格の名前で呼び、
凡例は案件の呼び名で書いている**組である。**どちらも間違いではない。**
**この「規格の名前 対 案件の呼び名」は、採点の問題であると同時に、
実務で照合するときに必ず起きる問題でもある。**

### 3. 1 段目を肩代わりしていることの影響

升目を切り出して渡したので、**囮の空の升目 5 件は、どちらの条件でも 3 回とも
「記号が無い」と正しく報告された。**これは読み手の手柄ではなく、
**切り出しが「ここに 1 つある」と教えてしまっている**ぶんが入っている。
**1 段目を含めた測定は、まだ一度もしていない。**
