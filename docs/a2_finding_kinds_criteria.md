# 23周目 診断・仮説・採否の基準

2026-09-23。**この文書は測る前に書いてコミットする。結果を見てから基準を変えない。**

## 1. 今回の対象

**指摘の出し方。**

## 2. 診断

22 周目(`docs/a2_printed_dimension_report.md`)で、基準の外の測定として
**正しく入れた値でも「食い違い」として出てしまう割合**を測った。

| 値の作り方 | 「印字に無い」と言われる |
|---|---|
| 2 区間の和 | **0.986** |
| 3 区間の和 | **0.997** |

壁の寸法は区間ごとに分けて印字されるので、**室の寸法は「区間の和」になるのが普通**である。
**いまの実装は、それをほとんど全部「食い違い」として出す。**

原因ははっきりしている。**「間違っている」と「確かめられない」を同じに数えている。**
20 周目に語彙の測定で見つけたのとまったく同じ形の間違いである。

- **桁違い** … 図面に 10 倍・10 分の 1 が印字されている。**間違いの見込みが高い。**
- **印字に無い** … その値がこのページに印字されていない。
  **区間に分かれていれば、正しくてもこうなる。間違いとは言えない。**

## 3. 仮説

> 2 つを分ければ、指摘は桁違いだけになり、**空振りが消える。**
> **桁違いの見つけやすさは落ちない。**

## 4. 変えること

- `印字に無い` の扱いを **「確かめられない」** に変える。**食い違いとして数えない。**
- **指摘(`mismatches`)として出すのは桁違いだけ**にする。
- **「確かめられない率」を別に出す**(20 周目に決めた測り方と同じ形)。
- この層の名前の意味を狭める。**一般の検算ではなく、桁違いの見張りである。**

**拾う層(`axes/image_axis/printed_dimensions.py`)には触らない。**
**窓の値・足し合わせを許さないことも変えない。**

## 5. 測る指標(分母を必ず付ける)

| 記号 | 何を測るか | 分母 |
|---|---|---|
| **V1** | **正しい見込みの値(2 区間の和)が指摘として出る割合**(空振り) | 2 区間の和の通り数 |
| **V2** | 桁違い(10 倍・10 分の 1)を指摘として出す割合 | 印字の通り数 |
| **V3** | でたらめな寸法 1,000 個が指摘として出る割合 | 1,000 |
| **V4** | 確かめられない率(正しい見込みの値・でたらめ、それぞれ) | それぞれの通り数 |
| **V5** | 壊し試験で検出できた数 | 仕掛けた数 |

## 6. 対照

1. **反復 3 回** … 同じ結果になること。
2. **乱数の種を変えて 3 回** … V3 が大きく動かないこと。
3. **印字が空のとき** … 指摘 0 件、確かめられない率 1.000 になること
   (**印字が無いことを「全部間違い」にしない**)。

## 7. 採否の基準(**これを先に決める**)

- **採用**: **V1 = 0.000** かつ **V2 = 1.000** かつ **V3 ≤ 0.05**
  かつ **V5 が全検出** かつ 対照が全部通る。
- **不採用**: **V2 < 1.000**(桁違いの見つけやすさが落ちた)、または **V1 > 0.05**。
- **保留**: その間。
