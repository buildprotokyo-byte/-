## 3. 測るもの

図面は **P011 の匿名化v2**(34 ページ、A3)。**v1 ではない。**

**種類の宣言だけを変えて、入口が出す数量の件数を数える。**
位相は渡さない(周36 とは別の問い)。

| 宣言する種類 | 繰り返す記号 | 室の輪郭 | 既に測った件数 |
| --- | --- | --- | ---: |
| 宣言しない | 開く | 開く | **2,887**(周36 追記1) |
| `平面図` | 開く | 開く | **2,887**(周36 追記1) |
| `その他` | 閉じる | 閉じる | **166**(周36) |
| **`設備図`** | **開く** | **閉じる** | **これから測る** |
| **`凡例`** | **凡例として読む別の道へ入る** | 閉じる | **これから測る** |

**`設備図` は室の輪郭だけを閉じるので、2 つの関門の値段を分けられる。**
**繰り返す記号だけを閉じて室の輪郭を開く種類は無い**ので、そちらは引き算になる。
**引き算で出した数は「足すと合う」の確認ができない。報告にそう書く。**

## 4. 線(合格・不通過の数字を先に書く)

### 線1 — **室の輪郭の関門は、繰り返す記号の関門より安いか**

- **合格 = `設備図` で失われる件数が、`その他` で失われる 2,721 件の半分未満(1,360 件未満)。**
- **予想**: 合格する(**記号は 1 ページに何百も出るが、室の輪郭は数個**)。
  **予想であって、確かめた事実ではない。**
- **落ちたら、室の輪郭のほうが高くついている**ことになり、直す順番が変わる。

### 線2 — **凡例と宣言すると何が起きるか**

`凡例` は `LEGEND_PAGE_KINDS` に入っているので、**止まるのではなく別の道へ入る。**

- **合格 = 件数が `その他` の 166 件と違う。**
- 同じなら、凡例の道は数量を 1 件も足していないことになる。

### 線3 — **裏返しの危険**

- **合格 = どの宣言でも自動確定した数量が 0 件。**
- **0 でなければ、その場で止めて報告する。**

## 5. 測らないこと(先に宣言する)

- **直さない。** `app.py` と `intake/` は 1 行も変えない(K-29、取り決め②)。
- 位相は渡さない(周36・周37 の問い)。
- 実案件の金額・数量の値・対象名・室名。**出すのは件数だけ。**

## 6. この測り方で分からないこと(先に書く)

- **繰り返す記号の関門の値段は引き算でしか出ない**(3 節)。**足し合わせの確認ができない。**
- **3 つ目の関門を見落としている可能性は、この測り方では消えない。**
  消すには、両方を開く種類と両方を閉じる種類の差が、2 つの関門の和と合うことを
  示す必要がある。**それができない理由は 3 節のとおり。**
