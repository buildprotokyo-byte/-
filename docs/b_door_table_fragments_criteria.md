# 42周目 基準: 建具表は、1 つの表が割れているのか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。41 周目(キラークエスチョン)の「次の周」に書いたとおり。

## なぜこの題なのか

**5 つ試して 5 つとも違った。残っているのは表の升目の取り方だけである。**

| # | 疑ったもの | 結果 |
|---|---|---|
| 1 | 罫線の表が無い | 違う(28 ページに 107 個) |
| 2 | 升目に文字が無い | 違う(107 個すべてに文字) |
| 3 | 言い換えの語が足りない | 違う(4 通りで最大 1 / 47) |
| 4 | 当て方の形が悪い | 違う(後方一致は当たりも誤爆も 0) |
| 5 | 見出しが列にある | 違う(転置しても最大 1) |

**そして 3 周ぶんの数字が同じ形を指している。**

- 36 周目: 建具番号らしい列を持つ表が **5 つ。その 5 つとも付き添いが 0。**
- 40 周目: 種別が **3 表**、数量が **2 表**で当たる。**なのに通った表は 0。**
- 41 周目: 転置しても種別 **4 表**・数量 **2 表**・高さ **1 表**。**通った表は 0。**

**どの向きで見ても、建具番号と付き添いが「同じ表の中」で出会わない。**

**いちばん素直な説明は、1 つの建具表が複数の表に割れていること。**
内側 10 ページに表が 47 個で、**1 ページに 5 個**の勘定である。

## 測るもの

**枠が接している・重なっている表をくっつけてから、同じ当て方を当てる。**
**くっつけ方はベンチマークの中だけ。実装には手を入れない。**

くっつけ方(**先に決める**): 同じページの表のうち、`rect_pt` の枠を
**上下左右に `SLACK` ポイントだけ広げたとき重なる**ものを同じ塊にする。
つながりは**推移的**に追う(A と B、B と C が接していれば A・B・C で 1 つ)。
塊にした表の升目は、**元の表の行をそのまま上から並べる**(幅がそろわない行はそのまま)。

`SLACK` は **0 / 2 / 6 / 12 ポイント**の 4 通りを並べる。**どれか 1 つを先に選ばない。**

| 記号 | 何を測るか |
|---|---|
| **P1** | `SLACK` ごとの、くっつけたあとの塊の数(内側・外側) |
| **P2** | **当たり**: 内側の塊で建具表として通った数 |
| **P3** | **誤爆**: 外側の塊で通った数 |
| **P4** | **誤爆 ÷ 当たり** |
| **P5** | 取り違え(升目が 2 役割以上) |
| **P6** | 役割ごとの当たり(内側の塊) |
| **P7** | 内装仕上表を同じくっつけ方で測った、通った数 |

当て方は 41 周目と同じ 4 通り(K0 完全一致 / K1 含み一致 / K2a 後方一致 / K2b 区切って完全一致)。

## 採否の線(**39〜41 周目と同じ 3 つ。結果を見てから変えない**)

| 条件 | 線 |
|---|---|
| **当たり** | **P2 ≧ 2**(くっつけないときの最大が 1 なので、1 では効いたと言えない) |
| **誤爆** | **P4 < 0.5** |
| **取り違え** | **P5 = 0** |

- **3 つとも満たす組み合わせ(`SLACK` × 当て方)がある** → **答え: 表が割れていた。**
  **`SLACK` が小さいほうを採る**(くっつけすぎない向き)。同じなら当たりの多いほう。
  **実装案を書く。判定に触るので PR のまま待つ。**
- **P2 ≧ 2 だが誤爆か取り違えで落ちる** → **割れてはいるが、くっつけ方が粗い。**
  接し方の向き(縦に続く / 横に並ぶ)を分ける周を作る。
- **どの `SLACK` でも P2 ≦ 1** → **割れているのでもない。**
  **ここで建具表の追跡をいったん止め、判断待ちとしておーちゃんに出す。**
  6 つ試して 6 つとも違ったことと、次に要るもの(**2 件目の案件の CAD 由来 PDF**)を書く。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 合成の建具表を 4 通りの `SLACK` でくっつける | **どの `SLACK` でも通り続ける**(壊していない) |
| **2** | `SLACK = 0` が 41 周目の数を再現するか | 内側 K0 0 / K1 1 / K2a 0 / K2b 0 |
| **3** | 内装仕上表(P7)が `SLACK = 0` のときから**減らない** | 減ったらその組み合わせは不採用 |
| **4** | 反復 3 回 | 3 回とも同じ |

**対照2 が再現しなければ、くっつけ方が `SLACK = 0` でも何かを変えている。**
そのときは結論を出さない。

- 実図面のパスは引数で渡す。**出すのは件数と割合だけ。図面の文字は 1 文字も出さない。**
