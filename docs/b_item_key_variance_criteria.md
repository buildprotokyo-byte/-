# 32周目 基準: 鍵の表記ゆれを揃えると、一致は増えるのか。偽の一致は出ないのか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。トライアル B(多方向からのアプローチ)の続き。

## なぜこの題なのか

`arbitration/multi_path_reconciler.py`(PR #72、まだマージされていない)の
`PathItem.item_key` の説明に、こう書いてある。

> **表記ゆれは呼ぶ側で揃える。**

PR #72 の報告にも「実案件では『埋込コンセント』と『コンセント(埋込)』が別の鍵になり、
一致がほとんど起きない。次の周の候補」と書いてある。**まだ何も手当てしていない。**

**コードを読んで確かめた。** `item_key` は文字列そのままで突き合わせており、
揃える処理はどこにも無い。

## いちばん危ないのは「増える」ほうではない

鍵を強く揃えるほど、一致は増える。**そして一致は根拠を強める向きに働く。**
つまり**別物を同じ鍵にまとめてしまうと、黙って確定する側に効く。**

PR #6 で出した「誤りが人へ回る向きと、黙って確定させる向きで分ける」という考え方が、
そのままここに当てはまる。

**したがってこの周は、増えた数と作ってしまった偽の一致を、必ず両方出す。**

## 使うデータ(**実案件も正解ファイルも使わない**)

公共建築工事内訳書標準書式(建築工事編・令和7年12月改定)の細目別内訳から、
`docs/knowledge/candidates.md` J 節 3・J 節 4 に写された**35 品目の名前**を使う。
**これらは互いに別の品目である**(だから「同じ鍵になったら偽の一致」と言える)。

## 表記ゆれの作り方(**測る前に決めた。機械的に作る**)

同じ品目を指す、別の書き方を機械的に作る。

| | 変形 | 例 |
|---|---|---|
| **T1** | 中黒・空白を 1 つ入れる | ビニル床タイル撤去 → ビニル・床タイル撤去 |
| **T2** | 先頭 2 文字を括弧に入れて末尾へ回す | 埋込コンセント → コンセント(埋込) の形 |
| **T3** | 先頭 3 文字を括弧に入れて末尾へ回す | 同上 |
| **T4** | 送り仮名を落とす(張り→張・塗り→塗・敷き→敷) | 床タイル張り → 床タイル張 |
| **T5** | 長音記号 ー を全角ハイフン − に置き換える | カーペット撤去 → カ−ペット撤去 |

**T1〜T5 は、同じ品目の別の書き方である。揃えば正しい。**

罠を 1 つ入れる。

| | 変形 | なぜ罠か |
|---|---|---|
| **T6** | 末尾の「撤去」を落とす | 「床タイル撤去」と「床タイル張り」は**別の品目**である。揃えてはいけない |

## 揃え方の候補(**測る前に決めた**)

| | 中身 |
|---|---|
| **N0** | 何もしない(いまの `item_key` そのまま) |
| **N1** | NFKC で正規化 → 記号と空白を落とす → ひらがなをカタカナに → 大文字に |
| **N2** | N1 に加えて、**括弧の中身を外に出す**(位置を無視する) |
| **N3** | N2 に加えて、**文字を並べ替えて比べる**(語順を完全に無視する) |

**N3 がいちばん危ない。** 語順を無視すると、別物が同じ鍵になりやすい。
**危ないと分かっていて入れるのは、どこで壊れるかを数で見るためである。**

## 測るもの

| 記号 | 何を測るか |
|---|---|
| **A1** | **拾えた真の一致。** T1〜T5 で作った書き方が、もとの品目と同じ鍵になった数 / 全変形数 |
| **A2** | **作ってしまった偽の一致。** 別の品目どうしが同じ鍵になった組の数 / 全組数(35 品目の組は 595 通り) |
| **A3** | **罠に落ちた数。** T6(撤去を落としたもの)が、撤去のある品目と同じ鍵になった数 / 35 |

## 採否

- **採用**: A1 が N0 より大きい **かつ** **A2 = 0** **かつ** **A3 = 0**。
- **保留**: A1 が N0 より大きいが、A2 か A3 が 0 でない。
- **不採用**: A1 が N0 以下。

**A2 と A3 に「小さければよい」は無い。0 でなければ採らない。**
偽の一致は黙って確定する側に効くからである。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | N0 で A1 を測る | **0 に近い**(揃えないと拾えない、が前提の確認) |
| **2** | でたらめな 35 個の文字列(同じ文字数分布)で A2 を測る × 10 回 | 本物の A2 と比べて、偽の一致の出やすさが説明できる |
| **3** | 反復 3 回 | 3 回とも同じ |
