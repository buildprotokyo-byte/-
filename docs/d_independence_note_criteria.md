# 49周目 基準: **`基準寸法` の「独立していない」という但し書きは、判定に効いているのか**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。48 周目の「次の周」に書いたとおり。

## なぜこの題なのか

47 周目で、**反実仮想で階層1 に通った唯一の対象は `基準寸法`** だった。
そして `intake/drawing_intake.py:1310-1317` のコメントはこう書いている。

> この2つは、**縮尺についてだけ独立している**。**2点の座標は共有している**ので、
> 座標の取り違えは両方に同じように効き、**この突き合わせでは捕まらない**。
> その但し書きは `provenance` に残す。

**コードは自分で「この一致は独立ではない」と言っている。**
**では、その但し書きを判定は読んでいるのか。**

## 先にコードを読んで分かっていること(**測る前に書く**)

`independence_note` という語が出てくるのは、製品コードでは **1 か所だけ**
(1330 行、`provenance` に**書き込む**側)に見える。**読む側は見当たらない。**
テストは `tests/test_intake_start_kit.py:179-181` に**記録されていることを固定したもの**がある。

**「見える」で止める。** 45・48 周目と同じく、**静的に読んだ結果を実行時と突き合わせる。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **X1 = 0 かつ X4 = 変わらない** → **但し書きは判定に効いていない。**
  **45 周目とは違う形である。** あちらは「正しいのに固定されていない」だった。
  こちらは**記録もされ、固定もされているのに、読む側がいない。**
  **「書いてあるだけの安全」である。**
  **判定に効かせる変更は判定のしかたを変えるので、取り決めどおり PR のまま待つ。**
  **この周でできるのは、効いていないことを記録に残すところまで。**
- **X1 ≧ 1 または X4 = 変わる** → **効いている。どこでどう効いているかを名指しする。**
- **X5 = 同じ**(別のデータ源として数えられていない)→ **危険は無い。**
  47 周目の 1 件は別の理由で通ったことになるので、**そちらを測り直す。**
