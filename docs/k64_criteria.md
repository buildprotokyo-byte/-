## 周 1 — 確度に「そのページの読めた割合」を入れる(1(d)、旗 `--with-page-confidence`)

- **読めた割合** = 1 − そのページの最後の読みの「落ちた率」(消して確かめる、K-51)。
- **基準の読めた割合(固定)**: **0.85**。いまの `HIGH_MISS_FLAG = 0.15`(「読み落としの可能性が高い」の線、K-61 から本線にある値)をそのまま使う。
  結果を見て動かさない。
- **決まり**: 読めた割合が 0.85 未満のページ、または読めた割合が測れなかったページ(未取得)の項目は、確度「高」を「中」に下げる。
  下げた項目には理由を書く。中・低は動かさない。上げることはしない。**旗がオフなら何も変わらない。**
- **測るもの**(いまある出力に決まりを当てて数え直す。AI は呼ばない):
  - 合意 = K-62 b1 の 3 回で、同じ鍵 (科目, 工事項目, 揃えた室名) が 3 回とも同じ数量・単位の行(K-63 と同じ)。
  - 「高なのに合意と数量が違う」= 行の項目が全部「高」で、数量があり、合意の鍵に当たり、数量・単位が合意と違う行の数。
- **線**(3 つとも通れば「通過」):
  1. 壊していない別の 3 回(K-62 r0 の 3 回)で、高なのに合意と違う行の**合計が 11(3+2+6)より少ない**。
  2. 壊した版(a・b・c・e・g)のそれぞれで、旗オンの高の割合が旗オフの高の割合より**下がる**。
  3. スキャン版(a)の旗オンの高の割合が、壊していない別の 3 回の旗オンの高の割合の**最大を超えない**。
- 報告だけ(線にしない): 合意と同じ数量の高の行がいくつ「中」に下がったか(下げすぎの量)。

## 周 2 — 画像だけで「消して確かめる」(2(b))

- PDF の図形も文字の層も無く、画像だけのページ(スキャン)で使う。
- **やり方**: ページを幅 2000 画素の灰色の画像にし、明るさ 128 未満を墨とする。ページの縁 2% は数えない(図面枠の代わり、仮の判断)。
  読みの四角(縦横 3 画素広げる、ページの面積の 1% を超える四角は塗らない。K-51 と同じ)を白で塗る。
  **落ちた率 = 塗った後に残った墨の画素 / 塗る前の墨の画素**。残った墨のつながった塊の数も数える。
- **線**(全部通れば採用。一本道で、画像だけのページの落ちにこの値を使う):
  1. **囮**: スキャン版(a)の読みで、本物の四角の「拾えた墨」が 4 つの囮(でたらめ・0.95 倍・1.05 倍・別ページ、K-63 と同じ作り方)
     すべてより多い。
  2. **図形の数え方と向きが合う**: 壊していない版(b1_R1)の読みに画像の数え方を当てたときのページごとの落ちた率と、
     図形の数え方(K-51)の落ちた率の順位の相関(スピアマン)が **0.5 以上**。
  3. スキャン版(a)のページ全体の落ちた率が 100% ではない(物差しが壊れていない)。
- 報告だけ: スキャン版で、周 1 の決まり(0.85)を画像の落ちた率で当てたときの高の割合。

## 周 3 — OCR の結果を受け取る口(2(a))

- 形: `{"ページ": [{"ページ": n, "幅": w, "高さ": h, "語": [{"文字": "...", "位置": [x0, y0, x1, y1], "確かさ": 0.9}]}]}`。
  PaddleOCR の出力(`[[四隅の点], [文字, 確かさ]]` の並び)もそのまま読む。座標は渡された幅・高さから幅 2000 画素に直す。
