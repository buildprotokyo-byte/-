# 36周目 基準: 建具表が 0 件になるのは、どこで落ちているからか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。35 周目の「次の周」に書いたとおり、**名指しした P1 建具表を測る。**

## なぜこの題なのか

35 周目の結論は「実図面では突き合わせの前に経路が足りない」で、折れている経路を
1 本名指しした。**`read_door_schedules` は匿名化 v2 の 34 ページで 0 件。**

そして建具表は、この経路が無いと代わりが無い。`schedule_tables.py` の冒頭に自分でこう書いてある。

> 円弧の幾何で判定するので、**引戸と折戸は原理的に拾えない。**
> P011 の新設建具は全部引戸か折戸で、だから新設分の検出は 0 件だった。
> **建具表の文字が読めれば、図形では拾えない建具が拾える。**

**つまり実図面の新設建具は、この 1 本が折れているあいだ、どの経路でも拾えない。**

**直す前に、どこで落ちているかを測る。** 当てずっぽうで実装を触らない(取り決め①)。

## 落ちどころの候補(**先に全部書く**)

`read_door_schedules` が 0 件を返す道筋は 4 つしかない。

| 記号 | 落ちどころ | そうだと分かる形 |
|---|---|---|
| **L1** | 罫線の表として引かれていない | `find_tables` が 0 個 |
| **L2** | 表はあるが、見出しの文字が読めていない | 表はあるが、升目に文字が無い |
| **L3** | 見出しは読めるが、`DOOR_COLUMN_SYNONYMS` に無い書き方 | 建具番号らしい列が 0 |
| **L4** | 建具番号は当たるが、付き添いの列が `DOOR_MIN_SUPPORTING_COLUMNS`(2)に届かない | 建具番号あり、付き添い 0〜1 |

**L1 は既に否定できる見込みが高い**(34 ページで表 107 個という数字が別の周で出ている)。
だが**その数字を前提にせず、この周で数え直す。**

## 測るもの

| 記号 | 何を測るか |
|---|---|
| **E1** | `find_tables` が返す表の数(ページごと) |
| **E2** | そのうち、升目に文字が 1 つでもある表の数 |
| **E3** | 見出し行に**建具番号らしい語**が当たる表の数 |
| **E4** | E3 の表それぞれの、**付き添いの列の数**の分布(0 / 1 / 2 以上) |
| **E5** | **落ちどころの名指し。** L1〜L4 のどれで一番多く落ちているか |
| **E6** | 内装仕上表(動いている経路)で同じ 4 つを測った数字。**動く表と動かない表の差** |

## 何を確かめたいのか(**先に書く**)

**見込み**(測る前に書く。外れたらそのまま外れたと書く):

1. **E1 は 0 にならない。** L1 ではない。
2. **落ちどころは L3 か L4。** 仕上表が同じ `find_tables` の上で動いている以上、
   表そのものと文字は取れていて、**建具表だけを落としているのは見出しの当て方**のはず。
3. **E6 との差が、直す場所をそのまま指す。**

**2 が当たるなら、直し方は「見出しの書き方を増やす」か「付き添いの数を見直す」のどちらか**になり、
**どちらも判定のしかたに触る変更なので、この周では直さずPRのまま待つ**(取り決め・マージ権限)。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 内装仕上表で同じ測り方をする | 仕上表は E3 以降で落ちない(測り方が壊れていない証拠) |
| **2** | 合成の建具表(テストで使っているもの)で同じ測り方をする | 最後まで通って 0 件にならない |
| **3** | 反復 3 回 | 3 回とも同じ |

**対照2 が通らなければ、測り方のほうが壊れている。** そのときは落ちどころを名指ししない。

## 採否(**この周も「測るだけ」なので、結論の形で書く**)

- **E5 が 1 つに決まる** → その落ちどころを名指しし、**直し方の案を書く。実装は触らない。**
- **E5 が決まらない(複数に散る、または対照2が落ちる)** → **名指ししない。**
  分かったことだけ書いて、次の周で測り方を作り直す。

## この周で変えないもの

- **実装には手を入れない。** 測るだけ。
- 判定のしかた・基準値・階層の条件にも触れない。
- 実図面のパスは引数で渡す。**出すのは件数とページ番号と割合だけ。**
  室名・寸法・数量・建具番号・事務所名は 1 文字も出さない。
  **見出しの文字も出さない**(図面の中身なので)。当たったか外れたかの数だけ出す。
