## 2. **39周目の予想が 1 つ外れていた(そのまま書く)**

39周目の報告書は、案2a について

> `有効幅`・`開口幅`・`内法高さ` は当たり、**`幅木`・`係数` は当たらない。**

と書いていた。**`係数` は当たる。** `係数` は `数`(数量の言い換え)で**終わる**ので、
後方一致では素通りする。`全幅` も同じ理由で `幅` に当たる。

**書いた時点で確かめていなかった予想が、そのまま次の周の案として残っていた。**
測って初めて分かった。**案を先に書くのはよいが、書いた予想は測るまで根拠にしない。**
