# 周10の基準: 落ちた字を、決まり文句の語彙表で直す

作成: 2026年9月25日。**測る前にコミットする。**

## 前の周と何が違うか

**読み方は一切変えない。**周6・周8・周9 が**すでに読んだ結果**を使う。
**変えるのは、読んだあとに直しを 1 段足すことだけである。**

周6〜周9 で残った崩れは、3 周とも同じ種類だった。

- 括弧の全角と半角
- 繋ぎの記号が別の字になる
- **決まり文句の見出しから字が落ちる**
- 似た形の字の取り違え

**このうち「決まり文句の見出し」だけを直す。数値には触らない。**

## 語彙表は先に固定した

**共有フォルダの `reports/周10_語彙表.json`。39 語。**
**リポジトリには置かない**(実案件の紙から拾った語なので、K-20・K-33 と同じ扱い)。

**中身が測る前に決まっていたことを示すため、指紋をここに書いておく。**

```
SHA256 9cb0b2fa3e9721a1bcc62e65718392ad1e220cbda4a1959b6a9ae7028e38fc65
```

**測ったあとに語を足さない。**足したくなったら、**足したことと、足す前の数字を両方書く。**

## 直し方(測る前に決める)

1. 返ってきた文字列を、**先頭から続く「数字でも記号でもない部分」**と、**残り**に分ける。
2. **先頭の部分だけ**を語彙表と突き合わせ、**2-gram の Dice が 0.5 以上**で
   いちばん近い語があれば、**その語に置き換える。**
3. **残り(数値・単位・型番)はそのまま。**
4. 語彙表に届かなければ**何もしない。**

## 測ること

正解は**周6〜周9 とまったく同じ 8 か所**。採点も同じ道具。
**直しは、周6・周8・周9 の 3 つの結果すべてに同じように掛ける。**
そうしないと、直しの効きが読み方と混ざる。

### 線1(この周の採否)

**どれか 1 つの読み方で、そのまま一致が 5 か所以上になれば通過**
(周6 の 4 か所を超える)。**4 か所以下なら不通過。**

### 線2: 直した件数と、直して正しくなった件数を**両方**出す

- **直した件数**(置き換えが起きた文字列の数)
- **そのうち、そのまま一致が増えた場所の数**
- **直したのに一致が増えなかった件数**
- **直したことで、前は合っていたものが外れた件数**(**0 でなければ必ず書く**)

### 線3: **囮にも同じ直しを掛ける**(この周でいちばん大事な線)

**引き当ては、当てずっぽうを本物らしく見せる。**だから**囮にも同じ直しを掛ける。**

- 囮の**3 文字以上の文字列の件数**を、**直す前と直した後**で数える。
- **直したことで囮の 3 文字以上が増えたら、この直しは当てずっぽうを作っている。**
  **増えた件数が本物の増えた件数の半分以上なら、線1 が通っても採らない。**

### 線4: 捏造していないか

**置き換えは Dice 0.5 以上のときだけ**なので、作りの上では無関係な語に化けない。
**それでも、置き換わった前後の組を全部、共有フォルダに書き出す。**
**数えるだけでなく、中身が見られる形にしておく。**

## 頭打ちの判定(おーちゃんの設計④)

**同じ対象に技術を 3 つ・出典を 3 つ当てて増えなければ頭打ち。**
このメーカー図 3 枚の 8 か所には、**切り方を 3 通り**(紙を端から / 罫線の升目 /
決まり 4 本)と、**切り出しの広さを 2 通り**当ててきた。

**この周で動かなければ、この 8 か所は「何通り試したか」を付けて残りへ回し、
設計の周2(意味が決まらなかったまとまりに 10〜20 の知識を当てる)へ進む。**

## 書かないこと

- **図面の中身・正解・語彙表はリポジトリに書かない。**共有フォルダとスレッドだけ。
- **本番の経路には繋がない**(K-29)。
- **直した件数が増えても、そのまま一致が増えていなければ効いたと書かない**(K-33)。
