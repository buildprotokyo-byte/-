# K-44: 捏造と仮説を分け、仮説を通して、辻褄が合わなければ遡って捨てる — **測る前の基準**

この文書は**測る前に**コミットする。決まりの原文は `docs/decision_k44.md`。

## 何を通すか・何を止めるか(K-44 の表のまま)

| | 中身 | 扱い |
|---|---|---|
| 捏造 | 根拠なしに作ったもの。図面に無い名前・図面に無い数字 | 禁止。1 件も出さない。**1 件でも出たら止めて報告** |
| 仮説 | 根拠はあるが確証が無いもの | 通す。必ず印を付ける。自動確定しない |

## 仮の判断(この周で決める定義。測りながら変えない)

1. **「近い」の定義**
   - 語: 全角半角・カナの大小をそろえたうえで、2 文字以上の部分一致。言い換え(例: 巾木と幅木)は読む役が「近い」と言ってよいが、そう判断した理由を書く。
   - 記号・線: 形が似ている(読む役が画像で見て、どこが似ているかを書く)。色は近い色(赤みが強い・青みが強い)でよい。
   - 数量: ㎡ は ±5%、個数は ±1(K-36 の許容差と同じ)。
2. **確からしさ**: 互いに矛盾しない根拠が 3 つ以上 → 高(K-44 の「確からしい」)、2 つ → 中、1 つ → 低。根拠が 0 → 仮説にせず「根拠が足りない」に残す(ここで作れば捏造)。
3. **根拠 1 つ** = ページ番号と、そのページにある文字の引用、または図の場所と見た目の説明。同じページの同じ場所を 2 回数えない(K-08 の決まり: 同じ表の同じ行から取れた 2 つは独立と数えない)。
4. **数量の仮説**は、引用した数字からの計算式を必ず書く。式の数字は全部、引用した場所に印字されていること。

## 捏造の検査(機械、全件)

- 引用した文字が、そのページの文字の層に**ある**か(全角半角をそろえ、4 文字以上の部分一致。4 文字未満の引用は全文一致)。
- 図の根拠は、別の AI(読む役とは別)がそのページの画像で「その場所にそう見えるものがあるか」を確かめる。
- 数量の式を計算し直し、仮説の値と ±1% で合うか。式の数字が引用の中にあるか。
- **引用が見つからない・式が合わない・式の数字がどこにも無い、のどれかが 1 件でもあれば捏造として止めて報告する。**

## 辻褄の検算(機械。合わなければ関わる仮説を遡って捨てる)

K-44 の 10 の場面のうち、この周で機械が見られるもの:

| 場面 | この周の検算 |
|---|---|
| 数が合わない | 室の床面積の仮説の合計が、計画概要に印字された施工床面積を超える |
| 順序が成り立たない / 工事の連鎖が切れている | 同じ室・部位で、仕上の新設があるのに下地の行が無い(下地「既存」と書かれている所は除く)。撤去があるのに新設も「既存のまま」も無い |
| 物理的にありえない | 長さ・面積・個数が 0 以下。天井高の仮説が、計画概要か断面に印字された高さを超える |
| 同じものを 2 回数えている | 同じ室の同じ面に、同じ工事の行が同じ面積で 2 つ以上(`estimating/cross_checks.py` と同じ見方) |
| 単位が合わない | 床・壁・天井の仕上と下地の行が ㎡ 以外、器具の行が個数以外 |
| 別の資料と食い違う | 仮説の根拠同士が食い違う(同じ量に 2 つの値が印字されている) |
| 仕様書にあるのに図面に無い | K-41 の全体像との突き合わせ(実装済み)をそのまま使う |

- **金額の桁**と**範囲の重なり**は、この周では見られない(金額を扱わない・範囲の図形を持っていない)。見られないと書く。
- 合わなかったら、関わった仮説のうち**確からしさがいちばん低いもの**を捨てる(同じなら後から置いたもの)。捨てた記録: 何を仮に置いたか・どの検算で合わなかったか・何を捨てたか。
- 捨てたあと、読む役にもう一度その項目を渡し、別の候補を置けるなら置く。**往復は最大 3 周。**矛盾が無くなるか 3 周で止める。

## 測るもの(順番は K-44 のとおり)

- 題材: K-41 の周 4 の全体像の 67 項目と、質疑 29 件(問いで止まっていたもの)。**これに無関係な囮の項目 10 件を混ぜる**(この改装に無い工事。読む役にはどれが囮か知らせない)。
- 読む役(AI)は図面の文字と画像だけを見る。**仕上表以外の見積・正解は見せない。**
- 出すもの:
  1. 仮説として通った件数(高・中・低)
  2. そのうち辻褄が合わずに捨てた件数
  3. 最後まで残った仮説の件数と、そのうち正解と合った件数(名前で結ぶのは採点する役、伏せた名前で。数量は許容差で)
  4. 捏造の件数(0 のままか)
  5. 囮の項目 10 件のうち、仮説として残った件数
  6. 当たりが K-41 の 64/93 からどう動いたか(K-41 の行に、この周で残った仮説の行を足した和で数える)。数量が合った件数も 14 からどう動いたか。

## 合格の線

- **成功**: 捏造 0 件のまま、64/93 に対して当たりか数量の一致が 1 件以上増え、**増えた分が囮の項目から来ていない**。
- **失敗**: 捏造が 1 件でも出る(その場で止める)。または、当たりの増えた分より、囮の項目で残った仮説のほうが多い。

**不通過になる数字の例**: 当たりが 64 → 66 に増えたが、囮の項目 10 件のうち 3 件が仮説として残った → 増えた 2 件より囮の 3 件が多いので失敗。

## 守ること

捏造は 0 件のまま。仮説には必ず印を付ける。自動確定は 0 件のまま。捨てた記録を残す。数字が動かなくても構わない。

## 結果(2026-09-26)

**基準の線では成功。捏造 0 件のまま、数量の一致が 14 → 20 件に増えた(当たりは 64 → 65 件)。増えた分は囮の項目から来ていない。**ただし、遡って捨てる往復は 1 度も動かなかった(下の「効かなかったこと」)。

| 測るもの | 数 |
|---|---:|
| 項目(全体像 67・質疑 29・囮 10) | 106 |
| 仮説として通った | 66(根拠の数で 高 56・中 8・低 2) |
| 根拠が足りない | 16(囮 5 を含む) |
| 無いと書かれている(記載を引用) | 24(囮 5 を含む) |
| 辻褄が合わずに捨てた | **0** |
| 最後まで残った仮説 | 66 |
| そのうち正解に当たった(伏せた名前で採点、案 B の線引き) | 18(18 件とも確からしさ「高」。中・低は 0 件) |
| そのうち数量が許容差内 | 6(6 件とも個数。図面の文字の層で数えた数が正解と合った) |
| **捏造** | **0** |
| 囮の項目 10 件のうち仮説になったもの | **0** |
| 当たり(K-41 の 64 件との和) | 64 → 65 |
| 数量の一致(K-41 の 14 件との和) | 14 → 20 |

### 捏造の検査で分かったこと

- 機械の検査が「捏造の疑い」とした 12 件は、12 件とも**個数を「◯◯を数えた」と文で書いた**もので、式の形になっていなかった。基準に書いた「式を計算し直す」を、個数については「引用した語がそのページの文字の層に何回出るかを数え直す」で行い、12 件とも数が合った(照明器具の 1 件は、印字された「×n」の足し算で、使った数字は全部印字にあった)。**捏造は 0 件。**
- 図の根拠 6 件は、読む役と別の役が画像で確かめ、6 件とも図にあった(うち 2 件は、記号の形が凡例と少し違うと添えられた)。
- **検査の弱いところ(持ち越し)**: 機械は「引用がそのページにあるか」を確かめるが、「引用が主張を支えているか」は確かめない。1 件、空欄の欄の名前を引用して、記載の無い工事(近隣挨拶)を仮説に含めていた。引用は実在するので捏造の検査には掛からない。**この形の捏造は、今の検査では見つけられない。**

### 効かなかったこと

- **遡って捨てる往復が 1 度も動かなかった。**検算 5 つ(単位・物理・二重・食い違い・連鎖)と床面積の合計は、66 件のどれにも引っかからなかった。理由は、面積の数量がある仮説が 0 件だったため(読む役は面積を印字の寸法から計算しなかった。数量を置いたのは個数の 20 件前後だけ)。数量が無いと、数・二重・食い違いの検算は働かない。**「辻褄が合わなければ戻る」を実際に確かめるには、面積の仮説を置かせる周が要る。**
- 当たりが 64 → 65 に増えた 1 件は、全体像の項目(K-41 の周 4 と同じもの)を採点する役が別の周と違う結び方をしたもので、仮説の効き目とは言えない。**増えたと言えるのは数量の一致の 6 件だけ。**
- 同じことを指す項目(全体像と質疑の重なり)が重複して仮説になり、採点ではまとめ行・細かく割れた行になった。重複を 1 つにまとめる段がまだ無い。

### 確からしさの印は効いていたか

当たった 18 件は全部「高」。仮説 66 件のうち「高」は 56 件で、当たりは 18 件(32%)。「中」「低」の 10 件からは 0 件。**根拠の数で付けた確からしさは、当たりやすさの順と揃っていた。**ただし「高」でも 3 件に 2 件は正解に当たっていない(正解に無い行・まとめ行を含む)。

自動確定は 0 件のまま。数量は仮説の印付きの候補で、確定させていない。
