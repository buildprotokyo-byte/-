# 45周目 基準(トライアルC): 「表の読み取りは縮尺に依存しない」は本当か

## なぜこの題なのか

44 周目で、**入れ替えられない並び**(縮尺 → 開き戸)は**何も取りこぼしていない**と分かった。
今度は**入れ替えられると書いてある並び**を測る。

コード自身がこう書いている(`intake/drawing_intake.py:931-932`)。

> **表の読み取りは縮尺に依存しない。** 印字された文字を読むだけなので、
> 縮尺が読めないページでも、読みが食い違ったページでも表は読める。

**取り決め①は「記録を信じずコードを読む」だが、コードのコメントも記録である。**
**書いてあることが本当かを測る。**

## 測るもの

**表の読み取りを、縮尺を読む前・後・縮尺なしの 3 通りで回し、出力が 1 件でも変わるかを数える。**

| 記号 | 条件 |
|---|---|
| **V0** | いまのまま(縮尺を読んでから表を読む) |
| **V1** | **表を先に読む**(縮尺をまったく読まずに表だけ読む) |
| **V2** | **縮尺を読んだうえで、縮尺が読めたページだけ**表を読む(依存させてしまった場合) |

| 記号 | 何を測るか |
|---|---|
| **W1** | 建具表として読めた表の数(V0 / V1 / V2) |
| **W2** | 内装仕上表として読めた表の数(V0 / V1 / V2) |
| **W3** | 読めた**行**の数(V0 / V1 / V2) |
| **W4** | **V0 と V1 の出力が 1 件でも違うか**(表の数・行の数・ページ番号の並び) |
| **W5** | **V2 で減る行の数**(依存させると何を失うか) |
| **W6** | ページ番号の並びが V0 と V1 で同じか |

**出力の比べ方は、表の数・行の数・ページ番号の並びの 3 つ。** 升目の文字は比べない(出さない)。

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **W4 = 違いなし** → **コメントは正しい。この順番は意味を持っていない。**
  **安全に入れ替えられる並びが 1 本あると確定する。**
  ただし**入れ替える理由が無いなら入れ替えない**(意味の無い変更をしない)。
  **記録として残すだけ。**
- **W4 = 違いあり** → **コメントのほうが間違っている。**
  何がどう違うかを名指しし、**コメントを直す変更を PR に出す**
  (コメントだけならマージ可。判定に触るなら PR のまま待つ)。
- **W5 ≧ 1** → **依存させると失うものがある**という数字になる。
  これは「いまの順番でよい」ことの裏付けとして記録する。**線には使わない。**
