## 線3 — 室の名前は、書き方が違っても引き当たるか

**予想が外れた。**

| 書き方の違い | 予想 | **実際** |
|---|---|---|
| 全角と半角(`洋室1` / `洋室１`) | 引き当たる | **引き当たる** |
| 前後の空白(`洋室1 `) | 引き当たる | **引き当たる** |
| **中の空白(`洋 室1`)** | **引き当たらない** | **引き当たる** |

`app.py` の `_nfkc()` は `"".join(NFKC(text).split())` である。
**`split()` が空白で切って `join` で繋ぐので、空白が全部取り除かれる。**

**だから、空白だけが違う 2 つの室名は、同じ室として引き当たる。**

**10 室の名前を数えた**(名前そのものは書かない。K-33)。

**ただし、人が打ち直す側に問題がある。**
**改行を含む室名が 1 つある。**仕上表の升目で複数行に分かれている室である。
**人がその室名を打つとき、区切り文字(`・` や `/`)を入れると引き当たらない。**
**繋げて打てば引き当たる。**

**つまり「人に室の寸法を入れてもらう」形にするなら、
室名は人に打たせず、機械が出した一覧から選ばせる必要がある。**
