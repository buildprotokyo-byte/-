# 周30(定数を import せず文字列で書いた引き当ては、ほかにあるか)の基準

**測る前に決めてコミットする。結果を見てから、ここは書き換えない。**

## 前の周と何が違うか

**変えるのは 1 つだけ。見る範囲を `app.py` の 3 か所からコード全体に広げる。**

周28・周29 で、**`app.py` が巾木の数量を `周長` という文字列で探し、
作られているのは `室の周長`(`KIND_PERIMETER`)**という食い違いを見つけた。

**この欠陥の正体は「定数を import せずに、文字列で書き写したこと」である。**
**書き写しは、書き写した先が変わっても気づかない。**

周29 はこう書いて止めた。

> **`estimating/` の中どうし、`arbitration/` の中どうしにも、
> 名前で引き当てている場所はあるのか。**

**ここを測る。**

## 着手前にコードを読んで分かったこと(**取り決め①**)

このリポジトリは、**名前を定数に置く書き方**をしている。
`KIND_FLOOR_AREA = "床面積"`、`METHOD_DIMENSION_TEXT = "pdf_dimension_text"`、
`REASON_OBSERVED = "観測"` のように、**大文字の名前に日本語や識別子を入れる。**

**`app.py` の `FINISH_PART_QUANTITY` だけが、その定数を import せずに
文字列を直接書いている。**そこで食い違いが起きた。

## 何に触らないか

**コードを 1 行も直さない。数えるだけ。**
見つけたものは**試験で固定して判断待ちに回す**(K-29・周28 と同じ)。
自動確定は 0 件のまま。

## 数え方(**先に決める**)

1. `app.py`・`axes/`・`estimating/`・`intake/`・`arbitration/` の `.py` を
   **構文木で読む**(正規表現ではない。説明文の中の文字列を拾わないため)。
2. **モジュールの直下で、大文字の名前に文字列を入れている代入**を集める
   (`KIND_FLOOR_AREA = "床面積"` の形。2 文字以上のものだけ)。
3. **別のファイルに書かれた文字列リテラル**を全部集める
   (**説明文は除く**。構文木で読むので分けられる)。
4. 3 の文字列と 2 の定数の値を突き合わせ、次の 2 つに分ける。
   - **書き写し**: **値が完全に一致する**(定数があるのに文字列で書いている)
   - **惜しい**: **片方がもう片方の一部**だが**一致しない**
     (`周長` と `室の周長` はここに入る)

## 線(3 本)

### 線1 — 「惜しい」組は何件あるか

**予想を先に書く**: **1 件(`周長` と `室の周長`)だけ。**
**当たっていたら「当たっていた」と書く。**

- **予想どおり**: 1 件
- **予想が外れた**: 0 件、または 2 件以上

**「惜しい」組は、そのまま欠陥とは限らない。**
`床` と `床面積` のように、**別のものを指す名前が偶然そういう関係になる**
ことがある。**だから件数を出したあと、1 件ずつ中身を見て振り分ける。**
**振り分けは報告に書く。**

### 線2 — 「書き写し」は何件あるか(**記述。判定は置かない**)

**定数があるのに文字列で書いている場所を数える。**

**これは欠陥ではない。**値が一致しているので、いま動いている。
**危ないのは、定数の側が変わったときに気づけないこと**である。

**判定を置かないことをここに書いておく。**書くのは件数と、
**どのファイルに多いか**だけ。

### 線3 — 対照: 数え方は、既に分かっている 1 件を拾えるか

**周28 で見つけた `周長` / `室の周長` を、この数え方が「惜しい」として
拾えること。**

- **数え方が働いている**: 拾える
- **働いていない**: 拾えない

**拾えなければ、線1 の結果は読まない。**

## 先に書いておく落とし穴

1. **「惜しい」が 0 件でも「食い違いは無い」とは書かない。**
   **定数に置かれていない名前どうしの食い違いは、この数え方では拾えない。**
2. **「書き写し」を減らすべきだ、とは書かない。**
   **減らす価値があるかは測っていない。**数えただけである。
3. **直さない。**見つけたものは試験で固定して判断待ちに回す。
4. **囮を置かない理由**: これは**コードの中の文字列どうしの突き合わせ**で、
   位置や当たりを当てる測定ではない。**でたらめな文字列を混ぜることに
   意味が無い。**そのかわり**対照(線3)を置く。**
5. **3 本とも「どういう数字が出たら不通過になるか」を書いてある**
   (線2 は判定を置かないと明記した)。
