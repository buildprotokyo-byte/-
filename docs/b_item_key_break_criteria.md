# 33周目 基準: 語順を無視する揃え方を、壊しにいく

## 32 周目で分かった、測り方の穴 3 つ

1. **罠(A3)が揃え方を見分けられなかった。** 何も揃えない場合にも同じ 1 件が出た。
2. **偽の一致(A2)が 0 だったが、それは安全の証明ではない。**
   35 品目は長くて特徴的すぎ、文字の多重集合がほぼ一意になる。
3. **対照(でたらめな 35 個)も 10 回とも 0 で、衝突の起きやすさを測れていなかった。**

**この周は 3 つとも直す。** そのうえで、**N3(語順を無視する)を壊しにいく。**

## 考え方

32 周目で N3 は A1 = 0.952 と、ほかを大きく引き離した。
**だから「良い」と言う前に、壊れる場所を探す。**

一致は根拠を強める向きに働くので、**偽の一致は黙って確定する側に効く。**
**壊れる場所が 1 つでも見つかったら、N3 は確定させる向きには使わない。**

## 鍵をたくさん作る(**測る前に決めた。機械的に作る**)

実案件の見積は行が多く、名前が似ている。そこを再現する。

**語はすべて、公共建築工事内訳書標準書式の 35 品目の名前から機械的に切り出す。
こちらで新しい語を作らない。**

- **部位**: 品目名の先頭に現れる部位の語(床・壁・天井)
- **材料**: 品目名から部位と動作を除いた残り(モルタル・タイル・ボード・シート など)
- **動作**: 品目名の末尾の語(撤去・張り・塗り・敷き)

**部位 × 材料 × 動作 の全組み合わせ**を鍵にする。
**組み合わせが違えば別の品目である**(だから同じ鍵になったら偽の一致と言える)。

## 揃え方の候補

32 周目の 4 つに 1 つ足す。

| | 中身 |
|---|---|
| **N0** | 何もしない |
| **N1** | NFKC → 記号と空白を落とす → ひらがなをカタカナに → 大文字に |
| **N2** | N1 + 括弧の中身を外に出す |
| **N3** | N2 + 文字を並べ替えて比べる(語順を無視する) |
| **N4** | **N3 + 送り仮名を落とす**(張り→張・塗り→塗・敷き→敷) |

**N4 を足す理由**: 32 周目に T4(送り仮名)がどの揃え方でも 0 / 6 だった。
**穴が分かっているのに埋めない理由が無い。** ただし送り仮名を落とすと
**動作の語が短くなる**ので、偽の一致が増える向きにも働く。**そこも測る。**

## 測るもの

| 記号 | 何を測るか |
|---|---|
| **B0** | 作った鍵の数 と 鍵の組の数 |
| **B1** | **偽の一致。** 組み合わせが違う 2 件が同じ鍵になった組の数 / 全組数 |
| **B2** | **動作が違うのに同じ鍵になった組の数。**(撤去と張りが混ざるのが、いちばん悪い形) |
| **B3** | **部位が違うのに同じ鍵になった組の数。** |
| **B4** | 32 周目と同じ A1(真の一致)を、この大きな集合でも測り直す |

## 対照(**32 周目の失敗を踏まえて作り直す**)

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | **同じ鍵の文字を並べ替えたものを鍵にする** × 10 回 | **偽の一致がたくさん出る**(この対照が 0 を出したら、測り方がまだ壊れている) |
| **2** | N0 で B1 を測る | **0**(何も揃えなければ、違う組み合わせは違う鍵) |
| **3** | 反復 3 回 | 3 回とも同じ |

**対照 1 が大事である。** 32 周目の対照は 0 しか出さず、何も言えなかった。
**今度は「偽の一致が出る条件」を先に作って、測り方がそれを捕まえられるかを確かめる。**

## 採否(**測る前に決めた**)

| 結果 | 決め方 |
|---|---|
| **B1 = 0** | その揃え方は**どちらの向きにも使える** |
| **B1 > 0 だが B2 = 0** | **向きで分ける。** 人へ回す向き(質問を作る・漏れを見つける)では使い、**黙って確定させる向きでは使わない** |
| **B2 > 0** | **確定させる向きには絶対に使わない。** 人へ回す向きでも、件数を報告に書いて判断を仰ぐ |

**「小さければよい」は無い。** 件数をそのまま出す。
