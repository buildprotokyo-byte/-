# 60周目 基準: **正しい答えが突き返されることはあるのか(やり直し)**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。59 周目のやり直し。

## なぜやり直すのか

59 周目は**対照2 が 5 件中 2 件で通らなかったので結論を出さなかった。**
**ずらす相手を間違えていた。** 他の変数との等式で縛られている変数は、
自分の読みをずらしても候補が動かない。

## 測り方(**合成案件だけ。取り決め④**)

58・59 周目と同じ 4 シナリオ。**代役は必ず正解を答える。**
**嘘をつくのは人ではなく、読み取りのほうである。**

**ずらし方を変える。** 問われた変数だけでなく、
**その案件の変数を 1 つずつ順にずらして試す。**
(星形なら `room_count` も `leaf_1〜3` も、それぞれ 1 回ずつ。)

**ずらし幅は 59 周目と同じ +2。** 幅をまるごとずらし、正解の値は動かさない。

**対照は変数ごとに見る。** ずらしても候補が変わらなかった組は
**「ずらせていない」として数から外す。**(59 周目は全部そろうことを求めて止まった。)

| 記号 | 何を測るか |
|---|---|
| **H0** | 試した組の数(案件 × ずらした変数) |
| **H1** | そのうち、**問われた変数の候補が現に変わった組**の数(**この組だけを数える**) |
| **H2** | H1 のうち、**正しい答えが突き返された**組の数 |
| **H3** | H1 のうち、矛盾として先に止まった組の数 |
| **H4** | H1 のうち、そのまま通った組の数 |

**H2 + H3 + H4 = H1。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **H2 ≧ 1** → **正しい答えが拒まれる場合が実在する。**
  設計 4 節(`docs/question_quality_design.md`)の提案に**実測の裏づけが付く。**
- **H2 = 0 かつ H3 ≧ 1** → **拒む前に、矛盾として先に止まる。**
  **提案4は理屈だけで実測の裏づけが無い**と報告書に書き、**提案を弱める。**
- **H2 = 0 かつ H3 = 0** → **読みがずれても何も起きない。**
  提案4 とは別の、もっと大きな問題として名指しする。
- **H1 = 0** → **1 組もずらせていない。**測り方がまだ間違っている。**結論を出さない。**

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 読みが正しいときの通し | **突き返しが 0 件** |
| **2** | ずらしが効いた組があるか | **H1 ≧ 1** |
| **3** | 反復 3 回(H2) | 3 回とも同じ |
| **4(数えた組の偏り)** | H1 と H0 の比 | **記録するだけ。線には使わない。**
どれだけの組を捨てたかを報告書に書く |

**対照1・2 が通らなければ結論を出さない。**
