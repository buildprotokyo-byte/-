# 17周目 診断・仮説・候補・採否の基準

2026-09-23。**この文書は測る前に書いてコミットする。結果を見てから基準を変えない。**

## 1. 今回の対象

**「届いた」という数え方そのもの。**

## 2. 診断

14・15・16 周で、記号を数える行への到達を 13 → 21 → 19(知識の語彙)と測ってきた。
**しかし、ここまで一度も「正しい記号に届いたか」を測っていない。**

いまの数え方は「見積の品目名の中に、その記号の名前が文字として含まれているか」だけである。

- **弱い根拠 1 本で判定している。** 原則③(単一の指標だけで自動確定させない)に近い形である。
- `配線` が別の行に当たっていても、`TEL` の行に `配線` と `TEL` の両方が当たっていても、
  どちらも「届いた 1 行」として同じに数えている。
- **数を増やす前に、数の意味を確かめる。**

## 3. 採点に使える手がかりが正解ファイルにある

正解ファイルの各行には `trigger_terms`(その行を見分ける手がかり語)が入っている。
`usage_policy` は **`expected_items` は生成のあとの採点にだけ使う**と明記している。

**だから採点側でだけ使う。** 抽出の側(語彙・別名表)には**絶対に渡さない。**

- 語彙は 16 周目に作ったもの(`estimating/examples/knowledge_symbol_vocabulary.json`)を
  **そのまま使う。1 語も足さず、1 語も削らない。**
- **この周の結果を見て語彙を直さない。** 直したらそれは正解に合わせたことになる。

## 4. 仮説

> 「届いた」の大半は「正しい記号に届いた」である。

## 5. 測る指標(分母を必ず付ける)

主に使うのは 16 周目の知識の語彙(61 語、届いた 19 行)。
比較のため 15 周目の当て推量の語彙(11 語、届いた 21 行)でも測る。

各行について:

- **当たった代表** … 語彙が当てた代表の名前の集合。
- **正しい代表** … その行の `trigger_terms` を語彙に通して得た代表の名前の集合。
  **手がかり語が語彙に無ければ、その行は「判定できない」に入れる。**

| 記号 | 何を測るか | 分母 |
|---|---|---|
| **P0** | 届いた行 | 26 |
| **P1** | **正しく当たった行**(当たった代表と正しい代表が重なる) | 届いた行 |
| **P2** | **取り違えた行**(当たったが、正しい代表と重ならない) | 届いた行 |
| **P3** | **判定できない行**(手がかり語が語彙に無い) | 届いた行 |
| **P4** | **曖昧な行**(2 語以上が当たっている) | 届いた行 |
| **P5** | 1 語が当たった行の数の分布(広く当たる語ほど見分けていない) | 語ごと |

**P1 + P2 + P3 = 届いた行** になるように数える。

## 6. 対照

1. **行の入れ替え** … 行 i に当たった代表を、**別の行の**正しい代表と突き合わせる
   (行の並びをずらす)。**P1 が大きく落ちること。**
   落ちなければ「正しく当たった」は当てずっぽうと区別がつかない。
2. **無関係な語 7 語** … 届く行 0、したがって P1 も 0。
3. **反復 3 回** … 同じ結果になること。

**対照1 が今回いちばん大事である。** 14・15 周で、宣言した対照が
測りたいことを測れない形になっていたことが 2 回あった。
**今回の対照1 は、突き合わせる相手だけを替えるので、構造上かならず同じにはならない。**

## 7. 採否の基準(**これを先に決める**)

知識の語彙(届いた 19 行)について:

- **採用**(= これまでの「届いた」を信用してよい):
  **P1 ≥ 14 / 19** かつ **P2 ≤ 2** かつ **対照1 の P1 が本測定の半分未満**
  かつ 対照2 = 0 かつ 対照3 が一致。
- **不採用**(= 数え方を作り直す): **P2 ≥ 5**、または **P1 < 10 / 19**。
  そのときは **14〜16 周の到達の数字を全部「見分けていない数」として書き直す。**
- **保留**: その間、または P3(判定できない行)が 5 以上で分母が足りない場合。

## 8. 止める条件

- **`trigger_terms` を見て語彙を足したり削ったりしない。** 一度でもやったら、
  14〜16 周の測定が全部無効になる。
- `trigger_terms` の中身(語そのもの)は**リポジトリにも記憶にも書かない。**
  出すのは件数と割合だけ。
- 既存の判定のしかたは変えない。
