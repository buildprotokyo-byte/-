# 業界の基礎知識(トライアルD)

「ループ作業マスタープロンプト v1」2-2節(トライアルD)の成果物置き場。目的は、
会社のルール・波及のルール・問いの一覧の**中身を埋めるための知識**を、公開されている
情報から広く集めること。R1など特定の基準に寄せず、複数出典の一致を「共通の土台」とする。

## このディレクトリの読み方

1. [access_report.md](./access_report.md) — この作業環境から外部情報にどこまで届くかの実測結果(最初に確認)
2. [sources.md](./sources.md) — 出典の一覧(発行元・文書名・版・URL・区分・拘束力など)
3. [coverage_matrix.md](./coverage_matrix.md) — 業種×内容の種類の一覧表(どこが埋まりどこが空か)
4. [candidates.md](./candidates.md) — 集めた内容から起こした、会社のルール・波及のルール・問いの一覧への反映案(すべて「候補」、採否はおーちゃんの確認待ち)
5. [report.md](./report.md) — 見つからなかった所・目立った一致と違い・次に読むべき順番

## 守ったこと

- 本文の写しは置いていない。要約と、章・条項の番号だけを記録した(原文はすべて発行元の公開URLで確認できる)。
- R1(リノベーション協議会)は広く参照される基準の一つとして扱い、正解や法律として扱っていない。
- 複数の出典で一致する考え方と、出典間の違いを区別して記録した。
- 有料・会員限定の資料は購入・ログインせず、書誌情報の記録だけに留めた。
- 法令の条文解釈が要る箇所は解釈せず、「解釈が要る」とだけ記録した。
- 実図面・見積明細・そこから作ったデータは扱っていない(この作業の対象外)。
