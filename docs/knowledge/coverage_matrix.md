## 読める形で埋まっている所(最も強い、次のトライアルへ直接渡せる)

**内装・建具・外壁防水・解体・仮設(改修)の「数量の数え方」** は `公共建築数量積算基準` 第5編・第7編で
条項番号つきに整理できた。これはA-2(面積と下地)・A-3の一部(墨出し・養生清掃・足場という「会社の諸経費」に
近い項目)に直接効く候補。詳細は[candidates.md](./candidates.md)。

## 大きく空いている所

- **電気設備・給排水設備の数量の数え方**: 公共建築数量積算基準の**設備工事編**が別文書として存在する
  (`公共建築工事内訳書標準書式(設備工事編)`は確認済みだが、数量積算基準の設備版そのものの所在は未確認)。
  A-1(電気設備の記号読み取り)が最も落ちている領域と一致するため、**次回最優先**。
- **法令要件**: e-Gov法令検索が遮断されているため、条文そのものへの到達が弱い。二次情報(解説記事)止まり。
- **メーカー技術資料**: サイトが軒並み遮断。ロス率・割付・端数の扱いは今回ほぼ手つかず。
- **自治体条例**: 東京都・横浜市とも遮断。首都圏の主要自治体条例は未着手。
- **失敗例(見積漏れの典型)**: 相談窓口の存在までは分かったが、個別の漏れパターンの深掘りは未着手。
