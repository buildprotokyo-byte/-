## A. 会社のルール・数量の数え方の候補(A-2「面積と下地」に直接効く)

いずれも出典: 公共建築数量積算基準(建築版) 第5編(仕上)・第7編(改修)。

1. **開口部による欠除は1か所0.5㎡以下なら無視する**(第5編-1-2-1・第5編-2-2-2)。
   間仕切下地・主仕上のどちらにも共通のルール。石材のみ0.1㎡が閾値(第5編-2-3(4))。
   → 建具の内法面積を壁面積から引くかどうかの判定基準として使える候補。
2. **壁高さは実測ではなく設計図書の天井高さを使う**(第5編-2-2-1(1)2)。
   → 「基準点で図った高さ」と「天井高さの申告」が食い違ったときにどちらを採るかの手がかり。
3. **耐火間仕切り(軽量鉄骨下地+両面ボード)は下地とボード両面を一括し、片面面積1枚で数える**
   (第5編-1-2-2(5))。→ 「内壁の軽鉄下地」「ボード」を別々の行として二重計上しない、という
   検算ルールの候補。
4. **内装改修の撤去数量は、部位・種別ごとに区分し、設計寸法による面積・長さ・箇所数とする**
   (第7編-3-2-2(4)1)。新設に伴う床・壁・天井の取合い部も同様(同2(4)3)。
   → 「置床解体」「天井解体」「間仕切り壁の軸組」がまさにこの区分に当たる。**数え方の単位
   (面積/長さ/箇所)を種別ごとに決め打ちできる候補表になり得る。**
5. **建具改修の撤去・新設は、建具の内法寸法による箇所数・面積・長さとする**
   (第7編-3-2-2(3)1・2)。開き戸の円弧検出結果と建具表の数量を突き合わせる際の
   「単位を何で揃えるか」の根拠になる。
6. **足場・墨出し・養生清掃(=会社の諸経費に近いA-3項目)も改修面積から機械的に算出する式がある**
   (第7編-1-2-2)。例: 内部仕上足場=天井の改修面積、壁のみ新設・改修なら「壁の水平長さ×1.0m」。
   墨出し(内装・塗装改修)=床又は天井の改修面積、壁のみなら「新設壁前面から1.0mの範囲の床面積」。
   養生清掃(建具改修のみ)=外部建具「建具幅×1.0m」・内部建具「建具幅×2.0m」。
   → **A-3で「会社のルールが無いと1行も埋まらない」とされた仮設・諸経費行の一部は、
   公共工事の慣行を係数として転用できる可能性がある。** ただし住宅リノベーションの実態
   (足場を組まない小規模改修が多い等)に合うかはおーちゃんの確認が要る。
7. **発生材は関係法令に基づき分別し、各章で定めた撤去数量をそのまま使う**(第7編-5-1-2)。
   → 廃棄物処理・小運搬・荷上費の数量根拠を「撤去数量からの係数」として組み立てられる可能性。

## A′. 電気設備・給排水設備の数量の数え方の候補(A-1「記号の読み取り」に直接効く、2周目追記)

出典: 公共建築設備数量積算基準(設備版、令和7年改定) 第3編(電気設備工事)・第4編(機械設備工事)。
建築版と共通の総則(第1編)が先に効く: **数量は原則「設計数量」**(設計図書記載の台数・組数・個数、
設計寸法から求めた長さ・面積・体積等)、**寸法の単位はm、機器は基・台・個・組等、少量の改修が
点在する場合は「か所」も可**、**端数は四捨五入、長さは小数第1位・面積等は小数第2位、工事費
内訳書の数量は整数**(設備版-1-2)。

1. **配線器具(コンセント・スイッチ等)の数量は「形式及び容量による組合せごとの個数」、
   照明器具の数量は「形式及び記号ごとの個数」**(設備版-3-2-3(2)(3))。
   → **A-1で落ちている「コンセント・スイッチ・引掛シーリング」は、まさにこの条項が定める
   数え方(記号ごとに個数を数える)そのもの。** 面積からの推定ではなく、凡例記号と器具表を
   突き合わせて個数を数える設計になっていることの裏付けになる候補。
2. **末端機器が実装されないプレート類は、プレートの材質・種類ごとに個数**
   (設備版-3-3-3(2))。→ TEL配線などプレートのみで機器が別途工事になる行の扱いの参考。
3. **電気設備の改修工事(撤去・取外し)は「配管・配線、機器、盤類、器具類等」に区分し、
   コンクリート埋込部分の配管は計測対象外、付随して撤去されるものは原則計測対象外**
   (設備版-3-4-1)。→ 「電灯配線」のような配線行を、機器(器具)行と別区分で拾う根拠になる。
4. **給排水設備の衛生陶器・衛生器具ユニットは種別・規格ごとの「組数」、附属品・構成部材は
   計測対象外**(設備版-4-3-1(1)(2))。→ 便器・洗面台等の数え方の単位(組)の根拠。
5. **ダクト・配管は原則「長さ」だが、制気口・ダンパー・吹出口等の器具は「個数」**
   (設備版-4-2-2、設備版-4-1-1)。→ 長さで数える系統(配管・ダクト・配線)と個数で数える系統
   (器具・機器・盤類)の**2系統に分かれる**という構造そのものが、記号検出(個数系)と
   線検出(長さ系)を最初から別の検出器として設計すべきという設計判断の裏付けになる。

**電気設備の「面積から拾う」規定は今回読んだ範囲(設備版第3編)には無かった。** 電気設備は
一貫して「記号(凡例)ごとの個数」で積算する建付けであり、A-1の落ち込みは「面積・線から
推定する手段しかない」という実装側の制約と、基準側が要求する「記号ごとの個数」という
数え方が噛み合っていないために起きている可能性がある(検証はA-1担当スレッドに委ねる)。

## B′. 内装改修(撤去)の波及ルールの候補(5周目追記、A-2「面積と下地」の核心)

出典: 公共建築改修工事標準仕様書(建築工事編)令和7年版 6章(内装改修工事)1〜4節、直読済み。

1. **間仕切壁を撤去すると、取り合う天井・壁・床の改修範囲にも波及する。その範囲は「特記が
   なければ壁厚程度」**(6.1.3(2))。→ 「壁を1枚消す」という操作が、その壁と接する床・天井・
   隣接壁の仕上にも「壁厚分」という具体的な量で波及する、という数値つきの波及ルール。
2. **天井裏に隠れていた既存間仕切壁を撤去すると、その壁が取り合っていた天井の改修範囲は
   「特記がなければ壁面から両側600mm程度」**(6.1.3(3))。→ 1と似て非なる規定で、**壁が見える
   位置にあるか天井内に隠れているかで波及の量(壁厚 vs 600mm)が変わる**。図面から「壁が天井内で
   止まっているか、床から天井まで通っているか」を判定する必要性の裏付けになる。
3. **天井を撤去しても、取り合う壁面の改修は「特記がなければ既存のまま」**(6.1.3(5))。→ 天井の
   撤去は壁には波及しない、という非対称なルール(2の逆方向は自動では起きない)。
4. **照明器具等の配置が既存と異なる新設をする場合、野縁・野縁受けを切断した箇所は同材で補強、
   天井点検口の開口部には取付け用補強材を設ける**(6.4.2(2))。→ 電気設備(器具の割付変更)が
   内装下地の数量(補強材)に波及する具体例。A-1とA-2をまたぐ波及ルールの候補。
5. **床・壁・天井いずれも、既存の下地材・下地張りボード等を残して仕上材だけを撤去する場合と、
   下地材を含めて全撤去する場合とで、工法(したがって拾うべき数量の層)が分かれる**(6.2.2(1)、
   6.3.2(2)(3)、6.4.2(1))。「仕上のみ撤去」か「下地共撤去」かは、数量を仕上層・下地層のどちらで
   拾うかを左右する分岐点になる(A-3の問いの候補にも追加できる)。

**注意**: いずれも「特記がなければ」という既定値であり、**特記(設計図書側の指定)があればそちらが
優先される。** つまりこれらの数値は「図面だけからは読み取れない場合のフォールバック値の候補」
であって、図面や仕様書に明示があればそれを優先すべき性質のもの。

## B. 波及のルールの候補

1. **仕上改修の順序は「既存仕上の撤去→新設仕上のための下地処理→新設仕上→補修」の4区分が
   公共基準の型**(第7編-3-2-1(2))。→ 差分(工事内容)の設計で扱う「撤去/新設/既存のまま/改修」の
   4区分と、この4区分(撤去・下地処理・新設・補修)は**粒度が違う**(後者は改修という1つの工事区分の
   内部工程)。用語の食い違い(status.md記載の3通りの区分)にもう1つ変種が増える形になるため、
   混同しないよう記録として残す。
2. **新設仕上の数量は「第5編(新築の仕上基準)」をそのまま参照する**(第7編-3-2-2(1))、
   **既存仕上撤去の数量は「既存主仕上の設計寸法」による**(同(2))。
   → 波及ルールの候補: 「新設側の数量が決まれば、新築用の仕上規則(第5編)がそのまま使える
   (改修専用の規則を別に持つ必要がない)」。実装上、新設側の規則ファイルを改修でも再利用できる
   可能性がある(設計文書`queue3_redesign.md`の規則差し替え可能性と関係)。
3. **壁のみ新設・改修する場合は、通常の面積算出と別に「幅木・見切り等の取合い」を意識した特例
   (新設壁前面から1.0mの範囲)がある**(第7編-1-2-2(1)4・(2)4・(3)2)。→ 「壁だけ改修」という
   工事範囲の申告が、床面積側の数量にも波及する具体例。工事範囲の申告(スタートキットの目的・
   ページ種類宣言)が数量計算式そのものを分岐させる実例として、原則3-2/3-3の設計に参考情報として渡せる。

## C. 軸ごとの問い(キラークエスチョン)の候補

1. 「開口部(建具)の面積は、1か所あたり0.5㎡を超えるか」— 超えなければ主仕上・下地の面積から
   控除しない、というほぼ機械的な判定に使える(A-2の閾値判定)。
2. 「この間仕切りは耐火間仕切り(軽鉄下地+両面ボード)か、それとも片面だけの下地か」— 二重計上の
   検算に使える。
3. 「改修する壁は、床・天井を含む全面改修か、壁のみの改修か」— 壁のみの場合は足場・墨出し・床面積の
   算出式が変わる(上記B-3)ため、面積読み取りの前提として確認する価値がある。
4. 「建具は取替え(既存枠を撤去して新規)か、かぶせ工法(既存枠を残す)か」— かぶせ工法では
   既存枠の補強・防錆は原則計測対象外(第7編-3-2-2(3)1②)になるなど、拾う数量の種類が変わる。
   **4周目追記: 工法の定義そのものを確認した**(公共建築改修工事標準仕様書(建築工事編)令和7年版
   5.1.3、https://www.mlit.go.jp/gobuild/content/001888823.pdf、直読)。**「かぶせ工法」= 既存建具の
   外周枠を残し、その上から新規建具を取り付ける工法。「撤去工法」= 既存建具の枠回りをはつり又は
   引抜きによって撤去し、新規建具を取り付ける工法。** どちらを採るかは「特記による」(設計図書・
   仕様書の指定次第)とされており、図面や仕様書に工法の指定が無ければ判定できない性質のものだと
   分かる。かぶせ工法では既存枠の耐力確認・清掃・錆止め・小ねじ留め(端部100mm以下・中間400mm以下)
   という付随作業が発生し(5.2.6(2)ｱ、これは施工要領であり数量には現れない)、数量積算基準側の
   「既存枠の補強・防錆は原則計測対象外」という扱いと整合する。
5. 「床・壁・天井は、仕上材だけを撤去するか、下地材(下地張りボード等)を含めて撤去するか」
   (改修工事標準仕様書6.2.2(1)・6.3.2(2)(3)・6.4.2(1)、5周目追記)— 仕上のみ撤去なら下地は
   残るため数量を仕上層だけで拾い、下地共撤去なら下地層の数量も拾う必要がある、という分岐点。

## F. 施工方法の候補(4周目追記)

出典: 公共建築改修工事標準仕様書(建築工事編)令和7年版(https://www.mlit.go.jp/gobuild/content/001888823.pdf、
直読。全299頁のうち第1章〈各章共通事項〉・第5章〈建具改修工事〉1節・2節を確認)。

1. **建具改修の工法は「かぶせ工法」と「撤去工法」の2つに限られ、定義が明文化されている**(5.1.3)。
   上記C-4に統合済み。工法の指定は「特記による」、つまり設計図書・特記仕様書側の情報であり、
   平面図や建具表だけからは決まらない可能性が高い(仕様書ページの読み取りが要る)。
2. **石綿含有建材の除去は改修工事の各章から独立して9章1節を参照する構成**(5.1.8(1))。
   → 解体・撤去を伴うすべての改修工事に、石綿の扱いという共通の前提が上位から掛かっている
   ことの裏付け(A-3の会社のルールというより、9章1節(未読)の内容そのものは今回未確認)。
3. 章立て全体(1章共通事項〜2章仮設〜3章防水改修〜4章外壁改修〜5章建具改修〜6章内装改修〜
   7章塗装改修〜8章耐震改修…)は、**建築版数量積算基準 第7編の区分(仮設改修・躯体改修・仕上改修
   〈防水・外壁・建具・内装・塗装〉・その他改修)とほぼ1対1で対応している。** 施工方法の基準と
   数量の数え方の基準が同じ分類体系を共有しているという構造そのものが、見積の行の型(工種分類)を
   設計する際の裏付けになる。

## E. 図面の描き方の候補(3周目追記、原則違反6番「寸法線の数字を読む経路が無い」に関係)

出典: 建築工事設計図書作成基準(国交省官庁営繕部、令和2年改定、https://www.mlit.go.jp/common/001157950.pdf、直読済み)。

1. **縮尺(尺度)は13種類に固定されている**(1/1・1/2・1/3・1/5・1/10・1/20・1/30・1/50・1/100・1/200・
   1/300・1/500・1/600。3.4)。原寸大含め、この13択のどれかであることが公共基準上は保証される。
   → 縮尺の印字が読み取れなくても、印字寸法との整合を13択の中から絞り込む検算に使える可能性(候補)。
2. **寸法の単位はミリメートル固定(単位記号は省略)**(3.5(1))。→ 「単位の書かれていない寸法をmmの
   仮説として扱う」(status.md記載の判定変更5件のうちの1つ)を裏付ける一次資料。
3. **平面表示記号(別表1)・材料構造表示記号(別表2)・建具開閉表示記号(別表3)は、いずれも標準化された
   記号の一覧として存在する**(3.6)。「建具の開閉表示記号は決まった記号セットの中のどれかである」
   という前提そのものは、開き戸の円弧検出のような記号認識の学習・検証データを作る際の母集団の定義に
   使える候補。**6周目: 別表1〜3の中身そのものを画像として読んだ。詳細はG節。**
4. **標準的な図面の並び・名称が30種類、番号付きで決まっている**(4.2、表紙・図面目録・特記仕様書・
   工事区分表・敷地案内図・敷地求積図・敷地現況図・配置図・面積表及び求積図・**仕上表**・平面図・
   立面図・断面図・矩計図・平面/断面/部分詳細図・**展開図**・天井伏図・**建具位置図**・**建具表**・
   工作物等詳細図・外構詳細図・植栽図・仮設計画図…)。**P011の1ページ目の図面リストがこの並びに
   近い**(既存平面図/改装平面図/既存撤去図/展開図/建具表/建具詳細図/内部仕上表/仕様書/平面図凡例/
   電気位置図/照明器具リスト)。ページ種類の自動判定を設計する際、この30種類を候補ラベルの母集団に
   使える可能性(候補、ページ種類宣言の設計 = 原則違反11番と関係)。
5. **改修工事の図面は、対象部分に「取外し・再取付け・撤去・新設」のいずれかを明示する規定がある**
   (5.1(1)、対象部分は寸法とともに図示)。→ **これは現況/計画/解体/不明(コード)、撤去/新設/既存の
   まま/改修(差分設計)、撤去・下地処理・新設・補修(建築版数量積算基準)に続く、工事区分の言い方の
