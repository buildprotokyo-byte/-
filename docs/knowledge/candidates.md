# 知識の表への反映案(候補、採否はおーちゃんの確認待ち)

**前提の注意**: 以下はすべて国土交通省官庁営繕部の統一基準
「公共建築数量積算基準」(令和5年改定、https://www.mlit.go.jp/common/001178206.pdf 、直読済み。
以下「建築版」)と
「公共建築設備数量積算基準」(令和7年改定、https://www.mlit.go.jp/common/001178207.pdf 、直読済み。
以下「設備版」)に基づく**公共工事の積算慣行**であり、
ビルドプロ社内の会社ルールそのものではない。この案件(住宅・マンションのリノベーション)への
そのままの適用が適切かは未検証。**「候補」であって「正解」ではない。** 条項番号を付したので、
採否の判断や中身の確認時に本文を直接参照できる。以下、条は「編-章-節-項」の略記。

## A. 会社のルール・数量の数え方の候補(A-2「面積と下地」に直接効く)

いずれも出典: 公共建築数量積算基準(建築版) 第5編(仕上)・第7編(改修)。

1. **開口部による欠除は1か所0.5㎡以下なら無視する**(第5編-1-2-1・第5編-2-2-2)。
   間仕切下地・主仕上のどちらにも共通のルール。石材のみ0.1㎡が閾値(第5編-2-3(4))。
   → 建具の内法面積を壁面積から引くかどうかの判定基準として使える候補。
2. **壁高さは実測ではなく設計図書の天井高さを使う**(第5編-2-2-1(1)2)。
   → 「基準点で図った高さ」と「天井高さの申告」が食い違ったときにどちらを採るかの手がかり。
3. **耐火間仕切り(軽量鉄骨下地+両面ボード)は下地とボード両面を一括し、片面面積1枚で数える**
   (第5編-1-2-2(5))。→ 「内壁の軽鉄下地」「ボード」を別々の行として二重計上しない、という
   検算ルールの候補。
4. **内装改修の撤去数量は、部位・種別ごとに区分し、設計寸法による面積・長さ・箇所数とする**
   (第7編-3-2-2(4)1)。新設に伴う床・壁・天井の取合い部も同様(同2(4)3)。
   → 「置床解体」「天井解体」「間仕切り壁の軸組」がまさにこの区分に当たる。**数え方の単位
   (面積/長さ/箇所)を種別ごとに決め打ちできる候補表になり得る。**
5. **建具改修の撤去・新設は、建具の内法寸法による箇所数・面積・長さとする**
   (第7編-3-2-2(3)1・2)。開き戸の円弧検出結果と建具表の数量を突き合わせる際の
   「単位を何で揃えるか」の根拠になる。
6. **足場・墨出し・養生清掃(=会社の諸経費に近いA-3項目)も改修面積から機械的に算出する式がある**
   (第7編-1-2-2)。例: 内部仕上足場=天井の改修面積、壁のみ新設・改修なら「壁の水平長さ×1.0m」。
   墨出し(内装・塗装改修)=床又は天井の改修面積、壁のみなら「新設壁前面から1.0mの範囲の床面積」。
   養生清掃(建具改修のみ)=外部建具「建具幅×1.0m」・内部建具「建具幅×2.0m」。
   → **A-3で「会社のルールが無いと1行も埋まらない」とされた仮設・諸経費行の一部は、
   公共工事の慣行を係数として転用できる可能性がある。** ただし住宅リノベーションの実態
   (足場を組まない小規模改修が多い等)に合うかはおーちゃんの確認が要る。
7. **発生材は関係法令に基づき分別し、各章で定めた撤去数量をそのまま使う**(第7編-5-1-2)。
   → 廃棄物処理・小運搬・荷上費の数量根拠を「撤去数量からの係数」として組み立てられる可能性。

## A′. 電気設備・給排水設備の数量の数え方の候補(A-1「記号の読み取り」に直接効く、2周目追記)

出典: 公共建築設備数量積算基準(設備版、令和7年改定) 第3編(電気設備工事)・第4編(機械設備工事)。
建築版と共通の総則(第1編)が先に効く: **数量は原則「設計数量」**(設計図書記載の台数・組数・個数、
設計寸法から求めた長さ・面積・体積等)、**寸法の単位はm、機器は基・台・個・組等、少量の改修が
点在する場合は「か所」も可**、**端数は四捨五入、長さは小数第1位・面積等は小数第2位、工事費
内訳書の数量は整数**(設備版-1-2)。

1. **配線器具(コンセント・スイッチ等)の数量は「形式及び容量による組合せごとの個数」、
   照明器具の数量は「形式及び記号ごとの個数」**(設備版-3-2-3(2)(3))。
   → **A-1で落ちている「コンセント・スイッチ・引掛シーリング」は、まさにこの条項が定める
   数え方(記号ごとに個数を数える)そのもの。** 面積からの推定ではなく、凡例記号と器具表を
   突き合わせて個数を数える設計になっていることの裏付けになる候補。
2. **末端機器が実装されないプレート類は、プレートの材質・種類ごとに個数**
   (設備版-3-3-3(2))。→ TEL配線などプレートのみで機器が別途工事になる行の扱いの参考。
3. **電気設備の改修工事(撤去・取外し)は「配管・配線、機器、盤類、器具類等」に区分し、
   コンクリート埋込部分の配管は計測対象外、付随して撤去されるものは原則計測対象外**
   (設備版-3-4-1)。→ 「電灯配線」のような配線行を、機器(器具)行と別区分で拾う根拠になる。
4. **給排水設備の衛生陶器・衛生器具ユニットは種別・規格ごとの「組数」、附属品・構成部材は
   計測対象外**(設備版-4-3-1(1)(2))。→ 便器・洗面台等の数え方の単位(組)の根拠。
5. **ダクト・配管は原則「長さ」だが、制気口・ダンパー・吹出口等の器具は「個数」**
   (設備版-4-2-2、設備版-4-1-1)。→ 長さで数える系統(配管・ダクト・配線)と個数で数える系統
   (器具・機器・盤類)の**2系統に分かれる**という構造そのものが、記号検出(個数系)と
   線検出(長さ系)を最初から別の検出器として設計すべきという設計判断の裏付けになる。

**電気設備の「面積から拾う」規定は今回読んだ範囲(設備版第3編)には無かった。** 電気設備は
一貫して「記号(凡例)ごとの個数」で積算する建付けであり、A-1の落ち込みは「面積・線から
推定する手段しかない」という実装側の制約と、基準側が要求する「記号ごとの個数」という
数え方が噛み合っていないために起きている可能性がある(検証はA-1担当スレッドに委ねる)。

## B. 波及のルールの候補

1. **仕上改修の順序は「既存仕上の撤去→新設仕上のための下地処理→新設仕上→補修」の4区分が
   公共基準の型**(第7編-3-2-1(2))。→ 差分(工事内容)の設計で扱う「撤去/新設/既存のまま/改修」の
   4区分と、この4区分(撤去・下地処理・新設・補修)は**粒度が違う**(後者は改修という1つの工事区分の
   内部工程)。用語の食い違い(status.md記載の3通りの区分)にもう1つ変種が増える形になるため、
   混同しないよう記録として残す。
2. **新設仕上の数量は「第5編(新築の仕上基準)」をそのまま参照する**(第7編-3-2-2(1))、
   **既存仕上撤去の数量は「既存主仕上の設計寸法」による**(同(2))。
   → 波及ルールの候補: 「新設側の数量が決まれば、新築用の仕上規則(第5編)がそのまま使える
   (改修専用の規則を別に持つ必要がない)」。実装上、新設側の規則ファイルを改修でも再利用できる
   可能性がある(設計文書`queue3_redesign.md`の規則差し替え可能性と関係)。
3. **壁のみ新設・改修する場合は、通常の面積算出と別に「幅木・見切り等の取合い」を意識した特例
   (新設壁前面から1.0mの範囲)がある**(第7編-1-2-2(1)4・(2)4・(3)2)。→ 「壁だけ改修」という
   工事範囲の申告が、床面積側の数量にも波及する具体例。工事範囲の申告(スタートキットの目的・
   ページ種類宣言)が数量計算式そのものを分岐させる実例として、原則3-2/3-3の設計に参考情報として渡せる。

## C. 軸ごとの問い(キラークエスチョン)の候補

1. 「開口部(建具)の面積は、1か所あたり0.5㎡を超えるか」— 超えなければ主仕上・下地の面積から
   控除しない、というほぼ機械的な判定に使える(A-2の閾値判定)。
2. 「この間仕切りは耐火間仕切り(軽鉄下地+両面ボード)か、それとも片面だけの下地か」— 二重計上の
   検算に使える。
3. 「改修する壁は、床・天井を含む全面改修か、壁のみの改修か」— 壁のみの場合は足場・墨出し・床面積の
   算出式が変わる(上記B-3)ため、面積読み取りの前提として確認する価値がある。
4. 「建具は取替え(既存枠を撤去して新規)か、かぶせ工法(既存枠を残す)か」— かぶせ工法では
   既存枠の補強・防錆は原則計測対象外(第7編-3-2-2(3)1②)になるなど、拾う数量の種類が変わる。
