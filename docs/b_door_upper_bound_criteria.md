# 43周目 基準: 上限を測る。この升目から建具表は取り出せるのか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。42 周目で**自分の測り方の穴**が見つかったので、それをふさぐ周。

## なぜこの題なのか

42 周目の結論は「くっつけるだけでは届かなかった」だが、**測り方に穴があった。**

**くっつけた塊でも、見出しを探すのは「上から 3 行」のままだった。**
塊は元の表の行を上から並べたものなので、**2 つ目以降の破片の行は 4 行目より下に来る。**
現に `幅` の当たりは**くっつけるほど減っている**(12 → 6 → 4)。

**窓を外さないと、割れているかどうかは測れていない。**

## 測るもの

**見出しの探索範囲を「上から 3 行」から「全部の行」に広げて、同じことをもう一度測る。**

**これは実装として正しい読み方ではない**(下のほうの行を見出しと言い張ることになる)。
**「この升目の集まりから建具表が取り出せるか」の上限としてだけ正しい。**
**上限で届かなければ、どんな正しい読み方でも届かない。** そこだけが言える。

| 記号 | 何を測るか |
|---|---|
| **Q1** | **当たり**: 内側で建具表として通った数 |
| **Q2** | **誤爆**: 外側で通った数 |
| **Q3** | **誤爆 ÷ 当たり** |
| **Q4** | 取り違え(升目が 2 役割以上) |
| **Q5** | 役割ごとの当たり(内側) |
| **Q6** | **建具番号と付き添いが 2 つ以上そろった塊の数**(通る手前の数。しきいを外した数) |
| **Q7** | 内装仕上表を同じやり方で測った数 |

**並べる組み合わせ**(先に決める):

- 向き: **そのまま / 転置**(2 通り)
- くっつけ: **しない / SLACK 6 pt**(2 通り)
- 当て方: **K0 / K1 / K2a / K2b**(4 通り)
- 窓: **上から 3 行 / 全部の行**(2 通り)

**合わせて 32 通り。** 窓が「上から 3 行」の側は、39〜42 周目の再現として使う。

## 採否の線(**39〜42 周目と同じ 3 つ。結果を見てから変えない**)

| 条件 | 線 |
|---|---|
| **当たり** | **Q1 ≧ 2** |
| **誤爆** | **Q3 < 0.5** |
| **取り違え** | **Q4 = 0** |

- **窓を外した側で 3 つとも満たす組み合わせがある** → **穴は窓だった。**
  直す場所が名指しできる。**実装案を書く。判定に触るので PR のまま待つ。**
- **窓を外すと Q1 は増えるが誤爆か取り違えで落ちる** → **窓は効いているが、それだけでは足りない。**
  **それでも「割れている」ことの証拠にはなるので、報告に残す。**
- **窓を外しても Q1 ≦ 1** → **上限で届かない。**
  **この図面の升目からは、この語彙で建具表は取り出せない。**
  **7 つ試して 7 つとも違ったことになり、42 周目に出した判断待ちの根拠が固くなる。**

**Q6 は線に入れない。** 通る手前で何がそろっているかを見るためだけに出す。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 合成の建具表に 32 通りとも当てる | **窓を外しても通り続ける**(壊していない) |
| **2** | 窓が「上から 3 行」の側が 42 周目を再現するか | そのまま・くっつけなし で K0 0 / K1 1 / K2a 0 / K2b 0 |
| **3** | 内装仕上表(Q7)が、窓を外して**減らない** | 減ったらその組み合わせは不採用 |
| **4** | 反復 3 回 | 3 回とも同じ |

**対照2 が再現しなければ結論を出さない。**

## この周で変えないもの

- **実装には手を入れない。** 窓も向きもくっつけも当て方も、ベンチマークの中だけ。
- 判定のしかた・基準値・階層の条件にも触れない。
- 実図面のパスは引数で渡す。**出すのは件数と割合だけ。図面の文字は 1 文字も出さない。**
