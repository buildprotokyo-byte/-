## 書き足す例外(おーちゃんが決めた。そのまま)

> **図面に無いことが確かな数字だけ**は、数字の入力を認める。
> 条件:全ページ(平面図・展開図・仕上表・縮尺換算)を探して無いことを確かめた室だけ。
> 入力は縦・横(mm)。ほかに「分からない」「現地で実測する」の選択肢。入力は「人の入力」の印を付け、自動確定にしない。

この枝での形(`draft/room_unknown.py`、旗 `--with-room-unknown`、既定オフ):

- 認めるのは**室の寸法の問い(鍵 `室の寸法:{室の番号}`)だけ**。ほかの型のカードの「数字の入力は禁止」は変えない。
- 「確かめた」は機械の確かめ(`docs/k73_room_unknown_criteria.md` 2 節)。4 つの種類の**全部**で「無かった」室だけ。
  1 つでも「候補があった」「見られなかった」なら、数字の入力欄を出さず、選択肢だけ
  (候補のページ・「図面に無い」「分からない」「現地で実測する」)。
- 入力欄は**図面に無い辺だけ**(縦・横の両方が無ければ両方)。図面にある辺の数字は受けない。数だけ受ける(文字・0 以下は受けない)。
- 入れた数字には「人の入力」の印。答えで決まった数量は状態「推論」・確度「中」・`自動確定: false`。
  理解の項目の数量は書き換えない。本番の入口(機械の検算)に通して自動確定 0 を確かめる。
- 推奨は出さない(K-65 のまま)。
