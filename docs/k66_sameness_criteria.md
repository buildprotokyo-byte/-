## 1. 判定の 5 値(おーちゃん K-66 1 節)

| 値 | 意味 |
|---|---|
| `○` | 同じ |
| `△上位・下位` | 片方がもう片方の上位・下位 |
| `△粒度` | 粒度が違う(**合計と位置が合えば `○` に格上げ**) |
| `×` | 違う |
| `比較不能` | 判定しない(片方の構造が取れていない、判定役が 2 人揃わない) |

- **科目・中科目**: 辞書で同じ分類か。
- **細目**: 構造のキー(**工事の種類・部位・状態・材料**)が同じか。**品名の文字は見ない。**
- **数量は別に判定する**(個数 ±1、面積・長さ ±5%、`式` は判定しない)。名前の判定に数量を混ぜない。

細目の決め方(測る前に決めた。これが「規則」):

1. 工事の種類・部位・状態の 3 つが両方とも取れていて、1 つでも違う → `×`
2. 3 つが同じで、材料も両方取れていて違う → `×`(フロアタイル張とクッションフロア張は別の行)
3. 3 つが同じで、材料が片方だけ取れている、または両方とも取れていない → `○`
4. 3 つが同じで材料も同じ → `○`
5. 片方だけ部位または材料が取れていない状態で、取れている側の上位に当たる → `△粒度`
6. 片方が細目、もう片方がその細目の属する科目(または上位の語)だけ → `△上位・下位`
7. 工事の種類が両方とも取れていない → `比較不能`

**`△` を `○` に格上げするのは、呼ぶ側が「合計が許容差内で合い、位置(科目・部位)も合う」を渡したときだけ。**
部品の中で勝手に格上げしない。

## 2. 部品の作り(おーちゃん K-66 2 節)

新しい package `sameness/`。**ここだけが「同じか」を決める。**

| 層 | 置き場所 | 中身 |
|---|---|---|
| (a) 機械で揃える | `sameness/normalize.py` | 全角半角(NFKC)、括弧、`洋室1`/`洋室(1)`、単位(`㎡`=`m2`=`m²`)、`材工`/`工`/`材` の接尾、記号・中黒・送り仮名 |
| (b) 辞書 | `sameness/terms/default.json` | 科目・中科目・部位・状態・材料の同義語。**差し替えられるファイル**(`SAMENESS_TERMS` か引数で差し替え) |
| (c) 構造のキー | `sameness/keys.py` | 品名から 4 つ(工事の種類・部位・状態・材料)。機械で取り、取れない品名だけ AI に 1 回だけ聞いてキャッシュ(`sameness/cache.py`、同じ品名には同じキー) |
| (d) 判定役 | `sameness/judge.py` | 迷う対(`比較不能`・`△`)だけ AI が比べる。**3 人のうち 2 人以上が「同じ」のときだけ `○`。2 人未満は `比較不能`**(`×` にしない) |
| (e) 理由 | 同じ `judge.py` | 1 行の理由を必ず返す(`Verdict.reason`)。確認画面に出せる形 |

- 辞書の元: ①`draft/vocab/default.json` の閉じた語彙(細目 75・部位 10・区分 10・単位 12)
  ②公開書式(B-08)の改修 9 科目と細目別内訳の品目名(`docs/knowledge/candidates.md` J 節)
  ③状態の語は建築の知識で最初の案を作る(`撤去`=`解体`=`取外し`=`はつり`、`新設`=`新規`=`設置`=`取付` など)
  ④各案件の見出し語(B-14 の結果)と、おーちゃんが確定した対は**後から足せる**(ファイルを差し替えるだけ)
- **AI を呼べない環境では (c) の AI 層と (d) は動かない。**そのとき部品は機械の層だけで答え、
  迷う対は `比較不能` のまま返す。**`○` を増やす方向に黙って倒れない。**

## 3. 判定自体を測る(おーちゃん K-66 3 節、線はここ)

**実案件も正解ファイルも使わない。** 語はすべて `draft/vocab/default.json` と公開書式(B-08)の品目名から取る。

| 測るもの | 数え方 | 線 |
|---|---|---|
| (a) 囮の通過率 | 「似ていて違う」対を機械で作り、`○`(格上げ後も含む)になった割合 | **0%。1 件でも通ったらこの規則は不合格** |
| (b) 正しい言い換えの合格率 | 同義の対(`大工工事`/`木工事` など)が `○` になった割合 | **0.80 以上**(旧規則の値も並べる) |
| (c) おーちゃんの目で確かめる 40 組 | 確認画面と同じ作りのカード。選択肢は `同じ`/`違う`/`上位・下位`。所要時間を記録し、部品との一致率を出す | 線は置かない(**おーちゃんの答えが来てから**部品を直す。先に直さない) |
| (d) 判定役 3 人の一致 | 3 人が同じ答えを出した割合、2 対 1 の割合 | 線は置かない(報告だけ)。AI を呼べなければ「未取得」 |

囮の作り方(**測る前に決めた**。すべて機械で作る):

1. **部位の入れ替え**: 床↔壁、天井↔壁、外壁↔内壁(同じ工事・同じ状態で部位だけ変える)
2. **状態の入れ替え**: 撤去↔新設、撤去↔張替、新設↔補修
3. **科目の入れ替え**: 電気設備↔機械設備(給排水)、内装↔木工事
4. **材料の入れ替え**: 同じ部位・同じ状態で材料だけ変える(フロアタイル↔クッションフロア など)
5. **数量違い**: 名前は同じで数量だけ許容差の外(個数 +2、連続量 ×1.2)。これは**数量の判定の囮**で、
   名前が `○` でも行としては当たりにしない、を測る

**囮が 1 件でも `○` になったら、規則を直してから測り直す。線は下げない。**
