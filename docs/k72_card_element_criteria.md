## 1 要素の重なり(測る前に固定)

### 1-1 対応づけの候補(K-71 の 1-3 の 1 に足す)

K-71 の候補(同じページ・行の箱の面積の重なり率 0.50 以上)のうち、**次の「要素が重なる」も満たす対だけ**を候補にする。
満たさない対は候補にしない(重なり率がいくら大きくても対応づけない)。

2 つの回の行 a・b が **要素が重なる** = a の要素と b の要素の組のうち、**次を全部満たす組が 1 つ以上ある**:

1. **同じページ**: 2 つの要素のページが同じ(行のページ。要素はその行のページの `読む.読み[ページ].要素` から id で引く)。
2. **同じ室**: 行 a と行 b の室の鍵(`sameness.rows.row_room`)が同じ。どちらも室が取れていなければ同じとみなす
   (K-66 の鍵がそうまとめるため)。**室の組(次元が `室`)では見ない**(室が問う値なので、見るとカードが作れない)。
   正直に書く: 数量・状態・部位の組は、組の鍵に室の鍵がもう入っているので、この条件はいつも満たされる。
3. **同じ種類**: 要素の `種類`(文字・線・数字・記号・図・表・写真)が同じ文字。
4. **近い大きさ**: 要素の箱の幅どうし・高さどうしの比(小さい方 ÷ 大きい方)が、**どちらも 0.5 以上**(2 倍まで)。
   幅・高さが 1 画素未満の箱は 1 画素として比べる(線の要素は高さ 0 がある)。
5. **要素の箱が重なる**: 2 つの要素の箱が、重なった面積 > 0(幅・高さ 1 画素未満の箱は 1 画素に広げてから)。
   (要素の id は回ごとに付け直されるので、回をまたいだ「同じ要素」は 1〜5 で決める。)

- 要素の id が `読む.読み` に見つからない要素は、無いものとして扱う。**要素が 1 つも引けない行は、どの行とも要素が重ならない**。
- 要素の重なりで落ちた行の行き先(K-71 の 1-4 の表に 1 行足す。上から順に見る):

| 入れ先 | 中身 |
|---|---|
| カードにした / 単位の同値で外した / 値が 1 つしか無い / 切り抜きが無い / 同点で決まらない | K-71 と同じ |
| **できなかった: 位置は重なるが要素が重ならない**(新) | 重なり率 0.50 以上の行がほかの回にあるが、どれも要素が重ならず、対応づかなかった |
| できなかった: 位置の重なる行がほかの回に無い | K-71 と同じ |

## 仮の判断(推奨つき)

**仮の判断 5-1(囮 2' の不合格)。**移した先に同じ種類・同じ大きさの要素があると、位置と要素の形では見分けられない。
