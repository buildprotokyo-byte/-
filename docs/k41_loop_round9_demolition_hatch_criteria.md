# K-41 10時間ループ 周9: 既存撤去図の網(凡例 m・j)を機械が測る — **測る前の基準**

この文書は**測る前に**コミットする。

## 前

- 機械の一本道は既存撤去図(33 ページ)を読んでいない。撤去の行は、内部仕上表から全室の壁・天井・床の全面で出している。
- 周 4 の食い違いの役: 「機械は撤去を全室の壁・天井全面で出している。既存撤去図の網は住戸の中央だけ」。
- 33 ページの線(機械で数えた): 青の斜めの線 1,176 本、赤の斜めの線 206 本。凡例 m(青の交差した網)= 床組・天井組の撤去範囲、凡例 j(2 本線の間の赤い×)= 軸組の撤去範囲。

## 変えるもの(1 つだけ)

**33 ページの青の斜めの線の網を機械が面として測り、「床組・天井組の撤去」の面積の行にする。**

- 手順(決めた値は測りながら動かさない): 青の斜めの線を 1pt の太さで塗る → 網の目(約 30pt)を埋めるため 40pt の四角で閉じる → 穴を埋める → 面積を縮尺 1/50(33 ページの表記、1pt = 17.64mm として K-38 の目盛りと同じ換算)で㎡にする。
- 面が複数に分かれたら、面ごとに行にする。場所は、面の中にある室名。
- 赤の×(凡例 j)は、この周では測らない(1 周 1 つ)。

## 囮

同じ手順を、33 ページの**黒の斜めの線**(既存のまま残す WIC の網など)に当てる。

## 採点

- 採点する役が、網の行・囮の行・機械の 67 行を、伏せた名前で正解 93 件に結ぶ(周 1 と同じ決まり)。
- 結ばれた行の**数量**を、正解の単位が㎡のものについて ±5% で判定する(K-36 の許容差のまま。判定のしかたは変えない)。

## 合格の線

1. 網の行が、機械の 67 行が当てていない正解を 1 件以上当て、囮は 0 件。
2. **網の行の面積が、当たった正解の数量の ±5% に 1 件以上入る**。
   (撤去の範囲の面積が、図の網から直接出るかを見る。)

**不通過になる数字の例**: 網の面積が 38㎡、結ばれた正解が 30㎡なら差 27% で 2 を満たさない。

## 守ること

**自動確定は 0 件のまま。**面積は候補で、確定させない。1 件でも確定に入ったら止める。人の入力・合成の寸法は使わない。
