  4. **回転したページで、文字の層の位置が画像に合う**: 一本道が画像の座標として使う文字の層の語の四角(`draft.pages.positioned_words` と

### 1(b) 拒否と落ちを分ける

- 未取得を 3 つの印に分けて数える: **拒否**(AI が安全判定などで答えを返さない。API の `stop_reason == "refusal"`、
  または置かれた答えのフォルダに「断られた」印のファイル)/ **落ち**(呼び出しの失敗・形の違う答え・まとめて送った 1 件が errored/expired/canceled・
  結果に無かった)/ **待っている問い**(鍵が無くて呼んでいない)。答えの出どころは今と同じ「未取得」のまま(下流を変えない)。
- 線(合成の試験): 偽の AI で 拒否 1・例外 1・形の違う答え 1 を混ぜて通すと、`AI を呼んだ記録` のまとめの「未取得の内訳」が
  **拒否 1・落ち 2・待っている問い 0** にぴったりなる。鍵なしで通すと **拒否 0・落ち 0・待っている問い = 未取得の数**。
  拒否を落ちと数える(またはその逆の)取り違えが 1 件でもあれば不合格。まとめて送る型でも errored は落ち、refusal は拒否。
- 報告だけ: f_rotated の通しの内訳(鍵が無いので全部「待っている問い」になる見込み。K-63 で断られたという記録は答えのフォルダに無いので、
  拒否とは数えない。**捏造しない**)。

### 1(c) 仕様書なし / 原価表だけ / 仕上表だけ

- 版(v4 から `draft.pages.hide_pages` で、そのページを同じ大きさの白紙に替えて作る。ページ番号を保つため。下の仮の判断 1):
  - **c1 仕様書なし**: 整理の段(基準の回)で「仕様書」とされた 1 ページを白紙に。合成の原価表(CSV、3 行、架空の単価)を渡す。
  - **c2 原価表だけ**: 仕様書 1 ページと仕上表 3 ページを白紙に。合成の原価表を渡す。
  - **c3 仕上表だけ**: 仕様書 1 ページを白紙に。原価表は渡さない。
- 出力に「資料の有無」(仕上表・仕様書・原価表、それぞれ あり / なし / 未取得)を足す。仕様書は整理の段の種類から決め、
  整理が未取得なら「未取得」(「なし」と言い切らない)。
- 線(3 版それぞれ):
  1. 止まらない(`段の中の例外` 0)・自動確定 整数の 0。
  2. 欠けさせた資料が「資料の有無」で **「あり」になっていない**(なし か 未取得)。渡していない原価表は「未取得」。
  3. **0 にならない**: 数量が 0 の項目が 0 件、未取得の読みのページで数字の読了率 0 件(1(a) の 3 と同じ数え方)。
  4. 囮との比べ: 壊していない基準の回の「資料の有無」は 仕上表・仕様書とも **あり** と出ること(何でも「なし/未取得」と出す物差しではない)。
- 合成の試験: 整理の答えに仕様書のページがあれば「あり」、無ければ「なし」、整理が未取得なら「未取得」。

### 周 1 の仮の判断

1. **「ページを抜いた」は白紙に替えて作った(推奨)**。抜くとページ番号がずれ、通読の 3 ページずつの組がすべて変わって比べられない。
   白紙のページは AI に渡さないので、中身としては抜いたのと同じ。
2. **「原価表だけ」は「図面と原価表はあるが、仕上表と仕様書が無い」と読んだ(推奨)**。図面なしでは一本道が始まらない。
   「仕上表だけ」は「仕上表はあるが、仕様書と原価表が無い」。
