## 周 2 — クラウドだけで通す・呼び出し口を段ごとに切り替える(測る前に書いた)

     **線**: b1 の 3 回の整理の種類との一致が 3 回とも **0.95 以上**、かつ囮(AI の種類をページの間ででたらめに並べ替えた、種 0)より **0.20 以上高い**。
     通れば整理の費用を全部引く。
  2. **通読・読み直し**(読みの要素の書き出し): 要素の種類が「文字」「数字」のものについて、要素の四角(3 画素広げる)に中心が入る文字の層の語を
     つないだ文字列と、要素の内容が同じ(NFKC・空白を除いて一致、または片方がもう片方を含み長さの比 0.8 以上)なら「プログラムで出せる」とする。
     **出せる割合** = 出せる要素の JSON の字数 ÷ 全要素の JSON の字数(読みの最後の形で数え、通読と読み直しの出力に同じ割合を当てる。仮の判断 7)。
     **線**: 3 回とも、出せる割合が囮(同じ四角に、次のページの文字の層を当てた)より **0.20 以上高い**。通れば通読と読み直しの**出力**の費用にその割合を掛けて引く
     (入力の画像は線・記号を読むのに要るので引かない)。
  3. **仕上表の原本**: AI が書き写した行のうち、室と仕上の両方の文字列(NFKC・空白を除く)がそのページの文字の層に入っている割合。
     **線**: 3 回とも **0.95 以上**、かつ囮(次のページの文字の層)より **0.20 以上高い**。通れば仕上表の原本の費用を全部引く
     (文字の層に入っていても、行と列の対応までプログラムで取れるかは測っていない。それは仮の判断 8 に書く)。
  4. **理解**: 意味の判断(工事・数量・確度)で、プログラムで同じものを出す道具が無い。**引かない**(大きいモデルのまま)。
- 出すもの: 段ごとの 元の費用 → ①の費用、合計の 前 → 後。②は「未測定」。
