## **測ったあとに見つけた、こちらのほうが大きい**

W5 の 59 行が**どこから来ているか**を見て気づいた。

**仕上表が読める 2 ページは、どちらも縮尺が読めないページだった。**
だから「表を縮尺に依存させる」と、**この図面で読めている仕上表は全部消える。**
一部ではなく、**全部**である。

そこで、それを止めるテストがあるかを探した。**1 件も無かった。**

- `tests/test_schedule_tables.py` に `scale` の語が 1 度も出てこない。
- `tests/test_drawing_intake_schedules.py` の合成ページは**全部「縮尺 1/50」を書いている。**

**なぜ気づかれなかったか。** 開き戸のほうは `if scale is not None:` で**現に塞いである**。
だから `_read_schedules` を同じ塊の中へ 1 行動かしても、**全件テストは何も言わない。**

**確かめた(壊し試験)。** `_read_schedules` を `if scale is not None:` の中へ移して全件テストを流した。

## この周でやった実装の変更

**テストを 1 件足した。判定のしかた・基準値・階層の条件には触っていない。**

`tests/test_drawing_intake_schedules.py::test_縮尺が読めなくても表は読める`
— 縮尺を書いていないページに建具表と仕上表を描き、**縮尺が `None` であることを確かめたうえで**、
それでも両方の表が読めることを固定する。

基準の「この周で変えないもの」には「実装には手を入れない」と書いた。
**測定の 3 通り(V0/V1/V2)はベンチマークの中だけで、そこは守っている。**
テストの追加は測定のあとの別の行為で、**振る舞いを 1 つも変えない**(足す前も後も同じ結果)。

全件テスト: **978 passed, 1 skipped**(足す前は 977 passed, 1 skipped)。

## 片側しか言えないこと

**言えること**

- この図面では、表を縮尺より前に読んでも**出力が 1 件も変わらない。**
- 表を縮尺に依存させると、**この図面で読めている仕上表 59 行が全部消える。**
- **既存の 977 件はその壊し方を 1 件も検出しなかった**(実測)。

**言えないこと**

- ほかの図面でも V0 と V1 が同じだとは言っていない(**1 件の図面で測った**)。
- 建具表が 0 なのはこの周の話ではない(36〜43 周目の別件。W1 が 3 通りとも 0 なのは
  **順番のせいではなく、もともと 0 だから**)。
- **59 行が正しい**とは言っていない。読めた行の数であって、正解との照合ではない。

## 次の周

**「コメントに書いてあるが、テストが無い前提」がほかにもあるのではないか。**

45 周目で見つけたのは 1 件だが、**見つけ方は 1 回きりの思いつきではない。**
「コードが自分で宣言している前提」を集め、**それぞれを壊して全件テストが気づくか**を数える。
気づかない件数が、**いま守られていない前提の数**になる。

判定: **壊して全件テストが落ちない前提が 3 件以上**なら、前提を固定するテストを足す周に進む。
**2 件以下**なら 45 周目は単発として、トライアル C の本体(段取り待ち)へ戻る。
