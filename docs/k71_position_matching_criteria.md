### 1-1 対応づけを使う組(a)

- K-70 作業 3 の「組」(数量は鍵そのもの、状態・室・部位は粗い鍵)のうち、**どれかの回に組の行が 2 行以上ある組だけ**に使う
  (前の周で「回の中で対応が 1 つに決まらない」になった組)。
- 回ごとに組の行が 1 行以下の組は、前の周と同じ(鍵で 1 対 1 に決まっている)。そのカードの行どうしが位置でも
  重なっているかは、参考として数だけ出す(線にしない)。

### 1-2 重なりの線(測る前に固定)

- **同じページ**の行どうしだけを比べる(`ページ` が違えば重ならないとみなす)。
- **重なり率 = 面積の重なり率(IoU)**= 重なった面積 ÷ 2 つの箱を合わせた面積。箱は `囲み`(幅 2000 画素の画像の座標)。
  同じページなら回が違っても同じ座標なので、PDF の点に戻さずに比べる。ひっくり返った四角(x0 > x1 など)は直してから比べる。
- **重なり率 0.50 以上**を「重なる」とする(しきい 0.50)。
- 箱が無い・ページが無い行は、どの行とも重ならない。

### 1-3 1 対 1 にするやり方

1. 基準の回(R1)と R2、R1 と R3 を、それぞれ組ごとに対応づける。候補 = 同じページで重なり率 0.50 以上の行の対。
2. 候補を重なり率の大きい順に取る(**貪欲**)。取った対の 2 行は、もう使わない。
3. **同点のとき**: 重なり率が同じ(差 1e-9 以下)で、まだ使っていない行を共有する候補が 2 つ以上あれば、
   `要素`(読みの部品の id)の重なり(共通 ÷ 和)の大きい方を取る。それも同じなら、**その同点に入った行は対応づけない**
   (`同点で決まらない` として残す。どちらかに寄せない)。
4. R1 に対応の無かった R2 の行と R3 の行は、R2 と R3 の間で同じやり方で対応づける。
5. 鎖 = R1 の行と、それに対応した R2・R3 の行(星形。R2 と R3 の行どうしの重なりは見ない)。または R2 と R3 の対。
   **鎖は回ごとに 1 行まで。**鎖が 2 回以上にまたがるときだけ、カードの候補にする。

### 1-4 鎖からカードを作る・できなかった理由(c)

鎖ごとに、K-70 作業 3 と同じやり方で選択肢を作る(3 回の値・機械の値・縮尺の値 +「どれでもない」「分からない」。
未取得を値にしない。室は K-66 の室の鍵でまとめる)。カードの鍵は名前を含まない記号(組の鍵と鎖の行 id のハッシュ)。

割れた鍵(組の `割れた鍵たち`。数量は鍵そのもの)は、1 つずつ次のどれか 1 つに入れる(上から順に見る):

| 入れ先 | 中身 |
|---|---|
| カードにした | その鍵の行を含む鎖が、カードになった(単位の同値で外したものを除く) |
| 単位の同値で外した | その鍵の行を含む鎖のカードが、1-5 で外れた |
| できなかった: 値が 1 つしか無い | その鍵の行が 2 回以上の鎖に入ったが、値が 1 つしか残らない |
| できなかった: 切り抜きが無い | 同じく、切り抜きが無い |
| できなかった: 同点で決まらない | その鍵の行が、1-3 の 3 の同点に入って対応づけなかった |
| できなかった: 位置の重なる行がほかの回に無い | その鍵の行が、どの回の行とも重ならなかった(重なり率 0.50 未満・別のページ) |

(1 つの鍵の行が 2 つ以上の鎖に入れば、上の表の上のものを書く。)
回の中で 1 行以下の組(1-1)は、前の周の理由(値が 1 つしか無い・切り抜きが無い)をそのまま使う。
**件数は鍵と組(カード)の両方で書く。** 前の周の 476 / 36 / 356 と並べる。

### 1-5 単位の同値でカードを外す(d)

- 数量のカードで、**実の値(どれでもない・分からないを除く)を `sameness.quantity.new_unit` の単位と数で揃えると 1 つになる**
  カードは外す(数が同じで単位だけ違う。例「1 個」と「1 台」)。外した数を数える。
- 揃えても 2 つ以上残るカードは残す。揃えると同じになる選択肢は **先に出た書き方 1 つにまとめる**(室の書き方と同じ扱い)。
- **式・本・組・セット**は `new_unit` で個と同じにならないので、**式が絡むカードは残る**(式を足し引きしない)。
- 数が違えば外さない(数の許容は使わない。「数が同じ」= 数が等しい)。
- 外したカードは、前の周の並べ方の数え方(1 つの答えで確定する・値が決まる行の数)でも数えない。

### 1-6 並べ方・答えの口・戻し方

K-70 作業 3 と同じ(1 つの答えで確定する → 値が決まる行の数 → 鍵。枠は `frame_of`。答えは「1-3、2-1 …」。
「どれでもない」「分からない」は何も決めない。自動確定は機械の検算の入口で数える)。

## 2 囮(b)(作り方は測る前に決める)

実案件の 3 回の行を写し、**1 つの回(R2、次に R3)の行の箱だけ**を動かして、1-3 をやり直す。
**数えるもの = 動かす前に鎖に入っていた行(1-1 の組の行)のうち、動かした後も、ほかの回のどれかの行と対応づいた行。**
動かした行には本当の位置が無いので、対応づいたら全部「誤って対応づけた」と数える(重なった先がたまたま同じ組の別の行でも誤り)。

- **囮 1 ずらす**: その回の **全部の行** の箱を、右へ 300 画素・下へ 300 画素動かす(幅 2000 画素の画像の座標。
  紙の外に出ても切らない)。ページは変えない。
- **囮 2 別の室へ移す**: その回の、動かす前に鎖に入っていた行それぞれについて、**同じ回・同じページの行のうち、
  K-66 の室の鍵(`sameness.rows.row_room`)が違い(室が取れていない行は使わない)、元の箱との重なり率が 0.50 未満の行**を
  id の順に見て、最初の行の箱を写す。当てはまる行が無ければ `移せなかった` として数え、分母から外す。
  全部の行を同時に動かす。
- 誤って対応づけた割合 = 誤って対応づけた行 ÷ 動かした行(R2 と R3 の和)。和を並べる。
