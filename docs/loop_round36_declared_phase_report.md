## 0. **先に断る**

**渡した位相の値はこちらが機械的に振ったもの**(奇数ページ=現況、偶数ページ=計画)で、
**意味は無い。おーちゃんが決めた値でもない。**

## 1. **いちばん重いこと — 種類を宣言すると読み取りが止まる**

基準の 4 節で、こちらは種類を `その他` にした。理由も書いてある——
「**位相だけを見たいので、種類は当たり障りのないものにする**」。

**当たり障りのないものではなかった。**

| | 宣言を渡さない | **`その他` と宣言した** |
| --- | ---: | ---: |
| 数量の件数 | **2,887** | **166** |

**94.3% が消えた。** 対照(線2)の不通過である。

原因はコードを読んで確かめた(推測ではない)。**関門は 2 か所ある。**

- `intake/drawing_intake.py:2024` … `kind is not None and kind not in REPEATED_SYMBOL_PAGE_KINDS`
  (`= ("平面図","設備図")`)なら、**その場で返して繰り返す記号を探さない。**
- `intake/drawing_intake.py:1954` … `kind is not None and kind not in ROOM_OUTLINE_PAGE_KINDS`
  (`= ("平面図",)`)なら、**その場で返して室の輪郭を探さない。**

**種類を宣言しなければ関門は無い**(`kind is None` は素通り)。
**宣言した瞬間に、その種類に割り当てられていない読み取りが止まる。**
`その他` はどちらにも入っていないので、**どちらも止まる。**

### **訂正 — 開き戸の円弧は止まらない**

**追記1 の基準に「開き戸の円弧も止まる」と書いたが、誤りである。**
`:1826` の `DOOR_ARC_EXPECTED_PAGE_KINDS` は**探すかどうかを決めていない。**
コード自身が注記で書いている——「**宣言は読み取りの範囲を決めない**」
「**宣言を理由に捨てていない**」。食い違ったページでは、円弧は読んだうえで
`derivation` を `read` から `assumed` に落とし、`PendingDecision` を立てて人へ回す。
**消えるのではなく、格が下がって人に回る。**

**この訂正は、追記1 の基準を書いた 20 分後に、同じファイルを行まで読んで気づいた。**
**`:1826` という行番号まで挙げておきながら、その行が何をするかを読んでいなかった。**
**4 節の失敗と同じ型を、同じ周で 2 回踏んだ。**

### **これは製品の危険である**

**人が正直に「このページは何の図か分かりません」と答えると、数量が黙って 94% 消える。**
**画面には「読めませんでした」とは出ない。件数が減るだけである。**
**親切に答えようとした人ほど損をする形になっている。**

**直していない**(取り決め②「修正は再現する失敗テストを先に書いてから」)。
**おーちゃんの判断待ちに載せる。**

## 3. **線1 の 0.988 は信じてはいけない**

**分母が壊れている。** 0.988 は **164 / 166**、つまり**関門を生き延びた 166 件の中の割合**である。

**入口の 2,887 件で数え直すと 164 / 2,887 = 0.0568。**

位相の内訳を並べると、何が起きたかが分かる。

| | 位相が決まっている | `不明` | **位相の器そのものが無い** | 合計 |
| --- | ---: | ---: | ---: | ---: |
| 渡す前 | 0 | **164** | **2,723** | 2,887 |
| 渡した後 | **164** | 0 | 2 | 166 |

**宣言は、位相の器を 1 つも増やしていない。**
渡す前から器を持っていた 164 件の中身が `不明` から値に変わっただけである。
**器の無い 2,723 件には、人が何を入れても届かない**
(`QuantityItem.meaning` が `None` の行。位相は `meaning` の中の欄なので、
`meaning` が無ければ入れる場所が無い)。

そして**関門が消したのは、ほぼそのまま器の無い行だった**(2,723 → 2)。
**だから 0.988 という高い割合は、線2 が落ちたおかげで出た数字である。**

## 4. **自分の線の設計の失敗(新しい型)**

これまでに記録した型に、**7 つ目**が加わる。

| 周 | 型 |
| --- | --- |
| 周13・周14 | 落ちようのない線 |
| 周22 | 効きようのない囮 |
| 周25 | 厳しすぎる線 |
| 周31 | 母数より大きい選び方 |
| 周33 | 作りから保証されている見立て |
| 周34 | 個数を合わせた囮は周をまたげない |
| **周36** | **対照に選んだ値が、対照になっていなかった** |

**「当たり障りのない値」を選ぶときは、その値が何をするかを読む。**
`PAGE_KINDS` の一覧は読んでいた。**一覧を読んで、それぞれが何をするかを読んでいなかった。**
取り決め①(記録を信じずコードを読む)は守ったつもりでいたが、**読んだのは名前だけだった。**

**そして同じ型を、同じ周で 2 回踏んだ**(1 節の訂正)。
1 回目は定数の名前だけを読んだ。2 回目は**行番号まで挙げておきながら、その行を読まなかった。**
**行番号を書くときは、その行を開く。**
