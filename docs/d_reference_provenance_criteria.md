# 54周目 基準: **正解データはどちらのファイルのどのページで作られたのか**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。53 周目の「次の周」に書いたとおり。

## なぜこの題なのか

**52 周目も 53 周目も、対照が働いて結論を止めた。**

| 周 | 紙の決め方 | 止まった理由 |
|---|---|---|
| 52 | ページ番号(参照データの「8 ページ目」) | 匿名化 v2 の 8 ページ目に図面番号の文字が無い |
| 53 | 室名の一致数 | 目次のページが 1 位に並ぶ |

**2 周続けて止まったのは、測り方が下手だったからではない。**
**参照データがどのファイルのものか、記録に書かれていないからである。**

`benchmarks/real_drawing_fixtures.py` の説明書きは
「**`設計図面_匿名化済み.pdf` の 8 ページ目**」としか書いていない。
**その名前で呼べるファイルは 2 つある。**

- **古いほう**(18MB・A0 相当・34 ページ・**文字データ 0**)
- **匿名化 v2**(27MB・A3・34 ページ・30 ページに文字)

**どちらの 8 ページ目なのかが書かれていない。**

## 測り方(**目で見ない。形だけで決める**)

参照データの箱(`HINGED_DOOR_ARCS` の 5 件)は
**「切り出したあとの画像における (x1, y1, x2, y2)」** と書いてある。
**画素の座標である。**

**切り出し画像の大きさは、紙の寸法と解像度と切り出し割合だけで決まる。**

```
切り出し幅(画素) = ページ幅(pt) / 72 * PLAN_DPI * (PLAN_CROP の x 幅)
切り出し高(画素) = ページ高(pt) / 72 * PLAN_DPI * (PLAN_CROP の y 幅)
```

**箱が切り出し画像の外にはみ出すページでは、その参照データは作れない。**
**これは目視の当たり外れではなく、入るか入らないかの話である。**

## 測るもの

| 記号 | 何を測るか |
|---|---|
| **Y0** | 2 つのファイルそれぞれのページ数 |
| **Y1** | **5 件の箱が全部収まるページの数**(ファイルごと) |
| **Y2** | 収まるページについて、**5 件の箱をすべて含む最小の矩形の面積 ÷ 切り出し画像の面積** |
| **Y3** | **収まるページの番号**(1 始まり、ファイルごと) |

**Y2 は記録だけに使う。Y2 だけで特定しない**(取り決め③)。

**出すのはページ数・画素数・件数・比・真偽だけ。図面の中身は 1 文字も出さない。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **片方のファイルだけ Y1 ≧ 1、もう片方が Y1 = 0**
  → **参照データはそのファイルのものである。**
  - さらに**収まるページが 1 つだけ**なら → **ページまで特定できた。**
  - **複数**なら → **ファイルは決まったがページは決まらない。**
    そのファイルの中で**どのページか**をおーちゃんに聞く。
- **両方のファイルで Y1 ≧ 1** → **画素の大きさでは決まらない。**
  **Y2 で決めない。**おーちゃんに聞く。
- **両方とも Y1 = 0** → **参照データはどちらのファイルとも形が合わない。**
  記録はもっと壊れている。**おーちゃんに聞く。**

**「古いほうだ」と決まった場合に、そこから言えること(先に書いておく)**

- **匿名化 v2 に対して、箱の座標をそのまま突き合わせることはできない。**
  紙の寸法が違えば画素の座標は意味が変わる。
- **52・53 周目が探していた「v2 のどの紙か」という問いは、そもそも答えが無かった。**
- **51 周目の結論は変えない。** 51 周目は箱の座標を使っていない。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 2 つのファイルのページ数 | **どちらも 8 ページ以上**(「8 ページ目」が成り立つこと) |
| **2(判定が「いいえ」を言えるか)** | 2 つのファイルの全ページのうち、**収まらないページ** | **1 ページ以上ある。**全ページが収まるなら判定は何も切り分けていないので**結論を出さない** |
| **3** | 反復 3 回(Y1) | 3 回とも同じ |
| **4** | 箱そのものの健全さ | 5 件とも**幅も高さも 0 より大きい** |

**対照1・2・4 が通らなければ結論を出さない。**

## この周で変えないもの

- **製品コードは 1 行も変えない。**
- **ページをラスター化しない。**紙の寸法から画素数を計算するだけなので、
  **図面の絵も文字も一切読まない。**
- 参照データは**採点にだけ**使う。
- **室の名前も図面の文字も座標も、報告書にも記憶にも書かない。**
