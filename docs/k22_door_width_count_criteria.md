# 内部の新設建具の幅に `W` が付かないかを、実際の平面図で数えるときの数え方

作成日: 2026年9月24日。**数える前にコミットする。**

PR #131 で「**内部の新設建具だけ、幅に `W` が付かない**」と書いたが、**それは凡例の絵から
読んだものであって、実際の平面図では数えていない。**ここで数える。

## 何を数えるか

1. 図面の全ページから、**`H` + 3〜4 桁の数**の形の語を拾う(建具の高さの書き方)。
   これを**建具の寸法の組の目印**にする。
2. その語の**すぐ上**(同じ x のあたり、上に 40pt 以内)にある語を見て、次のどれかに分ける。
   - **`W` + 数** … 幅に `W` が付いている
   - **数字だけ**(3〜4 桁) … 幅に `W` が付いていない
   - **どちらでもない** … 幅らしい語が無い
3. さらに、その組の**近く**(120pt 以内)に**赤い文字**があるかを見る。
   凡例は建具番号を**赤い丸の中**に書くと決めているので、**赤い文字があるものを
   「新設の建具らしい組」**、無いものを「既存の建具らしい組」として分けて数える。

## 先に書いておく注意

- **「らしい」までしか言えない。**赤い文字が近くにあることは建具番号があることと同じでは
  ないし、`H` + 数が建具の高さでないこともある。**数えるのは「どちらの書き方が
  どれだけあるか」であって、建具の本数ではない。**
- **図面の数値そのものは、報告にもリポジトリにも書かない。**件数だけを書く。
- **表題欄は外す**(紙の高さの 88% より下、表示の向き)。
  → `docs/provisional_decisions.md` の同項目。

## 結果の読み方(**先に決める**)

| 赤い文字が近くにある組のうち、幅に `W` が付かないものの割合 | 書くこと |
|---|---|
| **半分より多い** | PR #131 の言い分は図面でも当たっている |
| **半分以下だが 1 件以上** | **言い過ぎだった。**「内部の新設建具は」ではなく「一部の建具は」と書き直す |
| **0 件** | **PR #131 の言い分は図面では確かめられない。**凡例の絵にしか無い書き方だったと書く |

**どの結果でも、凡例の絵から読んだこと自体は消さない。**凡例が宣言していることと、
図面が実際にしていることは別で、**その食い違い自体が記録に値する**(天井高で 1 件出ている)。
