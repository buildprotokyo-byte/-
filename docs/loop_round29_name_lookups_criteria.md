## 線(3 本)

### 線1 — 引き当て側の名前で、作る側に無いものは何件か

**`FINISH_PART_QUANTITY` が持つ数量の種類**と、
**`estimating/from_room_dimensions.py` が作る種類**を突き合わせる。

**予想を先に書く**: **1 件(巾木の `周長`)だけ。**
**当たっていたら「当たっていた」と書く。**

- **予想どおり**: 1 件
- **予想が外れた**: 0 件、または 2 件以上

### 線2 — 部位の名前は取りこぼしていないか

**実図面を一本通した出力で、
「この部位の数量の作り方をまだ持っていない」と書かれた行**を数える。
**これは `FINISH_PART_QUANTITY` に部位の名前が無かった行である。**

**予想を先に書く**: **0 行。**

- **予想どおり**: 0 行
- **予想が外れた**: 1 行以上(**取りこぼしている部位がある**)

### 線3 — 室の名前は、書き方が違っても引き当たるか

**合成の室の名前で確かめる。**`app.py` は `_nfkc()` を通してから引いている。

| 書き方 | 予想 |
|---|---|
| 全角と半角の違い(`洋室1` と `洋室１`) | **引き当たる**(`_nfkc` が吸収する) |
| 前後の空白(`洋室1 `) | **引き当たる**(`_nfkc` のあと `strip` があるかで決まる) |
| 中の空白(`洋 室1`) | **引き当たらない** |

- **予想どおり**: 3 つとも上の表のとおり
- **予想が外れた**: 1 つでも違う

**この線は、実図面ではなく合成の名前で測る。**
**実案件の室名を試験にも報告にも書かないためである(K-33)。**

**囮を置かない理由**: これは**名前どうしの突き合わせ**であって、
位置や当たりを当てる測定ではない。**でたらめな名前を引くことに意味が無い。**
