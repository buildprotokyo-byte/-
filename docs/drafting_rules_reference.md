# 図面を読むための製図の決まり(自動化のポイント)

出典: JIS A 0150:1999 建築製図通則、JIS Z 8311(用紙と様式)、JIS Z 8312(線)、JIS Z 8317(寸法)
確認日: 2026-09-24

---

## 0. 前提

図面は絵ではなく、**決まりに従って書かれた文書**である。
決まりを知らずに見れば線の集まりにしか見えない。
だから画像処理・文字処理を汎用のまま当ててはいけない。

以下は「プログラムに入れられる形」に絞って抽出したもの。

---

## 1. ページの構造(いちばん最初に見るもの)

図面の1枚は次でできている(JIS Z 8311)。

- **輪郭線(外枠)** — 用紙の縁の内側に引かれた枠。**図ではない**
- **表題欄** — 通常は右下。図面名称・図面番号・縮尺・改訂日が入る。**図ではない**
- **中心マーク** — 用紙の各辺の中央
- **図の領域** — 外枠と表題欄を除いた残り

### 自動化のポイント

- **ページで一番大きい矩形は、必ず外枠である。** 表ではない
- **表題欄は右下にある。** その中の罫線は表の罫線ではない
- **図はこの2つの外側には存在しない**
- 順番は「表を探す」ではなく、**まずページの構造を決める** → 外枠・表題欄・図・表の領域に分ける → それぞれを読みに行く

---

## 2. 線の太さが意味を持つ(これが最重要)

JIS A 0150 13.2.3、13.2.5。

- 細線:太線:極太線 = **1:2:4**
- **断面の外形線は、見える部分の外形線より太い**
- 断面部分 = 太い実線 または 極太実線
- 見える部分の外形線 = 太い実線 または 細い実線
- 1つの図には 2〜3種類の太さしか使わない(13.2.4)

### なぜ効くか

**平面図は、床から1〜1.5m の高さで水平に切った断面である。**

| 描かれるもの | 切られているか | 線の太さ |
|---|---|---|
| 壁 | 切られている | **太い** |
| 柱 | 切られている | **太い** |
| 建具(枠) | 切られている | **太い** |
| 家具・設備・器具 | 切られていない(見えがかり) | 細い |
| 階段・斜路 | 見えがかり | **細い**(13.2.9.1、13.2.10.1) |
| 傾斜した床・屋根 | 見えがかり | **細い**(13.2.8) |
| 寸法線・寸法補助線・引出線 | 補助 | 細い |

### 自動化のポイント

- **部屋の輪郭を取るときは、太い線だけを見る。** 細い線は家具か補助線
- **いまの台帳は線の太さを記録していない。** 向きと長さだけ。ここを足す
- 太さは相対値で判定する(そのページで使われている太さを集めて、1:2:4 の比に当てはめる)
- 12周かけて部屋の輪郭が取れなかった原因は、ここかもしれない

## 3. 基準線(通り芯)の見つけ方

JIS A 0150 10.1、10.2。

- **基準線は通常は実線。はっきりさせる箇所では一点鎖線**
- 太さは細線・太線・極太線の順に選ぶ
- **端部に、細線でかいた円を付ける**(片側または両側)
- **円の中に基準記号(アルファベットまたは数字)を書く**

### 自動化のポイント

- **円+文字1〜2字の組を、図の外周部で探す。** それが通り芯の端部
- 見つかれば、そこから伸びる線が通り芯
- **通り芯の間の寸法が、外周に並んでいる**
- おーちゃんの説明と一致する:「外周部に基準線を持って、ここからここまでという寸法が出ている。それを平行移動・垂直移動すれば部屋の範囲が決まる」

---

## 4. 壁の識別(材料構造表示記号)

JIS A 0150 付表2、備考「壁体は、構造種別によって付表2に示す材料構造表示記号を用いる」。

壁の断面には、構造種別に応じたハッチング(網掛け)が入る。

- 壁一般
- コンクリート及び鉄筋コンクリート
- 軽量壁一般
- 普通ブロック壁 / 軽量ブロック壁
- 鉄骨
- 木材及び木造壁

縮尺で描き分けが変わる(1:100・1:200 / 1:20・1:50 / 現寸・1:2・1:5)。

### 自動化のポイント

- **太い線に挟まれてハッチングがある → 壁**
- ハッチングの模様で構造種別が分かる
- 13.2.7: 異なる材料の境界には太い実線または細い実線
- 大理石・寄せ木床のパターンは通常表示しない

---

## 5. 開口・穴・くぼみ・吊り天井

JIS A 0150 13.4。

| 表現 | 意味 |
|---|---|
| **細い実線の対角線2本** | 開口・穴 |
| **細い実線の対角線1本** | くぼみ |
| **二点細鎖線の対角線** | 吊り天井(下がり天井)。下面の高さか天井高を数値で表示 |
| 二点細鎖線の外形線 | 吊り天井で壁から離れている部分 |

対角線は、意味が背景から明らかな場合は省略できる。

### 自動化のポイント

- **吊り天井の表示があれば、そこに天井高が書かれている**
- 天井高が取れない問題に直接効く
- 開口の対角線は、壁の切れ目を確かめる手がかりになる

---

## 6. 建具の表現

JIS A 0150 13.3、付表1。

- 戸・窓は太い実線または細い実線
- **開き戸は、円弧を伴わない30°の扉、または円弧を伴う90°の扉**
- **縮尺1:50以上の図では、種類・開き勝手・敷居まで描く**
- **小さい縮尺では、平面表示記号(付表1)で代用する**

付表1の平面表示記号: 出入口一般 / 両開きとびら / 引違い戸 / シャッター /
片開き窓 / 引違い窓 / はめごろし窓 / 回転窓 / すべりだし窓 / 突出し窓 / 上げ下げ窓

### 自動化のポイント

- **13.6.2: 平面表示記号は、原則として縮尺1:100、1:200 の図面に用いる**
- **つまり、縮尺で読み方を切り替える必要がある**
  - 1:100・1:200 → 記号として読む
  - 1:50 以上 → 実形として読む
- 13.6.3: 表示記号にないものは、尺度に応じ実形を描いて説明を記入する
- 13.6.4: 類似の記号に説明を記入して代用することがある
  → **凡例に無い記号が出るのは、この決まりのため**

## 7. 文字と線の関係

JIS A 0150 12.4。

- 文字は図の下部、または右側、または関係する部分に隣接して書く
- **寸法線・引出線に関する文字は、その線と平行に、線の上部約1mm あけて書く**
- 一つの図に関するタイトルは、図の下に左側を合わせて配置
- 一連の図に共通なタイトルは、一連の図の左上

引出線の終端で意味が変わる(12.4)。

| 終端 | 意味 |
|---|---|
| **黒丸** | 輪郭線の間で終わる(面を指している) |
| **矢印** | 輪郭線の上で終わる(線を指している) |
| **斜め線** | 配管類を一連の近接したパイプ群として表現 |

### 自動化のポイント

- **文字がどの線に属するかは、位置関係で決まる**(平行、上部1mm)
- 引出線の終端の形で、指している対象の種類が分かる
- 文字をページ全体から拾って座標だけで扱ってはいけない

---

## 8. 図面どうしの参照

JIS A 0150 12.2。

- 断面・切断面・詳細には記号を付ける(大文字・数字・小文字)
- **図面番号で補う。例: 図面番号24のB-B断面図 → 「B-B/24」、図面番号45の断面図2 → 「2/45」**
- 詳細の位置は細線の円で示す(12.1)
- 切断位置を示す線と、見る方向の矢印

### 自動化のポイント

- **「B-B/24」の形の文字列を見つければ、ページ間の参照が辿れる**
- 細線の円 = 詳細図がある場所
- 平面図で分からないことは、参照先のページに書いてある

---

## 9. 図の配置

JIS A 0150 12.3。

- 図は名称の順番に配置する
- 同一物件における平面図は、なるべく同じ方向で配置する
- 主たる平面と、水平方向の断面図・切断図は、なるべく同じ方向
- 垂直方向の断面図は、なるべく正立方向に書く

### 自動化のポイント

- **平面図は全ページで向きが揃っている**はず
- 揃っていなければ、それ自体が確認事項

---

## 10. 簡素化の決まり

JIS A 0150 13.1。

- **他の資料(部材一般図・詳細図・詳細仕様書)で詳細に明示されているものは、
  総配置図・組立図では簡易な方法で表示してよい**
- 簡素化の程度は、表現された物の種類、図の縮尺、資料作成の目的で決まる
- 簡素化された表現では、不可欠な特徴だけ、可能なら外形だけを表示する
- 形態は、図記号・名称・文字によって完成させることができる

### 自動化のポイント

- **平面図に描かれていないことは、別の図に書かれている**
- 「図面に無い」は「存在しない」ではない。**参照先を探す**
- これは波及の判定にも効く

---

## 11. 優先して入れるべきもの(順番)

1. **ページの構造を先に決める**(外枠・表題欄・図・表) — いま外枠を表と誤認している
2. **線の太さを台帳に記録する** — 壁と家具を分ける唯一の手がかり
3. **基準線(通り芯)の端部を探す** — 円+記号。寸法の骨格
4. **縮尺で読み方を切り替える** — 1:100/1:200 は記号、1:50以上は実形
5. 壁のハッチングを識別する
6. 吊り天井の表示から天井高を取る
7. 引出線の終端で、指している対象を判定する
8. 図面番号の参照(B-B/24)を辿る

---

## 12. 注意

- **JIS A 0150 は強制力が無い。** 官公庁案件・大手設計事務所ではほぼ準拠が前提だが、
  住宅・小規模物件では事務所ごとの癖が JIS とずれることがある
- したがって **「JIS どおりであること」を前提に固定してはいけない**
- **JIS を既定値として使い、その案件の凡例が違うことを言っていればそちらを優先する**
- P011 の凡例が「改装種別凡例」を持っていたのは、まさにこの形
