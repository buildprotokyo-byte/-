# 65周目の報告: **知識の表の形式を確定した(候補 25 項目のうち 23 が入った)**

基準は `docs/d_knowledge_format_criteria.md`(**測る前にコミット済み**)。
形式は `docs/knowledge/format.md`、読み込みは `knowledge/table.py`、
測り方は `benchmarks/measure_knowledge_format_coverage.py`。

## 1. 数字(**この周の数字は 1 つ**)

**`docs/knowledge/candidates.md` の A・A′・B′・B・C の全 25 項目のうち、
新しい列を足さずに表せたのは 23 項目。**

**先に引いた線は 20(8 割)なので、この形式で確定する。**

書き直した行は 26 行(1 項目だけ 2 行に分けた)。種類ごとの内訳は
**数え方 15 行・波及 5 行・問い 6 行**。

## 2. **表せなかった 2 項目(名指しする)**

### Bd-3(天井を撤去しても壁は既存のまま)

**「波及しない」ことを書く欄が無い。** 波及の欄は
「何が起きたら / どこへ / どれだけ」なので、**波及しないという知識は、
どれだけの欄に文字で逃がすしかない。** 影響先の欄も空にせざるを得ない。

**これは軽くない。** Bd-1(壁の撤去は天井へ波及する)の**逆向きは自動では
起きない**という非対称は、**書けないと「両方向に波及する」と読まれる。**

### B-2(新設仕上の数量は新築の第5編をそのまま使う)

**これは数え方ではなく「別の規則集をそのまま使え」という指示である。**
数え方の欄に文章で押し込んだ。**知識どうしの参照を書く形が無い。**

## 4. 決めた形(要点だけ。詳しくは `docs/knowledge/format.md`)

- **出どころ(文書・条項・直接読んだか)は必須。** 空なら読み込みが失敗する。
- **`overridden_by` に「特記」を書ける。** 公共基準の多くは「特記がなければ」の
  既定値なので、これが無いと図面の明示を既定値で上書きしてしまう。
- **`scope` と `needs_human_check`。** 公共工事の基準は住宅の改修にそのまま
  当てはまるとは限らない。**そのまま使ってよいかを人に確かめる印を、行が持つ。**
- **答えが 1 つしかない問いは書けない**(読み込みが断る)。
- **知らない列・知らない種類・版違いは断る。** 半分だけ効いた表を作らないため。
