# 52周目 基準: **ベクターの円弧は、正解のあるページで何件拾っているのか**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。

## なぜこの題なのか

51 周目で「**読めた 7 件は、人が確かめに行ける材料がそろっている**」と結論した。
**そのとき自分でこう書いた。**

> **言えないこと**: **値が正しいかは測っていない。**
> そろっているのは**確かめるための材料**であって、**正しさではない。**

**そこを測る。** そして**測れることが分かっている。**
リポジトリに**人手で確定した参照データ**がある(`benchmarks/real_drawing_fixtures.py`)。
改装平面図 1 ページを目視で数え上げた**開き戸の円弧 5 件**である。

**だが、この参照データはラスターのテンプレート照合の時代に作られたもので、
いま本番で動いているベクターの円弧の経路とは、一度も突き合わせていない。**
(`docs/real_drawing_eval_report.md` の「正解 5 件に対して的中 0 件」は
**ラスターの話**であって、いまの経路の話ではない。)

**35 周目に、ベクターの経路は 34 ページで 90 件拾っている。** 正解が 5 件のページを含む。
**90 と 5 の差が何を意味するかは、まだ誰も測っていない。**

## 座標は使わない(**測り方を小さくする理由**)

参照データの箱は**別のファイルをラスター化した画像の画素**で書かれている。
**いま測る匿名化 v2 とは紙の大きさが違う**ので、座標を合わせるには
2 つのファイルの寸法を突き合わせる必要がある。**今回はそこまでしない。**

**件数だけで決着がつくからである。** 正解のページに開き戸が 5 件しかないと
人が確認したのなら、**そのページで何件拾っているか**を数えれば、
**人が正解 1 件につき何件を見ることになるか**が出る。

## 測るもの

| 記号 | 何を測るか |
|---|---|
| **U1** | **正解のあるページ**(参照データの `PLAN_PAGE_INDEX`)でベクターの経路が拾った件数 |
| **U2** | 正解の件数(参照データの `HINGED_DOOR_ARCS` の数) |
| **U3** | **U1 ÷ U2**(人が正解 1 件につき見ることになる数) |
| **U4** | 34 ページ全体で拾った件数 |

**出すのは件数と比だけ。図面に印字された文字も、室の名前も、座標も出さない。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **U3 ≦ 2** → **人がさばける量である。**
  51 周目の「人が見る材料として成立している」は**そのまま保たれる。**
- **U3 > 2** → **人は正解 1 件につき U3 件を見ることになる。**
  **51 周目の結論に但し書きが要る**ので、報告書とまとめの文書に足す
  (**設計の記録。判定のしかたは変えない**)。
- **U1 = 0** → **正解のあるページで 1 件も拾えていない。**
  そのときは**なぜ 0 なのか**(縮尺が読めないページかどうか)を名指しする。

**U3 を「精度」とは呼ばない。** 正解と 1 件ずつ突き合わせたわけではなく、
**数を比べただけ**だからである。**言えるのは「人が見る量」だけである。**

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1(同じ図面か)** | 匿名化 v2 の該当ページに、参照データが指す図面番号と図面名の**両方の文字があるか** | **両方ある。**(**真偽だけ出す。文字は出さない。**)無ければ**別の紙なので結論を出さない** |
| **2** | 34 ページ全体の件数 | **35 周目と同じ 90 件** |
| **3** | 反復 3 回(U1) | 3 回とも同じ |

**対照1・2 が通らなければ結論を出さない。**

## この周で変えないもの

- **製品コードは 1 行も変えない。** 反実仮想も使わない。
- 判定のしかた・基準値・階層の条件にも触らない。
- **参照データは採点にだけ使う。** 抽出の経路には渡さない(取り決めのとおり)。
- **参照データに書かれている室の名前は、報告書にも記憶にも書かない。**
