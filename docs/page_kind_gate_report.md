## 1. 何が起きていたか(コードで確かめたこと)

- 本番の入口 `read_drawing()` → `_extract()` → ページごとに
  `_room_outline_findings()` と `_collect_symbols()` を呼ぶ。この 2 つの中で、
  - 人が「平面図」**以外**と宣言したページでは `find_room_outlines()` を呼ばなかった
  - 人が「平面図」「設備図」**以外**と宣言したページでは `find_repeated_symbols()` を
    呼ばなかった(「凡例」と宣言したページも呼ばなかった)
- **宣言が無いページは、直す前から全部探していた。** 止まっていたのは
  「宣言があって、その種類が並びの外」のページだけ。
- 由来: A-1(繰り返す記号、`1b66b76`)と A-2(室の輪郭、`9b690c7`)は **#37 を
  含まないブランチ**で書かれ、#37 以前の形(宣言で探索を止める並び)のまま
  PR #75 で main に入った。#37 の報告の「この 1 箇所が唯一の関門だった」は、
  #37 の時点では正しかったが、その後に崩れていた。
- 室の輪郭から派生する経路(`room_regions`・`wall_network`)は、本番の入口からは
  **呼ばれていない**(`intake/` から import されていない)。手を入れていない。

## 2. 直したこと

開き戸(#37)と同じ形にそろえた。

1. 宣言があってもなくても、2 つの探索は常に行う。
2. 並びは `ROOM_OUTLINE_EXPECTED_PAGE_KINDS`(平面図)/
   `REPEATED_SYMBOL_EXPECTED_PAGE_KINDS`(平面図・設備図)に改名し、
   **食い違いの判定にだけ**使う。値は変えていない。
3. 並びの外と宣言されたページで室・記号が出たら、値は捨てずに由来を `assumed`
   (見積の行で「仮説に基づく」)にし、`page_kind_disagreement` で人へ回す。
   **同じページの食い違いは 1 件にまとめる**(開き戸・室・記号で 3 回聞かない)。
4. 0 件なら食い違いを立てない。宣言が無い・合っているページは何も変わらない。
5. 「凡例」と宣言したページからしか記号の名前を取らない決まり
   (`LEGEND_PAGE_KINDS`)は**変えていない**。変えたのは「凡例と宣言したら
   記号を数えない」ことだけ。
6. 手法の登録簿(`arbitration/method_policies.py`)は触っていない。
   室の輪郭・繰り返す記号とも `calibrated=False` / 上限 `weak` のまま。

## 5. 途中で間違えたこと・分かったこと

- **負の対照の作り方を 1 回直した。** 最初の「文字だけのページ」は文字しか無く、
  「描画オブジェクトが無いページ」として読み飛ばされて、2 つの探索に**届いて
  いなかった**。直す前のコードで 1 回回して気づき、外枠と表題欄を足した
  (修正より前にコミット、`ceee3c8`)。合否の基準は変えていない。
- **見積の行はこの経路では動かない。** 最初は合成の規則 1 つ
  (`synthetic_standing_rules.json`)で数えたが、そこには室・記号に当たる規則が無かった。
  室・記号の規則(`synthetic_room_rules.json`・`synthetic_symbol_rules.json`)も
  回したが、それらは人が入れた寸法・個数の種類(「床面積」「記号数量」)に当たる
  規則で、図面から読んだ `室::…` `記号::…` には当たらない。**つまり今の main では、
  図面から読んだ室・記号は見積の行に 1 行も届いていない**(直す前も後も 0)。
  この修正で見積の行が変わらないのはそのためで、「安全だと示せた」のではなく
  「まだ届く先が無い」である。
- 「設備図」と宣言した記号の平面図には室の輪郭が無かったので、**設備図のページで
  室が出て人へ質問が飛ぶ場合は、この測定では起きていない**。テスト
  (`test_equipment_page_symbols_agree_but_rooms_are_flagged`)でだけ確かめた。

## 6. 測れていないこと(Codex-A に回すもの)

実図面はこの作業環境では開いていない。次を実図面で測ってほしい。

1. 案件ごとに、宣言が並びの外(展開図・建具表・仕上表・凡例・その他)のページで、

4. 宣言が誤っていたページ(実際は平面図なのに別の種類と宣言)が実案件にあったか。
   あれば、直す前に黙って 0 件になっていた室・記号の数。
5. 1 案件の読み取り時間の増え方。
