## 1. 結論

**基準 4 節の 1 番目の分岐に落ちた。** C1 も C2 も通り、B 組で建具表の数量が
現況と計画に分かれ、意味の4欄が当てはめの層まで届いた。
**したがってマージはしない。** PR のまま置いて判断を待つ(承認の条件②)。

## 2. 対照(結論を出してよいかの確認)

### C1: 宣言が無ければ、対象名も値も 1 件も変わらないこと → **通った**

| | 対象名と値 |
| --- | --- |
| 前 | `専有延床面積` 95.54 / `建具数量::WD-01` 2.0〜5.0 / `施工床面積` 90.61 / `開き戸::ページ1` 2.0 / `開き戸::ページ2` 2.0 |
| 後 | **同じ(完全一致)** |

ページの宣言が無ければ現況も計画も名乗れないので、**分けようがない。**
`建具数量::WD-01` が `(2.0, 5.0)` のレンジのままなのも意図どおりで、
そこは「同じものを 2 回読んで値が違った」という値の幅である。

### C2: 階層 1 が 1 件も増えないこと → **通った**

| | A 組(宣言なし) | B 組(宣言あり) |
| --- | --- | --- |
| 前 | 階層3 が 5 件(階層1 は 0) | 階層3 が 5 件(階層1 は 0) |
| 後 | 階層3 が 5 件(階層1 は 0) | 階層3 が **6 件**(階層1 は 0) |

B 組で 5 → 6 になったのは、**建具表の数量が 1 対象から 2 対象に分かれたから**である。
**新しいデータ源は 1 つも増えていない**ので、階層 1 は 0 件のままである
(`docs/tier1_reachability_summary.md` の結論はそのまま)。

## 3. 変わったこと(B 組・宣言あり)

### 3-1. 建具表の数量が、現況と計画に分かれた

| | 対象名 → 値 |
| --- | --- |
| 前 | `建具数量::WD-01` → **2.0〜5.0**(現況 2 件と計画 5 件が 1 つのレンジ) |
| 後 | `建具数量::WD-01::現況` → 2.0、`建具数量::WD-01::計画` → 5.0 |

**足していない**(7 にはならない)。**選んでもいない**(2 とも 5 とも決めていない)。
分けただけである。

### 3-2. 現況/計画が、対象名から意味の欄へ移った

| | 開き戸の対象名 | 現況/計画の在り処 |
| --- | --- | --- |
| 前 | `開き戸::現況::ページ1` | 対象名の中だけ(`kind` は `::` の手前しか見ないので**規則から見えない**) |
| 後 | `開き戸::ページ1` | `Meaning.phase`(規則も差分の層も読める) |

### 3-3. 意味の4欄が、当てはめの層まで届くようになった

| | 意味が付いた読み | 意味が付いた数量(`QuantityItem`) |
| --- | --- | --- |
| 前 | 0 / 5 | **0 / 5**(入口で付けても写されていなかった) |
| 後 | 4 / 6 | 4 / 6 |

A 組(宣言なし)でも 0 → 3 になる。ただし `phase` は全部 `不明` で、
**`不明` のままの数量には現況/計画の規則は当たらない**ので、判定は動かない。

### 3-4. 現況/計画の内訳が数えられるようになった

| | `Meaning.phase` の内訳 |
| --- | --- |
| 前 | 意味そのものが無い(6 件とも `None`) |
| 後 | `現況` 2 件、`計画` 2 件、意味なし 2 件(埋め込み文字の面積) |

## 4. 変わらなかったもの(意図どおり)

- **埋め込み文字から読んだ面積には、まだ意味が付いていない。** この 2 件は
  `_area_findings` の経路で、今回の対象外である。**「付いていない」を
  `不明` で埋めなかった。** 埋めると「まだ付けていない」が
  「不明と分かっている」に化ける。
- **自動確定は 0 件のまま。** この変更はデータ源を増やさない。
- **差分(工事内容)そのものはまだ作っていない。** この 2 つは差分の層が立つための
  前提であって、差分の精度の話ではない。
