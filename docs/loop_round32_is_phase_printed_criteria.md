# 周32 の基準 — **現況・計画・解体は、紙に印字されているか**

## 1. 前の周との違い(おーちゃんの設計②「1周で変えるのは1つだけ」)

| | 周31 | 周32 |
| --- | --- | --- |
| 技術 | 語を数える + 囮 | **同じ** |
| 出典 | **入口が出した数量 2,887 件** | **紙に印字された文字** |
| 専門 | 積算 | 同じ |

**変えたのは出典ひとつ。** 周31 は「入口が何を出したか」を数えた。周32 は
同じ問いを**紙のほう**に当てる。技術(語の照合と囮)は周15・周16 と同じやり方で、
新しく持ち込むものは無い。

## 2. なぜこの問いか(手段ではなく目的から)

見積は、**撤去する物と新しく付ける物を分けないと書けない。** 同じ「ドア 1 本」でも、
外すのか付けるのかで行が別になる。

周31 で、入口が出した 2,887 件は**どれも現況か計画かが決まっていない**と分かった
(164 件が `不明`、2,723 件は意味そのものが付いていない)。いま規則を書いても、
両者を区別する規則は 1 件にも当たらない。

コードはその理由をこう書いている(`axes/reading/meaning.py`)。

> `phase` … 人がページの種類を宣言していない図面では、そのページが現況か
> 計画かは決まらない。**図面の文字からは決まらない**ので推測しない。

**この断りは、実図面で数えられていない。** K-26 の決まり(宣言している書き方は、
実際の図面で使われているかを数えてから根拠にする)に照らすと、いまは根拠にできない。

数えると、どちらに転んでも次に作るものが変わる。

- **紙に在る** → 読み取りの穴である。読めば決まる。断りのほうが誤り。
- **紙に無い** → 人に聞く口(スタートキットのページ宣言)しか道が無い。
  作るべきは読み手ではなく**用紙**である。

## 3. 測るもの

図面は **P011 の匿名化 v2**(34 ページ、A3、文字データあり)。**v1(18MB・A0)ではない。**
パスは引数で渡す。リポジトリには入れない。

### 探す語

**本物(位相を名指しする語・12 語)**

**囮(建築の語だが、現況か計画かを決めない語・12 語)**

どちらも**私が先に用意した一般の建築語**であって、図面から取り出した語ではない。
語の数は同じ 12 語にそろえる。

## 4. 線(合格・不通過の数字を先に書く)

### 線1 — **在るか**

位相の語が印字されているページ数。

- **合格 = 3 ページ以上、かつ囮の語のページ数を上回る。**
- 不通過なら「紙に無い」。

### 線2 — **囮**

囮の語を同じ数え方で当てる。**本物が囮以下なら線1は不通過。**
囮のページ数も報告に必ず載せる(囮に勝ち目があったかを読む人が見られるように)。

### 線3 — **行き先があるか**

周5 の教訓(天井高は紙に 71 か所あったのに、室に結び付いたのは 1 個)を先に入れる。
**在ることと、数量に結び付くことは別である。**

位相の語が印字されたページに載っている数量の割合を測る。

- 囮A = 囮の語が印字されたページで、同じ割合。
- 囮B = **同じページ数を無作為に引く**(10 回、中央値、seed 20260925)。
- **合格 = 本物の割合 0.10 以上、かつ囮A との差 0.20 以上、かつ囮B との差 0.20 以上。**

**囮B を入れる理由**: 位相の語が 34 ページのほとんどに出ていれば、重なりは
自動的に大きくなる。それは「場所を教えている」ことにならない。囮B は
その場合に必ず勝つので、本物は落ちる。

**周31 で踏んだ誤り(選ぶ数が母集団より大きい)を繰り返さないため**、
本物のページ数が 34 に達した場合、線3 は**測っても意味が無いので不通過**と書く。

### 線4 — **安全確認**

- `app.py` と `intake/` は変更しない(K-29)。
- 自動確定は 0 件のままであること。この測定は読むだけで、判定に触らない。
- **合格 = 本番の判定を 1 か所も変えていないこと。**

## 5. 測らないこと(先に宣言する)

- **紙から取り出した文字は、リポジトリにも報告にも 1 文字も書かない。**
  出すのは件数・割合・ページ番号だけ(周26 と同じ扱い)。
  語ごとの内訳は共有フォルダだけに置く(K-33)。
- どのページが現況でどのページが計画か、という**判定はしない。**
  語が 1 つ出ただけでそのページの位相が決まるわけではない(凡例は全部の語を並べる)。
  測るのは**語が在るか**であって、**ページの位相**ではない。
- 実案件で見積が何行出るか、金額、数量の値、対象名。
- コードは直さない(取り決め②。直すなら先に落ちるテストを書く別の周でやる)。

## 6. この測り方で分からないこと(先に書く)

- **文字が線で描かれた 3 ページは、この数え方では 0 件になる**
  (`jidou-sekisan-maker-drawings-line-text`)。語が在っても数えられない。
- **ページ単位までしか測れない。** 数量の根拠(`provenance`)にはページ番号は
  あるが、座標が全部の種類に付いているわけではない。「同じページ」までで、
  「同じ室の近く」は測れない。
- **語が在ることは、その数量の位相が決まることを意味しない。** 線3 が通っても
  「読めば決まる」ではなく「読める見込みがある」までしか言えない。
