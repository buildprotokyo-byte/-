## 1. 何を聞いたか

現況のまま手を入れない部分の扱い。会社によって
**「記載しない」** と **「確認済みとして記載する」** に分かれる。

| 選択肢 | どうなるか | 回答 |
|---|---|---|
| **規則で決める** | 工事内容としては出し、行にするかは規則ファイルで切り替える | **これ** |
| 常に行にする | 確認済みとして常に載る。行数は増える | |
| 行にしない | 一覧には残るが、見積には出ない | |

推した理由は「会社ごとに分かれるものをコードで決め打ちしないため」。

## 2. 決まったことの中身

- **読み取りの側では、区分「既存のまま」は必ず付ける。**(ここは規則で切り替えない)
- **見積の行にするかどうかだけが、規則ファイル側の設定になる。**
- **既定値はまだ決めていない。** 規則ファイルが何も言っていないときに
  行にするかは、別の判断として残る。
