# 39周目 基準: 見出しの当て方を緩めたら、どれだけ当たり、どれだけ誤爆するか

2026-09-23。38 周目の「次の周」に書いたとおり。

## なぜこの題なのか

38 周目で落ちどころが確定した。**建具表はこの図面にある**(`建具` の語が 10 ページにあり、
その 10 ページ全部に罫線の表が合わせて 47 個ある)。それでも 0 件なのは、
`_role_of()` が**升目の文字全体と言い換えの完全一致**で役割を決めているから。
`巾 W` も `寸法` も `W×H` も当たらない。

**素直な直し方は含み一致だが、そのまま入れると危ない。**
`幅` は `全幅`・`幅木` に含まれ、`数` は `係数`・`本数` に含まれる。
**取りこぼしを減らすと誤爆が増える**形で、27〜31 周目の面積の語とまったく同じ構図である。

**入れる前に上限を測る。**

## 測るもの

107 個の表を 2 つに分ける。

- **内側**: `建具` の語があるページの表(38 周目の数え方で 47 個)。**当たりを数える側。**
- **外側**: それ以外の表(60 個)。**誤爆を数える側。**

**これは当たり・誤爆の代わりの目印であって正解ではない。**
内側にも凡例や記事欄が混ざり、外側に続きの建具表があるかもしれない。
**上限を測るための粗い分け方であることを、結論に必ず書く。**

| 記号 | 何を測るか |
|---|---|
| **H0** | いまのまま(完全一致)で建具表として通る表の数。内側 / 外側 |
| **H1** | **案1 含み一致**にしたときに通る表の数。内側 / 外側 |
| **H2** | **誤爆 ÷ 当たり**。`外側で通った数 ÷ 内側で通った数` |
| **H3** | 役割ごとの当たり方の変化(種別・幅・高さ・数量が何個の表で当たるか)。内側のみ |
| **H4** | 含み一致で**1 つの升目が 2 つ以上の役割に当たった**回数(`幅` と `高さ` が同じ升目に、など) |

## 採否の線(**測る前に決める。結果を見てから変えない**)

**案1 を「次に進めてよい」と言うには、3 つ全部が要る。**

| 条件 | 線 |
|---|---|
| **当たり** | **内側で通る表が H0 から 1 個以上増える** |
| **誤爆** | **H2 < 0.5**(外側で通る数が、内側で通る数の半分未満) |
| **取り違え** | **H4 = 0**(1 つの升目が 2 つの役割に当たらない) |

- **3 つとも満たす** → **案1 を実装する周に進む。ただし判定に触るので PR のまま待つ。**
- **当たりが 0 個** → **案1 は不採用。** 含み一致では届かないので、案2(言い換えを増やす)へ。
- **当たりはあるが誤爆か取り違えで落ちる** → **保留。** 役割ごとに緩め方を変える案を次に測る
  (`種別` だけ含み一致、`幅`・`数量` は完全一致のまま、など)。

**H2 の 0.5 は 28〜31 周目で使った線と同じ値をそのまま使う。**
**あの周では「誤爆 < 当たり ÷ 2」だけだと語彙がほとんど空のとき素通りする穴があった**
ので、**当たりの下限(1 個以上)を並べて置いてある。**

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 合成の建具表に案1 を当てる | 通る(壊していない) |

**対照1 か 2 が落ちたら、案1 は数字を見るまでもなく不採用。**
