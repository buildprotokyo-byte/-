# 【測る前に決めた基準】内装仕上表から工事の有無を読む(K-05)

作成日: 2026年9月23日

## 0. 何を作るか

内装仕上表の 1 行を、おーちゃんが決めた読み方の表に従って区分に割り当て、
**既にある「要素」の形**(`docs/principles/scope_of_work_diff.md` 6節の
`WorkScopeItem`)に載せる部品。

**数量は出さない。** 面積と長さは人の入力から来る決まり(原則 3-1・4)。
この部品が出すのは「どの部屋のどの部位に、どういう工事があるか」までである。

## 1. おーちゃんが決めた読み方(会社の読み方。変えない)

| 下地欄 | 仕上欄 | 読み |
|---|---|---|
| 既存 | 既存 | 工事なし |
| 既存 | 材料名あり | 仕上だけやり替え |
| 交換 | 何でも | 既存を撤去して新設 |
| ー | 何でも | 該当なし。工事なし |
| 既存 | 空欄 | 工事なし |
| 材料名あり | 何でも | 下地からやり替え |

**下地欄が空欄の継続行は、自動で判定しない。問いとして出す。** 物によって
意味が違う(アクセントクロス=同じ壁の別の面で面積が分かれる /
出隅コーナー材=巾木に付属する部材で長さの単位が違う)ため。

## 2. 測る指標

対象は P011 匿名化v2 の 3・4 ページの内装仕上表(69 行)。
**パスは引数で渡す。図面はリポジトリに入れない。中身も書かない。**

| 記号 | 指標 | 合格の線 |
|---|---|---|
| M1 | どの区分にも割り当てられなかった行 | **0 件** |
| M2 | 区分ごとの件数 | おーちゃんが示した内訳と**完全一致** |
| M3 | この部品が作った数量 | **0 件**(`value_range` も `unit` も持たない) |
| M4 | 根拠にページ番号と行番号が入っている要素の割合 | **100%** |

M2 の内訳(おーちゃんの数から導いた期待値。**測る前に書いている**):

| 部品の区分 | 期待件数 | 内訳 |
|---|---|---|
| 工事なし | 16 | 下地既存/仕上既存 6 + 下地既存/仕上空欄 5 + 下地「ー」5 |
| 仕上だけやり替え | 12 | 下地既存/仕上に材料名 |
| 撤去して新設 | 8 | 下地「交換」 |
| 下地からやり替え | 17 | 下地に材料名 |
| 問い | 16 | 下地空欄の継続行 10 + 6 |
| **合計** | **69** | |

**この一致は独立した確認ではない。** 列の構造(下地欄がどの列か)を調べる
段階で同じ集計を一度しており、期待値はその集計とおーちゃんの内訳が
合ったことを根拠に書いている。**独立なのは、おーちゃんの内訳がこちらの
コードと別に数えられたものである、という一点だけ**である。

## 3. 対照(先に走らせる)

## 4. 採否の決め方

**この周では採否を決めない。** 判定に触る変更なので、おーちゃんの指示どおり
PR のまま置く。マージしない。

- M1〜M4 のどれかが外れたら、**表のほうを合わせに行かない。** 外れたことと
  外れ方をそのまま報告する。
- M2 が合わなかった場合、**おーちゃんの内訳が正しいという前提で**
  こちらの読み取りを疑う。ただし数を合わせるための場当たりの分岐は入れない。

## 5. 5 区分への対応づけ

`docs/principles/scope_of_work_diff.md` 4-1節の 5 区分
(`撤去` / `新設` / `既存のまま` / `改修` / `区分不明`)への対応づけは、
**報告書に書いて、おーちゃんの判断を仰ぐ。** 対応づけそのものは
この基準では合否を決めない(正解が無い)。
