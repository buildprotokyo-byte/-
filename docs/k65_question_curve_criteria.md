# K-65 キラークエスチョンを多用する道の、上限と実用性

**この文書は測る前にコミットする。** 結果を見て線を下げない。結果は末尾に追記する。

おーちゃんの考え(指示書より)。

- 推論しても出ないものは、人にも分からない。聞くしかない。AI の弱さの問題ではない。
- 決まれば、下の段が連鎖して決まる。
- KQ に答えるために図面を全部読み返す形は、本末転倒。避ける。
- 各 KQ の横に「答えると精度がどう変わるか」のメーターを出し、人が時間を選べるようにする。
- 質問数の固定の上限は強すぎた。精度・費用・時間のために、必要なら多用してよい。

## 1 未確定の 3 状態(確度に依らない信号)

各項目を **確定 / 仮説 / 未確定** の 3 つに分ける。**未確定を推論で埋めない。**

- **確定** = 独立した根拠が 2 つ以上あり、未確定の信号が 1 つも立っていない。
- **仮説** = 項目の状態が「仮説」か「推論」(K-44 の印をそのまま使う)。印を外さない。
- **未確定** = 下の信号が 1 つ以上立っている。

**信号は AI の確度を見ない。**(確度は AI 自身の自己申告なので、信号に混ぜると
「自信があると言ったから確定」になる)。立てる信号は次の 9 つだけとする。

1. `3回の読みの割れ` — 同じ鍵の項目が 3 回の読みで値・工事・室のどれかで割れた。
2. `機械とAIの食い違い` — 機械が数えた記号の数と AI の数量が違う。
3. `仕様書にあって図面で見つからない` — 照らし合わせが「原本のみ」。
4. `図面にあって仕様書に無い` — 照らし合わせが「ひな型のみ」。
5. `検算の不一致` — 検算の覚書が 1 つ以上ある。
6. `室が決まらない` — 場所が未確定・未取得。
7. `数量が取れない` — 数量が None。
8. `原価表との食い違い` — 原価表に同じ工事・品番の行があり、単位が違うか数量が許容差の外。
9. `同じ物が2枚の図にある疑い` — 「同じもの」で結ばれた項目の数量が割れている。

**抜き取り**: 確定の項目から各段階に 1〜2 問混ぜる(確度が高いのに外れた分を拾う)。
抜き取りの質問は印を付け、連鎖の金額には数えない(確定済みなので金額は動かない)。

**影響の小さい未確定**: 原価表があるときは金額が総額の **0.1% 未満**、無いときは
**連鎖で決まる項目が 1 個だけ** のものは、聞かずに「未確定(影響小)」として下書きに残す。
**この 2 つの数字は仮の判断。** 測って外れていたら次の周で直す(結果を見てここを緩めない)。

## 2 連鎖(芋づる式)

依存を有向グラフにする。**辺は保守的に書く。** 「答えが子を 1 つに決める」ときだけ辺を張る。
Z3 の変数グラフ(`killer_question/dependency_graph.py`)とは別の層で、
項目(内訳の行の元)の間の依存だけを持つ。**同じ依存を 2 か所に持たない**ため、
科目・中科目は K-66 の `sameness.structure_key` から取り、ここで決め直さない。

辺の種類(この 6 つだけ)。

| 種類 | 親 → 子 | 張る条件(保守的) |
|---|---|---|
| `科目` | 科目 → その科目の項目 | 親の科目が同じで、子の科目が未確定でない |
| `室部位` | 室 → その室の部位 → その部位の仕上 | 室の鍵が一致(K-66 の `room_key`) |
| `状態` | 状態(撤去・新設) → 撤去行・新設行・下地 | 同じ室・部位で、工事の語に撤去/新設/下地を含む |
| `有無` | 工事の有無 → その工事の材料・数量 | 同じ工事の語か品番 |
| `まとめ方` | 1 行か分けるか → 「同じもの」で結ばれた項目 | 「同じもの」が 1 個以上 |
| `資料` | 仕様書か図面か → その室・部位の項目 | 照らし合わせの行に対応する項目 |

**深さの上限は 3。** それより下は「連鎖で決まった」と言わない(保守的側に倒す)。
**記録は「質問で直接決まった」と「連鎖で決まった」を必ず分ける。**

## 3 質問カード

**カードだけで答えられない質問は無効。**(言い換えるか捨てる。捨てた数を報告に出す)

型(閉じた選択肢のみ): `工事の有無` / `どの室・部位か` / `状態` / `数量` /
`まとめ方` / `仕様書と図面のどちらを採るか` / `同じ物か別の物か`。

カードに入れるもの: 該当箇所の切り抜き画像 / 競っている読みの候補 / 選択肢 /
図面全体への入口(任意。使わなくても答えられること)。
**機械の推す答えはカードに入れない。**

**禁止(1 つでも当てはまれば無効)**: 数字の入力欄 / 自由記述欄 / 推奨の表示 /
選択肢が 2 個未満 / 切り抜きが無い / 「見る所」が 4 ページ以上(資料を通読しないと答えられない)。

`数量` の型は、**3 回の読みの値・機械の値・縮尺で換算した値から選ぶ**形にする。
**正しい値が選択肢に無いときは「どれでもない」を選ぶ。**(数字を打たせない。
そのかわり「正しい値が選択肢に無かった割合」を測る)

### メーター

- **この答えで確定する項目数と金額**(総額比 %)。**直接と連鎖の内訳を分けて出す。**
- **回答時間の見積**(型ごとの秒)。**未較正**なので、型ごとの秒は下の表を使い、
  画面に「未較正」と書く。section 7 の本物の人の回答で較正する。
  `工事の有無` 20 / `どの室・部位か` 30 / `状態` 20 / `数量` 40 /
  `まとめ方` 30 / `仕様書と図面のどちらを採るか` 30 / `同じ物か別の物か` 40 秒。
- **見込み精度の変化**: **未較正の間は出さない。**構造から出る数字(確定する項目数・金額比)だけ出す。
- **累積**: ここまで答えると総額の何 % が確定か。概算(±15%)・通常(±10%)・精密(±5%)に届く位置。
  **原価表が無い案件では金額の%を出さず、項目数の%を出し、「金額ではない」と書く。**

### 時間の止め線

5 分 / 10 分 / 15 分。**質問数の上限は置かない**(K-60 の 3/5/10 の上限は
`MODES` に残すが、既定では使わない)。止め線を越えて続けられる。

## 4 選び方

優先度 = **連鎖で確定する金額 × 不確実さ ÷ 回答時間**。

- 金額が無い案件では、金額の代わりに「連鎖で確定する項目数」を使い、報告にそう書く。
- 不確実さ = 立っている信号の数 ÷ 9(0 より大きく 1 以下)。**AI の確度は使わない。**
- 同じ原因で割れた項目は 1 問にまとめる(原因の鍵が同じものを 1 枚に畳む)。

## 5 答えを戻す口

`answers.json` を読んで再実行する。形は
`{"回答": [{"鍵": "...", "選択肢": "...", "秒": 12, "迷った": false}]}`。

- 答えた項目は確定(根拠は「人の回答」)。連鎖で下の段も更新。
- **矛盾を検出して再質問する。** 検出するのは次の 3 つだけ(保守的)。
  ① 同じ鍵に違う答えが 2 つ。
  ② 同じ室・部位で「今回の工事に入らない」と「図面の読みのとおり」の両方。
  ③ 同じ項目に「撤去」と「新設」の両方(状態の型)。
- **AI を呼び直さない。** 影響範囲(連鎖の閉包)だけ再計算する。
  **線: 答えを戻した再実行の AI 呼び出しは 0 件。**
- 答える前と後で変わった項目を一覧にする。

- (b) ランダム順(種 65)

**クラウドで測るもの**(正解を開かない)。

1. 質問の数・型の内訳・無効で捨てた数。
2. 連鎖で決まる項目数と金額(直接と連鎖を分ける)。
3. 回答時間の見積の合計、止め線 5/10/15 分に入る問数。
4. 未確定の残り(項目数と金額比)。
5. **メーターの較正**: 各質問の「見込み(確定すると言った項目数)」と

6. **回答の 10% / 20% を間違えたときの劣化**と、**矛盾の検出が見つける割合**。

金額で数量が合った割合 / ±15%・±10%・±5% に届くのに必要な質問数と回答時間。
**正解から「理想の人」の答えを作る**(選択肢から選ぶだけ。数字は打たない)。

# 仮の判断(おーちゃんの判断待ち)

1. **「KQ を多用する道」は、いまの材料では上限が低い。推奨: 質問の数を増やす方向ではなく、
   質問の作れる場所を増やす方向に直す。** 45 問が上限で、その 45 問に全部答えても未確定は
   725 → 724。**足りないのは人の時間ではなく、問いの作り方である。**
2. **「数量」の型を作れるようにするのが、いちばん効く見込み。推奨: 寸法線・縮尺から出した値を
   選択肢に入れる**(K-61 の寸法の経路。未測定)。いまは選択肢が 1 つも作れず、
   最大の信号に手が出ていない。
3. **資料が欠けたときに質問が増える形にする。推奨: 問いの出どころを、仕上表の原本から
   工事チェック表の枠へ移す**(枠の問いを 13 → 16 にし、原本があるときだけ出る問いを足しにする)。
   いまは原本なしで 18 問に落ちる。
4. **矛盾の検出の型を、実際の間違いから作り直す。推奨: いまの 3 型は捨てないが、
   「同じ室・部位に 2 つの仕上」「同じ工事に 2 つの数量」を足して測り直す。**
   いまは 0% なので、**間違いの検出があるとは言えない。**
5. **「影響小は聞かない」の線は、原価表が無い案件では強すぎる。推奨: 原価表が無いときは
   影響小で黙らせず、順位を下げるだけにする。** いま 150 件が黙っている。
6. **抜き取りは 2 問しか作れない。推奨: このままでよい。** 確定が 16〜23 項目しか無いので、
   抜き取りの母数がそもそも小さい。**確定が増えてから増やす。**
7. **メーターの時間(型ごとの秒)は未較正のまま出している。推奨: 手順書 2 の回答が返るまで、
   画面に「未較正」と書き続ける。**
