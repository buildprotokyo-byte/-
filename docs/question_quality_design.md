## 1. いまの形(コードを読んだ結果)

- 問いの形は **1 種類**。`killer_question.engine.Question` は**変数を 1 つ指して「この値は?」と聞く。**
- 選び方は **`score`(効き)だけ**。1 問で一番多くの未確定が閉じる変数を選ぶ。
- 返ってきた答えは、**候補の一覧に入ってさえいれば、そのまま確定値として置かれる。**
- 候補の一覧に無い答えは、**その場で突き返される**(`ValueError`)。

**質を表す欄はどこにも無い。**

## 2. 足すもの(3 つ)

### 2-1. 問いに「検算されるか」を持たせる

いま `Question` が持っているのは `variable` / `score` / `candidate_values` などである。
ここに**その変数が、答えのあとで突き合わせられるかどうか**を足す。

**判定は既にあるもので決まる。**その対象に、
**答える人とは別のデータ源の読みが 1 件以上あるか**である
(`AxisEvidence.independence_key` の数え方をそのまま使う。**新しい数え方を作らない**)。

| 階級 | 中身 |
|---|---|
| **A** | **別のデータ源の読みがある。**答えが間違っていれば突き合わせで出る |
| **B** | 読みはあるが、**同じデータ源のものだけ** |
| **C** | **読みが 1 件も無い。**答えがそのまま値になる |

**おーちゃんの言う「洋室の面積を教えてください」は C である。**

### 2-2. 選び方を二段階にする

**効きだけで並べるのをやめる。**

1. **A の問いを、効きの大きい順に出す。**
2. A が無くなったら **B**、それも無ければ **C**。

**効きを捨てるのではない。同じ階級の中では、いままでどおり効きの大きい順である。**

**C を禁止しない。** 禁止すると、読みが 1 件も無い対象は永久に埋まらない。
**出す順番を最後にするだけ。**

### 2-3. C の答えには仮説の印を付ける

**C の問いの答えは、そのまま確定値にしない。**
由来を `assumed`(仮説に基づく)にして、**自動確定に上げない。**

**理由**: C の答えは、誰にも突き合わされていない。
**「人が言ったから正しい」は、この設計がずっと拒んできた形**である
(原則2: 単一の根拠で自動確定しない)。

## 3. 答えの受け取り方(「お任せします」への備え)

**おーちゃんの指摘の後半がここである。**

> あなたにお任せします、自分で推論して正しいと思われる数字をもう入れちゃってください

**答えの形を先に決めておく。**

| 欄 | 中身 |
|---|---|
| 値 | 数値 |
| 単位 | mm・㎡・個 など |
| **出どころ** | **図面のここ / 現地で測った / 資料に書いてある / 分からない** |

**「分からない」と「お任せします」は、回答ではなく棄権として記録する。**
棄権のあと、こちらが推論した値を置くこと自体は止めない。
**ただし必ず仮説の印を付け、自動確定には絶対に上げない。**

**出どころの欄は、2-1 の階級とは別のことを言っている。**
階級は「仕組みの側に突き合わせる相手がいるか」、出どころは「人の側の根拠が何か」である。
**両方そろって初めて、その値が何に支えられているかが分かる。**

## 4. **ついでに見つかった、もっと危ない形**(別の提案)

58 周目の測定で、**候補の一覧に無い答えは突き返される**ことが分かった。

**これは危ない。** 候補の一覧は、仕組みが読み取りから作った予想でしかない。
**人が現場で正しく測ってきた値が、その予想の外にあることは起こりうる。**
いまの作りでは、**そのとき拒まれるのは人のほうである。**

**提案**: 候補の外の答えを突き返すのをやめ、**食い違いとして残して人に示す。**
どちらが正しいかを仕組みが決めない。**建具表と平面図の食い違いに対する
2026-09-22 の決定(「どちらかを選ばず、食い違いとして人に示す」)と同じ扱いにする。**

**これも判定のしかたを変えるので、提案までで止める。**

## 5. 入れたあとに何を測るか(**先に書いておく**)

**同じ嘘の試験をそのまま回す。**

| 記号 | 何を測るか | 入れる前 |
|---|---|---|
| F1 | 正解 +1 の嘘が素通りした問いの数 | **5 / 5** |
| F2 | **A の階級の問いだけ**での素通り | 測っていない(階級が無いため) |
| F3 | 問いの数(効きが落ちていないか) | 星形 1・2 つのまとまり 2・鎖 1・合流 1 |

**目標を先に宣言する。**

- **F2 = 0** を目標にする。**A の問いで嘘が素通りするなら、この設計は効いていない。**
- **F1 = 0 は目標にしない。** C の問いには突き合わせる相手がいないので、
  **原理的に素通りする。**そこは仮説の印(2-3)で受ける。
- **F3 が 2 倍以上に増えたら不採用。** 質のために問いが倍に増えるなら、
  人の負担のほうが重い(原則5「人の負担は操作の回数と時間で測る」)。

## 6. この設計が測れないこと

- **[人が要る=未測定]** その問いに人が本当に答えられるか
- **[人が要る=未測定]** 出どころの欄を人が正直に埋めるか
- **[人が要る=未測定]** 棄権がどれくらいの割合で起きるか
