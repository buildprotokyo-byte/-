# 周33 の基準 — **位相の語は、数量を出した物のそばにあるか**

**測る前にコミットする。結果を見てから、この文書の数字を変えない。**

---

## 1. 前の周との違い(おーちゃんの設計②「1周で変えるのは1つだけ」)

| | 周32 | 周33 |
| --- | --- | --- |
| 技術 | **ページに語が在るかを数える** | **語と物の距離を測る** |
| 出典 | 紙に印字された文字 | **同じ** |
| 専門 | 積算 | 同じ |

**変えたのは技術ひとつ。** 周32 はページ単位で数えた。周33 は同じ文字を
**位置**で見る。出典(紙の印字文字)は変えていない。

## 2. なぜこの問いか(手段ではなく目的から)

周32 で分かったこと。

- 位相の語は 34 ページ中 20 ページに印字されている。
- 数量 2,887 件の 89.9% がその 20 ページのどれかに載る。
- **だが語が在る 20 ページのうち 13 ページは、2 種類以上の位相の語が同じ紙に出る。**
  ページに 1 つ位相を宣言する形では、紙と粒度が合わない。

**だから次は「ページのどこに書いてあるか」である。**
「既存壁撤去」と書いてあるなら、その注記は**撤去する壁のそば**にあるはずで、
紙の反対側にある新設の建具とは離れているはずである。**そうなっていなければ、
位置からも位相は決まらない。**

**周5 の教訓を先に入れる。** 天井高は紙に 71 か所あったのに、室に結び付いたのは
1 個だった([[jidou-sekisan-height-has-no-destination]])。
**在ることと、行き先があることは別である。** 周32 でも同じ形が出た。
**今回もそうなる見込みがあるが、予想は根拠にしない。**

## 3. 測るもの

図面は **P011 の匿名化 v2**(34 ページ、A3)。**v1 ではない。**
パスは引数で渡す。リポジトリには入れない。

### 位置が取れる数量

入口の根拠(`provenance`)に座標を持つものだけを対象にする。

- 開き戸 … `arcs` の `center_pt`
- 室 … `polygon_pt`
- 記号 … `positions_pt`

**座標を持たない数量は、分母にも分子にも入れない。**
対象が何件になったかは必ず報告に書く(2,887 件のうち何件か)。

### 語

位相の語は周32 と同じ 12 語(`benchmarks/measure_phase_printed.py` の `PHASE_WORDS`)。
**周32 で当たったのは 6 語(既存・新設・新規・計画・増設・撤去)だが、語の表は減らさない。**
減らすと「結果を見てから条件を変えた」ことになる。

### 囮 — **周32 の反省を入れる**

**周32 の囮(防火・断熱などの材料と性能の語)は弱かった。** この図面にほとんど無い語で、
勝ち目が薄かった。

**周33 の囮は「紙に実際に印字されている、位相以外の語」にする。**
位相の語以外の語から**同じ個数**を無作為に引き(10 回、中央値、seed 20260925)、
同じ距離の測り方を当てる。**インクの在る所から引くので、勝ち目がある**
([[jidou-sekisan-decoy-must-keep-ink]])。

**問いはこうなる: 位相の語は、その辺にある普通の語より、数量を出した物に近いか。**

## 4. 線(合格・不通過の数字を先に書く)

距離は**紙の上のミリ**で測る(縮尺はページごとに違うので、実寸には直さない)。
**10mm / 25mm / 50mm** の 3 段。

### 線1 — **近いか**

いちばん狭い **10mm** で、位相の語がそばにある数量の割合。

- **合格 = 0.10 以上、かつ囮との差 0.20 以上。**

### 線2 — **囮**

上の囮を同じ 3 段で当てる。**本物が囮に勝てなければ線1 は不通過。**
**3 段とも本物と囮の両方を報告に載せる**(どちらが勝ち目を持っていたかを読む人が見られるように)。

### 線3 — **つまみを振ったとき、中身が入れ替わるか**

周18 の教訓。**「振っても動かない」は「中身が同じ」ではない。**
数だけでなく**どの数量が当たったか**も数える。

10mm で当たった数量の集合と、50mm で当たった集合を比べる。

- 報告に載せるのは、**10mm の集合が 50mm の集合にどれだけ含まれるか**と、
  **50mm で新しく入った件数**。
- **これは合格・不通過の線ではない。** 何が起きているかを見るための欄である。
  **線として立てない理由**: どういう数字なら不通過かを先に書けないから
  (周13・周14 で 2 度踏んだ失敗)。**書けないものは線にしない。**

### 線4 — **安全確認**

- `app.py` と `intake/` は変更しない(K-29)。
- 自動確定は 0 件のまま。
- **合格 = 本番の判定を 1 か所も変えていないこと。**

## 5. 測らないこと(先に宣言する)

- **紙から取り出した文字は、リポジトリにも報告にも 1 文字も書かない。**
  出すのは件数・割合・ページ番号・距離だけ。内訳は共有フォルダだけ(K-33)。
- **どの数量が現況でどの数量が計画か、という判定はしない。** 近いことは
  その語がその物を指している証拠ではない。
- 実案件で見積が何行出るか、金額、数量の値、対象名。
- コードは直さない(取り決め②)。

## 6. この測り方で分からないこと(先に書く)

- **近さは「指している」ことではない。** 注記は引出線で離れた所を指すのが普通で、
  そばにある語が別の物の注記であることは十分ありうる。**線1 が通っても
  「位置から位相が読める」ではなく「読める見込みがある」まで。**
- **座標を持たない数量は測れない。** 対象が 2,887 件の一部になるので、
  結果はその一部についてのものである。
- **文字が線で描かれたページは、この数え方では語が 0 件になる**
  (周32 で 34 ページ中 4 ページが文字 0 件)。
