## 1. 読了率の定義(K-67 1 節 a)

**読了率 = 台帳に位置付きで載った図形 ÷ 数える図形**(`erase_check.summarize` の `拾えた ÷ 数える図形`)。

- 除外: 図枠・表題欄(K-51 と同じ)。**凡例の枠線は除外しない**(落ちに数える側に倒す。K-51 のまま)
- 位置の許容: 要素の位置を 3 画素広げ、見本の点の半分以上が入れば印。**面積の上限は 1%**
- **画面に定義を常に出す**: 「位置の許容 1%。変えると数字が動く」「**読めた=台帳に載った。理解した、ではない**」

### 種類の内訳

**機械で分けられる 6 種類(重なりなし。合計が 100%)**: 文字 / 記号 / 線 / 点・小さい図形 / 塗り / 画像。
**`寸法` と `表` は、この 6 種類とは別の切り口として出す(重なる)。**理由は 0 節のとおり、
いまの機械の分け方には無いため。作り方は測る前に決めた:

- **表**: `page.find_tables()` が見つけた罫線の表の中にある図形。**平面図を表と誤認する欠陥**
  (周21、`pdf_dimensions`)があるので、`pdf_room_outlines._looks_like_a_ruled_table` と同じ守りを通す。
  守りに落ちたページは `表は測れない` と出す(**0 と書かない**)
- **寸法**: `文字` のうち、数字と記号(`-`・`×`・`,`・`.`・`φ`・`R`・`@`)だけでできた語。
  **名前は「数字だけの語(寸法の見込み)」とする。**寸法線に当たったかは見ていないので、
  「寸法」と言い切らない

### 測れないページ(K-67 1 節 d)

**次のどれかに当たるページは、読了率を出さず「測れない」と表示する。高い数字も低い数字も出さない。**

1. 文字の層が無く(`get_text("words")` が 0 件)、かつ `数える図形` が 3 個以下
2. ページの 8 割以上を 1 枚の画像が覆っている
3. `数える図形` が 0 個

**手段を必ず表示する**(`文字の層` / `画像の墨`(K-64 の 2)/ `OCR` / `手段なし`)。
手段がなければ「測れない(手段なし)」と出す。

**空だった枠の振る舞いがいちばん大事なところ**: 防水・断熱・防災は項目 0 件だったが、

クリーニング・諸経費は項目 0 件で語も見つからないが、原価表が無いので `資料が足りない` になった。

**`確認できた` が 3 回でのべ 1 枠しか出ない。**いまの定義が「その枠の**全部**の項目が数量と位置を
持つ」なので、1 件でも数量が無いと `一部確認` に落ちる。**だから「確認できた」の的中率は測れない**
(分母がほぼ 0)。定義を緩めるかは判断待ち(仮の判断 2)。
