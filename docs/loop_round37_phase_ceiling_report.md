## 0. **先に断る**

**入れた位相はこちらが作ったものである**(全部現況 / 全部計画 / ページ番号で交互)。
**正しい位相ではない。正しい位相はこの図面からは分からない**(周32・周35)。

**この周が見たのは「位相が何であれ、行の側が動くか」である。**
**「位相が正しく付く」とも「出た行が正しい」とも書いていない。**

**なぜこれを測ったか**: 周32〜周36 は「位相をどう付けるか」を 5 周やった。**それは手段である。**
**位相を付ける目的は、撤去の行と新設の行を分けることである。**
そこで**手段を全部成功させたことにして、目的の側が動くかを先に見た。**

## 1. **答え**

| 規則 | 位相を入れる前 | 入れた後 |
| --- | ---: | ---: |
| **いまある見本の規則** | 4 行 | **4 行(3 通りとも同じ)** |
| **位相を条件にした規則** | 0 行 | **141 行(交互なら 201 行)** |

**機械は位相を行にできる。止まっているのは規則の側である。**

- **いまある見本の規則では、位相を入れても行は 1 行も動かない。**
  3 通りの入れ方で**行の並びが 1 文字も変わらなかった**(線4 の囮が効いた)。
  **理由は読めば分かる**——**リポジトリにある見本の規則 23 本は、1 本も `phase` を条件に持っていない。**
- **位相を条件にした規則を当てると、0 行から 141 行へ動いた。**
  しかも**撤去と新設が位相どおりに分かれた**——全部現況なら撤去 141 行・新設 0 行、
  全部計画なら撤去 0 行、交互なら撤去 100 行。

**裏返しの危険(いちばん大事な線)は通った。**
2,887 件すべてに位相を作って入れても、**自動確定した数量は全条件で 0 件、
当てはめで確定した行も全条件で 0 件**(K-29 のとおり)。

## 2. **ただし 141 行は「いまの上限」ではない**(追記2)

1 回目は **2,887 件すべてに器を作って**入れている。
**周36 で分かったとおり、実際に器(`Meaning`)を持っているのは 164 件だけである。**

そこで**器を新しく作らず**、既に器を持つ 164 件だけに位相を入れて測り直した。

| | 器を作った(問題が片づいた後) | **器を作らない(いまの上限)** |
| --- | ---: | ---: |
| 行の数(全部現況) | 141 | **4** |
| 行の数(交互) | 201 | **4** |
| 撤去の行(全部現況) | 141 | **4** |

**いまの上限は 4 行である。器の問題が片づけば 141 行。**

**つまり、位相の仕事のほとんどは「位相を決めること」ではなく「器を付けること」にある。**
**周36 の結論がそのまま効いている**——**足りないのは読み取りでも人の入力でもなく、
`meaning` を持つ行が 2,887 件中 164 件しか無いこと。**

**予想は当たった。** 追記2 の基準に「**行は増えるが、141 行よりずっと少ないと予想する**」と
測る前に書いた。**出たのは 4 行。**
**予想が当たったことは成果にしない**——1 回目の内訳から素直に出る数である。

## 3. 線ごとの結果

| 線 | 合格(先に書いたもの) | いまある見本の規則 | 位相を条件にした規則 |
| --- | --- | --- | --- |
| 線1 行が増えるか | 1 行でも増える | **不通過**(4 → 4) | 通過(0 → 141) |
| 線2 撤去の行 | 1 行以上 | **不通過**(0 行) | 通過(141 行) |
| 線3 **裏返しの危険** | 前も後も 0 件 | 通過 | 通過 |
| 線4 **囮**(位相の中身を入れ替える) | 3 通りが全部同じではない | **不通過**(全部同じ) | 通過(2 通りが違った) |
| 線1' いまの上限 | 1 行でも増える | 不通過(4 → 4) | 通過(0 → **4**) |
| 線2' いまの上限の撤去 | 1 行以上 | 不通過 | 通過(**4 行**) |

**線4 の囮は、当たりうる囮だった**(周22 の型を避けられた)——
位相を条件にした規則のほうでは**中身を入れ替えたら実際に行が変わった**ので、
**いまある見本の規則で 3 通りとも同じだったことは、「囮が弱い」ではなく「規則が位相を見ていない」を意味する。**

## 4. **測る前に読んで、線にしなかったこと**(周33 の型を避けた)

道具を書きながら読んで分かったことが 3 つある。**どれも読めば分かるので線にしていない**
(追記1 に先に書いた)。

1. **見本の規則 23 本は 1 本も `phase` を条件に持っていない。**
2. **`app.py` が `phase` を読むのは `:445` の 1 か所だけで、そこは段の件数を数えているだけ。**
   **行の作られ方には効かない。**
3. **`Meaning.is_complete` は本番で 1 か所も読まれていない。**
   原則「**意味が付けられない値は、数量に使わない**」を**守らせている場所は無い**
   (`arbitration/` の同名は制約探索の別物)。
   **周50 の「独立していない但し書きは provenance に残るだけで判定を動かしていない」と同じ形。**

**この 3 つのせいで、規則を 1 つだけで測ると答えが決まってしまう。**
**だから規則を 2 通りにした。**

## 4.5 **周35 と合わせると、141 行には 2 つ要る**(報告を書いたあとに気づいた)

**器だけでは 141 行にならない。**
`estimating/rules.py:234` は、位相が **`不明`** の数量を**当てない**
(規則の条件に `不明` は書けない、`:623`)。

**つまり 141 行に要るのは 2 つ。**

1. **器(`Meaning`)があること** … いまは 2,887 件中 164 件
2. **その器に、`不明` ではない値が入っていること**

**2 のほうは、周35 で「読み取りでは決まらない」と出ている。**
どの粒度で聞いても手間と粗さの両方を満たす粒度は無く、
**1 つの物ごとに聞いても 2,173 件の質問が要り、それでも 40.27% は紙の上に
現況の側と計画の側の語が両方出る。**

**だから「器を付ける」だけを次にやっても、行は動かない。**
**器と、位相の値の出どころを、同時に決める必要がある。**
**報告の 1 節と 2 節だけを読むと、器を付ければ 141 行に届くように読めてしまうので、ここに書く。**

## 5. 設計④の数え(**この対象は頭打ちと書ける**)

**「位相を付ければ撤去と新設が分かれるか」という問いについては、答えが出た。**

  **反実仮想(周37)**

**だから「位相をどう読むか」の周はここで止める。**
