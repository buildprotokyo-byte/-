## 判定

| 線 | 観測(最良) | |
|---|---|---|
| 当たり **Q1 ≧ 2** | **2** | **◯** |
| 誤爆 **Q3 < 0.5** | **0.500** | **×** |
| 取り違え **Q4 = 0** | **27** | **×** |

**`0.500` は `< 0.5` を満たさない。ちょうど線の上なので、満たしていない側に数える。**

> **窓を外すと Q1 は増えるが誤爆か取り違えで落ちる** → **窓は効いているが、それだけでは足りない。
> それでも「割れている」ことの証拠にはなるので、報告に残す。**

**判定: 窓は効いているが、それだけでは足りない。**

## いちばん正直に書かないといけないこと

**増えた 1 個は、いちばん危ない当て方(K1 含み一致)でしか出ていない。**

- **K2a(誤爆も取り違えも 0 というきれいな当て方)は、窓を外しても 0 のまま。**
- **K2a の `幅` は、窓を外しても 0 のまま。**

**つまり「正しい読み方が届くようになった」のではない。** 含み一致が `幅木` のような語を
拾う範囲が、窓を外したぶんだけ広がっただけ、という読み方もできる。
**Q1 が 1 → 2 になったのを「前進」と書くのは言い過ぎである。**

**言えるのはここまで**: 見出しが上から 3 行に無い表が、内側に**少なくとも 1 つある**
(窓を外して初めて通ったため)。**表の形がこちらの思っている形ではない、という証拠にはなる。**
