# K-23 基準: 意味を当てない候補台帳は、同じ図面で毎回同じ件数を出すか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-24。おーちゃんの K-23(既存の積算プログラム SUGORAKU を読んだ報告)を受けて作る。
SUGORAKU の報告そのものはこちらに届いていないので、**K-23 の本文に書かれた処理の手順と
上限の数値を仕様として扱う。**

## 作るもの(K-23 の 1〜4)

| 番号 | 部品 | 中身 |
|---|---|---|
| 1 | 候補台帳 | 全ページに同じ固定処理を掛け、線・閉領域・小輪郭を**意味を当てずに**保存する。ベクターは PDF 内部の線(`get_drawings`)、ラスターは グレースケール → CLAHE → Canny → HoughLinesP → 輪郭抽出。座標はページ全体を 0〜1000 に揃える |
| 2 | 図枠・表題欄 | 本文より先に、下端と右下を切り出して図面名称・図番・縮尺・改訂日を読む |
| 3 | 品質ゲート | ページごとに passed / needs_review / blocked。**読めなかったページを「候補 0 個」と書かない** |
| 4 | キャッシュ | ページの画像と設定から SHA-256 の鍵を作り、同じ条件なら結果を使い回す |

上限は K-23 のとおり 線 1,800・閉領域 300・小輪郭(記号) 600。上限に当たったかをページごとに必ず残す。

**台帳は本番の入口にも、いまの判定にも繋がない。候補の数を数量に使わない。**
OCR は入れない。文字の層が無いページは「文字が読めない」として記録する。

## 測るもの

P011 の**2 つのファイル**に掛ける。どちらの話かを必ず書く。

- **匿名化v2**(27MB・A3・34 ページ。ほぼベクター。18 ページだけ全面スキャン)
- **v1**(18MB・A0 相当・34 ページ全部スキャン)… ラスターの経路を実図面で動かすため

| 記号 | 何を測るか |
|---|---|
| L1 | ページごとの線・閉領域・小輪郭の件数(見つけた数と、上限で残した数) |
| L2 | **同じファイルを別々のプロセスで 3 回、キャッシュ無しで処理して**、ページごとの件数と、残した候補の中身(座標まで)の指紋が 3 回とも同じか |
| L3 | 上限に当たったページの数と、どの種類で当たったか |
| L4 | passed / needs_review / blocked の内訳と、理由の内訳 |
| L5 | 図枠から図面名称・図番・縮尺・改訂日が取れたページの数(**取れたかどうかだけ。正しいかどうかは正解の台帳が無いので測らない**) |
| L6 | キャッシュを有効にして 2 回処理し、2 回目に全ページが使い回しになるか・出力が同じか。設定を 1 つ変えると使い回しにならないか |
| L7 | **いまの経路(繰り返す図形を群にする `pdf_repeated_symbols`)との比較**: 同じページで、いまの経路が縮尺を読めずに動かなかった(0 件になった)ページで、台帳は候補を出しているか |

**出すのは件数・真偽・ページ番号だけ。図面の文字は 1 文字も出さない。**
図枠から読んだ名称・図番もリポジトリや報告には書かない(取れた件数だけ書く)。

## 結論の形(測る前に決める)

- **L2 で 1 ページでも件数か指紋が食い違ったら、安定していない。** 原因を探し、直すまで「安定した」と書かない。
- **L4 で、候補が 0 件なのに passed のページが 1 つでもあったら、品質ゲートの欠陥**として直す。
- **「674 群になったり 0 件になったり」が直ったか**は、L2 と L7 の両方で判定する。
  - L2 が 3 回とも同じ、**かつ** L7 でいまの経路が縮尺のせいで 0 件だったページに台帳が候補を出している(または、出していない理由がゲートの理由として残っている)なら「**台帳の段では直った**」と書く。
  - それでも「**意味を当てたあとの数(記号がいくつあるか)が直った**」とは書かない。台帳は意味を当てないので、その問いには答えない。
- L5 の件数は、SUGORAKU の「主要 10 ページで 10/10」と**比べない**(こちらは正しさを測っていないので、同じ物差しではない)。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| C1(台帳が何かを測っているか) | ページごとの件数が全部同じ値ではないこと | ページ間でばらつく。全ページ同じなら L2 の「3 回とも同じ」は意味を持たない |
| C2(指紋が中身に反応するか) | 合成のページに線を 1 本足すと、件数と指紋が変わること | 変わる(テストで固定する) |
| C3(キャッシュが条件に反応するか) | 設定(Canny のしきい)を変えると鍵が変わること | 変わる |
