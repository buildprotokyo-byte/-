# A-2 室の輪郭と面積 — 測る前に決めた採否の基準

作成: 2026-09-23。**測定を始める前にこの文書をコミットする。**
結果を見てから基準を変えない(変える必要が出たら、変更と理由とコミットを残す)。

## 何を測るのか

`axes/image_axis/pdf_room_outlines.py` は、図面の線を平面グラフに直し、
線で囲まれた最小の領域を室の候補として取り出す。
これまで**室の輪郭を取る実装が無かった**ため、面積を要する見積の行
(置床解体・内壁解体・天井解体・間仕切りの軸組・石膏ボード・天井野縁組)は
1 行も数量の判定に乗っていなかった。

測るのは 4 つ。**合成図面の上での測定であって、実図面での誤り率ではない。**

| 指標 | 定義 | 分母 |
|---|---|---|
| 室の再現 | 正解の室のうち、輪郭として出たもの | 置いた室の数 |
| 面積の相対誤差 | \|読めた面積 − 正解\| ÷ 正解。**中央値と最大の両方**を出す | 出た室の数 |
| 室名の一致 | 輪郭に付いた名前が正解の室名と一致した数 | 出た室の数 |
| 作り話の室 | 正解に無いのに室として出たもの | 出た室の総数 |

## 先に決めておく採否の基準

面積の許容差は、いまの中心値の検査(`CENTER_TOLERANCES`)の連続量と同じ **±5%** を使う。
±5% 自体が暫定値である(v8 10章12項、本決めは判断待ち)ことは承知のうえで、
**ここで新しい値を作らない。**

- **採用**: きれいな条件で、室の再現 1.00・面積の相対誤差が**最大でも 5% 以内**・
  作り話の室 0 件。加えて、劣化させた条件(壁の 2 本線・建具の開口)でも再現が
  落ちないこと。
- **保留**: きれいな条件では通るが、劣化させた条件で再現が落ちる、
  または作り話の室が出る場合。どの劣化で落ちるかを報告書に書く。
- **不採用**: きれいな条件で面積の相対誤差の最大が 5% を超える。
  輪郭が取れても面積が使えないことになる。

## 必ず回す負の対照(これを回さずに数字を報告しない)

1. **閉じた領域が 1 つも無い図面**(ばらばらの線だけ)。期待: 0 室。
2. **罫線の表だけの図面**。期待: 0 室。升目は室ではない。
3. **入れ替え対照**: 読めた面積を、**正解の室名を 1 つずらして**突き合わせる。
   ここで相対誤差が本番と同じくらい小さいなら、その測定は
   「部屋ごとの面積」ではなく「だいたいの大きさ」しか測っていないことになる
   ([[jidou-sekisan-golden-coverage-not-recall]] と同じ罠)。

## この測定で分からないこと(報告に必ず書く)

- **実図面での誤り率は測れない。** 実図面 PDF はこの作業環境に無い。
- **面積が内法か壁芯かは、この実装では決めない**(``area_basis`` は常に「不明」)。
  だから「面積が読めた」ことと「見積の数量が決まった」ことは別である。
  どちらとして数えるかは積算の決まりで、判断待ちに入る。
- 壁・天井の面積は測っていない。輪郭と階高が要るが、階高は別の入力である。
- 見積の行が埋まるかどうかは測っていない。
