## 4. この測定で言えないこと(先に宣言したとおり)

- **どのページが現況でどのページが計画か、という判定はしていない。**
  「既存」と「新設」が同じページに出ることは、**そのページに位相が無い証拠ではない。**
  現況図に「撤去」と注記するのも、計画図に「既存に合わせる」と書くのも普通である。
  **言えるのは「語だけを見てページの位相は決められない」まで。**
- **ページ単位までしか測っていない。** 数量の根拠にページ番号はあるが、
  位相の語との距離は測っていない。「同じページ」までで「同じ室の近く」は測れない。
- **語が在ることは、その数量の位相が決まることを意味しない。** 線3 が通っても
  「読めば決まる」ではなく「読める見込みがある」までである。

## 5. 分かった別のこと

  描かれていて 0 件」と書いてある。**ここでは 4 ページが 0 件だった。**
  1 ページぶんの食い違いは**説明できていない**(この周では調べていない)。
- **位相が決まっても、撤去と新設の行はまだ作れない。**
  `intake/start_kit.py` の `PagePairing` にはこう書いてある。

  > **この対応から差分(撤去・新設)を計算する実装はまだ無い。**

  受け取って記録するところまでで、数量にはしていない。
  **つまり位相は 2 か所で止まっている。決める所と、差分にする所。**
