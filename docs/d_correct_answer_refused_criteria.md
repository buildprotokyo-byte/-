# 59周目 基準: **正しい答えが突き返されることはあるのか**

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。58 周目の続き。

## なぜこの題なのか

58 周目で、**候補の一覧に無い答えはその場で突き返される**ことが分かった。
そこから**こう書いた**(`docs/question_quality_design.md` 4 節)。

> 候補の一覧は、仕組みが読み取りから作った予想でしかない。
> **人が現場で正しく測ってきた値が、その予想の外にあることは起こりうる。**
> いまの作りでは、**そのとき拒まれるのは人のほうである。**

**これは理屈で書いた。実測していない。**
**自分の提案の根拠なので、自分で確かめる。**

**確かめた結果、起こらなければ提案を弱める。**

## 測り方(**合成案件だけ。取り決め④**)

58 周目と同じ 4 シナリオを使う。**代役は必ず正解を答える。**
**嘘をつくのは人ではなく、読み取りのほうである。**

**読みのずらし方は先に決める。** 変数の取りうる幅(`add_variable` の下限・上限)を
**まるごと +2 ずらす。**(その変数の正解が幅の外に出るように。)
**ずらすのは 1 つの変数の読みだけで、正解の値は動かさない。**

| 記号 | 何を測るか |
|---|---|
| **G0** | 読みが正しいときに、正解が候補に入っていた問いの数(対照) |
| **G1** | **ずらしたあと、正しい答えが突き返された問いの数** |
| **G2** | ずらしたあと、問いが 1 問も出なくなった回数(矛盾で先に止まる場合) |
| **G3** | ずらしたあと、何も起きずにそのまま通った回数 |

**G1 + G2 + G3 = 試した回数。**

## 結論の形(**測る前に決める。結果を見てから変えない**)

- **G1 ≧ 1** → **正しい答えが拒まれる場合が実在する。**
  設計 4 節の提案に**実測の裏づけが付く。**件数を添えて提案を強める。
- **G1 = 0 かつ G2 ≧ 1** → **拒む前に、矛盾として先に止まる。**
  **提案 4 は理屈だけで、実測の裏づけは無い**と報告書に書き、**提案を弱める。**
  (取り下げるかどうかは、そのとき改めて書く。)
- **G1 = 0 かつ G2 = 0** → **読みがずれても何も起きない。**
  これは提案 4 とは別の、もっと大きな問題である。**その旨を名指しする。**

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 読みが正しいときの通し | **正解が突き返される問いが 0 件。**出るなら測定が壊れている |
| **2** | ずらしが効いているか | **ずらした変数の候補の一覧が、ずらす前と変わる。**変わらないならずらせていない |
| **3** | 反復 3 回(G1) | 3 回とも同じ |

**対照1・2 が通らなければ結論を出さない。**
