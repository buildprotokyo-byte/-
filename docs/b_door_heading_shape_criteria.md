# 40周目 基準: 当て方の「形」を変えたら、誤爆せずに届くか

**このファイルは測る前に書いてコミットする。測ったあとで基準を変えない。**

2026-09-23。39 周目の「次の周」に書いたとおり。**案も線も、39 周目の報告に先に書いてある。**

## なぜこの題なのか

39 周目で**案1(丸ごと含み一致)は保留**になった。内側で 0 → 1 と届きはしたが、
**誤爆 ÷ 当たり = 1.000**(線は 0.5 未満)、**取り違え 7**(線は 0)で、2 つとも落ちた。

中身ははっきりしている。**`幅` の当たりが 0 → 12 に跳ね、そのうち建具表として通ったのは 1 個。**
`幅木` のような「役割の名前を含んだ別の言葉」を拾っている。

**粗く緩めるのをやめて、当たり方の形を変える。**

## 測るもの

39 周目と同じ分け方(内側 = `建具` の語があるページの表、外側 = それ以外)で、
**当て方を 4 通り**並べて測る。

| 記号 | 当て方 |
|---|---|
| **K0** | いまのまま(完全一致) |
| **K1** | 案1 含み一致(39 周目の再現。**測り方が同じことの確認**) |
| **K2a** | **後方一致**。升目の文字が言い換えで**終わる**ときだけ当てる |
| **K2b** | **区切ってから完全一致**。升目の文字を空白と記号で割り、**どれか 1 つが言い換えとちょうど同じ**なら当てる |

| 記号 | 何を測るか |
|---|---|
| **M1** | 内側で建具表として通った表の数(**当たり**) |
| **M2** | 外側で通った表の数(**誤爆**) |
| **M3** | **誤爆 ÷ 当たり** |
| **M4** | 1 つの升目が 2 つ以上の役割に当たった回数(**取り違え**) |
| **M5** | 役割ごとの当たり(内側)。種別・幅・高さ・数量 |
| **M6** | **内装仕上表**を同じ 4 通りで測った、通った表の数 |

## 採否の線(**39 周目と同じ 3 つ。結果を見てから変えない**)

**案を「次に進めてよい」と言うには、3 つ全部が要る。**

| 条件 | 線 |
|---|---|
| **当たり** | **内側で通る表が K0 から 1 個以上増える** |
| **誤爆** | **M3 < 0.5** |
| **取り違え** | **M4 = 0** |

- **K2a と K2b のどちらかだけが 3 つとも満たす** → **その案を実装する周に進む。PR のまま待つ。**
- **両方とも満たす** → **誤爆の少ないほう**を採る。同じなら**当たりの多いほう**。
  それも同じなら **K2b**(割り方のほうが仕掛けとして素直なため)。**この優先順位も先に決めておく。**
- **どちらも満たさない** → **両方とも不採用。** 見出しの当て方では届かないので、
  **次は「表を先に見分けてから列を読む」向き**(表題の文字で建具表を先に決める)に変える。

## 対照

| 対照 | 中身 | 通る条件 |
|---|---|---|
| **1** | 合成の建具表に 4 通りとも当てる | **4 通りとも通る**(どれも壊していない) |
| **2** | K1 が 39 周目の数を再現するか | 内側 1 / 外側 1 / M4 = 7 |
| **3** | **内装仕上表(M6)が K0 から減らない** | 減ったらその案は不採用 |
| **4** | 反復 3 回 | 3 回とも同じ |

**対照2 が再現しなければ測り方が変わっている。** そのときは結論を出さない。
**対照3 を線に入れたのは 39 周目の警告のため**(案1 は仕上表を 2 → 3 に動かしていた。
増やす向きは許すが、**減らす向きは許さない**)。
